Superpowers

概述

一套为 Claude Code 设计的 Agent Skills 集合，通过专业化分工的技能系统（brainstorming、writing-plans、using-git-worktrees 等）实现高质量软件开发的完整工作流。

关键内容

  1. 核心技能列表：
  2. brainstorming：创意探索与需求澄清
  3. writing-plans：将设计文档拆解为原子任务清单
  4. using-git-worktrees：创建隔离工作区
  5. subagent-driven-development：子 Agent 驱动开发
  6. executing-plans：计划执行（无子 Agent 平台）
  7. dispatching-parallel-agents：并行子 Agent 调度
  8. finishing-a-development-branch：开发分支收尾

  9. verification-before-completion：完成前验证

  10. 工作流链路： brainstorming（设计批准） → using-git-worktrees（创建 worktree） → writing-plans（原子任务清单） → subagent-driven-development / executing-plans（实现） → verification-before-completion（验证） → finishing-a-development-branch（收尾）

  11. 核心原则：

  12. 专业化分工：每个 Skill 负责特定阶段
  13. 文件系统通信：通过文件而非上下文传递信息
  14. 隔离与并行：Git Worktree 支持并行开发

  15. TDD：每个任务以测试开始

  16. 与 GSD 的区别：

  17. Superpowers：通用软件开发技能集
  18. GSD：完整项目管理框架（含 .planning/ 目录系统）
