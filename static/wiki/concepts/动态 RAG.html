动态 RAG

概述

动态 RAG 是一种检索增强生成模式，系统在多步搜索中动态发现相关信息，并根据新发现实时适应搜索策略，而非预先检索后静态注入上下文。

关键内容

  1. 与传统 RAG 的区别：传统 RAG 采用"预先检索 → 静态注入上下文 → 一次生成"的线性流程；动态 RAG 则支持迭代式多步搜索，每步搜索结果都会影响后续搜索策略。

  3. 动态发现：信息不是预先确定的，而是在搜索过程中逐步发现
  4. 策略适应：根据新发现的信息调整后续搜索方向和方法

  5. 迭代分析：多轮检索与分析交替进行，逐步生成高质量答案

  6. 在研究系统中的应用：Anthropic 的 Research 功能采用动态 RAG 模式，多 Agent 系统通过子 Agent 并行探索不同方向，每个子 Agent 独立进行动态检索，再将压缩后的信息传递给主 Agent 综合。

  7. 信息论优势：动态 RAG 的本质是信息压缩——从海量语料中提炼洞见，子 Agent 在独立上下文窗口中并行探索，压缩信息后再传递给主 Agent，减少路径依赖，避免陷入局部最优。
