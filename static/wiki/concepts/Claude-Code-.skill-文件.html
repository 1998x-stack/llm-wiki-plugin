Claude Code .skill 文件

概述

Claude Code .skill文件是学术界LLM技能研究的工程实践产物，将多年研究的技能管理、工具调用、任务规划等理论转化为可操作的工程实现。它代表了学术洞见在实际开发中的应用。

关键内容

  1. 设计哲学与学术支撑：
  2. description字段对应Gorilla的检索机制，是LLM检索相关技能的语义锚点
  3. 代码模板对应CRAFT的代码复用理念，提供可执行的代码骨架
  4. 工作流对应GITM的任务分解树，将复杂任务分解为可验证子目标

  5. 约束规则对应Toolformer的负样本过滤机制

  6. 核心组成部分：

  7. name：技能标识
  8. description：触发词密集的自然语言描述，用于技能检索
  9. 工作流：任务分解的线性展开
  10. 代码模板：可执行的代码骨架
  11. 约束与禁忌：负样本示例和使用限制

  12. 示例：Few-shot示例

  13. 与学术研究的对应关系：

  14. 工具检索 ←→ Gorilla、AnyTool
  15. 技能库 ←→ Voyager
  16. 任务分解 ←→ GITM、HuggingGPT
  17. 示例演示 ←→ ReAct、Toolformer
  18. 文档质量 ←→ API-Bank

  19. 验证机制 ←→ AssistGPT PEIL

  20. 未来发展路径：

  21. 从纯人工定义到半自动生成（结合LATM工具制造思路）
  22. 支持技能冲突处理、动态技能生成、版本管理等功能
