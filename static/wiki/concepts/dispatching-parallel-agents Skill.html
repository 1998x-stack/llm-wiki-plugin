dispatching-parallel-agents Skill

概述

Superpowers 框架中的一个关键技能，负责调度多个并行子 Agent 同时处理不同任务。该技能依赖 Git Worktree 为每个子 Agent 提供独立的工作目录，确保各 Agent 之间的工作不会相互干扰或覆盖。

关键内容

  1. 核心机制：
  2. 并行调度：同时启动多个子 Agent 处理独立任务
  3. 工作隔离：通过 Git Worktree 为每个子 Agent 创建独立工作目录

  4. 资源分配：合理分配计算资源给不同子 Agent

  5. 与 Git Worktree 的关系：

  6. 在执行并行任务前，为每个子 Agent 预先创建独立的 worktree
  7. 每个 worktree 对应一个分支和独立工作目录

  8. 防止多个 Agent 同时修改相同文件时的冲突

  9. 工作流程： 主 Agent 分析任务 ↓ 识别可并行的任务单元 ↓ 通过 using-git-worktrees Skill 为每个任务创建 worktree ↓ 启动并行子 Agent（每个在独立 worktree 中） ↓ 监控各子 Agent 进度 ↓ 汇总并行工作的结果

  10. 应用场景：

  11. 功能模块并行开发：不同 Agent 开发不同功能模块
  12. 测试并行执行：多个 Agent 并行运行不同类型测试
  13. 重构并行处理：不同 Agent 负责不同组件的重构

  14. 文档并行生成：多个 Agent 并行生成不同类型文档

  15. 优势：

  16. 提高效率：充分利用多核 CPU 和并发能力
  17. 降低风险：每个 Agent 在隔离环境中工作，减少冲突

  18. 可扩展性：支持根据任务复杂度调整并行度

  19. 限制与注意事项：

  20. 需要足够硬件资源支撑多个并行进程
  21. 依赖 using-git-worktrees Skill 确保环境隔离

  22. 某些任务无法并行化，需顺序执行

  23. 与 Superpowers 流水线的关系：

  24. 通常在 using-git-worktrees Skill 之后执行
  25. 为 subagent-driven-development Skill 提供并行基础设施
  26. 最终结果汇总到主分支通过 finishing-a-development-branch
