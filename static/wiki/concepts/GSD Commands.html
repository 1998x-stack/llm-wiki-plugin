GSD Commands

概述

GSD 系统的核心命令集，覆盖从项目初始化到里程碑完成的完整开发链路，每个命令对应特定职责，形成单向信息流。

关键内容

  1. 项目生命周期命令：
  2. /gsd:new-project — 项目初始化（提问→研究→需求→路线图）
  3. /gsd:new-milestone — 新版本里程碑

  4. /gsd:complete-milestone — 里程碑归档

  5. 阶段工作流命令：

  6. /gsd:discuss-phase N — 捕获实现偏好（生成 CONTEXT.md）
  7. /gsd:ui-phase N — UI 设计契约（生成 UI-SPEC.md）
  8. /gsd:plan-phase N — 研究 + 规划（生成 RESEARCH.md + PLAN.md）
  9. /gsd:execute-phase N — 波次并行执行
  10. /gsd:verify-work N — 人工验收测试

  11. /gsd:ship N — 创建 PR

  12. 辅助命令：

  13. /gsd:next — 自动推进（分析状态执行下一步）
  14. /gsd:quick — 临时任务（轻量流程）
  15. /gsd:fast "task" — 极小微调（内联执行）
  16. /gsd:resume-work — 恢复会话
  17. /gsd:pause-work — 暂停会话
  18. /gsd:progress — 查看进度

  19. /gsd:help — 帮助

  20. 代码库命令：

  21. /gsd:map-codebase — 棕地代码库分析

  22. 工作流原则：

  23. 每个步骤单一职责
  24. 信息单向流动：discuss → CONTEXT.md → plan → PLAN.md → execute → SUMMARY.md → verify
