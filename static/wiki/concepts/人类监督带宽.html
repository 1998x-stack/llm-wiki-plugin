人类监督带宽

TUI 设计的核心哲学——Agent 的执行速度远超人类审阅速度，因此界面必须在关键决策点精确呈现恰好需要的上下文，让人类能在 2 秒内做出正确判断。

概述

人类监督带宽是 Agent 交互设计的约束条件：不是展示所有信息，而是在每个决策点提供最精简但充分的上下文，最大化人类单位时间内的有效监督决策数量。

设计三原则

  1. 最小化审批摩擦：常见的安全操作自动放行，不浪费人类注意力
  2. 最大化审批信息：危险操作展示完整 diff + 命令意图，确保决策质量
  3. 可逆性优先：所有 session 有 transcript，所有文件改动可 git 回滚，降低决策压力
