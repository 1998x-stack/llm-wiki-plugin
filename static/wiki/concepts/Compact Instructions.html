Compact Instructions

概述

Compact Instructions 是 CLAUDE.md 中定义的压缩策略，用于在上下文窗口达到 92% 阈值时触发 Compressor wU2，确保重要的内容在压缩过程中得以保留。

关键内容

  1. 压缩策略定义：
  2. 在 CLAUDE.md 文件中通过 Compact Instructions 定义保留规则
  3. 指定哪些内容必须在压缩过程中保持不变

  4. 常见保留项：API 端点签名、数据库模式变更、标记为 [CRITICAL] 的 TODO 注释

  5. 压缩触发条件：

  6. 当上下文窗口达到 92% 阈值时自动触发 Compressor wU2

  7. 确保在空间不足时优先保留最重要的信息

  8. 压缩优先级：

  9. 高优先级：旧的工具调用输出（体积大，可重新获取）
  10. 中优先级：早期对话历史（总结保留）
  11. 保留：用户显式请求 + 关键代码片段

  12. 保留：CLAUDE.md 规则（跨会话持久，不受压缩影响）

  13. 手动控制命令：

  14. /compact focus on the API changes - 保留 API 相关内容
  15. /compact - 默认压缩策略
  16. /context - 查看当前 Token 占用
