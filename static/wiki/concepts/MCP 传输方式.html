MCP 传输方式

概述

MCP（Model Context Protocol）支持多种传输方式来连接 Claude Code 与外部 MCP 服务器，每种方式适用于不同的部署场景和需求。

关键内容

  1. HTTP 传输（推荐）：
  2. 适合远程 MCP 服务器连接
  3. 支持认证头和 bearer-token
  4. 具有良好的防火墙兼容性

  5. 便于在不同环境中配置

  6. Stdio 传输（本地）：

  7. 适用于本地 Node.js 服务器
  8. 通过标准输入输出进行通信
  9. 无网络开销，性能较高

  10. 适合开发和测试环境

  11. WebSocket 传输：

  12. 适用于需要实时双向通信的场景
  13. 支持续长连接和实时消息推送

  14. 适合需要频繁交互的工具

  15. SSE 传输（已弃用）：

  16. Server-Sent Events 方式
  17. 仅支持单向通信（服务器到客户端）

  18. 已被其他传输方式取代

  19. 选择准则：

  20. 远程服务：优先选择 HTTP
  21. 本地服务：优先选择 Stdio
  22. 实时交互：选择 WebSocket
  23. 避免使用 SSE（已弃用）
