有效需求

概述

有效需求（Effective Demand）是约翰·梅纳德·凯恩斯主义经济学的核心概念，指经济社会在某一特定价格水平下，消费者、企业和政府愿意且能够购买的商品和服务的总量。与传统古典经济学认为“供给创造需求”不同，约翰·梅纳德·凯恩斯提出，决定就业水平和产出的关键因素是有效需求。当有效需求不足时，即使有生产能力，企业也会减少生产并解雇工人，导致非自愿失业。这一概念构成了现代宏观经济学需求管理政策的理论基础。

关键内容

理论起源与定义

在《就业、利息和货币通论》中，约翰·梅纳德·凯恩斯正式提出了有效需求原理，以此反驳统治经济学界百年的萨伊定律。萨伊定律认为生产过程中支付的收入（工资、利润等）最终都会转化为对产品的购买，因此不会出现普遍的生产过剩。约翰·梅纳德·凯恩斯则指出，在货币经济中，收入持有者不一定将所有收入用于消费或投资，他们可能出于交易、预防或投机动机而“囤积”货币。这种储蓄与投资的脱节导致总支出（即有效需求）低于总产出能力。

有效需求的构成

有效需求由四个主要部分组成： 1. 消费需求 (C)：取决于当前的可支配收入，受边际消费倾向制约。随着收入增加，消费增加的幅度小于收入增加的幅度。 2. 投资需求 (I)：受资本边际效率和利率的影响，且具有极大的不稳定性，常受“动物精神”驱动。 3. 政府支出 (G)：作为外生变量，是弥补私人部门需求不足的关键工具。 4. 净出口 (NX)：受汇率和国外收入水平影响。 公式表达为：$AD = C + I + G + NX$。当 $AD < Y_{full_employment}$ 时，经济将出现衰退和失业。

与经济均衡的关系

约翰·梅纳德·凯恩斯认为，经济均衡点并不必然位于充分就业水平。如果有效需求不足，经济会在低于充分就业的水平上达到均衡（即“失业均衡”）。在这种情况下，降低工资并不能解决问题，因为降薪会进一步减少工人的收入和消费，加剧有效需求的萎缩，形成恶性循环。因此，解决失业问题的唯一途径是直接提升有效需求，通常需要通过政府增加公共支出或利用乘数效应来实现。

政策意义

有效需求理论为政府干预经济提供了坚实的逻辑支撑。它表明市场机制本身无法保证资源充分利用，特别是在大萧条这样的极端情况下。基于此，政府应采取扩张性财政政策（增加 G 或减少税收）和货币政策（降低利率以刺激 I）来提升有效需求，从而拉动产出和就业。这一思想成为了二战后各国制定反周期经济政策的基石。
