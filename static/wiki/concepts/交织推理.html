交织推理

概述

交织推理（Interleaved Thinking）是一种推理模式，Agent 在工具调用之间插入思考步骤，用于评估结果质量、发现信息缺口并细化下一步查询。

关键内容

  1. 工作模式：
  2. LeadAgent 用 Extended Thinking 规划整体研究方法
  3. SubAgent 在每次工具调用结果后，插入交织 thinking 步骤

  4. 思考内容包括：评估当前结果质量、发现信息缺口、细化下一个查询

  5. 实验效果：Anthropic 实验发现 Extended Thinking 改善了指令遵从性、推理质量和效率。

  6. 在研究系统中的应用：

  7. 子 Agent 在迭代搜索过程中，每次获取搜索结果后进行交织推理
  8. 判断当前结果是否足够，是否需要调整搜索策略

  9. 避免盲目搜索，提高信息获取的针对性

  10. 与 Token 消耗的关系：交织推理会增加 Token 使用量，但 Anthropic 的 BrowseComp 评测显示 Token 使用量解释 80% 的性能方差，合理的推理投入是性能提升的关键。
