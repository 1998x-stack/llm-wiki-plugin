Compressor wU2

概述

Compressor wU2 是 Claude Code 中的上下文管理器，用于管理模型的上下文窗口，当上下文达到 92% 阈值时触发压缩操作。

关键内容

  1. 触发机制：当上下文使用率达到 92% 时自动触发压缩操作，确保模型有足够的上下文空间继续工作。

  2. 功能目的：防止上下文窗口溢出，保持重要信息的同时移除冗余或不太重要的信息，维持代理运行的连续性。

  3. 在 Claude Code 中的作用：作为上下文管理器，在 TAOR Loop 中发挥作用，确保代理在长时间运行的任务中不会因上下文耗尽而中断。

  4. 设计考虑：平衡信息保存和上下文空间管理的需求，保留对当前任务最重要的上下文信息。
