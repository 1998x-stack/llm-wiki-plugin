TOML

一种极简的配置文件数据格式，设计目标是"人类可读、机器易解析"，在 Codex CLI 中作为 ExecPolicy 规则文件和主配置的标准格式。

关键内容

  1. 在 ExecPolicy 中的应用：规则文件以 .rules 扩展名存储，使用 TOML 数组表（rule）定义多条规则。每条规则包含 name、prefix、decision、justification 以及可选的 match/not_match 单元测试用例。

  2. 嵌套数组表示"或"逻辑：prefix = ["git", ["log", "status", "diff"]] 中，内层数组表示子命令的可选集合，外层表示命令序列。这种嵌套结构是 TOML 原生支持的。

  3. 相比 YAML/JSON 的优势：

  4. 比 JSON 更易读（无花括号、无引号冗余）
  5. 比 YAML 更严格（无缩进歧义、无类型推断陷阱）

  6. 原生支持注释，适合策略文件的 justification 字段

  7. 在 Codex 配置体系中的统一使用：从 config.toml 到 .rules 文件，全链路 TOML，降低认知负担。
