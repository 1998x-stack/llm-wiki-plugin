非交互模式（Non-interactive Mode）

概述

非交互模式是 Claude Code 通过命令行参数 -p 实现的一次性执行模式，适用于脚本集成、CI/CD 管道和批量文件处理场景。

关键内容

  1. 基本用法：通过 claude -p "prompt" 执行单次查询，无需进入交互式会话。例如 claude -p "解释这个项目做什么" 用于快速代码理解。

  2. 结构化输出：使用 --output-format json 参数可以获取结构化的 JSON 输出，便于下游工具解析。例如 claude -p "列出所有 API 端点" --output-format json。

  3. CI/CD 集成：通过 --permission-mode auto 参数可以在无需人工确认的情况下自动执行工具调用，适合集成到 CI/CD 流水线中。例如 claude -p "修复所有 lint 错误" --permission-mode auto。

  4. 批量文件处理：可以结合 shell 循环对多个文件并行执行相同的操作： bash for file in $(cat files.txt); do claude -p "将 $file 从 React 迁移到 Vue。返回 OK 或 FAIL。" \ --allowedTools "Edit,Bash(git commit *)" done 每个会话拥有独立的 上下文窗口，互不干扰。

  5. 与交互式模式的对比：

  6. 交互式模式适合探索性工作和多轮对话
  7. 非交互模式适合可重复、可脚本化的确定性任务

  8. 非交互模式的每次执行都是全新的会话，不保留历史上下文

  9. 上下文经济学意义：非交互模式天然避免了上下文累积问题——每次执行都是独立会话，不存在 上下文窗口 填满后的性能退化。这是 上下文经济学 中最激进的上下文管理策略：用完即弃。
