Topic Files

概述

Topic Files 是 Claude Code 三层记忆架构的第二层，是存储实际项目知识的文件，按主题组织在 memory/topics/ 目录下。

关键内容

  1. 存储特征：
  2. 存储实际的项目知识和详细信息
  3. 按主题进行组织，如认证系统、数据库模式、API设计模式等

  4. 文件位于 memory/topics/ 目录下

  5. 访问方式：

  6. 按需加载（On-Demand Fetch）：Agent 只在需要特定领域知识时才读取对应文件
  7. 可以包含很详细的内容，没有严格的大小限制

  8. 可以包含完整的代码示例、决策记录等详细信息

  9. 维护方式：

  10. 由 Agent 自主维护：Agent 在工作过程中会主动更新这些文件

  11. 与 MEMORY.md 索引配合使用，实现快速定位和加载

  12. 典型主题：

  13. auth-system.md：认证系统的所有知识
  14. db-schema.md：数据库模式文档
  15. api-patterns.md：API 设计模式
  16. known-issues.md：已知问题和临时方案
  17. user-preferences.md：用户偏好设置
  18. deployment.md：部署相关知识
