Context Window

概述

AI模型能够处理的最大上下文长度限制，是影响AI编码工具性能和功能设计的关键因素，需要通过各种优化策略进行管理。

关键内容

  1. 基本概念：
  2. AI模型能够处理的最大上下文长度
  3. 限制了可同时加载的信息量

  4. 影响AI编码工具的性能表现

  5. 对Skills系统的影响：

  6. Claude Code将Skill description字段总量限制在约上下文窗口的2%
  7. 超出部分会被静默忽略

  8. 需要通过渐进式加载等机制优化利用

  9. 最佳实践：

  10. 不要安装太多Plugin，避免description重复占用过多上下文
  11. description要精确，使用明确的触发短语

  12. 合理分层使用Skills（个人通用放在~/.claude/skills/，项目专属放在.claude/skills/）

  13. 项目设计原则：

  14. jezweb/claude-skills项目强调"The context window is a public good"，只包含Claude不知道的信息
  15. "Teach patterns, not ship scripts"，技能描述做什么，由Claude生成适应环境的脚本
