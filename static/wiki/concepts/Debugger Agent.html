Debugger Agent

概述

Debugger Agent是一种专门用于处理错误、测试失败和异常行为的专家级排错人员，负责根因分析和故障修复。

关键内容

  1. 主要职责：
  2. 获取错误信息和堆栈追踪
  3. 复现问题步骤
  4. 定位故障位置
  5. 实施最小修复

  6. 验证修复效果

  7. 排错流程：

  8. 分析错误信息和日志
  9. 检查最近的代码变更
  10. 提出并测试假设
  11. 隔离故障

  12. 实现并验证修复

  13. 调试输出格式：

  14. Error: 原始错误信息
  15. Root Cause: 故障根本原因
  16. Evidence: 确定原因的证据
  17. Fix: 具体代码修改
  18. Testing: 修复验证方法
  19. Prevention: 避免复发策略
