Saga 模式

概述

Saga 模式是分布式系统中处理长事务的设计模式，将长事务分解为一系列可补偿的短步骤，每步成功后记录进度，失败时从最近检查点回滚或继续，与 Agent Harness 设计高度相似。

关键内容

  1. 核心思想：
  2. 将长事务分解为多个可独立执行的短步骤
  3. 每个步骤完成后记录进度（检查点）
  4. 失败时从最近的检查点回滚或继续执行

  5. 每个步骤都有对应的补偿操作

  6. 与 Agent Harness 的类比：

  7. Agent Harness 设计与 Saga 模式高度相似
  8. 长时 Agent 任务 ≈ 分布式长事务
  9. Agent 的每个执行步骤 ≈ Saga 中的本地事务
  10. 检查点 ≈ Saga 的补偿点

  11. 错误恢复 ≈ Saga 的补偿执行

  12. 设计启示：

  13. 这种类比为 Harness 工程师提供了丰富的已知解决方案库
  14. 可以从分布式系统领域借鉴成熟的错误处理和恢复策略

  15. Saga 模式的补偿机制可应用于 Agent 任务的回滚设计

  16. 在 Agent 工程中的应用：

  17. 将长时任务分解为可验证的短步骤
  18. 每步成功后更新进度文件（如 claude-progress.txt）
  19. 失败时从最近检查点恢复，而非从头开始
  20. 设计补偿操作来撤销已完成的步骤
