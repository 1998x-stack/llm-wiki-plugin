设备像素比

概述

设备像素比（DPR，Device Pixel Ratio）是物理像素数与逻辑像素数之比，决定高 DPI 屏幕（Retina/高清屏）上的渲染清晰度。常见值：1.0（普通屏）、2.0（Retina）、3.0（超高密度屏）。

关键内容

  1. 核心关系：系统逻辑分辨率 = 物理分辨率 / DPR。在 UrhoX 中通过 graphics:GetDPR() 获取，物理分辨率通过 graphics:GetWidth()/GetHeight() 获取。
  2. 高DPI适配意义：若忽略 DPR 直接以物理像素为单位绘制（模式C），在 DPR=2 的屏幕上 UI 尺寸仅为设计稿的 1/4，导致界面过小；正确传入 pixelRatio=dpr 给渲染器可确保清晰度与尺寸正确。
  3. 输入坐标转换：引擎鼠标/触摸输入 API 返回物理像素坐标，转换到逻辑坐标需除以 DPR：logicalX = inputX / dpr；进一步转到设计坐标还需除以设计缩放比 scale。
