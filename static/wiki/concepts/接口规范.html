接口规范

概述

接口规范是并行软件开发中定义模块间交互契约的文档，确保各开发单元遵循统一的数据结构和行为约定。

关键内容

  1. 核心作用：在并行开发中，接口规范文件（如 interface_spec.h）定义了各模块间的数据结构、函数签名和交互协议，是避免集成冲突的关键前置条件。

  2. Anthropic 实验发现：C 编译器实验中，Agent-Lexer 和 Agent-Parser 对 Token 结构的假设不同、Agent-Parser 和 Agent-Semantic 对 AST 节点格式的理解分歧，都源于接口规范不够详细。

  3. 执行纪律：所有并行 Agent 必须在开始工作前确认已读取规范，任何对接口的修改都需要通知其他 Agent，这需要严格的版本控制纪律。

  4. 与测试的关系：接口规范的可执行版本就是测试用例，测试先行方法将接口规范转化为可验证的代码，使并行 Agent 有明确的完成标准。

  5. 对人类工程的启示：好的并行化场景需要模块接口清晰、稳定，模块间依赖是有向无环的，每个模块有独立的验证手段（单测）。
