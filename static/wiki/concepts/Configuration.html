Configuration

概述

Claude Code 的配置系统，通过多层级配置文件实现灵活而安全的系统设置，确保不同层面的需求得到满足。

关键内容

  1. 四层配置结构：
  2. 企业策略层（企业管理员托管配置）：影响所有用户、所有项目，如禁止访问生产 DB、强制代码审计日志
  3. 用户全局层（~/.claude/settings.json）：当前用户的所有项目范围，如个人偏好、常用工具白名单
  4. 项目共享层（./.claude/settings.json）：当前项目的所有成员（提交到 Git），如团队级权限、项目级 Hooks、共享 MCP

  5. 项目本地层（./.claude/settings.local.json）：仅当前用户在此项目（加入 .gitignore），如个人实验配置、临时覆盖

  6. MCP 配置位置：

  7. 用户级 MCP：~/.claude.json（注意：不在 ~/.claude/ 目录内）
  8. 项目级 MCP：./.mcp.json（提交到 Git，团队共享）

  9. 规则：项目级 MCP 补充（不覆盖）用户级 MCP

  10. 关键环境变量：

  11. ANTHROPIC_API_KEY：API 认证
  12. CLAUDE_MODEL：模型选择
  13. MAX_MCP_OUTPUT_TOKENS：MCP 输出 Token 上限

  14. ENABLE_TOOL_SEARCH：工具搜索模式

  15. 反模式清单：

  16. Token 硬编码在配置文件中导致机密泄露
  17. CI/CD 中不加 -p 标志导致作业无限期挂起
  18. 永久允许所有 MCP 工具导致权限过度
  19. settings.local.json 提交到 Git 导致个人配置污染团队
