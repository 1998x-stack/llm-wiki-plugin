同步编排引擎

概述

Hermes Agent 的核心执行模型：AIAgent 是单线程同步循环而非异步事件驱动，简化状态管理，通过子 Agent 委派处理多任务。

关键内容

  • 循环结构：组装 System Prompt → 解析 Provider → 主执行循环（含 IterationBudget）→ 工具执行 → 最终响应 → 持久化到 SessionDB
  • 同步 vs 异步：选择同步而非异步事件驱动，代价是单任务阻塞，但大幅简化状态管理和调试
  • 多任务处理：通过 delegate_task 子 Agent 委派解决单任务阻塞问题，而非并发执行
  • 核心文件：run_agent.py 中的 AIAgent 类，约 9,200 行，是整个系统的心脏
  • 数据流：CLI/Gateway/Cron 三条数据流最终都汇入同一个 AIAgent.run_conversation()，保证行为一致性
  • 工程权衡：同步设计使状态可预测、易于测试和调试，适合 Agent 场景而非高并发服务场景
