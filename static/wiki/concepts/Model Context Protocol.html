Model Context Protocol

概述

Model Context Protocol (MCP) 是 Claude Code 连接外部世界的标准化协议，提供统一接口替代碎片化的专用集成方案。这是一种标准化协议，用于接入外部服务到AI模型环境中，使模型能够与各种外部系统进行交互。

关键内容

  1. 标准化接入：提供统一的协议规范，使得不同类型的外部服务可以通过一致的方式接入AI系统。

  2. 基本架构：

  3. 客户端：Claude Code
  4. 服务端：MCP Server（封装外部服务访问逻辑，如 GitHub / DB / Browser 等）

  5. 通信：JSON-RPC 通过 stdio/SSE/HTTP

  6. 传输模式：

  7. stdio：本地进程，原生隔离，不经过网络
  8. SSE：远程 HTTP 流式，实时推送

  9. HTTP：远程 HTTP 非流式，简单请求-响应

  10. 配置管理：

  11. 用户级配置：~/.claude.json
  12. 项目级配置：./.mcp.json（提交到 Git）

  13. 项目级 MCP 补充（不覆盖）用户级 MCP

  14. 外部服务集成：允许AI模型访问如GitHub、数据库、监控系统(Sentry)、通讯工具(Slack)等各种外部服务。

  15. 在Claude Code中的应用：Claude Code使用MCP协议来标准化外部服务接入，使其能够连接到各种第三方服务，扩展其功能边界。

  16. Connect能力基元：作为Claude Code四大能力基元之一的"Connect"的基础，MCP使模型可以连接到外部服务。

  17. Token 保护机制：

  18. 警告阈值：10,000 tokens
  19. 默认上限：25,000 tokens
  20. 最佳实践：让 MCP 服务器分页/过滤响应，而非增加上限
