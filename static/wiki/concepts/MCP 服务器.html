MCP 服务器

概述

MCP 服务器是实现 Model Context Protocol 的中间件服务，作为 Claude Code 与外部工具或数据源之间的桥梁，处理工具调用并将结果返回给 Claude。

关键内容

  1. 架构角色：
  2. 位于 Claude Code 和外部工具/数据源之间
  3. 接收来自 Claude 的工具调用请求
  4. 将请求转发给对应的外部系统

  5. 处理并格式化返回结果

  6. 功能特性：

  7. 工具注册：支持动态注册可用工具
  8. 请求路由：将工具调用准确路由到相应功能
  9. 结果封装：将外部系统响应格式化为 MCP 标准格式

  10. 错误处理：统一处理异常情况

  11. 配置方式：

  12. 支持项目级和用户级配置
  13. 可通过环境变量管理认证信息
  14. 支持多种传输协议（HTTP、Stdio 等）

  15. 配置可版本化管理

  16. 安全管理：

  17. 通过最小权限原则限制工具访问
  18. 支持 OAuth 2.0 等认证方式

  19. 可控制哪些工具对 Claude 可用

  20. 部署类型：

  21. 本地服务器：运行在开发者本地环境
  22. 远程服务器：部署在独立服务器上

  23. 云端服务：托管在云平台的 MCP 服务

  24. 管理命令：

  25. 添加/删除 MCP 服务器
  26. 列出已配置的服务器
  27. 获取服务器详细信息
  28. 重置批准选择
