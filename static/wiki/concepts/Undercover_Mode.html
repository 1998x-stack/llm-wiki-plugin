Undercover Mode

概述

Undercover Mode 是 Claude Code 中的一个特殊模式，旨在当 Anthropic 员工向外部开源项目贡献代码时，确保生成的内容不包含任何 Anthropic 内部信息。

关键内容

  1. 功能描述：
  2. 屏蔽内部模型代号（Capybara、Tengu、Fennec 等）
  3. 隐藏内部 Slack 频道名称、内部仓库名称

  4. 移除 "Claude Code" 字样及 Anthropic 内部术语

  5. 关键设计特点：

  6. 有强制启用的选项（环境变量 CLAUDE_CODE_UNDERCOVER=1）
  7. 但没有强制关闭选项（NO force-OFF）

  8. 这是为了防止模型代号泄露的关键保护措施

  9. 实现机制：

  10. 在外部构建中，整个 undercover 模块被编译时移除

  11. 替换为返回 false 的空函数

  12. 伦理争议：

  13. 批评者认为这违反了许多开源社区对 AI 生成内容的披露要求
  14. 让 AI 生成的代码在提交时没有任何标注，仿佛是人类编写
  15. Anthropic 主张他人应标注 AI 生成内容的同时，自己却隐藏 AI 贡献
