subagent-driven-development Skill

概述

Superpowers 技能，通过为每个任务派遣全新子 Agent 实现计划，配合两阶段评审（规格合规性 → 代码质量），是 Superpowers 在有子 Agent 支持平台的首选执行引擎。

关键内容

  1. 核心公式：

    Fresh subagent per task + two-stage review (spec then quality) = high quality, fast iteration

  2. 为什么不让主 Agent 直接做：

  3. 上下文窗口污染（需求讨论占用空间）
  4. 污染推理路径（被否定的方案干扰）

  5. 降低执行精度（协调与执行认知模式冲突）

  6. 子 Agent 状态协议： | 状态 | 含义 | 处理 | |------|------|------| | DONE | 任务完成，测试通过 | 进入 Phase A 评审 | | DONE_WITH_CONCERNS | 完成但有问题 | 评估后处理 | | NEEDS_CONTEXT | 缺少信息 | 提供信息后重派 | | BLOCKED | 无法解决的阻碍 | 升级模型/拆分/人工 |

  7. 两阶段评审：

  8. Phase A：规格合规性评审（Spec Compliance Review）
    • 确认做了正确的事
    • 评审员角色：怀疑论者

  9. Phase B：代码质量评审（Code Quality Review）

    • 确认做得对不对
    • 代码组织、命名规范、可维护性

  10. 平台要求：

  11. ✅ Claude Code
  12. ✅ Codex（需 multi_agent = true）
  13. ❌ Gemini CLI（无子 Agent，用 executing-plans）
