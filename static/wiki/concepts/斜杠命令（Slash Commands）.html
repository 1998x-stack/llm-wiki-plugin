斜杠命令（Slash Commands）

概述

Claude Code 中用户手动触发的快捷操作，分为四类：内置命令（55+ 个）、Skills（自定义命令）、插件命令（来自已安装插件）和 MCP prompts（来自 MCP server）。

关键内容

  1. 四类命令：
  2. 内置命令：Claude Code 自带，如 /help、/clear、/model、/compact、/context、/cost
  3. Skills：用户自定义命令，基于 SKILL.md 文件，如 /optimize、/pr
  4. 插件命令：来自已安装插件，如 /frontend-design:frontend-design

  5. MCP prompts：来自 MCP server，如 /mcp__github__list_prs

  6. 重要内置命令：

  7. /compact [instructions]：压缩对话，可附带聚焦指令
  8. /context：用彩色网格可视化上下文占用
  9. /cost：查看 token 使用统计
  10. /effort [low|medium|high|max|auto]：设置推理强度，max 需要 Opus 4.6
  11. /fast [on|off]：切换快速模式
  12. /branch [name]：将当前对话分支到新会话（v2.1.77 中 /fork 更名为 /branch）
  13. /sandbox：切换沙箱模式
  14. /teleport：将会话转移到另一台机器

  15. /rewind：回退到 checkpoint

  16. 自定义命令合并：自定义 slash command 已合并进 Skills。.claude/commands/ 仍然可用，但更推荐使用 .claude/skills/。两者都会创建 /command-name 形式的快捷命令。
