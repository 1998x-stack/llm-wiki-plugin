nO 主循环

概述

nO 主循环是 Claude Code 的核心执行引擎，设计原则是 Runtime 是"哑循环"，所有智能在模型里。

关键内容

  1. 设计原则：
  2. Runtime 是哑循环，智能在模型里

  3. 从"代码控制模型"到"模型控制循环"的根本范式转变

  4. 消息历史管理：

  5. 单一扁平消息历史（非树状/多线程）

  6. 包含用户输入、工具调用、工具结果等

  7. 循环机制：

  8. Think 阶段：调用 Claude API 推理
  9. Act 阶段：执行工具调用
  10. Observe 阶段：处理工具结果

  11. Repeat 阶段：继续或终止循环

  12. 终止机制：

  13. 自然终止条件：无工具调用时返回纯文本响应
  14. 不使用固定迭代上限，避免过早终止
