frontend-design Skill

概述

Anthropic 官方 Skill，指导创建独特、生产级前端界面，避免通用的"AI Slop"美学，强制在编码前进行设计决策（Purpose → Tone → Constraints → Differentiation）。

关键内容

  1. 安装方式： bash /plugin marketplace add anthropics/skills /plugin install frontend-design@anthropics/skills

  2. 核心定位：

  3. distinctive（独特的）：每次生成的设计都应该不同
  4. production-grade（生产级）：真实可用的代码

  5. real working code（真实可运行代码）：不允许伪代码或占位符

  6. 设计前思考框架：

  7. Purpose：界面解决什么问题？谁使用它？
  8. Tone：美学方向（必须选一个极端彻底执行）
  9. Constraints：技术要求（框架、性能、无障碍）

  10. Differentiation：什么让这令人难忘？

  11. 美学方向选项：

  12. brutally minimal（极简暴力）
  13. maximalist chaos（最大化混乱）
  14. retro-futuristic（复古未来）
  15. organic/natural（有机自然）
  16. luxury/refined（奢华精致）
  17. playful/toy-like（玩具感）
  18. editorial/magazine（杂志感）
  19. brutalist/raw（野兽派）
  20. art deco/geometric（装饰艺术）

  21. soft/pastel（柔和粉彩）

  22. 五大设计维度：

  23. Typography：禁止 Inter/Roboto，选择独特有个性字体
  24. Color & Theme：主色调 + 锐利对比色，避免紫色渐变
  25. Motion：staggered reveal、物理反馈微交互
  26. Spatial Composition：打破居中容器，尝试不对称布局

  27. Backgrounds：渐变网格、噪点纹理、几何图案

  28. 实现底线：

  29. ✅ 完整实现所有交互逻辑
  30. ✅ 处理 loading/error/empty 状态
  31. ✅ 正确的语义 HTML
  32. ✅ 基本无障碍（ARIA labels）
  33. ❌ 不允许 // TODO 或占位符
