Agent Skills 三层渐进式加载

概述

Agent Skills中最精妙的设计之一，解决"大量Skill导致Context Window爆炸"的核心矛盾，采用三层加载机制优化上下文效率。

关键内容

  1. 三层加载机制：
  2. 第1层（启动时，始终加载）：
    • skill-a: name + description ~100 tokens
    • skill-b: name + description ~100 tokens
    • skill-n: name + description ~100 tokens
  3. 第2层（任务匹配后，按需加载）：
    • skill-b: 完整SKILL.md内容 <5,000 tokens

  4. 第3层（执行过程中，明确需要时）：

    • skill-b/references/REFERENCE.md 仅在Claude决定需要时加载

  5. 上下文占用估算：

  6. 20个Skills常驻：20 × 100 = 2,000 tokens（仅~0.5%典型上下文）
  7. 激活2个Skills：2 × 5,000 = 10,000 tokens

  8. 总开销：~12,000 tokens，完全可控

  9. 解决的问题：

  10. 避免大量Skills导致Context Window过载
  11. 实现上下文效率的最优化
  12. 在保持丰富功能的同时控制上下文成本
