模型无关设计

概述

AI Agent 框架不绑定特定模型供应商或 API，支持 200+ 模型无缝切换，避免供应商锁定的架构设计理念。

关键内容

  • 核心定义：Agent 框架与底层 LLM 解耦，支持任意 OpenAI 兼容接口，切换模型无需改一行代码
  • 支持供应商：Nous Portal（官方首选）、OpenRouter（200+ 模型统一接口）、OpenAI（GPT 系列）、z.ai/GLM（智谱 AI）、Kimi/Moonshot（月之暗面）、MiniMax（海螺 AI）、自定义 Endpoint
  • 切换方式：通过 hermes model 命令即可切换，无需修改代码或配置
  • 与传统对比：传统 Agent 框架通常绑定特定 API，模型无关设计彻底避免供应商锁定
  • 战略价值：用户可根据成本、性能、可用性自由选择模型，保持架构灵活性和未来兼容性
  • 在 Hermes 中的角色：六大核心能力之一，与随处运行、无处不在、闭环学习等能力协同
