Checkpoints 与 Rewind

概述

Checkpoints 保存 Claude Code 对话状态快照（消息、文件修改、工具使用历史、会话上下文），让用户可以回退到之前的时间点，安全地试验和探索多种方案。

关键内容

  1. 核心概念：
  2. Checkpoint：保存消息、文件和上下文的对话快照
  3. Rewind：回到之前的 checkpoint，并丢弃之后的更改

  4. Branch Point：从同一个 checkpoint 出发，探索多个方案

  5. 访问方式：

  6. 键盘快捷键：按两次 Esc（Esc + Esc）打开 checkpoint 界面

  7. Slash Command：/rewind（别名：/checkpoint）

  8. Rewind 选项：

  9. 恢复代码和对话：文件和消息都恢复到那个 checkpoint
  10. 恢复对话：只回退消息，保留当前代码不变
  11. 恢复代码：只回退文件修改，保留完整对话历史
  12. 从这里开始总结：把从这里往后的对话压缩成 AI 生成的摘要，而非直接丢弃

  13. 算了：取消并返回当前状态

  14. 自动 Checkpoints：Claude Code 会自动在关键操作前后创建 checkpoints，如文件写入、命令执行等，确保用户可以随时回退。
