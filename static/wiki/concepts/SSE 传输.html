SSE 传输

概述

MCP (Model Context Protocol) 的 Server-Sent Events (SSE) 传输协议，一种已被弃用的传输方式，曾用于单向服务器到客户端的消息推送。

关键内容

  1. 历史地位：
  2. 在早期 MCP 版本中使用的传输协议

  3. 现已被 HTTP 和其他更稳定的传输方式取代

  4. 工作原理：

  5. 基于 HTTP 的单向通信
  6. 服务器向客户端推送消息

  7. 保持长连接以持续传输数据

  8. 局限性：

  9. 仅支持单向通信（服务器到客户端）
  10. 连接稳定性不如现代协议

  11. 维护和调试困难

  12. 现状：

  13. 已被弃用，不再推荐使用
  14. 新配置应优先选择 HTTP 或 Stdio 方式

  15. 仅在维护旧系统时可能遇到

  16. 替代方案：

  17. HTTP 传输协议：双向通信，更好的认证支持
  18. WebSocket 传输协议：实时双向通信
  19. Stdio 传输协议：本地进程高效通信
