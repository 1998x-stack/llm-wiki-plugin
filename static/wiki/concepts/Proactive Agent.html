Proactive Agent

概述

Proactive Agent是指能够主动监控环境、预测需求并采取行动的AI代理，区别于传统的被动响应式AI系统。

关键内容

  1. 发展阶段：
  2. 阶段一：被动问答（ChatGPT范式）- 用户问 → AI答 → 等待
  3. 阶段二：主动执行（Claude Code当前版本）- 用户请求 → AI规划 → AI执行 → 等待

  4. 阶段三：自主守护（KAIROS范式）- AI持续监控 → 在合适时机主动行动 → 用户回来时已有积累

  5. 核心特征：

  6. 常驻守护进程模式：AI持续存在，不需要每次显式召唤
  7. 主动感知能力：持续监控环境变化并做出响应
  8. 时机选择机制：在合适时机采取行动，避免干扰用户工作流

  9. 状态维护：在后台维持长期状态和上下文

  10. 技术实现：

  11. 定时器机制：定期接收信号并分析当前状态
  12. 文件监控：监视文件系统变化
  13. Webhook集成：订阅外部服务事件（如GitHub）
  14. 简洁输出模式：克制地向用户报告重要信息
