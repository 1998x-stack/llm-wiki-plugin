CodeAct

概述

CodeAct是由Wang等人提出的概念，主张使用可执行的Python代码作为LLM代理动作的统一表示形式，以替代传统的结构化JSON或自然语言动作。该方法在15/17任务上表现最优，平均提升20%以上。

关键内容

  1. 核心理念：
  2. Python代码是最优的动作格式，相比JSON和自然语言具有更强的表达力、可执行性和可组合性

  3. 代码原生支持状态传递、条件分支、循环和函数组合

  4. 技术优势：

  5. 表达力：Python > JSON > 自然语言
  6. 可执行性：Python = JSON > 自然语言
  7. 可组合性：Python >> JSON >> 自然语言

  8. 状态传递：直接引用中间结果，无需特殊变量绑定机制

  9. 实验验证：

  10. 在17个多样化任务上比较了Text、JSON和CodeAct三种动作格式
  11. CodeAct在15/17任务上表现最优，显著优于其他方法

  12. 关键优势在于中间结果的直接引用和复杂的控制流表达

  13. 工程意义：

  14. 现代.skill文件倾向于包含可执行代码模板
  15. 代码模板让代理可以直接组合和执行技能，无需中间解析层
  16. 为"代码即技能"的统一范式提供了理论支撑
