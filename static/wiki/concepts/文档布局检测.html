文档布局检测

概述

文档布局检测（Document Layout Detection）是从 PDF 页面中识别和定位不同语义区域（文本区、图像、表格、公式框等）的计算机视觉任务，是高质量 PDF 解析的关键环节。

关键内容

任务定义

输入：PDF 页面（原始或渲染为图像） 输出：带类别标签的边界框列表，类别包括： - 文本区（title / text / abstract / reference 等） - 图像区域（figure） - 表格区域（table） - 公式框（formula）

在 MinerU 流水线中的位置

文档布局检测是 MinerU 七层流水线的第三层，承接底层 PDF 解析，为后续内容专项识别提供检测框。

主要模型

  • DocLayout-YOLO：基于 YOLO 架构，推理速度快，专为文档布局场景优化
  • LayoutLMv3：微软多模态文档理解模型，结合视觉和文本特征，精度更优但推理成本更高

与下游环节的协同

布局检测输出的 layout_bboxes 直接驱动第四层的内容专项识别： - 文本区 → OCR（PaddleOCR） - 公式框 → 公式识别（UniMERNet） - 表格区域 → 表格识别（TableMaster）
