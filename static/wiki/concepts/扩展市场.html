扩展市场

概述

扩展市场是 Claude Desktop 中分发和安装 Desktop Extensions 的平台，类似 Chrome Web Store 或 App Store，降低 MCP 工具的分发摩擦。

关键内容

  1. 核心功能：用户可在扩展市场中浏览可用的 Desktop Extensions，查看扩展描述、图标截图和权限请求，一键安装所需扩展。安装流程包括：找到扩展 → 点击 Install → 查看权限 → 输入配置（如 API 密钥）→ 完成。

  2. 开发者发布流程：开发者开发 MCP 服务器后，创建 manifest.json，使用 claude-desktop pack 打包为 .dxt 文件，可提交到 Anthropic 审核后发布到市场，或直接分发文件。

  3. 生态影响：扩展市场的存在降低了 MCP 服务器的分发门槛，使非技术用户也能使用 MCP 工具。降低安装门槛 → 更多用户尝试 → 更多开发者有动力开发 → 生态丰富度提升，形成正向循环。

  4. App Store 模式类比：降低分发摩擦是生态繁荣的关键因素。Desktop Extensions 市场对 MCP 生态的影响类似于 Chrome Extension Store 对浏览器扩展生态、App Store 对移动应用生态的影响。

  5. 审核机制：Anthropic 提供可选的审核流程，推荐开发者提交审核以获得市场分发资格，确保扩展质量和安全性。
