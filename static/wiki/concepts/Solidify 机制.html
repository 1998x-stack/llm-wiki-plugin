Solidify 机制

概述

Evolver 的固化机制，负责在允许代码自进化的同时，验证并固化进化的代码变更，确保系统稳定性。

关键内容

  1. 核心功能：
  2. 解析 LLM 输出的 FilePatches（统一差异格式）
  3. 执行多层安全检查和验证
  4. 应用变更并固化到代码库

  5. 记录 EvolutionEvent 和更新记忆图

  6. 安全门检查：

  7. 基因验证命令白名单（只允许 node/npm/npx）
  8. 禁止命令替换（反引号和 $()）
  9. 禁止 Shell 操作符（&、|、; 等）
  10. 作用域锁定在仓库根目录

  11. 每条命令最长 180 秒超时

  12. 固化流程：

  13. 解析 FilePatches → 受保护文件检查 → 应用变更 → 计算 Blast Radius → 执行验证命令 → 提交变更 → 构建 Capsule → 记录事件
