Claude Code Skills

概述

Claude Code技能是一种强大的扩展机制，允许开发者通过简单的Markdown文件和相关脚本、资源来扩展Claude Code的功能。技能系统提供了灵活、易创建且易于分发的自动化功能。

关键内容

  1. 技能的定义与结构：
  2. 技能不仅仅是Markdown文件，而是包含脚本、资产、数据等的完整文件夹
  3. Claude可以发现、探索和操作这些文件

  4. 拥有多种配置选项，包括动态钩子注册

  5. 技能的主要类型：

  6. 库与API参考：解释如何正确使用库、CLI或SDK
  7. 产品验证：描述如何测试或验证代码是否正常工作
  8. 数据获取与分析：连接到数据和监控堆栈
  9. 业务流程与团队自动化：将重复性工作流自动化为单个命令
  10. 代码脚手架与模板：为特定函数生成框架样板
  11. 代码质量与审查：在组织内强制执行代码质量并帮助审查代码
  12. CI/CD与部署：帮助获取、推送和部署代码
  13. 运行手册：处理症状分析并生成结构化报告

  14. 基础设施操作：执行例行维护和操作程序

  15. 制作技能的最佳实践：

  16. 构建常见陷阱部分：最高信号的内容是Gotchas部分
  17. 使用文件系统和渐进式披露：技能是文件夹而非仅Markdown文件
  18. 避免过度引导Claude：给Claude信息但给予适应情况的灵活性
  19. 考虑设置过程：一些技能可能需要用户上下文
  20. 描述字段面向模型：描述应该说明何时触发此技能
  21. 内存与数据存储：技能可以在内部存储形式的数据作为内存
  22. 存储脚本与生成代码：给Claude提供脚本使其能够组合功能
