MCP（Model Context Protocol）

概述

MCP（Model Context Protocol）是 Claude Code 访问外部工具、服务和 API 的标准协议，允许将 GitHub、数据库、文件系统、聊天系统等外部系统集成到 Claude 环境中。

关键内容

  1. MCP 架构：
  2. 由 Claude Code、MCP server 和外部工具或数据源三部分构成

  3. Claude 通过 MCP 协议向 server 发起工具调用，并把结果带回当前会话

  4. MCP 生态：

  5. 支持 GitHub 集成、数据库集成、文件系统集成

  6. 支持组织内部工具和第三方服务

  7. 传输方式：

  8. HTTP 传输（推荐）
  9. Stdio 传输（本地）
  10. WebSocket 传输（适用于需要实时双向通信的场景）

  11. SSE 传输（已弃用）

  12. 安全特性：

  13. 支持 OAuth 2.0 认证
  14. 通过环境变量管理认证信息

  15. 最小权限原则的安全控制

  16. 配置管理：

  17. 支持项目级和用户级的不同作用域
  18. 提供命令行工具进行服务器管理（添加、列出、删除等）

  19. 支持动态工具更新和实时感知变化

  20. 使用方式：

  21. 可将 MCP Prompts 暴露为 Slash Commands（如 /mcp__github__list_prs）
  22. 支持通过 @ 提及使用 MCP 资源
  23. 可作为代码执行接口减少上下文膨胀
