Harness分层架构

概述

Harness分层架构是一种7层分类框架，描述了Agent系统中Harness的组成部分，强调模型几乎无关紧要，Harness才是一切。

关键内容

  1. 七层架构模型：
  2. 第1层 - Human Oversight（人类监督）：最终决策权
  3. 第2层 - Spec Tools（规格工具）：把需求变成Agent可执行的任务描述
  4. 第3层 - Full Lifecycle Platforms（全生命周期平台）：从spec到部署的端到端管理
  5. 第4层 - Task Runners（任务执行器）：大任务拆解为可并行的子任务
  6. 第5层 - Agent Orchestrators（Agent编排器）：协调多个Agent协作
  7. 第6层 - Harness Frameworks/Runtimes（Harness框架和运行时）：通用执行环境

  8. 第7层 - Coding Agents（编码Agent）：商品化层（Claude Code、Cursor、Codex等）

  9. 价值分布：

  10. 最底层的Coding Agents是最容易被替代的商品化层
  11. 壁垒在上面几层：如何定义spec、如何编排任务、如何做人类监督

  12. 模型几乎无关紧要，Harness才是一切

  13. 设计模式：

  14. 渐进式信息披露：不一次性把所有文档塞给Agent，而是根据需要按需加载
  15. 独立执行环境：每个Agent在独立的git worktree里工作，互不干扰
  16. Repo as System of Record：任务定义、架构约束、质量标准全部写在仓库里
  17. 机械化约束执行：架构约束通过CI规则强制执行，而非口头约定

  18. 嵌入式验证反馈：测试、验证反馈回路嵌入Agent执行循环内部

  19. 性能影响：

  20. SWE-agent论文显示：仅靠Agent-Computer Interface设计改进，获得64%的性能提升
  21. LangChain在Terminal Bench 2.0上的成绩从52.8%升到66.5%，排名从Top 30跳到Top 5
  22. 模型未改变，仅优化Harness架构带来的显著提升
