本地 MCP Servers

概述

本地 MCP (Model Context Protocol) 服务器，是在本地机器上运行的 MCP 服务，通常作为子进程与 Claude Code 通信，提供高效的本地工具集成能力。

关键内容

  1. 特点：
  2. 在本地机器上运行
  3. 通过子进程与 Claude 通信
  4. 低延迟，高性能

  5. 无需网络连接

  6. 工作方式：

  7. Claude 启动本地工具作为子进程
  8. 通过 Stdio 传输协议进行通信

  9. 适用于本地开发和调试

  10. 典型应用：

  11. 本地文件系统操作工具
  12. 本地开发环境集成
  13. 本地数据库客户端

  14. 本地 Git 工具封装

  15. 与远程 MCP 对比：

  16. 本地 MCP：低延迟，高效率，适用于本地工具

  17. 远程 MCP：支持远程服务，需要网络连接和认证

  18. 配置示例： toml [mcp_servers.local_tool] command = "node" args = ["local-server.js"]
