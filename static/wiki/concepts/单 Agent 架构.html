单 Agent 架构

概述

单 Agent 架构是一种 AI Agent 设计模式，使用单一 Agent 实例配合精心设计的工具集完成复杂任务，而非依赖多 Agent 编排，体现了"简单优于复杂"的工程哲学。

关键内容

  1. SWE-bench 验证：Claude 3.5 Sonnet 的 SWE-bench Agent 采用相对简单的单 Agent 架构——Claude 3.5 Sonnet 作为核心推理引擎，一套精心设计的工具集（文件读写、命令执行、搜索等），无复杂的多 Agent 编排。

  2. SOTA 成绩证明：单 Agent 配合优质工具就能达到 SWE-bench SOTA（49%），这个设计选择体现了 Anthropic 一贯的"简单优于复杂"哲学——复杂的多 Agent 架构并未带来额外收益。

  3. 与多 Agent 系统的对比：

  4. 单 Agent：简单、低延迟、上下文一致、调试容易
  5. 多 Agent：复杂、高延迟、需要协调机制、调试困难

  6. 关键结论：在 SWE-bench 这类任务上，单 Agent + 优质工具 > 复杂多 Agent 编排

  7. 适用场景：

  8. 任务可在单个 Agent 的上下文窗口内完成
  9. 工具集设计良好，能覆盖任务所需的所有操作

  10. 延迟敏感，需要快速响应

  11. 设计要点：

  12. 核心推理引擎选择强模型（如 Claude 3.5 Sonnet）
  13. 工具集深度优化（Poka-Yoke 设计）
  14. 引入 Think 工具 增强中间推理能力
