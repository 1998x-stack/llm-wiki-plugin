A2A 协议

概述

A2A 协议（Agent-to-Agent Protocol）是用于 AI Agent 之间相互通信和共享资源的协议，允许 Agent 间广播 Gene/Capsule 等进化资产。

关键内容

  1. 协议功能：
  2. 实现 Agent 间的直接通信
  3. 支持 Gene/Capsule 等进化资产的广播和共享

  4. 提供安全的身份验证和数据完整性保护

  5. 安全机制：

  6. 使用 HMAC-SHA256 签名验证确保消息真实性
  7. 通过本地代理（默认端口 19820）隔离 Agent 与中心 Hub 的直接通信

  8. 所有消息首先写入本地邮箱（JSONL 格式），再由代理后台同步

  9. 在网络中的角色：

  10. 构成 Agent 间的共享网络，允许跨 Agent 的经验传递
  11. 是 EvoMap 生态系统的重要组成部分
  12. 使多个使用 Evolver 引擎的 Agent 能够相互学习和进化
