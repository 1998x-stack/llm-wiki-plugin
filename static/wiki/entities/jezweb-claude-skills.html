jezweb/claude-skills

概述

社区最活跃的 Claude Code Skills 仓库之一，由 Jeremy Dawes (Jez) 开发，专注于前端 React 风格的技能实现，强调工程实现和错误预防。项目核心理念是"上下文窗口是公共资源"，只包含 Claude 不知道的信息。

关键内容

  1. 设计理念：与 Anthropic 官方 Skills 不同，jezweb Skills 注重工程实现和错误预防，每个 Skill 必须产出可见成果。项目有明确的 documented errors 数量统计和版本锁定机制。

  2. 插件结构：包含 10 个插件，63 个技能，其中 Frontend Plugin 包含 10 个前端相关技能，涵盖了从 Tailwind v4 主题配置到完整落地页生成的完整工作流。

  3. Frontend Plugin：前端插件包含多个核心技能，如 tailwind-theme-builder（Tailwind v4 主题基础设施）、shadcn-ui（组件安装配置）、react-patterns（React 19 性能模式）、design-review（设计质量审查）等。

  4. 错误预防机制：通过 ERRATA.md 管理版本变更，避免频繁修改核心技能内容，确保技能内容的稳定性。ERRATA状态生命周期包括active→absorbed→outdated。

  5. 全栈集成：设计考虑了完整的 Cloudflare 全栈部署链路，从前端到 Cloudflare Workers 的完整流程。

  6. 核心原则：

  7. "The context window is a public good" — 只包含 Claude 不知道的内容
  8. "Teach patterns, not ship scripts" — 技能描述做什么，由 Claude 生成适应环境的脚本
  9. 每个技能必须产生可见输出（文件、配置、可部署项目）
