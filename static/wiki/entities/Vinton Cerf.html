Vinton Cerf

概述

美国计算机科学家（1943–），TCP/IP 协议的共同发明者，被尊称为"互联网之父"。2004年与 Robert Kahn 共同获得 ACM 图灵奖。

关键内容

TCP/IP 的诞生

  • 1973年春天，受 Robert Kahn 邀请共同合作设计网络互联协议
  • 两人在旧金山一家酒店的大厅里，在信封背面勾勒出了最初的协议草图
  • 1974年5月共同发表论文《A Protocol for Packet Network Intercommunication》
  • 论文提出了传输控制协议（TCP）的原始设计

ARPANET 经历

  • 斯坦福大学助理教授期间深度参与 ARPANET 协议设计
  • 是 NCP（Network Control Program）协议的核心设计者之一
  • 1983年见证了 ARPANET 从 NCP 到 TCP/IP 的"旗帜日"切换

后续贡献

  • 推动了 TCP 和 IP 的分离（1978年，与 Jon Postel 和 Danny Cohen）
  • 参与了 MCI Mail 的商业化互联网接入
  • 长期倡导网络中立性
  • 在 Google 担任副总裁和首席互联网布道师

图灵奖（2004）

与 Kahn 共同获得，授奖理由是"对互联网基础通信协议 TCP/IP 的开创性工作，以及在网络领域的卓越领导力"。
