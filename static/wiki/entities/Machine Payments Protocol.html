Machine Payments Protocol

概述

Machine Payments Protocol (MPP) 由 Tempo Labs 和 Stripe 联合设计，基于 HTTP 402 状态码的支付协议，已提交 IETF 规范草案。

关键内容

  1. 核心定位：
  2. 解决任何 API 如何向任何客户端（Agent/App/人类）收取费用，无需注册、API Key

  3. 被称为"按请求付费"的互联网原语，是对 API Key 的革命性替代

  4. 协议流程：

  5. 客户端发起请求
  6. 服务端返回 HTTP 402 Payment Required 及支付选项
  7. 客户端完成支付（签名/转账/扣款）
  8. 客户端再次发起请求，携带支付凭证

  9. 服务端验证后返回资源和支付收据

  10. 支持的支付方式：

  11. Tempo (USDC.e)：微支付、Agent 间支付，~0.6s 最终确认
  12. Stripe (Card)：传统法币支付，T+1 结算
  13. Lightning (BTC)：极小额、即时，链下通道毫秒级
  14. Solana：高频微支付，低手续费
