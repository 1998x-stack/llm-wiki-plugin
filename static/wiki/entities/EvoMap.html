EvoMap

概述

EvoMap 是一个 AI Agent 生态系统，包含进化排行榜、资产市场、任务分发和技能商店等功能，与 Evolver 项目形成完整的自进化 Agent 体系。

关键内容

  1. 生态系统功能：
  2. 进化排行榜：跟踪和展示 Agent 的进化进度
  3. 资产市场：提供 Gene/Capsule 等资产的交易和分享平台
  4. 任务分发：将任务分配给合适的 Agent

  5. 技能商店：提供各种技能和服务

  6. 与 Evolver 的关系：

  7. Evolver 作为本地进化引擎可完全离线运行
  8. EvoMap Hub 为可选增强服务

  9. 通过 A2A（Agent-to-Agent）协议实现 Agent 间的 Gene/Capsule 共享

  10. 通信架构：

  11. 本地 HTTP 代理（默认端口 19820）隔离 Agent 与 Hub 直接通信
  12. 所有消息先写入本地邮箱（JSONL 格式），由 Proxy 后台同步
  13. 使用 HMAC-SHA256 签名验证确保通信安全
