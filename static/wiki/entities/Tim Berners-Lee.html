Tim Berners-Lee

概述

英国计算机科学家（1955–），万维网发明者，2016年 ACM 图灵奖得主。1989年在 CERN 提交了改变人类文明进程的技术提案。

关键内容

万维网的诞生

  • 1989年3月向 CERN 提交《Information Management: A Proposal》
  • 主管 Mike Sendall 的批语："Vague, but exciting..."
  • 1990年10月在 NeXT 计算机上完成第一个浏览器和服务器
  • 1990年12月25日第一次成功的 HTTP 通信

三大发明

  • URL：为全球信息空间统一编址
  • HTTP：极简的请求-响应协议
  • HTML：人人都能写的标记语言

免费开放决策

  • 1993年 CERN 宣布万维网技术对所有人免费开放
  • 被后世誉为"技术史上最慷慨的馈赠"

后续贡献

  • 1994年在 MIT 创立 W3C（World Wide Web Consortium）
  • 2015年推动 Solid 项目，试图解决数据垄断问题
  • 2012年伦敦奥运会开幕式上发推："This is for everyone."

图灵奖（2016）

授奖理由是"发明了万维网、第一个网页浏览器和允许 Web 扩展的基础协议与算法"。
