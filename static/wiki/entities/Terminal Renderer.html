Terminal Renderer

概述

Claude Code 的自定义终端 UI 渲染引擎，基于 Ink 框架构建的高度优化渲染层。

关键内容

  1. 核心技术架构：
  2. 基于 Ink（React 终端 UI 框架）的自定义渲染层
  3. 使用 Int32Array 作为 ASCII 字符池，每个 Int32 同时编码字符码和样式元数据
  4. 采用位掩码样式编码节省内存，避免对象分配

  5. 借鉴游戏引擎 ECS（Entity-Component-System）思想优化性能

  6. 性能优化技术：

  7. 渲染补丁优化器（Optimizer）：计算最小变更补丁，而非重新渲染整个屏幕
  8. 相比朴素实现在 Token 流式传输期间减少约 50x 的 stringWidth 函数调用
  9. 自蒸发行宽缓存（self-evicting line-width cache）避免重复计算

  10. 光标移动合并优化，消除不必要的 hide/show 对

  11. 工程应用：

  12. 屏幕缓冲管理通过 ink/screen.ts 实现
  13. 渲染补丁优化通过 ink/optimizer.ts 实现
  14. 在逐 Token 实时流式输出场景下显著提升性能
