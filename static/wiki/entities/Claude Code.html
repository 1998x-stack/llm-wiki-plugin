Claude Code

概述

运行在终端的自主编码智能体，采用极简 Harness 架构——LLM 大脑 + 真实世界身体（Shell / 文件系统 / 外部服务）。Anthropic 推出的 AI 驱动代码编辑器，基于 Claude 模型，支持 Agent Skills、MCP Servers 和 Plugins 扩展机制，提供多智能体协作和上下文工程能力。

关键内容

  1. 产品哲学："The product is the model"。不像其他编码产品把 LLM 层层包裹，Claude Code 让模型直接与系统交互，提供原始模型体验。强调最少业务逻辑原则：Client 端只负责 UI 渲染 + 工具路由，智能完全来自模型。

  2. 三代 LLM 应用演化：

  3. 第一代：聊天机器人（无状态问答，控制权归人）
  4. 第二代：工作流（LangChain / n8n，代码驱动的 DAG 链，控制权归代码）

  5. 第三代：自主 Agent（Claude Code，模型驱动的循环，控制权归模型）

  6. 技术栈：

  7. 语言：TypeScript（类型安全 + 模型自编率极高）
  8. UI 框架：React + Ink（声明式终端 UI，模型可控）
  9. 布局引擎：Yoga（Meta 开源，约束布局，适配任意终端宽度）
  10. 构建工具：Bun（比 Webpack/Vite 显著更快）
  11. API：Anthropic Messages API（直接暴露模型能力）
  12. 协议：MCP（Model Context Protocol，标准化外部服务接入）

  13. 持久化：~/.claude/sessions/<id>/transcript.jsonl（会话历史，支持 /resume）

  14. 系统架构：

  15. 用户接口层：CLI、VS Code 插件、Web UI
  16. 核心 Agent 层：nO 主循环（TAOR Loop - Think → Act → Observe → Repeat）
  17. 上下文管理器：Compressor wU2（触发阈值：92%）
  18. 规划系统：TodoWrite、Reminder 注入（目标锚定、防目标漂移）
  19. 确定性控制层：Hooks 系统（21 个生命周期事件，4 种处理器类型）
  20. 工具生态系统：Read、Write、Execute、Connect 四大能力基元
  21. 配置权限层：settings.json 4 级层级，Permission 白名单/黑名单
  22. 扩展层：MCP 外部服务、Skills、Plugins
  23. 委派层：子 Agent、Git Worktree 隔离、并行 Agent Teams

  24. 持久化上下文层：CLAUDE.md 三级层级（全局/项目/子目录），跨会话架构记忆、编码规范、架构决策记录（ADR）

  25. 工具系统与安全机制：

  26. 内置40+工具：文件系统工具、代码执行工具、网络API工具、多智能体工具、Git版本控制工具、记忆状态工具
  27. BashTool安全机制：23项安全检查，包括命令黑名单、Zsh特有威胁防护、Unicode安全检查、管道与重定向分析
  28. 权限三级体系：Level 3自动执行、Level 2单次确认、Level 1永久拒绝或特殊授权

  29. 85+斜杠命令系统：Git工作流命令、记忆与项目管理命令、多智能体命令、调试诊断命令

  30. 四大能力基元：

  31. Read（读）：View、LS、Glob、GrepTool - 理解代码库、搜索文件
  32. Write（写）：Edit、Write/Replace、Create - patch、全文替换、新建文件
  33. Execute（执行）：Bash（持久 Shell 会话）- git、npm、docker、pytest

  34. Connect（连接）：MCP 协议 - GitHub、DB、Sentry、Slack

  35. 运营指标：

  36. 代码自生率：90% 由 Claude Code 自己编写
  37. 发布频率：每位工程师每天约 5 次
  38. 年化收入：GA 后 3 个月突破 $500M ARR，增长 10×
  39. 用户粘性：7×24 小时不间断运行，触发 Anthropic 实施周用量限制
  40. 迭代速度：每个新功能经历 10+ 个真实原型迭代

  41. 模型上下文：Sonnet：200k tokens，Opus 默认输出上限 64k tokens

  42. 扩展机制全家桶：

  43. CLAUDE.md：项目持久记忆文件
  44. Agent Skills (SKILL.md)：目录级可复用能力包
  45. MCP Servers：进程级工具服务
  46. Claude Connectors：远程 MCP 服务（Slack、Figma 等）
  47. Plugins：Skills + Agents + Hooks + MCP Server 的发布单元
  48. Agents：专用子智能体
  49. Hooks：生命周期钩子（PreTool、PostTool 等）

  50. Slash Commands：斜杠命令系统，包括内置命令、Skills、插件命令和 MCP Prompts

  51. 三层渐进式加载机制：

  52. 第 1 层：启动时加载所有 Skill 的 name + description（~100 tokens/skill）
  53. 第 2 层：任务匹配后按需加载完整 SKILL.md（<5,000 tokens）

  54. 第 3 层：执行过程中明确需要时加载 references/

  55. 跨工具兼容性：Agent Skills 规范被 Claude Code、OpenAI Codex、Cursor、Gemini CLI 共同采用
