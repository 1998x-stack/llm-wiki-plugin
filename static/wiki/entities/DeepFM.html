DeepFM

概述

Guo 等人于 IJCAI 2017 提出的 FM + DNN 并行架构模型，FM 组件捕获显式低阶交互，DNN 组件捕获隐式高阶交互，共享嵌入层，无需手工特征工程。

关键内容

  1. 并行架构：DeepFM 由两部分并行组成——FM 部分（浅层模块）负责捕获显式的低阶（二阶）特征交互，DNN 部分（深层模块）负责捕获隐式的高阶非线性特征交互。两部分共享同一组嵌入向量，联合训练。最终输出为 sigmoid(y_FM + y_DNN)。
  2. 共享嵌入：FM 和 DNN 共享类别型特征的嵌入表示，避免了分别学习导致的参数冗余和不一致性。这种"浅层 + 深层"的并行设计模式已成为推荐系统的标准架构。共享嵌入带来三重优势：参数效率、联合优化、消除预训练。
  3. 无需手工特征：DeepFM 的端到端设计消除了对人工构造交叉特征的依赖，模型自动学习特征交互，大幅降低了特征工程成本。相比 Wide &amp; Deep 的 Wide 部分需要手工 cross-product 特征，DeepFM 用 FM 完全替代。
  4. 与 FM 的关系：DeepFM 直接在架构中保留了完整的 FM 组件作为"浅层"模块，是 FM 思想在深度学习时代的自然延伸。FM 负责低阶交互的显式建模，DNN 补足高阶交互的隐式学习，两者互补。
  5. CTR 预估效果：在 Criteo 数据集上 AUC=0.8016、LogLoss=0.44985（最优）；在华为应用市场约10亿条记录的真实数据上 AUC=0.8715。在线 A/B 测试中 DeepFM-D 相比精心调优的 LR 模型，CTR 提升超过 10%。
  6. 后续影响：DeepFM 的"浅层 + 深层"并行架构启发了后续一系列工作，包括 DCN（Google 2017，Cross Network 显式交叉）、xDeepFM（微软 2018，CIN 向量级显式交叉）、AutoInt（2019，多头自注意力可解释交互）等。
  7. 局限性：FM 组件仍局限于二阶交叉；DNN 高阶交互为黑盒难以解释；FM 暴力枚举所有特征对缺乏选择性；缺乏时序动态建模；DNN 学习的是维度级而非向量级交互。后续工作如 xDeepFM、AutoInt、DIN 分别针对这些局限进行了改进。
  8. 架构一般性：DeepFM 框架具有可扩展性，论文提出 DeepFM-D（Deep 部分用标准 DNN）和 DeepFM-P（Deep 部分用 PNN）两个变体，"FM + Deep 共享嵌入"是可替换 Deep 部分实现的通用范式。
