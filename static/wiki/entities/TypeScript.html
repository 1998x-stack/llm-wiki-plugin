TypeScript

由 Microsoft 开发的 JavaScript 超集语言，添加静态类型系统。编译为 JavaScript 后在 V8 等引擎上运行。

关键内容

  1. Codex 原版实现语言：Codex CLI 最初以 TypeScript 实现，后于 2025 年由 OpenAI 以 Rust 重写。
  2. 被取代的原因：
  3. V8 冷启动开销大，不适合 CLI 工具
  4. GC 抖动影响确定性延迟
  5. Node native addon 绑定系统调用（Landlock/seccomp）繁琐
  6. 需要 Node.js runtime 依赖，无法分发单一二进制
  7. 事件循环单线程模型限制真并发
  8. 适用场景：TypeScript 适合 Web 前端和快速原型，但在需要 OS 级系统调用绑定的安全关键场景中不如 Rust。
