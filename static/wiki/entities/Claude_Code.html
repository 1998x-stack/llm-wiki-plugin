Claude Code

概述

Claude Code 是 Anthropic 推出的 AI 编码助手，支持多种扩展机制包括 Skills、Agents、Hooks 等。

关键内容

  1. 扩展机制：
  2. 最初提供 Custom Slash Commands 机制
  3. 后来采用 Agent Skills 规范，全面替代 Slash Commands

  4. 支持 MCP Servers、Claude Connectors、Plugins 等多种扩展方式

  5. Skills 系统：

  6. 基于 SKILL.md 文件定义
  7. 支持三层渐进式加载机制

  8. 通过 description 字段进行语义匹配激活

  9. 生态系统：

  10. 与社区共同制定 Agent Skills 规范
  11. 支持 Plugin Marketplace 进行分发
  12. 可与其他工具（OpenAI Codex、Cursor、Gemini CLI）互通
