InstructRec

概述

微信团队提出的基于指令调优的推荐方法，借鉴 P5 的任务统一思想，用指令格式替代 Prompt 模板。

关键内容

  1. 核心思想：借鉴 P5 论文 的任务统一思想，但将固定 Prompt 模板升级为更灵活的指令调优格式，使模型能够理解更复杂的推荐指令。

  2. 与 P5 的区别：P5 使用 47 个预定义的 Prompt 模板，InstructRec 使用自然语言指令，格式更灵活，覆盖更广的任务描述空间。

  3. 技术特点：

  4. 使用指令调优训练 LLM 适配推荐场景
  5. 支持多种推荐任务的统一处理

  6. 更强的 zero-shot/few-shot 泛化能力

  7. 团队背景：由微信团队提出，代表了工业界对 LLM 推荐方向的探索。

  8. 在 LLM 推荐谱系中的位置：属于生成式 LLM 推荐范式，与 TALLRec、LC-Rec、LLMRec 等工作共同推动了从 P5 到现代 LLM 推荐的演进。
