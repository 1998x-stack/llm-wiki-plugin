Joseph Redmon

概述

计算机视觉研究者，YOLO（You Only Look Once）实时目标检测算法的发明者。

关键内容

  1. YOLO 论文（2016）：发表《You Only Look Once: Unified, Real-Time Object Detection》，提出将目标检测视为单一回归问题，直接从图像像素预测边界框和类别。
  2. 单阶段检测：YOLO 与 R-CNN 系列 的两阶段范式不同，实现了端到端的实时检测，速度远超当时的其他方法。
  3. 后续影响：YOLO 系列（v2、v3、v4 等）持续演进，成为工业界最常用的实时检测方案。
