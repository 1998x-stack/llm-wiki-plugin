# LLM能力

## 概述

LLM能力 相关概念与实体的集群。核心主题：上下文压缩、上下文感知、上下文窗口、上下文编辑。

## 概念

- [[上下文压缩]] — 上下文压缩是 Anthropic 官方推出的服务端上下文管理策略，当长时对话接近[[上下文窗口]]限制时，自动将旧内容压缩为简洁摘要，替换原始历史记录，从而扩展 (confidence: 0.95)
- [[上下文感知]] — 上下文感知是 Claude 4.5+ 模型（[[Claude-Sonnet-4-6]]、[[Claude-Sonnet-4-5]]、[[Claude-Haiku (confidence: 0.9)
- [[上下文窗口]] — 上下文窗口是语言模型在生成回复时可参考的所有文本总量，包括输入和输出，相当于模型的"工作记忆"。Claude 最新模型支持最大 1M tokens 的上下文窗口 (confidence: 0.95)
- [[上下文编辑]] — 上下文编辑是 Anthropic 提供的细粒度上下文管理策略集合，适用于比 [[上下文压缩]] 更专业的需求场景，包括工具结果清除和思考块清除等操作。 (confidence: 0.85)
- [[交错式思考]] — 交错式思考是 Claude 4 模型支持的能力，允许模型在工具调用之间进行思考，并在获取工具结果后进行更复杂的推理，而无需等待非工具结果的用户轮次介入。 (confidence: 0.85)
- [[扩展思维]] — 扩展思维是 Claude 模型的一种能力，允许模型在生成回复前进行深度推理。思考 token 计入[[上下文窗口]]和输出计费，但在多轮对话中会被自动剥离以节省 (confidence: 0.9)
- [[提示词缓存]] — 提示词缓存是 Anthropic API 的缓存优化机制，通过在消息中标记 `cache_control` 断点，将固定不变的前缀内容（如系统提示、工具定义）缓 (confidence: 0.9)
- [[自适应思考]] — 自适应思考是 Claude 模型的一项能力，使模型能动态决定每次请求所需的思考分配，因此实际思考 token 使用量可能因请求而异，而非固定预算。 (confidence: 0.85)
- [[零数据保留]] — 零数据保留（ZDR）是 Anthropic 为企业客户提供的数据隐私协议，确保通过特定 API 功能发送的数据在 API 响应返回后不会被存储，满足合规和隐私要 (confidence: 0.85)
- [[首次令牌时间]] — 首次令牌时间（T[[TensorFlow|TF]]T）衡量 Agent 会话从接受工作到产生第一个响应 token 之间的等待时间，是用户最能**直观感受**到 (confidence: 0.85)
