# 文档处理

## 概述

文档处理 相关概念与实体的集群。核心主题：PDF解析、光学字符识别、公式识别、文档布局检测。

## 概念

- [[PDF解析]] — PDF 解析是从 Portable Document Format 文件中提取结构化文本和语义信息的技术。PDF 本质上是"打印指令集"而非语义结构，解析的核心 (confidence: 0.85)
- [[光学字符识别]] — 光学字符识别（OCR）是将图像中的文字转换为机器可读文本的技术，是扫描件 PDF 解析的核心手段。 (confidence: 0.85)
- [[公式识别]] — 公式识别（Formula Recognition）是将 PDF 中以图像形式存储的数学公式转换为 LaTeX 代码的技术，是高质量学术文档解析的关键环节。 (confidence: 0.75)
- [[文档布局检测]] — 文档布局检测（Document Layout Detection）是从 PDF 页面中识别和定位不同语义区域（文本区、图像、表格、公式框等）的计算机视觉任务，是 (confidence: 0.8)
- [[文档结构化提取]] — 文档结构化提取是将非结构化的文档（如 PDF）转换为带有语义标签的结构化数据（如 Markdown、JSON）的过程，是 [[检索增强生成|RAG]] 系统和知 (confidence: 0.8)
- [[表格识别]] — 表格识别（Table Recognition）是将 PDF 中的表格还原为结构化数据（如 Markdown 表格）的技术，核心挑战在于从仅靠线条暗示的单元格边界 (confidence: 0.75)
- [[阅读顺序重建]] — 阅读顺序重建（Reading Order Reconstruction）是从 PDF 页面元素的空间坐标中还原人类阅读序列的算法，解决多栏布局、脚注、侧边栏等复 (confidence: 0.8)
