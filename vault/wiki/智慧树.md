# 智慧树

## 概述
智慧树是一家教育科技公司。作者曾在此从0到1搭建面向校园的智能问答系统，覆盖教务、教学两大板块，包括新生选课规则查询和课程知识点答疑等场景。该项目是 RAG 落地实践的重要案例，从中总结出数据分块是 RAG 项目最关键环节的核心经验。

## 关键内容
1. **项目背景**：从0到1搭建面向校园的智能问答系统
2. **覆盖场景**：教务查询、教学答疑
3. **技术栈**：Elasticsearch + Milvus 混合检索 → Neo4j 知识图谱树
4. **核心经验**：发现 RAG 项目的瓶颈不在检索优化，而在数据分块设计
