# 历史唯物主义

## 概述 (50-200字符)
马克思创立的历史解释框架，主张"不是观念决定存在，而是存在决定观念"，经济基础（生产力×生产关系）决定上层建筑（国家/法律/宗教/哲学/文化）。

## 关键内容 (≥300字符, 用[[双链]])
1. **对黑格尔的翻转**：黑格尔认为历史是"绝对精神"的自我实现过程（观念演化）。马克思"将黑格尔头足倒置，使他重新站立"——人们首先要吃饭、生产、交换，才能做政治、法律、哲学。
2. **核心框架**：生产力（技术、工具、劳动力）× 生产关系（谁拥有生产资料？劳动如何组织？）→ 经济基础（Base）→ 上层建筑（Superstructure = 国家/法律/宗教/哲学/文化）。
3. **革命机制**：当生产力的发展与现存生产关系产生矛盾时，**革命**就会爆发，推动社会从一种生产方式跃迁到另一种（奴隶制→封建制→资本主义→…）。
4. **与[[共产党宣言]]和[[资本论]]的关系**：这是两部作品共享的同一套理论内核，是[[阶级斗争]]分析和[[剩余价值]]理论的哲学基础。
