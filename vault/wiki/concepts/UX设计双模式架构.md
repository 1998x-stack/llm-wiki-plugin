# UX设计双模式架构

## 概述
UX设计双模式架构是一种为同一UX设计领域提供两种完全不同AI行为模式的方法，分别适用于不同的项目需求。

## 关键内容

1. **创新模式 (Innovative)**：
   - 大胆、独特、出人意料的设计风格
   - 主动选择美学方向，大胆执行
   - 允许艺术性低对比度（有[[意识]]地）
   - 使用意外的、有个性的字体配对
   - 适用于创意机构、作品集、新产品

2. **控制模式 (Controlled)**：
   - 系统化、可控、符合规范的设计方法
   - 始终先询问，再实施设计决策
   - 严格遵循WCAG AA 4.5:1对比度标准
   - 品牌规范优先的字体选择
   - 适用于企业应用、受监管行业、设计系统

3. **设计思维协议 (Design Thinking Protocol)**：
   - 在实现任何组件之前，必须询问四个关键问题
   - 界面要解决的问题、主要用户、应传达的情感、让人难忘的元素

4. **应用场景差异**：根据项目类型选择合适的模式，确保设计既满足功能需求又符合品牌规范
