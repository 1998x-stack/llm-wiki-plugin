# 枚举值使用规范

## 概述
[[UrhoX引擎|UrhoX]] 开发中处理输入事件、渲染模式等场景时，必须使用枚举常量（如 `MOUSEB_LEFT`、`KEY_SPACE`），禁止使用数字常量。

## 关键内容
1. **常用枚举类别**：鼠标按钮（`MOUSEB_LEFT`、`MOUSEB_MIDDLE`、`MOUSEB_RIGHT`）；键盘按键（`KEY_SPACE`、`KEY_ESCAPE`、`KEY_A`~`KEY_Z` 等）；[[UrhoX鼠标模式|鼠标模式]]（`MM_ABSOLUTE`、`MM_RELATIVE`、`MM_FREE`）；刚体类型（`BT_STATIC`、`BT_DYNAMIC`、`BT_KINEMATIC`）。
2. **错误示例**：`if button == 0 then` 是错误的，因为 `MOUSEB_LEFT` 不一定是 0。正确写法：`if button == MOUSEB_LEFT then`。
3. **查阅方式**：不确定枚举值时查阅 `engine-docs/api/enums.md`，不要凭记忆或从其他框架（如 SDL）迁移数字常量。
