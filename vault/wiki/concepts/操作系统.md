# 操作系统

## 概述

操作系统是管理[[计算]]机硬件和软件资源的系统软件，为用户和应用程序提供抽象接口。UNIX 定义了现代操作系统的基本特征：层次化文件系统、多进程多用户、Shell 命令行、管道和重定向、文件[[Permissions|权限]]。

## 关键内容

### 历史发展

- **1960年代**：批处理系统（如 IBM OS/360）和分时系统（如 [[Multics]]）并存
- **1969年**：UNIX 原型在 PDP-7 上诞生
- **1973年**：UNIX 用 [[C 语言]]重写，首次实现操作系统可移植性
- **1974年**：[[UNIX 论文]]发表，向世界正式介绍

### 核心功能

- **进程管理**：创建、调度、终止进程
- **[[内存管理]]**：分配和回收内存
- **文件系统**：组织、存储、检索数据
- **I/O 管理**：管理输入输出设备
- **安全**：访问控制、[[Permissions|权限]]管理

### UNIX 的贡献

UNIX 几乎定义了我们今天所理解的"操作系统"应该具有的基本特征：
- 层次化文件系统
- 多进程多用户
- Shell 命令行
- 管道和重定向
- 文件[[Permissions|权限]]

### 现代操作系统

截至2020年代：
- Top 500 超级[[计算]]机 100% 运行 Linux
- 约80%的智能手机运行 Android（Linux 内核）
- 大多数 Web [[服务]]器运行 Linux
- Apple 全部产品线运行基于 UNIX 的操作系统
