# 心理地形模型

## 概述
[[弗洛伊德]]提出的心灵结构理论，将心灵分为[[意识]]、[[前意识]]、[[无意识]]三个层次。

## 关键内容
1. **基本结构**：
   ```
   ┌─────────────────────────────┐
   │         意识（Conscious）      │  ← 我们能直接觉察的部分
   ├─────────────────────────────┤
   │       前意识（Preconscious）   │  ← 暂时在意识之外，可被召回
   ├─────────────────────────────┤
   │        无意识（Unconscious）   │  ← 被压抑的欲望、冲动、创伤
   │         （深不可测）           │    通常无法进入意识
   └─────────────────────────────┘
   ```

2. **各层次功能**：
   - [[意识]]：我们能直接觉察的心理部分
   - [[前意识]]：暂时在[[意识]]之外但可被召回的内容
   - [[无意识]]：被[[压抑]]的欲望、冲动、创伤的储存地

3. **核心理念**：
   - [[无意识]]不是被动的"储藏室"，而是充满活力的心理力量
   - [[压抑]]机制作为守门人，阻挡被[[压抑]]内容进入[[意识]]
   - 被[[压抑]]内容通过症状、口误、遗忘和梦境等方式"渗透"出来

4. **理论意义**：
   - 为精神分析提供了理论基础
   - 揭示了人类心理的多层次结构
   - 解释了[[无意识]]活动如何影响行为和感受
