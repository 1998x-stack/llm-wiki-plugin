# 语义记忆

## 概述
[[Hermes Agent]] 通过 MEMORY.md 存储的环境客观事实层，包含运行环境、项目约定、经验教训和里程碑记录，上限 2,200 字符。

## 关键内容
- **存储内容**：运行环境（OS、已安装工具、Docker 设置）、项目约定（代码风格、构建命令、CI 配置）、学到的工具技巧（SSH 端口特殊、命令需要 sudo）、已完成的重要任务记录、反复纠正的错误
- **存储规格**：文件路径 `~/.hermes/memories/MEMORY.md`，字符上限 2,200（约 800 tokens），典型 8-15 条，会话开始时冻结快照注入 System Prompt
- **呈现格式**：标题行显示用量百分比和字符数（如 `MEMORY [67% — 1,474/2,200 chars]`），条目以 `§`（节符）分隔，支持多行
- **与 USER.md [[区分]]**：关于运行环境的事实存 MEMORY.md，关于用户个人的信息（身份、偏好、技术水平、禁忌）存 USER.md
- **容量分配建议**：运行环境(~400)、主要项目(~800，最多 3-4 个活跃项目)、经验教训(~500)、已完成里程碑(~500)
