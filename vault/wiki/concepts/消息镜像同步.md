# 消息镜像同步

## 概述
将同一 Agent 在多个平台的对话内容镜像同步，实现跨设备无缝切换的机制。

## 关键内容
- **实现模块**：`gateway/mirror.py`，负责跨平台消息同步
- **工作原理**：用户在 Telegram 发送的消息内容，通过 mirror.py 同步到其他已连接平台，使得在 CLI 或其他平台打开时，Agent 已经知道用户在其他平台表达的内容
- **应用场景**：早上通勤用手机 Telegram 提任务 → 到办公室打开 CLI 时 Agent 已了解上下文 → 直接继续工作，无需重复说明
- **与[[会话持久化]]的关系**：[[会话持久化]]维护每个（平台 × 用户）的独立历史；消息镜像同步在此基础上将内容跨平台复制，实现上下文共享
- **与[[跨会话记忆]]的协同**：消息镜像同步是实时的消息级别同步；[[跨会话记忆]]中的 FTS5 按需召回是按需的历史检索，两者互补
- **适用场景**：需要跨设备无缝切换的用户，如移动办公、多设备协作
