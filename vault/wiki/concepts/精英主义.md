# 精英主义

## 概述
精英主义是一种认为社会核心权力应由少数具备卓越能力、知识或财富的精英掌握的政治与社会理论。它并非少数人的阴谋，而是人类社会应对能力差异、组织运行和秩序需求的必然产物。其思想源头可追溯至古希腊[[柏拉图]]的"[[哲学王统治]]"，正式成型于19世纪末20世纪初的意大利学派，后发展为与民主制度相结合的精英民主理论。

## 关键内容

1. **四大产生逻辑**：
   - **能力差异**：人和人的能力天生存在差异，让更专业的人做决策效率更高
   - **组织分层铁律**：任何组织规模超过一定限度后，必然走向少数人掌权的寡头模式（[[寡头统治铁律]]）
   - **对大众民主的警惕**：群体易被煽动、情绪裹挟，需要理性精英把控决策权
   - **历史惯性**：从古希腊到现代，精英统治的逻辑贯穿人类历史

2. **真正对立面**：
   - [[民粹主义]]：权力归属之争——信少数精英 vs 信多数平民
   - [[平等主义]]：[[价值观]]冲突——认可社会分层合理性 vs 追求人人平等
   - [[多元主义]]：权力结构之争——权力集中 vs 权力分散、多方博弈
   - [[人民史观]]：历史观对立——精英创造历史 vs 人民群众创造历史

3. **完整起源脉络**：
   - **思想萌芽期（公元前4世纪-19世纪）**：[[柏拉图]]《理想国》提出[[哲学王统治]] → [[马基雅维利]]《君主论》→ [[尼采]]"超人哲学" → 卡莱尔"英雄崇拜论"
   - **正式成型期（19世纪末-20世纪初）**：[[莫斯卡]]《统治阶级》(1896) → [[帕累托]]《精英的兴衰》(1901，提出[[精英循环理论]]) → [[米歇尔斯]]《[[寡头统治铁律]]》(1911)
   - **转型与发展期（20世纪中叶至今）**：[[熊彼特]]精英民主理论(1940s) → [[权力精英]]实证研究(1950s) → 新精英主义(1970s后，讨论约束精英与民主平衡)

4. **核心评价**：
   - 合理之处：承认能力差异，认可"专业的人做专业的事"
   - 危险之处：精英阶层闭环后垄断资源、固化阶层，从推动力变为撕裂导火索
   - 健康社会需做到：精英对大众负责 + 保留普通人上升通道（精英循环）
