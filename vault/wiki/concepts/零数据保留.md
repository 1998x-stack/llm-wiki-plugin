# 零数据保留（Zero Data Retention / ZDR）

## 概述

零数据保留（ZDR）是 [[Anthropic]] 为企业客户提供的数据隐私协议，确保通过特定 API 功能发送的数据在 API 响应返回后不会被存储，满足合规和隐私要求。

## 关键内容

### 核心承诺

当组织签订 ZDR 协议后：
- 通过符合条件的功能发送的数据**不会在 API 响应后保留**
- 数据仅用于生成即时响应，不进入训练集或日志存储
- 适用于对数据隐私有严格要求的企业场景

### 适用功能

根据 [[Anthropic]] 官方文档，[[上下文压缩]] 功能符合 ZDR 条件。其他符合条件的功能需参考 [[Anthropic]] 官方的 [API 和数据保留文档](https://platform.claude.com/docs/en/build-with-claude/api-and-data-retention)。

### 工程意义

对于使用 [[上下文压缩]] 等长时对话管理功能的企业：
- 可以在不违反数据保留政策的前提下使用[[上下文压缩|服务端压缩]]
- 压缩摘要同样受 ZDR 保护，不会持久化存储
- 这解决了"长对话需要压缩，但压缩内容可能包含敏感信息"的合规困境
