# 软件即意图

## 概述
软件即意图（Software as Intent）是LLM工程长期发展（2028-2030+）的预测阶段，人类通过自然语言、UML或原型表达意图，由意图编译器自动转化为形式化规格并生成软件。

## 关键内容

1. **核心转变**：
   - 当前（Harness 时代）：人类写规格/约束 → Agent 写代码 → CI 验证
   - 未来（Intent 时代）：人类表达意图（自然语言/UML/原型）→ 意图编译器（AI）→ 形式化规格 → 实现 Agent → 验证 Agent → 自动部署
   - 代码变成中间态，不再是人类表达的终点，从写代码转向写意图的最终完成

2. **技术特点**：
   - 意图编译器能够将自然语言、图形化原型等形式的人类意图自动转化为形式化规格
   - 实现Agent根据形式化规格自动生成代码
   - 验证Agent确保生成的代码符合原始意图
   - 自动部署系统无缝集成整个流程

3. **对工程师角色的影响**：
   - 工程师从编码者转变为意图表达者和领域专家
   - 技术专家的稀缺性从"会写代码"转移到"理解复杂系统的因果关系和边界条件"
   - 重点在于如何准确、完整地表达软件系统的意图和约束
