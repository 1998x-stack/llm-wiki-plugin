# 行业色彩情绪映射

## 概述

行业色彩情绪映射是一种将产品类型与色彩方案通过**情绪关键词**对应起来的设计知识编码方式：颜色选择的依据不是「好看」，而是**行业惯例形成的用户信任联觉 + 色彩心理学研究**的结合。

## 关键内容

### 三个核心洞见

1. **行业语境优先于美学偏好**：金融行业用蓝色是因为几十年行业惯例形成了信任联觉，而非蓝色「好看」。
2. **色彩是情绪的触发器**：心理健康应用用薰衣草紫是心理学支撑的——冷紫色调降低焦虑感。
3. **字体配对是层级系统**：标题字体任务是「吸引 + 气质」，正文字体任务是「消失在阅读中」。

### UUPM 的实现方式（colors.csv）

```
product_type   → 161 种类型 1:1 对应 161 套色彩方案
color_mood     → 情绪描述关键词
primary/secondary/cta/background/text  → 完整色值
dark_primary   → 暗色模式变体
notes          → 色彩使用注解（含 WCAG 合规说明）
```

所有方案预先验证 [[WCAG|WCAG 2.1]] AA 级对比度（正文 ≥ 4.5:1，UI 组件 ≥ 3.0:1）。

### 字体配对体系（57 组）

按气质分类，每组包含 [[Google]] Fonts 直链 + CSS import + 字号建议：

| 气质 | 代表配对 | 场景 |
|------|---------|------|
| 权威优雅 | Playfair Display / Source Sans Pro | 金融、法律、医疗 |
| 现代专业 | Inter / Plus Jakarta Sans | SaaS、工具 |
| 奢华精致 | Cormorant Garamond / Montserrat | Spa、高端品牌 |
| 工业极简 | Space Grotesk / DM Sans | 开发者工具、初创 |
| 科幻未来 | Orbitron / Rajdhani | 游戏、科技展示 |

**配对逻辑**：标题用个性强字体（衬线/几何感）对比正文的中性高可读性字体（无衬线），形成层级对比张力。
