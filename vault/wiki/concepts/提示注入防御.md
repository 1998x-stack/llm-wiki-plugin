# 提示注入防御

## 概述
[[Prompt Injection|提示注入]]防御是保护 AI Agent 免受恶意输入操控的安全策略，通过在语义层和系统层建立多重防线，防止 Agent 被外部注入的恶意指令欺骗执行未授权操作。

## 关键内容

1. **攻击场景**：[[Claude Code]] 读取包含恶意指令的文件时，可能被操控尝试：上传项目文件到外部[[服务]]器、修改系统[[Configuration|配置]]、访问其他项目的代码。这类攻击利用 LLM 对输入内容的信任。

2. **[[Claude Code 沙箱机制|沙箱]]维度的防御价值**：即使 [[Claude_Code|Claude]] 被注入指令欺骗，[[Claude Code 沙箱机制|沙箱]]的系统级约束仍能阻止危险操作：
   - 网络请求 → 被拦截（目标域名不在白名单）
   - 系统文件修改 → 被拦截（超出文件系统访问范围）
   - 其他项目访问 → 被拦截（文件系统隔离限制）

3. **[[纵深防御]]中的位置**：[[Prompt Injection|提示注入]]防御是[[纵深防御]]体系中的重要一环。语义层分类器可识别可疑意图，[[Claude Code 沙箱机制|沙箱]]层提供硬性系统约束，两者结合确保即使语义层失效，系统层仍能兜底。

4. **与传统 Web 安全的类比**：类似 Web 安全中的 CSP（Content Security Policy）和[[Claude Code 沙箱机制|沙箱]] iframe，不信任输入内容，通过执行环境约束限制恶意代码的影响范围。
