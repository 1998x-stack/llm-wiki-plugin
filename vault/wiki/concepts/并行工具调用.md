# 并行工具调用

## 概述
并行工具调用是 Anthropic Claude API 的一项高级功能，允许模型在单次响应中同时发起多个独立的工具调用，而非顺序执行，从而显著降低 Agent 系统的延迟。

## 关键内容

1. **延迟优化**：原本需要 N 次网络往返的操作现在只需 1 次——对于多步骤任务，延迟可降低 50-80%。例如查询多个城市天气时，不再需要逐个查询后汇总。

2. **自动依赖判断**：Claude 会分析工具调用之间是否存在依赖关系，自动决定并行或顺序执行。独立查询（如不同城市天气、不同产品价格）可并行；依赖查询（如先搜索用户 ID，再用 ID 查询详情）必须顺序执行。这种判断是模型层面的推理，不需要开发者显式声明依赖关系。

3. **工具链构建**：结合并行工具调用和顺序依赖，Claude 可以自动构建复杂的工具调用图。例如分析股票时，Step 1 并行获取多只股票和指数数据，Step 2 依赖 Step 1 结果计算相关性，Step 3 综合生成报告。

4. **性能权衡**：并行工具调用节省延迟，但每个工具调用都有网络开销。对于快速、轻量级的工具，顺序调用可能总延迟更低（避免并行协调开销）。
