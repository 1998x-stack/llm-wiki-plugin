# Documentation Writer Agent

## 概述
Documentation [[Write]]r Agent 是一个专门负责创建 API 文档、用户指南和架构文档的技术写作子代理。

## 关键内容
1. **主要职责**：
   - 创建清晰、完整的文档
   - 分析要记录的代码或功能
   - 确定目标读者
   - 按项目规范编写文档
   - 根据实际代码验证文档准确性

2. **文档类型**：
   - 带示例的 API 文档
   - 用户指南和教程
   - 架构文档
   - Changelog 条目
   - 代码注释改进

3. **文档标准**：
   - 清晰 - 使用简单、明确的语言
   - 示例 - 包含实用的代码示例
   - 完整 - 覆盖所有参数和返回值
   - 结构 - 使用一致的格式
   - 准确 - 根据实际代码验证
