# 可行系统模型（VSM）

## 概述
Stafford Beer 于 1972 年在《企业的大脑》中提出的可行系统模型：任何能在变化环境中存活的系统都必须具备五层递归嵌套的控制结构，每层本身也必须是一个完整的可行系统。

## 关键内容

1. **历史背景**：1960-70 年代大型组织复杂性空前增长，传统层级管理反应太慢。Beer 发现运筹学的局限：真正的管理问题不是"如何优化已知系统"，而是"如何设计一个能在未知环境中存活的系统"。

2. **五层结构**：
   - System 1：运营单元（执行层）
   - System 2：协调机制（防振荡）
   - System 3：内部控制（资源分配）
   - System 4：战略智能（环境扫描与规划）
   - System 5：政策制定（身份与方向）

3. **核心原理**：递归原理——每个子单元本身也是一个可行系统。多样性工程——通过吸收、放大、传递多样性来匹配环境复杂性。

4. **Cybersyn 项目**：Beer 将 [[向量空间模型|VSM]] 应用于智利 Allende 政府的经济管理，是控制论在国家级管理中的首次大规模实践。
