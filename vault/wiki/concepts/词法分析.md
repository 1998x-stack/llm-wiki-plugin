# 词法分析

## 概述
词法分析是编译器的第一阶段，负责将源代码字符流转换为 Token 序列，为后续[[语法分析]]提供结构化输入。

## 关键内容

1. **核心职责**：词法分析器（Lexer）读取源代码字符流，识别关键字、标识符、运算符、字面量等词法单元，输出 Token 序列供[[语法分析]]器使用。

2. **[[接口规范|接口定义]]关键性**：在[[并行 Agent 开发]]中，Agent-Lexer 和 Agent-[[语法分析|Parser]] 对 Token 结构的假设不同是常见的接口冲突来源，必须在[[接口规范]]文件中明确定义 Token 数据结构。

3. **与[[语法分析]]的关系**：词法分析是[[语法分析]]的前置阶段，两者通过 Token 流接口连接，Token 结构的一致性直接影响编译器的正确性。

4. **AI 并行开发挑战**：在 [[Anthropic]] 的 [[C 编译器]]实验中，词法分析器由独立的 Agent-Lexer 实现，需要在开始前确认已读取架构师 Agent 生成的[[接口规范]]。
