# CO-STAR Framework

## 概述
CO-STAR 框架是一种系统性的 Prompt 设计方法论，提供了一个结构化的方式来构建高质量的提示词，以获得更准确、更有用的AI模型输出。

## 关键内容

1. **框架构成**：
   - **C**ontext（背景）：设定场景，告诉模型它的角色或当前情境
   - **O**bjective（目标）：明确指出你希望模型完成的具体任务
   - **S**tyle（风格）：指定输出的文体、语调或专业程度
   - **T**one（语气）：定义输出的情感色彩或态度
   - **A**udience（受众）：确定目标读者群体
   - **R**esponse（输出）：规定输出的格式、长度或结构

2. **应用场景**：
   - 商业文档撰写
   - 创意内容生成
   - 技术问题解答
   - 学术研究辅助
   - 个性化内容定制

3. **优势特点**：
   - 结构化设计，便于记忆和应用
   - 覆盖了Prompt设计的关键要素
   - 提高了AI输出的一致性和质量
   - 降低了与AI沟通的模糊性
