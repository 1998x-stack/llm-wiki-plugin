# 工具错误处理

## 概述
工具错误处理是 Claude API 支持的新工具结果格式，允许工具返回结构化错误信息（含 `is_error` 标志），使模型能够根据错误类型自适应调整策略。

## 关键内容

1. **错误结果格式**：新的工具结果格式支持 `is_error: true` 标志和描述性错误内容。例如 API 限流时返回 `"API rate limit exceeded. Retry after 60 seconds."`，Claude 可据此理解错误性质。

2. **自适应策略**：Claude 会根据错误类型调整后续行为——等待后重试（如限流错误）、使用备用工具（如主数据源不可用时）、或告知用户（如权限不足等不可恢复错误）。

3. **与错误复合的关系**：工具错误处理直接影响 [[错误复合]] 的风险——如果工具错误未被正确标记和处理，可能导致后续工具调用基于错误前提执行，产生复合错误链。

4. **验证循环模式**：工具调用 → 检查结果 → 决定是否重试，构成基本的验证循环。这与工具组合模式中的验证循环一致，是构建可靠 Agent 系统的基础模式。
