# 剩余价值

## 概述 (50-200字符)
马克思在《[[资本论]]》中揭示的利润来源：工人创造的超过其工资等价物的价值被资本家无偿占有，是利润、利息、地租的共同来源。

## 关键内容 (≥300字符, 用[[双链]])
1. **产生机制**：工人一天工作8小时，前4小时创造等于自己工资的价值（**必要劳动时间**），后4小时继续劳动但价值被资本家无偿占有（**剩余劳动时间**）。被占有的价值即剩余价值。
2. **量化表达**：工人劳动一天产生100元价值，工资50元（必要劳动等价物），资本家获得50元剩余价值。剩余价值率 = 50/50 = 100%。
3. **理论核心**：资本家并非因"聪明""勤劳"或"冒险"而获利，而是因为对工人劳动力的系统性剥削。**剥削不是市场失灵，而是资本主义的正常运作**。
4. **与[[劳动价值论]]的关系**：继承李嘉图的劳动价值论——商品价值由社会必要劳动时间决定。剩余价值是劳动价值论在资本主义条件下的必然推论。
5. **在[[资本论]]中的地位**：是马克思回答"资本主义利润从哪里来"的核心答案，也是理解[[商品拜物教]]和[[异化]]的经济学基础。
