# 通信系统模型

## 概述

通信系统模型是 Shannon (1948) 提出的五组件抽象框架：信源 → 编码器 → 信道（含噪声）→ 解码器 → 信宿，同时涵盖电报、电话、无线电、人类语言交流等所有形式的通信。

## 关键内容

### 五组件

```
信源 → 编码器 → 信道 → 解码器 → 信宿
         ↑                          ↑
     (发送方)       噪声        (接收方)
```

1. **信源（Source）**：产生消息的实体
2. **编码器（Encoder）**：将消息转换为适合传输的信号
3. **信道（[[channel|Channel]]）**：传输信号的媒介，可能引入噪声
4. **解码器（Decoder）**：从接收到的信号恢复消息
5. **信宿（Destination）**：接收消息的实体

### 普适性

这一模型的简洁性和普适性是惊人的——它同时涵盖了电报、电话、无线电、人类语言交流、神经信号传导等所有形式的通信。

### 与语义的分离

Shannon 在论文开篇就指出，通信问题的**语义方面是不相关的**——通信系统的设计应该处理的是符号的准确传输，而非符号的意义。这一立场直接继承了 Hartley 的认识论突破。
