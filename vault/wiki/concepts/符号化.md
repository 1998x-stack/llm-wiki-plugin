# 符号化

## 概述
[[弗洛伊德]][[梦理论]]中梦的四种伪装机制之一，指某些普遍性象征符号在梦中代表特定含义。

## 关键内容
1. **基本定义**：
   - 某些普遍性象征符号在梦中代表特定含义
   - 梦的四种伪装机制之一
   - [[弗洛伊德]]认为许多符号具有跨文化的普遍性

2. **常见符号**：
   - 细长的物体（手杖、塔）= 男性生殖器
   - 箱子、洞穴 = 女性生殖器
   - 飞翔 = 性欲的升华
   - 牙齿脱落 = 阉割恐惧或对死亡的焦虑

3. **争议性**：
   - 这部分是[[弗洛伊德]]理论中争议最大的
   - 对某些象征的普遍性存在学术争论
   - 不同文化背景可能存在不同理解

4. **理论意义**：
   - 为梦境解析提供符号参照体系
   - 帮助理解梦境的隐含意义
   - 是连接[[显梦]]与[[隐梦]]的桥梁之一
