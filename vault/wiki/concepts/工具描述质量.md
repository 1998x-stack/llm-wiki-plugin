# 工具描述质量

## 概述
工具描述质量指 Agent 系统中工具（Tool）接口文档的完整性、清晰度和准确性，直接影响 Agent 能否正确选择、调用和配合工具完成任务。

## 关键内容

1. **核心影响维度**：工具描述质量决定 Agent 是否知道何时使用该工具、是否了解正确的参数格式、是否理解工具的限制和边界情况、是否能将工具与其他工具正确配合。糟糕的工具描述会导致错误的工具选择、参数格式错误导致调用失败、Agent 绕过有用工具的"死路"探索。

2. **自包含性要求**：好的工具描述应包含目的陈述（1-2 句话）、使用示例（典型调用的具体例子）、边缘情况（已知的特殊情形及处理方式）、输入格式要求（期望的数据类型、格式、约束）、与其他工具的边界（何时用这个工具而非类似工具）。

3. **避免功能重叠**：工具集的常见失败模式是功能相似的工具过多，Agent 无法确定使用哪个。判断标准：如果有经验的人类工程师也无法立即判断应该用哪个工具，那 Agent 也无法。这是 [[ACI 设计原则]] 中"明确职责边界"的具体体现。

4. **量化影响**：[[Anthropic]] 的实践表明，经过 AI 辅助优化的工具描述可使后续 Agent 任务完成时间减少 **40%**，证明了投资工具描述质量的高 ROI。这一发现与 [[SWE-bench]] 评测中 [[Claude_Code|Claude]] 使用绝对路径而非相对路径的经验一致。
