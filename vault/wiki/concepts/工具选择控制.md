# 工具选择控制

## 概述
工具选择控制是 Claude API 的 `tool_choice` 参数功能，允许开发者精确控制模型何时使用工具、使用哪些工具，或完全禁用工具调用。

## 关键内容

1. **四种控制模式**：
   - `auto`（默认）：让 Claude 自行决定是否使用工具
   - `any`：强制 Claude 使用至少一个工具
   - `tool` + `name`：强制使用特定工具，如确保 Agent 总是将计划写入文件（`save_plan`）
   - `none`：完全不使用工具，即使定义了工具

2. **强制使用特定工具的应用场景**：确保 Agent 总是将计划写入文件；确保格式化输出通过专用工具完成，避免直接文本输出的格式不一致。

3. **禁用工具的价值**：在对话的特定阶段只需要文本响应时使用；降低成本——工具定义消耗 token，禁用时可节省。这是 [[Token 资源管理]] 的重要优化策略。

4. **与并行工具调用的协同**：工具选择控制可与 [[并行工具调用]] 结合使用，在不需要工具的步骤跳过工具定义，在需要时精确指定工具集合。
