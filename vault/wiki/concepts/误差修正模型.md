# 误差修正模型

## 概述
误差修正模型(Error Correction Model, ECM)是体现变量间长期均衡关系与短期动态调整过程的计量经济学模型。

## 关键内容

1. **理论基础**：
   - 基于Granger表示定理：如果变量之间存在协整关系，那么一定存在一个误差修正表示
   - 模型表达：变量的短期变动 = 对长期均衡偏离的修正 + 其他短期冲击

2. **数学形式**：
   - 假设Y_t和X_t是协整的，则：ΔY_t = α(Y_{t-1} - βX_{t-1}) + 短期动态项 + ε_t
   - 括号中的Y_{t-1} - βX_{t-1}是上一期对长期均衡的偏离("误差")
   - 系数α(必须为负数)衡量系统纠正偏离的速度

3. **经济意义**：
   - 描述了变量偏离长期均衡后的调整机制
   - 体现了经济系统内在的稳定力量
   - 允许短期波动与长期均衡并存
