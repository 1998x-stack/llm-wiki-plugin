# Humans steer. Agents execute.

## 概述
"Human steer. [[Agents]] execute." 是 [[OpenAI]] 提出的 AI 时代软件工程核心哲学，强调人在 AI 辅助开发过程中负责战略决策和引导方向，而 AI Agent 负责具体执行任务。

## 关键内容

1. **核心理念**：
   - 人负责掌舵（steer）：制定方向、设定目标、做出关键决策
   - Agent 负责执行（execute）：具体实现、[[代码生成]]、任务执行
   - 体现了人机协作的新模式，而非完全替代

2. **应用实践**：
   - 工程师不再直接写代码，而是设计运行环境
   - 构建反馈回路，让 Agent 能够自我验证和修正
   - 将架构约束编码成可执行规则，让 Agent 遵循规范

3. **演变过程**：
   - 传统模式：人编写代码，AI 提供辅助建议
   - 新模式：人设计环境和规则，AI 负责生成符合规范的代码
   - 强调了 [[Harness-Engineering|Harness Engineering]] 的重要性
