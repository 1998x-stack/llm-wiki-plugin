# 外化进度追踪

## 概述
外化进度追踪是 [[Agent Harness模式|Agent Harness]] 设计中的核心实践，使用文件系统作为外部记忆，通过结构化的进度文件（如 claude-progress.txt 和 features.json）实现跨会话的状态传递和任务协调。

## 关键内容

1. **核心文件结构**：
   - **claude-progress.txt**：
     - 已完成的任务列表
     - 当前进行中的任务
     - 下一步计划
     - 关键决策和约束背景
     - 已知问题和阻塞点
   - **features.json**：
     - 功能列表及各自状态
     - 每个功能的完成标准
     - 功能间的依赖关系

2. **设计原则**：
   - 文件系统作为单一真相源（Single Source of Truth）
   - 不依赖 Agent 的对话历史来维护状态
   - 每个执行步骤结束后必须更新进度文件
   - 进度文件应包含足够的上下文，使新实例能无缝继续

3. **与 [[外化工作记忆]] 的关系**：
   - 外化进度追踪是 [[外化工作记忆]] 概念在长时任务中的具体实现
   - 通过持久化存储减轻模型对内部上下文记忆的负担
   - 使 Agent 可以专注于当前推理，而非全局状态管理

4. **与 [[Session 交接机制]] 的对比**：
   - 两者都使用文件外部化状态
   - 外化进度追踪更细粒度，专注于任务级别的进度
   - [[Session 交接机制]]更宏观，关注跨会话的知识传递
