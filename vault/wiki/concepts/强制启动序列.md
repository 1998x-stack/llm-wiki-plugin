# 强制启动序列

## 概述

强制启动序列是 [[Ralph Loop 系统]]中每个编码 Agent 实例启动后必须按顺序执行的 7 步初始化流程，确保 Agent 在充分了解项目状态和环境正常的情况下才开始开发工作。

## 关键内容

1. **确认工作目录**：`pwd && ls -la`，验证当前在正确的项目根目录。
2. **查看最近 Git 历史**：`git log --oneline -8`，了解最近的代码变更轨迹。
3. **读取交班日记**：`cat progress.txt`，了解上一个 Agent 实例完成的工作、遇到的问题、下一步建议。
4. **加载经验手册**：`cat AGENTS.md`，读取[[项目约定手册|项目约定]]、已知坑点、历史经验。
5. **查找最高优先级未完成任务**：通过 [[Python]] 脚本解析 `prd.json`，按 priority 排序找出 pending 的 Story，输出前 5 个待办并标记当前要处理的 Story。
6. **启动开发环境**：`bash init.sh`，启动开发[[服务]]器并等待就绪信号。
7. **冒烟测试**：`curl -s http://localhost:[PORT]` 验证当前代码库是可运行状态，如果冒烟测试失败则先修复再开发新功能。
