# Machine Payments

## 概述
Machine Payments是指机器之间直接进行的支付交易，无需人类干预，是[[Agentic Commerce]]的基础技术。

## 关键内容
1. **自动支付**：允许API、[[服务]]和AI Agent之间自动完成小额支付，无需注册、无需API Key。

2. **支付方式**：支持多种支付手段，包括稳定币（USDC.e）、传统银行卡、闪电网络、Solana等区块链支付。

3. **应用场景**：适用于API调用付费、数据访问费用、AI[[服务]]计费等微支付场景。
