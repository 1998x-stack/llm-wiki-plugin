# 代码执行

## 概述
AI Agent 通过 [[MCP]] 等协议在安全隔离环境中运行代码的能力，使 Agent 从"描述解决方案"跃迁为"直接执行验证"，是 Agent 走向生产可用的关键能力。

## 关键内容

1. **从"描述"到"实践"的跃迁**：
   - 无代码执行的 Agent 只能用语言描述"你可以用 Python 的 pandas 库读取 CSV..."
   - 有代码执行的 Agent 直接编写并运行代码，返回实际执行结果
   - 区别不仅是便利——代码执行允许 Agent 处理大规模数据，用结果验证推理而非依赖语言描述

2. **代码作为工具的独特性**：
   - **无限组合性**：代码可以组合任意逻辑，不受预定义工具集限制
   - **自验证性**：代码执行结果是直接的事实反馈，无需人工验证
   - **精确性**：消除了语言描述可能带来的歧义和模糊性

3. **问题解决策略的改变**：
   - **数据分析**：Agent 直接执行分析、展示实际结果、根据结果迭代改进方向
   - **假设验证**：写测试代码验证 API 实际行为，结果确定无疑而非基于文档推断
   - **批量处理**：直接编写并执行批量处理脚本，而非给出手动操作步骤

4. **效率提升量化**：
   - 无代码执行：用户 → 描述 → 用户测试 → 反馈错误 → 修正 → 再测试（3-5 轮）
   - 有代码执行：用户 → 执行验证 → 直接修正（1-2 轮）
   - 将"语言准确性"转化为"逻辑准确性"，代码执行结果是绝对确定的

5. **最佳实践**：
   - 明确告知 Agent 可以执行代码、说明可用库、指明输入数据位置和期望输出格式
   - 始终在[[安全沙箱]]中执行，不允许直接文件系统写入（除沙箱目录外）
   - 对超时和内存设置合理限制，审查涉及外部系统的代码
   - 代码执行与文件读写工具组合极为强大：读取文件 → 代码处理 → 写入结果

6. **与 [[MCP]] 的集成**：
   - 通过 [[MCP]] 提供安全的代码执行服务器
   - 工具定义示例：`execute_python`，支持 numpy、pandas、matplotlib 等预安装库
   - 最大执行时间通常限制 30 秒，无网络访问
