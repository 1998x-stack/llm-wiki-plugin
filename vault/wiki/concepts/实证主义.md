# 实证主义

## 概述 (50-200字符)
实证主义是[[奥古斯特·孔德|孔德]]提出的知识哲学立场，主张所有有效知识必须来自感官经验和观察，科学的目标是发现规律而非追问本质。

## 关键内容 (≥300字符, 用[[双链]])
1. **观察优先**：所有有效知识必须来自感官经验和观察，拒绝神学和形而上学的超验解释。[[奥古斯特·孔德]]将这一原则作为[[实证哲学教程]]的核心主张。
2. **规律追求**：科学的目标是发现现象之间的规律（定律），而非追问"原因"或"本质"。这一立场深刻影响了后来的逻辑实证主义（维也纳学派）。
3. **预测能力**：真正的科学知识使预测成为可能——"知道为了预见"（savoir pour prévoir），预见的最终目标是行动。
4. **价值中立**：科学描述"是什么"，而非"应当是什么"。这一主张成为20世纪[[社会学]]中定量研究传统的哲学基础。
5. **四种方法**：[[奥古斯特·孔德|孔德]]提出[[社会学]]应使用观察、实验（包括自然实验如病理现象）、比较（跨文化、跨物种）、历史方法（研究社会演变）。
6. **历史影响**：实证主义深刻影响了[[涂尔干]]的[[社会学]]方法准则、逻辑实证主义、以及当代大学里的问卷调查和统计回归分析传统。
