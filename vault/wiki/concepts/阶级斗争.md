# 阶级斗争

## 概述 (50-200字符)
马克思的核心历史命题："至今一切社会的历史都是阶级斗争的历史"，在资本主义社会简化为资产阶级与无产阶级的对立。

## 关键内容 (≥300字符, 用[[双链]])
1. **核心命题**：《[[共产党宣言]]》开篇即宣告："至今一切社会的历史都是阶级斗争的历史。"在资本主义社会，这场斗争的两个主角极度简化为：[[资产阶级]]（资本家，拥有工厂、机器、土地）与[[无产阶级]]（工人，只拥有自己的劳动力）。
2. **阶级定义**：阶级的身份由与生产资料的关系决定。资产阶级已经取代了封建贵族，成为新的统治阶级。国家是阶级统治的工具——"现代的国家政权不过是管理整个资产阶级的共同事务的委员会"。
3. **历史动力学**：资产阶级摧毁了封建关系、解放了生产力，但同时也制造了自己的掘墓人。无产阶级越来越集中、越来越有组织，当矛盾激化到极点，革命将把生产资料公有化，阶级本身将最终消亡。
4. **与[[历史唯物主义]]的关系**：阶级斗争是生产力与生产关系矛盾的社会表现形式。当生产力的发展与现存生产关系产生矛盾时，阶级斗争激化为革命，推动社会形态跃迁。
