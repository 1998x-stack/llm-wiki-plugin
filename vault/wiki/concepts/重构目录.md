# 重构目录

## 概述
[[重构]]目录是 [[Martin Fowler]]《[[重构]]》（第2版）中的一份精选[[重构]]手法集合，为开发者提供了改善现有代码设计的具体方法。

## 关键内容

1. **使用方法**：
   - 识别代码中的异味（坏味道）
   - 查找对应的[[重构]]手法
   - 按照步骤执行
   - 每步完成后进行测试

2. **核心[[重构|重构技术]]**：
   - [[Extract Method]]（[[Extract Method|提取方法]]）
   - [[Inline Method]]（[[Inline Method|内联方法]]）
   - [[Extract Variable]]（[[Extract Variable|提取变量]]）
   - [[Inline Variable]]（[[Inline Variable|内联变量]]）
   - [[Rename Variable]]（[[Rename Variable|重命名变量]]）
   - [[Change Function Declaration]]（变更函数声明）
   - [[Encapsulate Variable]]（[[Encapsulate Variable|封装变量]]）
   - [[Introduce Parameter Object]]（[[Introduce Parameter Object|引入参数对象]]）
   - [[Combine Functions into Class]]（[[Combine Functions into Class|组合函数到类]]）
   - [[Split Phase]]（[[Split Phase|分割阶段]]）

3. **异味到[[重构]]的映射**：
   - [[长函数]] → [[Extract Method]]、[[Replace Temp with Query]]
   - [[重复代码]] → [[Extract Method]]、[[Pull Up Method]]、Form Template Method
   - [[大类]] → [[Extract Class]]、Extract Subclass
   - [[Feature Envy]] → [[Move Method]]、[[Move Field]]
   - [[基础类型沉迷]] → [[Replace Primitive with Object]]、Replace Type Code with Class
   - [[长参数列表]] → [[Introduce Parameter Object]]、Preserve Whole Object
   - [[数据泥团]] → [[Extract Class]]、[[Introduce Parameter Object]]
   - [[switch语句]] → [[Replace Conditional with Polymorphism]]
   - [[臆想泛化]] → Collapse Hierarchy、Inline Class、Remove [[死代码|Dead Code]]
   - [[死代码]] → Remove [[死代码|Dead Code]]

4. **实施策略**：
   - 分阶段推进：快速收益→结构改进→架构改动
   - 阶段A：快速收益（低风险，高价值）- [[Rename Variable|重命名变量]]、提取[[重复代码]]、删除[[死代码]]
   - 阶段B：结构改进（中风险）- 从[[长函数]][[Extract Method|提取方法]]、[[Introduce Parameter Object|引入参数对象]]、[[Move Method|移动方法]]
   - 阶段C：架构改动（高风险）- 用多态替代条件分支、[[Extract Class|提取类]]、引入设计模式

5. **安全准则**：
   - 修改 → 测试 → 通过？→ 提交 → 下一步
   - 每次只做一个小改动
   - 保持改动最小化
   - 保证测试始终通过

6. **高级[[重构|重构技术]]**：
   - [[Move Method]]（[[Move Method|移动方法]]）
   - [[Move Field]]（[[Move Field|移动字段]]）
   - [[Replace Primitive with Object]]（[[Replace Primitive with Object|用对象替换原语]]）
   - [[Replace Temp with Query]]（[[Replace Temp with Query|用查询替换临时变量]]）
   - [[Decompose Conditional]]（[[Decompose Conditional|分解条件]]）
   - [[Consolidate Conditional Expression]]（[[Consolidate Conditional Expression|合并条件表达式]]）
   - [[Replace Nested Conditional with Guard Clauses]]（[[Replace Nested Conditional with Guard Clauses|用卫句替换嵌套条件]]）
   - [[Replace Conditional with Polymorphism]]（[[Replace Conditional with Polymorphism|用多态替换条件]]）
   - [[Introduce Special Case]]（[[Introduce Special Case|引入特例]]）
