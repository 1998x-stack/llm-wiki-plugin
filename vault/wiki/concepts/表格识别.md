# 表格识别

## 概述

表格识别（Table Recognition）是将 PDF 中的表格还原为结构化数据（如 Markdown 表格）的技术，核心挑战在于从仅靠线条暗示的单元格边界中还原完整表格结构。

## 关键内容

### 在 PDF 解析中的挑战

- PDF 表格的单元格边界仅靠线条暗示，没有语义结构信息
- 复杂表格包含合并单元格、嵌套表头、跨行跨列等结构
- 需要检测表格位置（布局检测）→ 识别表格结构（表格识别）→ 输出结构化表格

### TableMaster 方案

[[TableMaster]] 是 [[MinerU]] 第四层流水线中的表格识别引擎：
- 接收布局检测输出的表格检测框
- 输出结构化的 Markdown 表格
- 支持复杂表格结构（合并单元格、嵌套表头等）
