# 凝缩

## 概述
[[弗洛伊德]][[梦理论]]中梦的四种伪装机制之一，指多个[[无意识]]想法、人物或愿望被压缩进一个单一的梦中意象。

## 关键内容
1. **基本定义**：
   - 多个[[无意识]]想法、人物或愿望被压缩进单一梦中意象的过程
   - 梦的四种伪装机制之一
   - 使梦的内容更加密集和浓缩

2. **工作方式**：
   - 将多种心理内容整合为一个象征
   - 通过压缩减少被[[压抑]]内容的暴露风险
   - 使梦的内容更难被[[意识]]直接理解

3. **实例**：
   - 梦见一个人的脸是父亲的，但说话方式是老师的，穿着是老板的
   - 这个人物可能代表多个权威形象，体现对权威的复杂情感

4. **理论意义**：
   - 揭示梦境内容的多重象征意义
   - 解释梦境中复杂象征的形成机制
   - 帮助分析师解读梦的真实含义
