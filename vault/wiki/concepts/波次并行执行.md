# 波次并行执行

## 概述
波次并行执行（[[Wave Execution]]）是 GSD 系统中的一种任务并行执行策略，通过分析计划文件间的依赖关系构建有向无环图（DAG），将可并行的计划放入同一"波次"进行批量执行。

## 关键内容

1. **核心机制**：
   - 分析 PLAN 文件间的依赖关系，构建 DAG
   - 将可并行的计划放入同一"波次"（Wave）
   - 按波次顺序执行，每个波次内的计划并行运行

2. **执行流程示例**：
   ```
   WAVE 1（并行）              WAVE 2（并行）          WAVE 3
   ┌──────────┐ ┌──────────┐  ┌──────────┐ ┌──────┐  ┌──────────┐
   │ Plan 01  │ │ Plan 02  │→ │ Plan 03  │ │ P04  │→ │ Plan 05  │
   │User Model│ │Prod Model│  │Orders API│ │CartAPI│  │ Checkout │
   └──────────┘ └──────────┘  └──────────┘ └──────┘  └──────────┘
   ```

3. **优势**：
   - 垂直切片比水平切片并行度高得多
   - 按功能端到端切分的计划，各模块之间相互独立，可以完全并行
   - 相比按技术层次切分的计划，避免了严格的顺序执行限制

4. **实现原理**：
   - DAG 依赖分析确保任务执行顺序正确
   - 同一波次内的任务真正实现了并行处理
   - 减少了整体执行时间
