# 跨会话记忆

## 概述
AI Agent 在多次对话会话间持久化存储和召回知识的能力，使 Agent 记住环境、[[项目约定手册|项目约定]]和用户偏好。

## 关键内容
- **核心能力**：跨[[会话持久化]]记忆，使 Agent 在下次交互时能"认识你"，记住之前的环境[[Configuration|配置]]、[[项目约定手册|项目约定]]和用户偏好
- **技术实现**：基于 [[SQLite]] + FTS5（全文检索）实现持久化存储，结合 LLM 摘要进行智能召回
- **与传统对比**：传统聊天机器人每次对话后清空状态，跨会话记忆是核心设计目标而非附加功能
- **个性化方式**：自动构建跨会话用户模型，而非依赖手动编写 System Prompt
- **在闭环中的角色**：与 [[Honcho]] 用户建模、[[Skills|Skill]] 创建、FTS5 召回协同工作，构成[[闭环学习系统]]的基础设施
- **应用场景**：跨设备知识助手（手机发任务→云端 VM 执行→手机收结果，全程保持上下文连贯）
- **FTS5 架构**：sessions 表存储 id、created_at、platform、session_key、messages（JSON）、summary（LLM 摘要），FTS5 虚拟表对消息内容建立全文索引；Agent 按需触发搜索，辅助 LLM 对结果摘要精炼后注入上下文
- **方案优势**：相比全部历史进 Prompt（Token 爆炸）和固定数量最近消息（丢失早期上下文），FTS5 按需召回只在需要时加载，精确相关，成本可控
