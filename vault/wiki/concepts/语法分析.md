# 语法分析

## 概述
语法分析是编译器的第二阶段，负责将 Token 序列转换为抽象语法树（AST），验证源代码是否符合语言的语法规则。

## 关键内容

1. **核心职责**：语法分析器（Parser）接收词法分析器输出的 Token 序列，根据语言的语法规则构建抽象语法树（AST），识别程序的结构层次。

2. **接口冲突来源**：在并行 Agent 开发中，Agent-Parser 和 Agent-Semantic 对 AST 节点格式的理解出现分歧是常见的集成问题，这些不一致只在集成测试时才暴露。

3. **任务分解粒度**："实现 Parser"这类任务过大，并行 Agent 难以协调，需要按子功能进一步细分（如表达式解析、声明解析、语句解析）。

4. **测试先行实践**：在并行开发前，先由一个 Agent 为语法分析器编写完整的接口测试，测试本身成为接口规范的可执行版本。
