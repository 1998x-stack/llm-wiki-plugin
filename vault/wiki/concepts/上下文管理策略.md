# 上下文管理策略（Context Management Strategy）

## 概述
上下文管理策略是 [[Claude Code]] 中用于控制 [[上下文窗口]] 内容积累的一系列命令和技巧，包括主动清理、子 Agent 隔离和经验法则。

## 关键内容

1. **`/clear` 命令**：在不相关任务之间完全重置上下文，清除所有对话历史。适用于从一个任务切换到另一个完全无关的任务时，避免前一个任务的上下文污染。

2. **`/compact <指令>` 命令**：自定义压缩，将对话历史压缩为摘要并保留聚焦指令。例如 `/compact 聚焦在 API 变更上` 告诉 Claude 压缩时应保留哪些关键信息。详见 [[上下文压缩（Context Compaction）]]。

3. **`Esc+Esc` 或 `/rewind` 命令**：恢复到之前的检查点，回滚到对话的某个历史状态。适用于发现当前对话方向错误、需要回到干净状态时。详见 [[Checkpoints 与 Rewind]]。

4. **`/btw` 命令**：侧边问题——不进入对话历史，不消耗上下文。适用于询问简短的附带问题而不影响主任务的上下文。

5. **子 Agent 隔离**：当探索导致 Claude 读取大量文件时，用子 Agent 隔离探索上下文。子 Agent 在独立上下文中探索代码库，只将摘要返回给主对话，详见 [[子 Agent 模式（Sub-Agent Pattern）]]。

6. **经验法则**：
   - 同一问题纠错 2 次以上 → 清理上下文，重写更精确的 prompt
   - 探索导致 Claude 读取大量文件 → 用子 Agent 隔离探索上下文

7. **策略选择指南**：
   | 场景 | 推荐策略 |
   |------|---------|
   | 切换到无关任务 | `/clear` |
   | 需要保留核心信息但释放空间 | `/compact` |
   | 发现对话走入错误方向 | `/rewind` |
   | 附带小问题 | `/btw` |
   | 大量文件探索 | 子 Agent 隔离 |
