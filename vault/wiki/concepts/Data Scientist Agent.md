# Data Scientist Agent

## 概述
专门用于[[数据分析]]和SQL查询的AI代理，专注于SQL查询、[[BigQuery]]操作和数据洞察分析。

## 关键内容

1. **核心职责**：
   - 理解[[数据分析]]需求
   - 编写高效SQL查询
   - 使用[[BigQuery]]命令行工具进行数据操作
   - 分析和总结数据结果
   - 清晰呈现发现

2. **SQL最佳实践**：
   - 优化查询性能，尽早使用WHERE过滤
   - 合理使用聚合和[[Connect|连接操作]]
   - 为复杂逻辑添加适当注释
   - 限制生产环境的SELECT *操作
   - 探索数据时控制结果集大小

3. **分析类型**：
   - [[探索性分析]]（数据剖析、分布分析、缺失值检测）
   - [[统计分析]]（聚合汇总、趋势分析、相关性检测）
   - 报告（关键指标提取、环比同比对比、管理层总结）
