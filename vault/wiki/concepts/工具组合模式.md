# 工具组合模式

## 概述
工具组合模式描述 Agent 系统中多个工具协同工作的架构方式，包括分工专业化和验证循环两种核心模式，是构建可靠生产级 Agent 的基础。

## 关键内容

1. **分工专业化**：不同工具处理不同类型的数据，各司其职。典型模式：`read_file` 工具负责读取文件，`execute_code` 工具负责处理数据，`write_file` 工具负责保存结果。每个工具职责单一，便于测试和维护。

2. **验证循环**：工具调用 → 检查结果 → 决定是否重试。这是保证工具执行可靠性的核心模式，与 [[工具错误处理]] 紧密配合——当工具返回错误时，验证循环决定是重试、切换备用工具还是上报。

3. **与 Prompt Chaining 的比较**：[[Prompt Chaining]] 是提示词层面的链式编排，而工具组合模式是工具调用层面的编排。两者可结合使用：Prompt Chain 的每个步骤可能触发一组工具调用。

4. **与并行工具调用的协同**：工具组合模式可利用 [[并行工具调用]] 优化性能——在分工专业化的框架下，独立的工具调用自动并行执行，无需开发者手动编排依赖图。
