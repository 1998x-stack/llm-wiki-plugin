# 终止机制

## 概述
终止机制是 [[Claude Code]] 中用于正确结束 Agent 执行的策略，避免无效或危险的循环行为。

## 关键内容
1. **反模式 1：任意迭代上限**：
   - 问题：while iteration < MAX_ITER，任务可能在第8次迭代就完成，也可能需要50次
   - 结果：固定上限要么过早截断，要么浪费

2. **反模式 2：自然语言终止判断**：
   - 问题：if "任务完成" in response.text，LLM 可能用不同措辞表达完成，也可能错误地声称完成

3. **反模式 3：无终止条件**：
   - 问题：while True 忘记检查 has_tool_calls，模型返回纯文本时无法停止，造成无限循环

4. **正确做法**：
   - 使用程序性检查：if not response.has_tool_calls
   - 确定性自然终止：当无工具调用时返回纯文本响应
   - 避免任意硬编码的迭代限制
