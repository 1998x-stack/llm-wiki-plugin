# 先广后深搜索策略

## 概述
先广后深搜索策略是一种信息检索方法，模仿专家人类研究者的行为，先用短而宽泛的查询探索全局，评估可用信息后再逐步缩小焦点。

## 关键内容

1. **问题背景**：Anthropic 发现 Agent 默认倾向于使用过于具体的查询，导致返回结果少，信息覆盖不足。

2. **策略设计**：
   - **第一阶段（广）**：使用短、宽泛查询探索全局信息
   - **第二阶段（评估）**：评估可用信息的分布和质量
   - **第三阶段（深）**：逐步缩小焦点，进行针对性深入搜索

3. **在 Prompt 中的实现**：在 Prompt 中引导 Agent 模仿专家人类研究者的行为模式，而非直接给出具体查询指令。

4. **与动态 RAG 的关系**：先广后深是动态 RAG 系统中的核心搜索策略，支持在搜索过程中根据新发现动态调整方向。

5. **效果**：相比直接使用具体查询，先广后深策略能发现更多相关信息，减少遗漏重要信息源的风险。
