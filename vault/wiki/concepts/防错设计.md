# 防错设计

## 概述
防错设计（Poka-yoke）是一种通过接口设计使常见错误在结构上不可能发生的设计方法论，在 Agent 工具设计中表现为使用具体类型、枚举值和绝对路径等手段减少调用错误。

## 关键内容

1. **核心原则**：通过接口设计使常见错误在结构上不可能发生。具体手段包括：使用具体类型而非宽泛的字符串（如用 Date 类型而非自由格式字符串）、提供枚举值而非自由文本（限制选择范围）、要求绝对路径而非相对路径（避免路径解析错误）。

2. **在 Agent 工具设计中的应用**：防错设计是提升 [[工具描述质量]] 的具体方法。当工具接口本身限制了错误可能性时，即使工具描述不够完善，Agent 也不容易犯错。这与 [[ACI 设计原则]] 中"减少认知负担"的原则一致。

3. **实践案例**：Claude 在 [[SWE-bench]] 上的经验表明，要求绝对路径而非相对路径可以显著减少文件操作错误。这是防错设计在代码编辑工具中的典型应用——通过强制使用绝对路径，消除了相对路径解析带来的歧义。

4. **与工具描述的关系**：防错设计和工具描述质量是互补的。防错设计从接口层面预防错误，工具描述从文档层面指导正确使用。两者结合可以最大化 Agent 的工具使用成功率。Anthropic 的实践表明，这种结合能使任务完成时间减少 40%。
