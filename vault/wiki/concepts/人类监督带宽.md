# 人类监督带宽

TUI 设计的核心哲学——**Agent 的执行速度远超人类审阅速度，因此界面必须在关键决策点精确呈现恰好需要的上下文**，让人类能在 2 秒内做出正确判断。

## 概述

人类监督带宽是 Agent 交互设计的约束条件：不是展示所有信息，而是在每个决策点提供最精简但充分的上下文，最大化人类单位时间内的有效监督决策数量。

## 设计三原则

1. **最小化审批摩擦**：常见的安全操作自动放行，不浪费人类注意力
2. **最大化审批信息**：危险操作展示完整 diff + 命令意图，确保决策质量
3. **可逆性优先**：所有 session 有 transcript，所有文件改动可 git 回滚，降低决策压力

## 不确定性应对矩阵

| 不确定性来源 | 应对设计 |
|-------------|---------|
| Agent 执行了什么，我不知道 | 实时展示每个 tool call 和其输出 |
| 我不知道 Agent 要改哪些文件 | diff 预览在审批前可见 |
| Agent 误操作了，想撤销 | Session resume + git 快照回溯 |
| 多个任务并行，状态混乱 | `/title` 命名 session，parallel session 面板 |
| 不知道 Agent 用的什么模型 | `/status` 实时展示[[Configuration|配置]]摘要 |
| Draft 写了一半，意外关闭 | Draft history 自动保存，Up/Down 恢复 |

## 与渐进式披露的关系

人类监督带宽是 [[渐进式披露（Progressive Disclosure）]] 在 Agent 系统中的具体应用：默认展示最少信息，用户需要时按需展开细节（diff、命令历史、Agent 树）。
