# 多智能体编排

## 概述
多智能体编排（[[Multi-Agent Orchestration]]）是 GSD 系统中的核心架构模式，采用主会话作为编排者协调多个[[Subagents-in-Claude-Code|子智能体]]执行专业任务的模式，避免主上下文被历史信息污染。

## 关键内容

1. **架构模式**：
   - **主会话（编排者）**：轻量，不做重型工作，协调顺序、等待、整合结果
   - **[[Subagents-in-Claude-Code|子智能体]]（专家执行者）**：各自拥有独立的干净 200k 上下文，深度专注于单一专业任务

2. **核心优势**：
   - 主会话上下文保持在 30-40%，不会被历史垃圾污染
   - [[Subagents-in-Claude-Code|子智能体]]拥有干净的全量 200k token，无需处理历史信息
   - 任务完成即退出，不积累历史垃圾
   - 并行执行多个专业任务

3. **工作流程**：
   - 主会话分析任务依赖关系
   - 将任务分发给专业[[Subagents-in-Claude-Code|子智能体]]
   - [[Subagents-in-Claude-Code|子智能体]]在独立上下文中完成任务
   - 主会话收集结果并整合

4. **GSD 实现**：
   - 每个[[Subagents-in-Claude-Code|子智能体]]拿到的是干净的全量 200k token，而非被历史垃圾污染的上下文
   - 主会话只负责协调和整合，不执行重型任务
   - 与[[波次并行执行]]结合，实现高效的并行处理
