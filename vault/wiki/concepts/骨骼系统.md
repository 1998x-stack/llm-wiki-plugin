# 骨骼系统

## 概述
[[UrhoX引擎|UrhoX]] 骨骼系统由 Skeleton 和 Bone 两个类构成，定义角色的骨架层级结构，驱动蒙皮网格变形，是骨骼动画的数据基础。

## 关键内容

### Skeleton（骨架）
骨架是所有骨骼的容器，通过 [[AnimatedModel骨骼动画模型|AnimatedModel]] 组件访问：

- `GetNumBones()` — 骨骼总数
- `GetRootBone()` — 获取根骨骼
- `GetBone(name/index)` — 按名称或索引查找骨骼
- `GetBoneIndex(name/bone)` — 获取骨骼的索引
- `GetBoneParent(bone)` — 获取父骨骼

### Bone（骨骼）
每根骨骼包含变换信息和碰撞体积：

| 属性 | 说明 |
|------|------|
| `name` / `nameHash` | 骨骼标识 |
| `parentIndex` | 父骨骼索引 |
| `initialPosition/Rotation/Scale` | 绑定姿势变换（世界空间） |
| `offsetMatrix` | 蒙皮偏移[[矩阵]]（[[矩阵|Matrix]]3x4） |
| `animated` | 是否受动画驱动（false 则固定） |
| `node` | 关联的场景节点（Node*），可直接操作变换 |
| `collisionMask` | 碰撞掩码，用于布娃娃物理 |
| `radius` / `boundingBox` | 碰撞体积定义 |

### 骨骼节点操作
每根骨骼对应一个 Node，可通过 `bone.node` 访问并手动修改变换，实现程序化动画（[[逆向运动学|IK]]、布娃娃等）。

### 在动画混合中的作用
[[动画状态|AnimationState]] 的 `startBone` 属性指定动画影响的骨骼子树起点，配合骨骼系统实现上下半身独立动画混合。
