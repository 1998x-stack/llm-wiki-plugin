# 主动性Agent

## 概述
AI Agent的进化方向，体现了从被动工具到主动执行再到常驻守护者的演进路径。不再是简单的"更好的问答机器"，而是"持续存在的数字协作者"，代表人机协作模式的根本变革。

## 关键内容
1. **三阶段演进**：
   - 阶段1：工具（被动）- 用户问→AI答
   - 阶段2：Agent（主动执行）- 用户请求→AI规划→AI执行
   - 阶段3：守护者（常驻主动）- AI持续监控→[[KAIROS|合适时机]]主动行动
2. **常驻守护进程模式**：如[[KAIROS]]所体现，Agent具备持续监控能力，在检测到[[KAIROS|合适时机]]时主动采取行动。
3. **主动整合机制**：如[[AutoDream]]睡眠整合守护进程，能够自主整理和归纳信息。
4. **人机协作变革**：下一代AI产品不是功能增强的问答机器，而是具备持续存在和协作能力的数字伙伴。
