# 性能审查

## 概述
性能审查是[[代码审查]]中的重要环节，旨在识别和解决可能导致系统性能下降的代码问题。

## 关键内容

1. **[[算法]]效率**：
   - 进行 Big O 复杂度分析
   - 评估时间复杂度和空间复杂度
   - 识别可能导致性能瓶颈的[[算法]]
   - 推荐更高效的[[算法]]替代方案

2. **资源优化**：
   - 内存使用优化评估
   - 识别内存泄漏的潜在风险
   - 检查对象创建和销毁的最佳实践
   - 评估[[垃圾回收]]的影响

3. **数据库优化**：
   - 数据库查询效率分析
   - 索引使用情况检查
   - 查询计划评估
   - 识别 N+1 查询问题

4. **缓存策略**：
   - 识别合适的缓存机会
   - 评估缓存命中率
   - 检查缓存失效策略
   - 验证缓存一致性

5. **并发问题**：
   - 检查线程安全问题
   - 识别死锁和竞态条件
   - 评估锁的使用效率
   - 确保并发处理的正确性
