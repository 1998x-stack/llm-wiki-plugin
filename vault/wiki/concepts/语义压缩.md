# 语义压缩

## 概述
语义压缩是一种保留语义可理解性的[[有损压缩]]方法，通过删除语言冗余成分（助词、冠词、系动词）来降低 token 消耗，同时保持 AI 对内容的理解能力。

## 关键内容
- **核心思想**：保留英语的语义可理解性，但激进地删除冗余成分，利用 LLM 对自然语言缩写的强泛化能力
- **与[[有损压缩]]的区别**：传统[[有损压缩]]可能丢失信息，语义压缩删除的是"冗余"而非"信息"——被删除的助词、冠词等不承载核心语义
- **与无损压缩的关系**：AAAK 声称在语义层面实现"无损压缩"——所有核心事实（决策者、决策原因、执行者、截止时间）都被保留
- **压缩手段**：
  - 去掉助词、冠词、系动词（"The user is using" → `usr>use`）
  - 符号替代高频短语（`>` 表示使用/决定，`[reason]` 表示原因，`@` 表示上下文）
  - [[实体缩写]]（首次建立映射后持续使用缩写）
- **AI 理解成本**：LLM 见过大量速记、代码注释、学术缩写，面对结构化简写时理解成本很低
- **注入机制**：每次 AI Agent 启动时，在 System Prompt 里注入 AAAK 字典说明，Agent 几秒内掌握当前会话的缩写体系
- **应用场景**：Closet 压缩摘要、System Prompt 优化、长期记忆存储、大规模实体积累场景
