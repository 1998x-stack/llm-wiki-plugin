# 上下文窗口经济学

## 概述
[[上下文窗口]]经济学是 [[Claude Code]] 中管理消息历史增长和优化 Token 消耗的策略。

## 关键内容
1. **消息历史增长模型**：
   - 初始状态：用户指令（约100 tokens）
   - 每次工具调用增加：Tool Call 请求（约50 tokens）+ Tool Result 返回（50-2000 tokens）+ System Reminder（约100 tokens）
   - 随任务进行，历史持续增长

2. **压缩机制**：
   - 达到92%上下文阈值时触发 [[Compressor wU2]]
   - 清除旧工具调用输出（优先）
   - 总结早期对话
   - 保留：用户关键指令 + 代码片段 + [[CLAUDE.md]] 规则

3. **Token 消耗优化**：
   - MCP 工具搜索：只加载工具名称（轻量），[[渐进式披露（Progressive Disclosure）|按需加载]]工具 Schema（重）
   - [[Skills]] [[渐进式披露（Progressive Disclosure）|按需加载]]：只加载 [[Skills|Skill]] 描述（轻量），[[渐进式披露（Progressive Disclosure）|按需加载]]完整 [[Skills|Skill]] 内容（重）

4. **优化策略**：
   - 维持上下文精简
   - 避免不必要的历史积累
   - 智能压缩和总结
