# 单元测试

## 概述
单元测试是对软件中最小可测试单元进行检查和验证的方法，通常针对单个函数或类的方法进行测试。

## 关键内容
1. **核心原则**：
   - **独立性**：每个测试应当独立于其他测试运行
   - **快速性**：测试应当能够快速执行
   - **可重复性**：测试在任何环境下应当产生一致结果
   - **专注性**：单个测试只验证一个特定功能或行为

2. **测试框架**：
   - **JavaScript/[[TypeScript]]**：Jest、Vitest、Mocha
   - **[[Python]]**：pytest、unittest
   - **Go**：Go testing/testify
   - **Rust**：Rust test framework

3. **最佳实践**：
   - 测试边界条件和异常情况
   - 使用模拟对象隔离依赖
   - 保持测试代码简洁清晰
   - 持续监控[[测试覆盖率]]
