# 技能自我改进

## 概述
[[Hermes Agent]] 的[[Skills|技能]]在使用过程中发现问题后自动更新 [[SKILL.md 格式规范|SKILL.md]] 的机制，使[[Skills|技能]]文档随使用持续进化而非一次性创建后静止。

## 关键内容
- **改进触发场景 A — 步骤出错**：Agent 执行[[Skills|技能]]某步骤遇到错误，修复后更新 [[SKILL.md 格式规范|SKILL.md]]，在 Pitfalls 中添加已知问题，修正命令，版本号递增
- **改进触发场景 B — 发现更好方法**：执行任务时发现更简单的命令可替代多个步骤，Agent 更新[[Skills|技能]]简化流程，同时更新 Verification 部分
- **改进触发场景 C — 用户纠正**：用户指出错误做法并给出正确方式，Agent 更新[[Skills|技能]]记录正确做法，同时在 [[语义记忆|MEMORY.md]] 记录用户偏好
- **语义化版本管理**：`1.0.0 → 1.0.1` 小修正（错别字、命令参数），`1.0.0 → 1.1.0` 功能改进（新增步骤、更好方法），`1.0.0 → 2.0.0` 重大[[重构]]（流程结构性变化）
- **与[[Skills|技能]]创建的关系**：创建只是开始，自我改进才是[[Skills|技能]]价值的核心——[[Skills|技能]]在使用中不断积累错误经验和优化方案，形成越来越可靠的工作流指南
- **description 字段的关键性**：[[Skills|技能]]被创建后，`description` 是 Level 0 目录中 Agent 看到的唯一信息，决定了下次是否会想到调用该[[Skills|技能]]。好的 description 应精确描述触发条件和使用场景
