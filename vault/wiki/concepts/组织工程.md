# 组织工程

## 概述
组织工程（Organizational Engineering）是LLM工程的第四阶段，重点设计人机协作的整个组织系统，人类专注于目标设定、价值判断、伦理边界和战略方向。

## 关键内容

1. **核心理念**：
   - 组织工程不再局限于设计代码库环境，而是设计整个人机协作的组织系统
   - 人类专注于：目标设定、价值判断、伦理边界、战略方向
   - AI Agent 负责：研究、设计、实现、测试、运维、监控
   - 代表了从"设计代码"→"设计系统"→"设计系统中的规则"→"设计系统中规则的规则"的进一步演进

2. **关键技术预测**：
   - **Agent 编排协议**: 超越 MCP，出现完整的"AI 工作流[[操作系统]]"
   - **形式化验证集成**: Agent 生成代码 → 自动形式化证明正确性
   - **自适应约束**: 约束系统根据项目演进自动调整
   - **跨组织 Agent 市场**: 专业领域 Agent 作为"API [[服务]]"被订阅
   - **Harness OS**: 专为 AI-native 开发团队设计的[[操作系统]]级工具链

3. **驱动问题**：
   - Agent 系统的目标对齐（Alignment at Scale）
   - [[子 Agent 系统|多 Agent 系统]]的不可解释性（Interpretability）
   - AI 产出的知识产权与责任归属
   - 人类[[Skills|技能]]退化与核心竞争力重建
