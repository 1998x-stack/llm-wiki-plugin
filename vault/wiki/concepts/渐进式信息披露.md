# 渐进式信息披露

## 概述
渐进式信息披露是一种信息架构设计原则，通过[[渐进式披露（Progressive Disclosure）|按需加载]]而非一次性提供全部信息，降低[[上下文窗口]]压力，提升AI Agent处理效率。

## 关键内容

1. **核心理念**：
   - 避免一次性将所有文档塞给AI Agent
   - 根据当前任务[[渐进式披露（Progressive Disclosure）|按需加载]]相关信息
   - 将信息供给从"一次性灌入"变为"按需拉取"

2. **实现策略**：
   - **结构化组织**：使用docs/目录按主题组织文档（如[[OpenAI]]实践）
   - **[[Skills|技能]]机制**：如[[Claude Code]]的skills机制，[[Skills|技能]]描述仅占用少量token，需要时才加载完整内容
   - **模块化设计**：将信息分解为独立、可重用的模块
   - **[[渐进式披露（Progressive Disclosure）|按需加载]]**：Agent根据当前任务需求加载相应文档

3. **优势**：
   - 大幅降低[[上下文窗口]]的压力
   - 提高AI Agent处理效率
   - 减少无关信息干扰
   - 更好的[[可维护性]]
   - 避免[[信息过载]]导致的决策质量下降
   - 支持更复杂和长篇的开发任务

4. **在[[Harness-Engineering|Harness Engineering]]中的应用**：
   - 作为Harness框架的关键设计模式之一
   - 在[[Harness分层架构]]中的具体实现
   - 支持Agent在复杂项目中的高效运作
   - 优化资源利用和响应时间
