# 记忆工具

## 概述
[[Hermes Agent]] 管理 [[语义记忆|MEMORY.md]] 的内置工具，支持 add、replace、remove 三种操作，采用子字符串匹配实现鲁棒的条目管理。

## 关键内容
- **三种操作**：`add` 添加新条目、`replace` 替换现有条目（子字符串匹配，无需完整内容）、`remove` 删除过期条目
- **子字符串匹配设计**：完整条目可能经过多次修改，原始内容不再准确。子字符串匹配只需提供唯一标识片段，更鲁棒；若匹配到多条则返回错误要求更精确
- **自动触发**：Agent 自动在发现新环境事实、学到[[项目约定手册|项目约定]]、被用户纠正、完成重要里程碑时保存记忆，无需用户提醒
- **显式触发**：用户可直接要求"记住 X"来手动添加记忆条目
- **容量管理**：[[语义记忆|MEMORY.md]] 上限 2,200 字符，满时返回错误提示当前用量和条目列表，Agent 需先 replace 合并或 remove 删除后再 add
- **好的条目特征**：信息密集、可操作、具体、有动作指导意义；避免模糊、冗长、可随时搜索到的事实
- **条目打包策略**：将多个相关事实打包进一条，如[[操作系统]] + 工具链 + Shell + 编辑器 + [[Python]] 版本合并为一条环境记录
