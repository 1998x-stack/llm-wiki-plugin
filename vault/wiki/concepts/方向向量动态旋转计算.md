# 方向向量动态旋转计算

## 概述
从移动方向向量动态推算旋转四元数（Yaw + Pitch分解），使Slerp插值始终走最短路径，是避免硬编码四元数导致旋转反向的根本解法。

## 关键内容

### 核心思想
**不要为每个离散方向硬编码四元数**，而是用数学函数（`atan2`）从方向向量连续推算旋转，保证目标四元数的连续性，让Slerp自然选择最短路径。

### 标准模式（Lua/UrhoX Y-up坐标系）
```lua
-- 在每帧或方向变化时调用
if currentDirection:Length() > 0.01 then
    -- 1. 用 atan2 计算水平偏航角（Yaw）
    local yaw = math.atan2(currentDirection.x, currentDirection.z)

    -- 2. 构造 Yaw 旋转（绕 Y 轴）
    local yawRot = Quaternion(yaw * 57.2958, Vector3(0, 1, 0))  -- rad→deg

    -- 3. 添加模型特定的 Pitch 修正（如圆锥尖端朝前需要 +90°）
    local tiltRot = Quaternion(90, Vector3(1, 0, 0))

    -- 4. 组合旋转
    targetRotation = yawRot * tiltRot
end

-- Slerp 插值（路径始终最短）
local newRot = node:GetRotation():Slerp(targetRotation, speed * dt)
node:SetRotation(newRot)
```

### 为什么能解决问题
- `atan2` 输出连续角度（-π 到 π），方向微小变化对应角度微小变化
- 连续的 Yaw 角度 → 连续的目标四元数 → Slerp 点积始终为正 → 始终走短路径

### 旋转分解原则
将复杂旋转分解为独立轴的旋转再组合，便于理解和调试：
- **Yaw**（偏航）：绕 Y 轴，控制水平朝向
- **Pitch**（俯仰）：绕 X 轴，控制模型倾斜（如圆锥尖端方向修正）
- **Roll**（翻滚）：绕 Z 轴，通常不需要

### 三种朝向方案对比
| 方案 | 适用场景 | 代码 |
|------|---------|------|
| `LookAt` | 引擎支持时首选 | `node:LookAt(pos, Vector3.UP)` |
| atan2动态计算 | 本文方案，通用 | `atan2(dir.x, dir.z)` → Quaternion |
| `LookRotation` | 引擎支持时可用 | `Quaternion.LookRotation(dir, up)` |

### 调试技巧
1. 打印欧拉角（比四元数直观）：`node:GetRotation():EulerAngles()`
2. 使用 `URHO3D_LOGINFO` 记录每帧旋转值，对比预期
3. 可视化方向向量（Debug[[Renderer渲染器|Renderer]]箭头）
