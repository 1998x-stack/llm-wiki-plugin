# 彩虹部署

## 概述
彩虹部署（Rainbow Deployments）是一种部署策略，新旧版本同时运行，流量逐步从旧版本转移到新版本，避免中断运行中的有状态 Agent。

## 关键内容

1. **解决的问题**：Agent 系统是高度有状态的 Prompt + 工具 + 执行逻辑的网络，几乎持续运行。代码更新时，Agent 可能处于流程中的任意位置，传统部署会中断运行中的 Agent。

2. **工作原理**：
   - 新旧版本同时运行
   - 流量逐步从旧版本转移到新版本
   - 避免中断正在执行任务的 Agent

3. **在 Anthropic Research 系统中的应用**：多 Agent 研究系统需要长时间运行，使用彩虹部署确保在代码更新时不会中断正在进行的研究任务。

4. **与传统部署的对比**：
   - 传统蓝绿部署：切换是瞬时的，会中断有状态任务
   - 彩虹部署：渐进式迁移，允许有状态任务在新旧版本间平滑过渡
