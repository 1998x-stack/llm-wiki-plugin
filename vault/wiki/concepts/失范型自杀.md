# 失范型自杀

## 概述 (50-200字符)
[[涂尔干]]自杀类型之一，因道德规范过低导致——社会规范断裂，个体欲望失去约束，欲望无边界导致永远不满足和精神崩溃。

## 关键内容 (≥300字符, 用[[双链]])
1. **原因**：道德规范过低——社会规范断裂，个体欲望失去约束。这正是[[失范]]概念在自杀领域的具体体现。
2. **案例依据**：[[涂尔干]]在《[[自杀论]]》中证明：经济繁荣时期和经济崩溃时期自杀率均上升（两者都是正常秩序的打破）；离婚率高的地区自杀率高。
3. **心理状态**：欲望无边界→永远不满足→精神崩溃。当社会规范缺位时，个体的欲望失去边界和调节，导致持续的不满足感和精神痛苦。
4. **在四类型中的位置**：属于规范维度过低的一端。与[[宿命型自杀]]（规范过高）形成对照。[[涂尔干]]的四种自杀类型基于两个维度：社会整合（integration）和道德规范（regulation）。
