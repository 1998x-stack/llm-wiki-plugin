# 属性动画

## 概述
属性动画是 [[UrhoX引擎|UrhoX]] 中对任意对象属性进行关键帧驱动的动画系统，由 ObjectAnimation 和 ValueAnimation 两个类组成，与骨骼动画系统独立，可驱动材质颜色、位置、透明度等任意属性。

## 关键内容

### ObjectAnimation（对象动画容器）
ObjectAnimation 是多个属性动画轨道的集合，继承自 Resource：

- `AddAttributeAnimation(name, valueAnimation, wrapMode, speed)` — 注册一条属性轨道
- `RemoveAttributeAnimation(name/anim)` — 移除轨道
- `GetAttributeAnimation(name)` — 获取指定轨道
- `GetAttributeAnimationWrapMode(name)` — 查询循环模式（WrapMode）
- `GetAttributeAnimationSpeed(name)` — 查询播放速度

### ValueAnimation（数值动画轨道）
ValueAnimation 定义单个属性的关键帧曲线，继承自 Resource：

| 方法/属性 | 说明 |
|-----------|------|
| `interpolationMethod` | 插值方式（InterpMethod：线性、样条等） |
| `splineTension` | 样条张力（Catmull-Rom 等） |
| `valueType` | 属性值类型（[[Hal Varian|Varian]]tType） |
| `SetKeyFrame(time, value)` | 添加关键帧 |
| `SetEventFrame(time, eventType, data)` | 在指定时间触发事件 |

### WrapMode 循环策略
通过 `AddAttributeAnimation` 的第三个参数设置：
- `WM_LOOP` — 循环（默认）
- `WM_ONCE` — 播放一次
- `WM_CLAMP` — 停在终止帧

### 与骨骼动画的区别
- 骨骼动画（Animation/[[动画控制器|AnimationController]]）驱动骨骼变换，面向角色
- 属性动画（ObjectAnimation/ValueAnimation）驱动任意 Serializable 属性，面向场景物件（门、灯光、UI 等）
