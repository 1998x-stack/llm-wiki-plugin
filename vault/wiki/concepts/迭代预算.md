# 迭代预算

## 概述
[[Hermes Agent]] 防止无限循环的安全机制，通过跟踪迭代次数、Token 消耗和工具调用次数，在任一指标超阈值时优雅终止循环。

## 关键内容
- **跟踪指标**：当前迭代次数、总 Token 消耗、工具调用次数 — 三个维度共同约束 Agent 行为
- **终止策略**：当任一指标超出阈值，循环优雅终止并返回当前进度，而非突然中断
- **在[[游戏主循环模式|主循环]]中的角色**：`while not done and iteration < budget` — 预算检查是主执行循环的退出条件之一
- **安全价值**：防止 Agent 因错误逻辑或复杂任务陷入无限循环，消耗大量 Token 和时间
- **与[[上下文压缩]]协同**：Token 消耗跟踪与 `context_compressor.py` 的压缩触发阈值配合，共同管理资源使用
