# 自适应思考（Adaptive Thinking）

## 概述

自适应思考是 [[Claude_Code|Claude]] 模型的一项能力，使模型能动态决定每次请求所需的思考分配，因此实际思考 token 使用量可能因请求而异，而非固定预算。

## 关键内容

### 工作机制

- 思考预算 token 仍是 `max_tokens` 的子集
- 模型根据任务复杂度动态调整思考量
- 简单任务可能只需少量思考，复杂任务则分配更多
- 实际思考 token 使用量因请求而异

### 与固定思考预算的对比

| 维度 | 固定思考预算 | 自适应思考 |
|------|------------|-----------|
| 控制方 | 用户指定 | 模型自主决定 |
| 灵活性 | 低 | 高 |
| 适用场景 | 需要可预测 token 消耗的场景 | 任务复杂度多变的场景 |

### 计费影响

自适应思考 token 仍按输出 token 计费，计入速率限制。
