# 代码生成

## 概述
代码生成是编译器的最后阶段，负责将中间表示（IR）或 AST 转换为目标机器码，包括寄存器分配、指令选择和优化。

## 关键内容

1. **核心职责**：代码生成器（Codegen）将语义分析后的中间表示转换为目标平台的机器码，涉及指令选择、寄存器分配、指令调度等关键任务。

2. **x86-64 代码生成**：在 Anthropic 的 C 编译器实验中，最终实现了基本的 x86-64 代码生成，通过了自定义测试套件约 85% 的测试。

3. **接口依赖**：代码生成阶段依赖语义分析阶段的输出，两者之间的接口必须清晰定义，包括中间表示格式、符号表结构等。

4. **并行开发可行性**：代码生成阶段相对独立，可以与其他编译阶段并行开发，前提是接口规范已在开发前达成一致。
