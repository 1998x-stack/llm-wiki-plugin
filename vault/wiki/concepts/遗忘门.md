# 遗忘门

## 概述
遗忘门是 LSTM 架构中的三个[[门控机制]]之一，用于控制[[记忆细胞]]中有多少旧信息需要被丢弃。遗忘门的输出值在 0 到 1 之间，决定保留多少先前的记忆状态。

## 关键内容
1. **功能机制**：
   - 遗忘门决定[[记忆细胞]]中的信息有多少应该被保留或丢弃
   - 通过 sigmoid 函数[[计算]]输出值（0 表示完全丢弃，1 表示完全保留）
   - 当某个信息已经过时或不再重要时，遗忘门会输出较小的值，将这部分信息"冲走"
   - 如果信息仍然有用，遗忘门会保持较大的值，保护信息不被覆盖

2. **数学表达**：
   - 遗忘门的[[计算]]公式为：fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf)
   - 其中 hₜ₋₁ 是上一时刻的隐藏状态，xₜ 是当前时刻的输入
   - Wf 是遗忘门的权重[[矩阵]]，bf 是偏置项

3. **在 LSTM 中的作用**：
   - 与[[输入门]]和[[输出门]]协同工作，实现选择性记忆
   - 配合[[常误差流（Constant Error Carousel）|常误差流]]（CEC）机制，确保重要的长期信息得以保留
   - 通过精确控制信息的保存与删除，提高 LSTM 对长期依赖的学习能力

4. **历史发展**：
   - 遗忘门的概念最早在 1997 年 Hochreiter 和 Schmidhuber 的 LSTM 论文中提出
   - 2000 年 Gers 等人对该机制进行了重要的改进和补充
   - 现已成为现代 LSTM 的标准[[Configuration|配置]]
