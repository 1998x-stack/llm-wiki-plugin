# 代码审查严重性

## 概述
[[代码审查]]严重性分类是评估和分级代码问题重要程度的标准，帮助开发团队确定修复问题的优先级。

## 关键内容

1. **Critical（严重）**：
   - 可能导致系统崩溃或安全漏洞的问题
   - 数据丢失或损坏风险
   - 需要在合并前立即修复的问题
   - 直接影响核心功能的问题

2. **High（高）**：
   - 影响用户体验但不会导致系统故障的问题
   - 性能问题可能显著影响响应时间
   - 潜在的安全风险
   - 应该在发布前修复的问题

3. **Medium（中等）**：
   - 可能影响[[可维护性|代码维护性]]的问题
   - 潜在的功能问题但有临时解决方案
   - 非关键性能优化机会
   - 可以在下一个版本周期内解决的问题

4. **Low（低）**：
   - 风格或命名约定问题
   - 小的改进建议
   - 不紧急的优化机会
   - 可选的增强建议
