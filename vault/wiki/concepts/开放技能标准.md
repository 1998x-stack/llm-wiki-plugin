# 开放技能标准

## 概述
定义 AI Agent 技能为纯文本 Markdown 文件的开放规范，支持 Git 管理、社区共享和跨平台迁移。

## 关键内容
- **标准定义**：由 [[agentskills.io]] 社区维护的开放规范，[[Agent Skills|Skills]] 是纯文本 Markdown 文件（[[SKILL.md 格式规范|SKILL.md]]）
- **三大特性**：可移植（纯文本、Git 管理）、可共享（[[Agent Skills|Skills]] Hub 社区贡献和安装）、可迁移（支持从 [[OpenClaw]] 一键迁移）
- **技能来源**：传统 Agent 技能由人工编写且固定不变，开放技能标准下技能从成功经验中自动生成并在使用中持续自我改进
- **[[Hermes Agent|Hermes]] 实现**：成功的工作流自动变成 [[SKILL.md 格式规范|SKILL.md]] 文件存入技能库，技能在使用过程中发现不足会自动更新内容
- **迁移工具**：`hermes claw migrate` 支持从 [[OpenClaw]] 交互式完整迁移，`--dry-run` 预览，`--preset user-data` 只迁移用户数据
- **生态价值**：打破供应商锁定，形成开放的技能共享社区，类似 npm/pip 的包管理生态
