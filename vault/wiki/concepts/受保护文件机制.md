# 受保护文件机制

## 概述
[[Evolver]] 中防止自我修改的核心安全机制，通过保护关键源码文件不被进化的代码修改来确保系统的稳定性。

## 关键内容

1. **保护名单**：
   - src/evolve.js, src/gep/solidify.js, src/gep/selector.js
   - src/gep/prompt.js, src/gep/signals.js, src/gep/a2aProtocol.js
   - index.js
   - assets/gep/genes.json, assets/gep/events.jsonl

2. **启用条件**：
   - 当 EVOLVE_ALLOW_SELF_MODIFY=false 时激活（默认值）
   - 检测时机在 solidify.js 执行 FilePatches 之前

3. **风险提示**：
   - EVOLVE_ALLOW_SELF_MODIFY=true 可能导致 [[Evolver]] 引入 Bug 到自身 Prompt 生成逻辑
   - 会造成级联失败，需要人工干预恢复
   - 仅用于受控实验
