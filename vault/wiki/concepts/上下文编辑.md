# 上下文编辑（Context Editing）

## 概述

上下文编辑是 [[Anthropic]] 提供的细粒度[[Context Management|上下文管理]]策略集合，适用于比 [[上下文压缩]] 更专业的需求场景，包括工具结果清除和思考块清除等操作。

## 关键内容

### 策略清单

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| **工具结果清除** | 清除 Agent 工作流中的旧工具结果 | 长时 Agent 会话，工具调用产生大量输出 |
| **思考块清除** | 管理 [[扩展思维]] 产生的思考块 | 需要精细控制思考 token 占用的场景 |

### 与压缩的对比

| 维度 | [[上下文压缩]] | 上下文编辑 |
|------|--------------|-----------|
| 自动化程度 | 服务端自动 | 手动控制 |
| 集成复杂度 | 低 | 中 |
| 控制粒度 | 粗（整段摘要替换） | 细（逐块清除） |
| 适用场景 | 通用长时对话 | 专业需求 |

### 推荐策略

对于长时间运行的对话和 Agent 工作流，[[上下文压缩]] 是主要策略。上下文编辑作为补充手段，用于压缩无法满足的特定控制需求。
