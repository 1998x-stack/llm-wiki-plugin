# 工具注册机制

## 概述
[[Hermes Agent]] 的工具发现和执行分发系统，利用 Python 模块加载机制实现工具在导入时自动注册，无需手工维护工具列表。

## 关键内容
- **注册原理**：工具在导入时通过 `@register_tool` 装饰器自动注册到 `tools/registry.py`，利用 Python 模块加载机制实现自动发现
- **核心功能**：`model_tools.py` 提供 `get_tool_definitions()` 收集所有工具的 JSON Schema 传给 LLM，`handle_function_call(call)` 根据工具名分发执行
- **工具体系**：48 个工具 + 40 个工具集（Toolset），覆盖终端执行 (6)、文件操作 (4)、网络搜索 (4)、浏览器自动化 (11)、代码执行沙盒 (1)、子 Agent 委派 (1)、记忆管理 (1)、[[Agent Skills|Skills]] 管理 (3)、MCP 客户端 (动态)、视觉/图像、语音等
- **工具集系统**：工具集是工具的逻辑集合，支持按需启用/禁用（`hermes tools enable/disable`），在 chat 时通过 `--toolsets` 参数指定
- **典型配置**：通用编程助手 (terminal+file+web)、网络研究 (web+browser)、数据分析 (terminal+file+execute_code)、消息平台 Agent (terminal+skills+memory)、最小化 (skills 仅)
