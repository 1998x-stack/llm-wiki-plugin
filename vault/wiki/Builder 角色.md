# Builder 角色

## 概述
Builder是AI时代互联网人的三种新活法之一，指有极强产品感、能熟练使用Agent、有基本设计直觉的实战派，能把想法从0到1直接做成可上线的功能。

## 关键内容
1. **定义**：能快速做出复杂项目原型，把模糊需求变为清晰可执行prompt的实战派。
2. **核心能力**：不是自己写代码，而是精准给Agent下达指令，快速验证想法能不能跑通。
3. **产品经理转型路径**：立刻开始学用Agent自己做原型、自己验证想法，不用再等研发排期。
4. **研发工程师转型路径**：跳出纯代码执行圈子，补产品感和设计直觉，懂用户要什么、懂业务核心逻辑。
