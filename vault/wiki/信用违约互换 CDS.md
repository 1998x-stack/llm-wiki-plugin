# 信用违约互换 CDS

## 概述
信用违约互换（Credit Default Swap, CDS），既是违约保险也是合法对赌的金融衍生品。买方（空头）每年支付固定保费赌债券违约，卖方（华尔街投行）稳赚保费却忽视巨额赔付风险。迈克尔·伯里等空头通过CDS做空楼市，最终投行签下的CDS合约成为自己的催命符。

## 关键内容
1. **买方逻辑**：每年支付固定保费，一旦房贷债券违约可获得巨额赔付，核心诉求是笃定楼市崩盘
2. **卖方逻辑**：每年稳拿保费视为无风险收益，认为房价永远涨债券不会违约
3. **对赌本质**：空头赌崩盘 vs 投行赌不违约，投行笑着签下给自己准备的催命符
4. **市场盲区**：华尔街完全没意识到卖CDS赌上的是整个公司的身家性命
