# The Perceptron: A Probabilistic Model for Information Storage

## 概述
1958年Frank Rosenblatt提出的感知机模型，是第一个能够学习的神经网络，标志着机器学习的重要开端。

## 关键内容
1. **可学习模型**：感知机是第一个具有学习能力的神经网络模型，能够通过调整权重来学习分类任务。
2. **线性分类器**：实现了线性分类功能，对于线性可分的数据能够找到合适的决策边界。
3. **感知机学习规则**：提出了权值更新的学习算法，奠定了后续神经网络训练的基础。
4. **硬件实现**：最初的感知机有物理实现，被称为Mark I Perceptron。
