# 社会学的想象力

## 概述 (50-200字符)
[[C. 赖特·米尔斯]]1959年出版的[[社会学]]经典著作，批判宏大理论与抽象经验主义，提出在[[个人困扰与公共议题]]间建立联系的思维能力，呼吁公共知识分子责任。

## 关键内容 (≥300字符, 用[[双链]])
1. **双重批判**：[[C. 赖特·米尔斯]]发起两线攻击——批判[[塔尔科特·帕森斯|帕森斯]]"宏大理论"（Grand Theory）为术语迷雾包裹的简单话语，批判拉扎斯菲尔德"抽象经验主义"（Abstracted Empiricism）将[[社会学]]缩减为问卷统计技术而回避真正重要的社会问题。
2. **核心主张**：提出[[社会学的想象力]]——在[[个人困扰与公共议题]]之间建立联系的思维能力。"一个男人失业是[[个人困扰与公共议题|个人困扰]]，但1500万人失业就是[[个人困扰与公共议题|公共议题]]。"当困扰是系统性的，仅凭个人努力无法解决，需要[[社会学]]想象力与政治回应。
3. **三个坐标**：完整的[[社会学]]分析需在历史（现在如何从过去形成）、社会结构（制度关系权力分配）、传记（个体如何生活选择受苦）三维度间自由穿行。理解穷人的生命轨迹不能脱离资本主义历史扩张、当前经济结构及个人机遇选择。
4. **政治责任**：批评冷战背景下美国社会科学[[服务]]于国家和企业权力，呼唤"公共知识分子"——不躲在学院里，用[[社会学]]工具回应[[个人困扰与公共议题|公共议题]]、挑战权力、启蒙公众。后来在布洛维（Michael Burawoy）"公共[[社会学]]"运动中得到系统回应。
5. **与戈夫曼对照**：与[[欧文·戈夫曼]]《[[日常生活中的自我呈现]]》同年（1959）出版，一宏观一批判、一微观一描述，构成完整[[社会学]]视野地图。
