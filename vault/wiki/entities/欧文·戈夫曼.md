# 欧文·戈夫曼

## 概述 (50-200字符)
加拿大裔美国[[社会学]]家（1922–1982），[[芝加哥学派]]传统继承者，被誉为"微观[[社会学]]之父"，以[[戏剧论]]框架分析日常互动中的[[印象管理]]与社会秩序。

## 关键内容 (≥300字符, 用[[双链]])
1. **学术背景**：戈夫曼继承[[社会学]][[芝加哥学派]]的田野观察传统，在苏格兰偏远岛屿社区生活一年获取《[[日常生活中的自我呈现]]》素材，后在精神病院做卧底观察完成《精神病院》。
2. **[[拟剧论]]框架**：提出[[拟剧论]]（dramaturgy），将社会生活比作戏剧——每个互动场合是舞台，社会成员是演员，通过[[印象管理]]维持社会秩序。核心[[区分]][[前台与后台]]：前台是有观众在场、表演符合社会期待行为的区域；后台是观众不在场、演员可以放松准备的区域。
3. **面子与失态**：分析"面子"（face）作为社会秩序的条件——当所有人默契维持彼此面子，互动才能顺畅。失态（embarrassment）发生在表演出错时，旁观者往往自发配合遮掩，揭示深层礼貌机制。
4. **[[污名]]研究**：在《[[污名]]》（*[[污名|Stigma]]*，1963）中将[[戏剧论]]扩展到社会边缘群体，分析被[[污名]]化者在互动中的表演困境，对残障研究、LGBTQ+研究、精神健康[[社会学]]产生深远影响。
5. **理论局限**：去政治化（极少分析权力结构对互动的系统性影响）、行动者过于[[理性化]]、文化普适性问题（东亚"面子"与西方"self-presentation"的差异）。
