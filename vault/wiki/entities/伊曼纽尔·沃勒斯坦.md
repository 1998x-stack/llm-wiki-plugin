# 伊曼纽尔·沃勒斯坦

## 概述
美国[[社会学]]家与历史学家（1930–2019），[[世界体系]]分析创始人，提出[[核心-半边缘-边缘]]的三层结构理论，重新定义全球不平等的历史根源。

## 关键内容
1. **《[[现代世界体系]]》**：1974年出版第一卷，提出资本主义[[世界体系]]自16世纪开始形成，是一个以经济分工为基础的全球性结构。
2. **[[核心-半边缘-边缘]]结构**：[[世界体系]]由三层构成——核心国家（高附加值生产、强国家）、半边缘国家（混合特征）、边缘国家（原材料出口、弱国家），这一框架取代了"第一/第三世界"的二元划分。
3. **[[世界体系]]分析**：主张分析单位应是"[[世界体系]]"而非"民族国家"，这一方法论转向深刻影响了全球化研究。
4. **资本主义的历史扩张**：分析资本主义如何通过殖民主义、不平等交换和军事力量实现全球扩张，将经济史与[[社会学]]深度融合。
