# C. 赖特·米尔斯

## 概述 (50-200字符)
美国[[社会学]]家（1916–1962），批判[[社会学]]先驱，以《[[社会学的想象力]]》闻名，主张在[[个人困扰与公共议题]]之间建立联系，呼吁[[社会学]]家承担公共知识分子责任。

## 关键内容 (≥300字符, 用[[双链]])
1. **学术立场**：米尔斯是[[社会学]]界的"烈马"，同时批评学院派[[社会学]]的脱离现实和保守主义的精英偏见，被主流视为"麻烦制造者"，但被批判[[社会学]]和知识分子圈子奉为英雄。46岁因心脏病去世。
2. **双重批判**：在《[[社会学的想象力]]》（1959）中发起两线攻击——批判[[塔尔科特·帕森斯|帕森斯]]的"宏大理论"（Grand Theory）为语言虚张声势，批判拉扎斯菲尔德的"抽象经验主义"（Abstracted Empiricism）将[[社会学]]缩减为技术操作而回避重要社会问题。
3. **[[社会学的想象力]]**：提出核心概念[[社会学的想象力]]——在[[个人困扰与公共议题]]之间建立联系的思维能力。"一个男人失业是[[个人困扰与公共议题|个人困扰]]，但1500万人失业就是[[个人困扰与公共议题|公共议题]]。"完整分析需在历史、社会结构、传记三个坐标间自由穿行。
4. **政治责任**：批评冷战背景下美国社会科学越来越服务于国家和企业权力，呼唤"公共知识分子"的[[社会学]]家——用[[社会学]]工具回应[[个人困扰与公共议题|公共议题]]、挑战权力、启蒙公众。这一呼唤后来在布洛维（Michael Burawoy）的"公共[[社会学]]"运动中得到系统回应。
5. **与戈夫曼的对照**：1959年与[[欧文·戈夫曼]]同年出版代表作，构成[[社会学]]完整地图——戈夫曼的近焦镜头（微观互动秩序）与米尔斯的广角镜头（宏观历史结构）。
