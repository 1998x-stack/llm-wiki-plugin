# Zsh

## 概述
一个功能强大的命令行shell，兼容bash并提供大量增强功能，常用于Unix和Linux系统。

## 关键内容
1. **特性**：Zsh提供高级脚本功能、更好的自动补全、拼写校正、可定制提示、主题系统、数组和浮点运算等，是bash的增强替代品。
2. **[[Claude Code 插件系统|插件系统]]**：通过[[Oh-My-Zsh]]等框架可以轻松管理和安装插件，提供大量预[[Configuration|配置]]的功能和主题。
3. **兼容性**：完全兼容bash脚本，可以从bash无缝迁移，同时提供更多高级功能和更好的用户体验。
