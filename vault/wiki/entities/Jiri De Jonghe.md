# Jiri De Jonghe

## 概述
Jiri De Jonghe 是 Anthropic 的工程师，参与了 Agent 评测系统工程指南的撰写，是《Demystifying evals for AI agents》一文的合著者。

## 关键内容

1. **在 Anthropic 的工作**：
   - 参与 Agent 评测从零到一的系统工程指南
   - 贡献于评测维护方法和长期质量保障体系的研究

2. **技术贡献**：
   - 参与建立 Agent 评测的长期维护方法论
   - 参与"eval 作为活文档"理念的提出

3. **合作者**：与 Mikaela Grace、Jeremy Hadfield、Rodrigo Olivares 共同完成评测指南的撰写。
