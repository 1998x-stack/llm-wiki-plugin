# 房利美与房地美

## 概述
房利美（Fannie Mae）和房地美（Freddie Mac）是美国房地产市场的两大支柱，有政府背书的机构。它们拿走优质低风险房贷，在次贷危机中因巨额亏损于2008年9月7日被美国政府直接接管，涉及负债超过5万亿美元，被称为"两房"。

## 关键内容
1. **政府背书**：两家机构有美国政府隐性担保，是优质房贷的主要承接方
2. **业务模式**：拿走优质低风险房贷，与华尔街次贷MBS形成市场分层
3. **被接管**：2008年9月7日被美国政府直接接管，负债超5万亿美元
4. **市场地位**：美国房地产市场的两大支柱，接管标志着危机全面爆发
5. **与次贷的关系**：虽然主要做优质贷款，但危机中同样遭受巨额亏损
