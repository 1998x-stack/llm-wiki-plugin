# 黎叔

## 概述
[[TapTap Maker]]（TTM）产品负责人，[[嗒啦啦]]项目核心人物，主张 AI 原生游戏开发工具设计理念，认为 GUI 不适合 AI、应优先为 Agent 设计架构。

## 关键内容

1. **产品设计理念**：GUI 不适合 AI，图形界面是给人用的，AI 更适合直接调接口；产品面向「Agent + 人」双端，优先 [[AI 原生架构]]。给 AI 灌[[Skills|技能]]而非灌知识，[[Skills|技能]] = 游戏品类开发流程的抽象理解。

2. **关键决策**：[[Skills|技能]]库重质不重量，保证不降低 Agent 性能；隐藏代码，普通用户编程不如 AI，专注玩法创意；不自动判断可玩性，走人机共创路线，AI 给方案，人做决定。

3. **竞争判断**：TTM 相比 [[Cursor]] 等通用工具有专业游戏引擎 + 垂直数据 + 开发-发布全闭环优势；相比 Unity 无历史包袱，引擎专为 AI 设计。

4. **行业判断**：不用 AI 的团队很快没优势；长周期重资产项目风险变大；AI 原生新游戏品类会快速出现。
