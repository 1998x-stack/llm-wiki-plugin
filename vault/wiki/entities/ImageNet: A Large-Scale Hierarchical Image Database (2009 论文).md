# ImageNet: A Large-Scale Hierarchical Image Database (2009 论文)

## 概述
介绍 [[ImageNet]] 数据集的论文，该数据集催生了[[计算]]机视觉领域的深度学习革命。

## 关键内容

1. **数据集规模**：包含超过 1400 万张[[标注]]图像，覆盖 2 万多个类别，按 WordNet 层次结构组织。
2. **[[ILSVRC]] 挑战赛**：基于 [[ImageNet]] 的图像分类挑战赛成为评估视觉模型的标准基准，直接催生了 2012 年的 [[AlexNet]] 突破。
3. **数据驱动[[规范化理论|范式]]**：[[ImageNet]] 证明了大规模数据对深度学习的关键作用，确立了"数据 + 算力 + [[算法]]"的 AI 发展[[规范化理论|范式]]。
