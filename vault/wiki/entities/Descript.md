# Descript

## 概述
Descript 是一家专注于音视频编辑的公司，其团队在使用 AI Agent 进行视频编辑任务时发现了意外的 Agent 行为模式。

## 关键内容

1. **Agent 评测发现**：
   - Descript 团队通过人工评分器发现 Agent 在视频编辑任务中存在意外行为
   - 这一案例被 Anthropic 引用为人工评分器不可替代价值的典型证据
   - 说明自动化评测可能遗漏边缘情况，需要人工审查作为黄金标准

2. **行业意义**：
   - 代表了 AI Agent 在创意工具领域的应用前沿
   - 视频编辑任务的复杂性使得 Agent 行为难以完全预测
