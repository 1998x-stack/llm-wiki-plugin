# Dennis Ritchie

## 概述

美国[[计算]]机科学家（1941–2011），[[C 语言]]发明者，[[UNIX|UNIX 操作系统]]的共同创造者。1983年与 [[Ken Thompson]] 共同获得 ACM [[阿兰·图灵|图灵]]奖。

## 关键内容

### C 语言

- 在 B 语言（来源于 BCPL）的基础上设计了 [[C 语言]]
- 增加了类型系统、结构体、指针运算等特性
- 使其既有高级语言的可读性，又有接近汇编语言的底层控制能力
- 与 [[Brian Kernighan]] 合著《[[C 语言|C 程序设计语言]]》（The [[C 语言|C Programming Language]]），成为 [[C 语言]]的权威参考

### UNIX

- 与 [[Ken Thompson]] 共同创造了 [[UNIX|UNIX 操作系统]]
- 1973年用 [[C 语言]]重写了 UNIX 内核——人类历史上第一次用高级语言编写[[操作系统]]内核
- 1974年在 Communications of the ACM 上发表了 [[UNIX 论文]]
- [[C 语言]]本身就是为了编写 UNIX 而发展起来的

### 图灵奖（1983）

与 Thompson 共同获得，授奖理由是"开发通用[[操作系统]]理论，特别是 [[UNIX|UNIX 操作系统]]的实现"。

### 设计哲学

Ritchie 在[[阿兰·图灵|图灵]]奖演讲中讨论了 UNIX 的设计哲学，体现了 UNIX 文化的特征：深刻而不故作高深，实用而不缺乏优雅。

### 名言

> "UNIX 基本上是一个简单的[[操作系统]]，但你需要是个天才才能理解这种简单。"
