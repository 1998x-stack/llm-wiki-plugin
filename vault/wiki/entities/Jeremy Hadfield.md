# Jeremy Hadfield

## 概述
Jeremy Hadfield 是 [[Anthropic]] 的工程师，参与了 Research 功能（多 Agent 研究系统）从原型到生产的开发工作。

## 关键内容

1. **在 [[Anthropic]] 的工作**：
   - 参与 Research 功能的[[多 Agent 系统]]架构设计
   - 负责从原型到生产的完整工程实现
   - 共同撰写了《How we built our multi-agent research system》技术博客

2. **技术贡献**：
   - 多 Agent 研究系统的 [[多Agent架构|Orchestrator-Worker]] 模式设计
   - Prompt 工程策略的制定与优化
   - 生产可靠性挑战的解决方案

3. **合作者**：与 [[Barry Zhang]]、[[Kenneth Lien]]、[[Florian Scholz]]、[[Jeremy Fox]]、[[Daniel Ford]] 共同完成了 Research 功能的开发和技术分享。
