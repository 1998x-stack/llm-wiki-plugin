# Robert C. Martin

## 概述
Robert C. Martin (又称 Uncle Bob) 是著名的软件工程师、作家和技术思想家，以提出 Clean Code 理论和敏捷软件开发原则而闻名。

## 关键内容

1. **Clean Code 运动**：作为 Clean Code 运动的主要倡导者，他撰写了《Clean Code》一书，定义了编写高质量、可维护代码的最佳实践。

2. **SOLID 原则**：推广了面向对象编程的五个基本原则，这些原则已成为现代软件架构的核心概念。

3. **敏捷软件开发**：参与制定了敏捷软件开发宣言，并在敏捷实践中发挥了重要作用。

4. **软件工艺运动**：倡导软件开发作为一种专业工艺，强调开发者对代码质量和专业责任的重要性。

5. **著作贡献**：除了《Clean Code》，他还撰写了《The Clean Coder》、《Clean Architecture》等多部影响深远的技术书籍。
