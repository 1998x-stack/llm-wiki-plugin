# Using Collaborative Filtering to Weave an Information Tapestry 论文

## 概述
1992年发表于《Communications of the ACM》的开创性论文，首次提出了"[[协同过滤]]"概念。该论文介绍了[[Tapestry 系统|Tapestry]]系统，展示了如何利用用户之间的协作来帮助彼此从海量信息中筛选有价值的内容。

## 关键内容
1. **历史意义**：这篇论文是推荐系统领域的起点，首次提出并定义了"[[协同过滤]]"概念。论文定义："[[协同过滤]]的含义很简单：人们通过记录自己对所阅读文档的反应，来协作地帮助彼此进行信息过滤。" 

2. **核心技术**：论文介绍的[[Tapestry 系统|Tapestry]]系统基于一个核心信念："当人类参与到过滤过程中时，信息过滤可以更加有效。" 系统允许用户通过记录对文档的反应（如"Like It!"或"Hate It!"[[标注]]）来进行协作过滤。

3. **应用场景**：[[Tapestry 系统|Tapestry]]系统设计用于处理1992年[[信息过载]]问题，特别是电子邮件、[[Usenet]][[Usenet|新闻组]]文章等电子文档流的过滤。系统通过TQL（[[TQL|Tapestry Query Language]]）查询语言实现内容过滤与[[协同过滤]]的融合。
