# LIGO

## 概述 (50-200字符)
激光干涉[[引力波]]天文台，人类首个直接探测[[引力波]]的大型科学设施，由两台相距三千公里的L形激光干涉仪组成，分别位于华盛顿州汉福德和路易斯安那州利文斯顿。

## 关键内容 (≥300字符, 用[[双链]])
1. **历史沿革**：概念最早可追溯至1972年，[[雷纳·韦斯]]在麻省理工学院提出利用激光干涉术探测[[引力波]]的详细方案，后与[[基普·索恩]]联手推动。经过数十年研发和数十亿美元投入建成。2015年初完成"先进LIGO"升级，灵敏度提升约十倍。
2. **探测原理**：每台探测器由两条互相垂直、各长四公里的真空管臂组成。激光被分光镜分为两束，在末端镜子反射后返回叠加。无[[引力波]]时调节为相消干涉；[[引力波]]经过时一臂伸长一臂缩短，光程差改变产生可检测的干涉条纹移动。
3. **首次探测**：2015年9月14日捕获[[GW150914]]信号，来自两个质量约36倍和29倍太阳质量的[[黑洞]]合并，距地球约十三亿光年。[[信噪比]]达24，虚警率低于每203000年一次，统计显著性超过5.1个标准差。
4. **科学影响**：打开[[引力波]]天文学大门，与[[Virgo探测器]]合作陆续探测数十个事件。[[雷纳·韦斯]]、[[巴里·巴里什]]、[[基普·索恩]]因决定性贡献获2017年诺贝尔物理学奖。
