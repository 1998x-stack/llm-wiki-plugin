# Shaoqing Ren

## 概述
[[计算]]机视觉研究者，[[R-CNN 系列|Faster R-CNN]] 的主要作者之一，提出了区域提议网络（RPN）概念。

## 关键内容

1. **[[Faster R-CNN: Towards Real-Time Object Detection with Region Proposals (2015 论文)|Faster R-CNN 论文]]（2015）**：与 [[Kaiming He]]、[[Ross Girshick]]、Jian Sun 合作发表，提出区域提议网络（RPN），将区域提议与目标检测统一到单个网络中。
2. **RPN 创新**：用神经网络替代传统的选择性搜索[[算法]]，大幅提升了检测速度和精度。
3. **与 [[残差网络（ResNet）|ResNet]] 的关系**：同一团队后续提出 [[残差网络（ResNet）]]，进一步推动了视觉识别的发展。
