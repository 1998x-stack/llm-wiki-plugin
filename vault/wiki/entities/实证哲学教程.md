# 实证哲学教程

## 概述 (50-200字符)
《实证哲学教程》（Cours de philosophie positive），[[奥古斯特·孔德|孔德]]六卷本著作（1830–1842），[[社会学]]诞生的标志文献。

## 关键内容 (≥300字符, 用[[双链]])
1. **出版历程**：共六卷，历时12年完成（1830–1842）。[[奥古斯特·孔德|孔德]]写作方式极为特殊——几乎不读别人的书（称之为"大脑卫生"），完全依靠自己的思维进行体系建构，每卷完成后即交付出版，不作修改。
2. **结构划分**：前三卷（1830–1835）梳理数学、天文学、物理学、化学、生物学五门科学的历史与方法，为[[社会学]]确立知识论地位；后三卷（1835–1842）正式建立[[社会学]]，分为"[[社会静力学]]"与"[[社会动力学]]"两部分。
3. **[[三阶段定律]]**：提出人类知识必然经历[[神学阶段]]→[[形而上学阶段]]→[[实证阶段]]的演进，为进化论思想传统提供社会版本。
4. **[[科学等级体系]]**：构建数学→天文学→物理学→化学→生物学→[[社会学]]的层级，[[社会学]]处于顶端，是"科学之王"。
5. **方法论贡献**：提出[[社会学]]应使用观察、实验、比较、历史方法四种方法，成为后世经验[[社会学]]的哲学基础。
