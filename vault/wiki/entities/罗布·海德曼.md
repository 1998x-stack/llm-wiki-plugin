# 罗布·海德曼

## 概述
澳大利亚统计学家，提出了ETS（Error, Trend, Seasonal）状态空间框架，将[[指数平滑]]从工程技巧提升为具有完整统计理论基础的方法。

## 关键内容

1. **专业领域**：澳大利亚著名统计学家，专注于[[时间序列分析]]和预测方法研究。

2. **主要贡献**：2002年前后提出ETS（Error, Trend, Seasonal）框架，即"误差-趋势-季节性"[[State-Space Model|状态空间模型]]。

3. **理论突破**：证明了每一种[[指数平滑]]方法都对应一个[[State-Space Model|状态空间模型]]，拥有完整的概率分布假设，将[[指数平滑]]从"启发式[[算法]]"提升为"统计方法"。

4. **统一框架**：[[ETS框架]]完成了[[指数平滑]]与[[ARIMA|ARIMA模型]]的理论统一，某些[[指数平滑]]模型恰好等价于特定的[[ARIMA|ARIMA模型]]。

5. **著作影响**：2008年出版专著《Forecasting with [[指数平滑|Exponential Smoothing]]: The State Space Approach》，成为该领域的标准参考。

6. **实际应用**：开发了R语言的forecast包，将[[ETS框架]]推广到实际应用中。
