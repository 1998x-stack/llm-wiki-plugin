# George Box

## 概述
George Edward Pelham Box (1919-2013)，英国统计学家，以与[[Gwilym Jenkins]]共同发展的Box-Jenkins方法论而闻名，该方法论成为[[时间序列分析]]的标准[[规范化理论|范式]]。

## 关键内容
1. **主要贡献**：
   - 与[[Gwilym Jenkins]]共同发展了Box-Jenkins方法论
   - 系统化地发展了[[ARIMA|ARIMA模型]]建模方法（识别、估计、诊断）
   - 为[[时间序列分析]]提供了完整的实用方法论框架
   - 方法论的理论核心基于Wold分解定理

2. **学术影响**：
   - Box-Jenkins方法成为[[时间序列分析]]的标准[[规范化理论|范式]]
   - 影响了现代统计学和计量经济学的发展
   - 为工业界和学术界提供了实用的[[Time Series Analysis|时间序列]]建模工具
