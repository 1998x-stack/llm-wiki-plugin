# 冯·诺依曼

## 概述
[[约翰·冯·诺依曼]]（John von Neumann，1903-1957）是匈牙利裔美国数学家，对现代数学、物理学、经济学和[[计算]]机科学做出了广泛贡献，提出了[[存储程序计算机]]架构。

## 关键内容
1. **生平简介**：
   - 生于1903年，逝于1957年
   - 普林斯顿高等研究院教授
   - 曼哈顿计划的关键参与者

2. **主要贡献**：
   - **[[冯·诺依曼架构]]**：提出了[[存储程序计算机]]的概念，程序和数据一同存储在内存中
   - **博弈论**：与摩根斯特恩合著《博弈论与经济行为》
   - **算子理论**：在泛函分析和算子代数方面的重要工作
   - **[[计算]]机科学**：[[EDVAC报告]]中阐述了现代[[计算]]机的基本架构

3. **与[[Alan Turing|图灵]]的关系**：
   - 在普林斯顿期间与[[Alan Turing|图灵]]是同事
   - 了解[[Alan Turing|图灵]]的工作，受其[[通用图灵机]]概念的影响
   - 1945年发表的[[EDVAC报告]]体现了[[通用图灵机]]的思想

4. **[[计算]]机架构的影响**：
   - [[冯·诺依曼架构]]是现代[[计算]]机的基础
   - 程序和数据统一存储的思想直接对应[[通用图灵机]]的机制
   - 将机器描述和数据一同写在纸带上的概念被工程化实现

5. **跨学科影响**：
   - 在集合论、量子力学、流体力学、气象学等多个领域有重要贡献
   - 被誉为"现代[[计算]]机之父"之一
