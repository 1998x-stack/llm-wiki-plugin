# Florian Scholz

## 概述
Florian Scholz 是 [[Anthropic]] 的工程师，参与了 Research 功能（多 Agent 研究系统）从原型到生产的开发工作。

## 关键内容

1. **在 [[Anthropic]] 的工作**：

2. **技术贡献**：
   - 多 Agent 研究系统的工程实现
   - Prompt 工程策略的制定

3. **合作者**：与 [[Jeremy Hadfield]]、[[Barry Zhang]]、[[Kenneth Lien]]、[[Jeremy Fox]]、[[Daniel Ford]] 共同完成了 Research 功能的开发和技术分享。
