# 丘奇

## 概述
阿隆佐·丘奇（Alonzo Church，1903-1995）是美国数学家和逻辑学家，[[计算理论]]的奠基人之一，提出了[[λ演算]]并独立于[[Alan Turing|图灵]]解决了[[判定问题]]。

## 关键内容
1. **生平简介**：
   - 生于1903年，逝于1995年
   - 普林斯顿大学教授
   - 指导过[[Alan Turing|图灵]]等众多著名学生

2. **主要贡献**：
   - **[[λ演算]]**：1930年代发明的函数抽象与应用的形式系统，是[[函数式编程]]语言的理论基础
   - **[[判定问题]]的解决**：1936年率先使用[[λ演算]]证明了[[判定问题]]的否定回答
   - **丘奇论题**：提出了可[[计算]]性概念的形式化

3. **与[[Alan Turing|图灵]]工作的关系**：
   - 在1936年春天，丘奇率先发表论文使用[[λ演算]]证明[[判定问题]]无解
   - [[Alan Turing|图灵]]几乎同时独立地用[[图灵机]]模型得到了相同结论
   - 两人工作互补：[[Alan Turing|图灵]]的模型更直观，丘奇的系统更抽象

4. **学术影响**：
   - [[λ演算]]对后来的[[计算]]机科学影响深远，特别是[[函数式编程]]语言
   - [[Church-Turing 论题|丘奇-图灵论题]]确立了可[[计算]]性的标准定义
   - 培养了大批[[计算理论]]领域的杰出人才
