# C++

## 概述
C++ 是静态强类型、支持多[[规范化理论|范式]]（面向对象、泛型、过程式）的系统级编程语言，以手动内存管理、零开销抽象和丰富的类型语义（指针、引用、const 修饰）著称。

## 关键内容
1. **类型系统**：[[区分]]值语义（`T`）、引用语义（`T&`、`const T&`）和指针语义（`T*`、`const T*` 等），每种对应不同的所有权与可变性语义。
2. **const 正确性**（const-correctness）：通过 `const` 修饰符在编译期约束对象可变性，是 C++ 设计的核心习惯用法。
3. **零开销抽象**：引用、内联函数、模板等高层抽象不引入运行时开销，编译期展开。
4. **多[[规范化理论|范式]]支持**：面向过程（函数 + 数组）、面向对象（class + 继承 + 多态）、泛型（模板 + STL 容器如 vector/map）共存。
5. **主要标准版本**：C++11（现代 C++ 起点：`auto`、lambda、`std::move`、范围 for）、C++14/17/20/23 持续演进。
6. **入门学习路径**：基本语法（变量/循环/函数）→ 数组/字符串 → 指针与引用 → STL 容器（vector/string/map）→ 类与对象 → 模板/智能指针 → C++11+ 新特性。
