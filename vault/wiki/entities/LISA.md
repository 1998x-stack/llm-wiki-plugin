# LISA

## 概述 (50-200字符)
欧洲空间局主导的空间[[引力波]]探测计划，预计2030年代发射，将在太空中展开数百万公里长的干涉臂，探测超大质量[[黑洞]]合并等低频[[引力波]]源。

## 关键内容 (≥300字符, 用[[双链]])
1. **项目概况**：LISA（Laser Interferometer Space Antenna）是欧洲空间局（ESA）主导的空间[[引力波]]探测任务，预计于2030年代发射。将在太空中部署数百万公里长的干涉臂，远超地面探测器的四公里尺度。
2. **探测目标**：专注于低频[[引力波]]源的探测，包括超大质量[[黑洞]]合并、极端质量比旋进、以及宇宙早期可能产生的随机[[引力波]]背景，这些是地面[[LIGO]]等探测器无法触及的频段。
3. **技术优势**：空间环境消除了地面振动噪声的限制，能够实现比现有地面设备更高的灵敏度。与地面探测器形成互补，覆盖[[引力波]]谱的不同频段。
4. **科学愿景**：将与地面探测器如[[LIGO]]、[[Virgo探测器]]及下一代设备（[[爱因斯坦望远镜]]、宇宙探索者）共同构成多频段[[引力波]]观测网络，推动[[多信使天文学]]向更深层次发展。
