# J. Presper Eckert

## 概述

美国电气工程师（1919–1995），[[ENIAC]] 和 EDVAC 的主要设计者之一。与[[John Mauchly|Mauchly]]共同设计了世界上第一台通用电子数字[[计算]]机 [[ENIAC]]，并在 EDVAC 项目中提出了存储程序的核心硬件概念。

## 关键内容

### ENIAC 设计

- 与 Mauchly 在[[宾夕法尼亚大学]]莫尔电气工程学院共同设计了 [[ENIAC]]（1945年完工）
- [[ENIAC]] 使用了 17,468 根真空管，每秒可完成 5000 次加法运算，比当时任何机电式[[计算]]设备都快上千倍
- 但 [[ENIAC]] 通过物理接线和开关进行"编程"，每次更换任务需要数天甚至数周重新[[Configuration|配置]]线路

### EDVAC 与署名争议

- 在与 von Neumann 的多次讨论中，Eckert 和 Mauchly 围绕 EDVAC 展开了深入的设计探讨
- Eckert 和 Mauchly 认为存储程序的核心概念源自他们在1944年的讨论，von Neumann 是将他们的工程直觉提炼为逻辑框架的人
- 报告以 von Neumann 一人署名分发，直接导致 Eckert 和 Mauchly 后来申请的 EDVAC 专利无法执行
- 这场争议至今仍是[[计算]]机史上最著名的优先权之争之一

### 后续事业

- 离开学术界后，Eckert 和 Mauchly 共同创立了 Eckert-Mauchly Computer Corporation
- 该公司设计了 UNIVAC I——美国第一台商用[[计算]]机
- 公司后来被 Remington Rand 收购
