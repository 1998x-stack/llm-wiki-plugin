# 莫斯卡

## 概述
加埃塔诺·莫斯卡（Gaetano Mosca），意大利学者，[[精英主义|精英理论]]三杰之一。1896年出版《统治阶级》，提出任何社会都必然存在统治阶级（精英）和被统治阶级（大众），所有社会权力永远掌握在统治阶级手中，从未有例外。该书直接奠定了经典[[精英主义|精英理论]]基础。

## 关键内容
1. **核心命题**：任何社会都存在两个阶级——统治阶级（精英）和被统治阶级（大众）
2. **权力垄断论**：所有社会权力永远掌握在统治阶级手里，从来没有例外
3. **代表著作**：《统治阶级》(1896)
4. **历史地位**：与[[帕累托]]、[[米歇尔斯]]并称"[[精英主义|精英理论]]三杰"，其著作标志现代[[精英主义]]正式成为完整理论体系
