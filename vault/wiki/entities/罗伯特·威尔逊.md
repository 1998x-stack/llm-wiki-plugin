# 罗伯特·威尔逊

## 概述 (50-200字符)
罗伯特·威尔逊（Robert Wilson, b. 1936），美国射电天文学家。1965年与[[阿诺·彭齐亚斯]]共同发现[[宇宙微波背景辐射]]，获1978年诺贝尔物理学奖。

## 关键内容 (≥300字符, 用[[双链]])
1. **发现CMB**：1965年，威尔逊与[[阿诺·彭齐亚斯]]在[[贝尔实验室]]新泽西州霍姆德尔站点，使用20英尺喇叭形天线进行射电天文观测时，发现了一个约3.5开尔文的各向同性微波噪声信号。该信号不随方向、季节或时间变化，无处不在且无法消除。
2. **排除干扰**：威尔逊和彭齐亚斯对天线进行了系统性排查，排除了所有已知噪声来源。他们发现一对鸽子在天线内筑巢，鸽子粪便覆盖了天线表面。他们清理并释放了鸽子（鸽子又飞回，最终不得不采取更决绝手段），但神秘信号依然存在。
3. **关键通话**：经伯纳德·伯克建议，彭齐亚斯致电普林斯顿大学的[[罗伯特·迪克]]。迪克[[意识]]到他们发现的正是[[宇宙微波背景辐射]]——宇宙大爆炸的余辉。
4. **极简论文**：威尔逊与彭齐亚斯合著的论文仅约600词，风格极度冷静克制，通篇未出现"大爆炸"三字，仅在最后一段提及迪克等人的理论解释。这种低调描述成为科学史上对诺贝尔奖级发现最克制的表达。
5. **荣誉**：因发现[[宇宙微波背景辐射]]，威尔逊与彭齐亚斯共同获得1978年诺贝尔物理学奖。
