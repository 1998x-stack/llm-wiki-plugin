# React

## 概述
React 是一个用于构建用户界面的 JavaScript 库，被 [[Anthropic]] 的 [[frontend-design Skill]] 支持用于生成高质量的前端界面。

## 关键内容
1. **核心特性**：组件化架构，声明式 UI，虚拟 DOM
2. **生态系统**：支持 [[Tailwind CSS v4|Tailwind]]、Framer Motion 等现代前端工具
3. **与 AI [[Skills|技能]]集成**：与 [[Claude Code]] 的 [[frontend-design Skill]] 紧密集成，用于生成具有独特设计的 React 组件
