# 布莱兹·帕斯卡

## 概述

布莱兹·帕斯卡（1623–1662）是法国数学家、物理学家和哲学家。他以[[帕斯卡三角形]]、流体静力学的帕斯卡定律，以及哲学著作《思想录》闻名。1654年，31岁的帕斯卡与[[皮埃尔·德·费马|费马]]通过书信交流，首次用系统的数学方法解决了赌博中的"[[点数问题]]"，从而开创了[[概率论]]这一独立的数学分支。

## 关键内容

### 生平

- 生卒年：1623–1662（39岁）
- 国籍：法国
- 领域：数学、物理学、哲学
- 代表作：《论算术三角形》（Traité du triangle arithmétique，1665年出版）

### 主要贡献

1. **[[帕斯卡三角形]]**：虽然这个数学结构更早已被中国和波斯数学家发现，但帕斯卡系统地研究了它的性质，并应用于[[概率论]]。

2. **流体力学**：在流体静力学领域提出帕斯卡定律（Pascal's Law），即闭容器中流体压力处处相等。

3. **[[概率论]]的诞生**：1654年与[[皮埃尔·德·费马|费马]]的通信中，提出了解决"[[点数问题]]"的**[[递推方法]]**：
   - 设 f(a, b) 为当A还差a局获胜、B还差b局获胜时，A应得的赌注份额
   - 递推关系：**f(a, b) = [f(a-1, b) + f(a, b-1)] / 2**
   - 这个方法本质上是[[期望值]][[计算]]的原型

4. **哲学**：著有《思想录》（Pensées），是重要的哲学著作。

### 在概率论中的角色

帕斯卡的[[递推方法]]的核心洞察：
- 不仅考虑已经发生的事（当前局数），还考虑所有可能的未来情景
- 每个参与者应得的份额取决于其在未来所有等可能情景中获胜的概率
- 这隐含了**[[期望值]]**的定义，尽管他没有明确使用这个术语

与[[皮埃尔·德·费马|费马]]的关系：
- 两人分别独立地用不同方法解决了[[点数问题]]
- 帕斯卡用递推法，[[皮埃尔·德·费马|费马]]用[[组合枚举法]]
- 两人的答案相同，相互验证了解答的正确性
- 这是欧洲数学史上最重要的平等学术合作之一
