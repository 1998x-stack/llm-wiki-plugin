# Guorui Zhou

## 概述
阿里巴巴集团阿里妈妈精准定向检索及基础算法团队的研究员，深度兴趣网络（DIN）论文的主要作者之一。

## 关键内容
1. **主要贡献**：作为第一作者提出了深度兴趣网络（DIN）模型，首次将注意力机制成功应用于工业级CTR预估系统，对推荐系统领域产生了深远影响。

2. **所属机构**：阿里巴巴集团（阿里妈妈精准定向检索及基础算法团队），该团队专注于电商推荐、广告CTR预估等领域的算法研究与工业应用。

3. **重要论文**：作为主要作者发表了《Deep Interest Network for Click-Through Rate Prediction》，该论文在KDD 2018发表，截至2025年已被引用超过4000次。

4. **技术影响**：其提出的DIN模型开创了基于深度学习的用户行为序列建模方向，催生了一系列后续工作，包括DIEN、DSIN、BST、MIND等。
