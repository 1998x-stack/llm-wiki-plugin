# Norbert Wiener

## 概述
美国数学家和哲学家，[[控制论视角|控制论]]的创始人之一，[[Wiener Filter|维纳滤波]]理论的提出者。

## 关键内容

1. **生平背景**：
   - 美国数学家，20世纪最重要的科学家之一
   - [[控制论（Cybernetics）]]学科的奠基人
   - 在信号处理和随机过程领域做出重要贡献

2. **主要贡献**：
   - 1940年代提出[[Wiener Filter|维纳滤波]]理论，从含噪信号中提取有用信息的经典方法
   - 开创了[[控制论视角|控制论]]这一跨学科领域，研究系统、控制和通信的科学
   - 在随机过程、[[Wiener过程|布朗运动]]、调和分析等方面有重要成就

3. **[[Wiener Filter|维纳滤波]]的特点**：
   - 要求信号是平稳的（统计特性不随时间变化）
   - 需要对整段信号历史做频域分析
   - 在频域中工作，求解维纳-霍普夫方程
   - 难以处理多变量系统，工程实现困难

4. **与[[卡尔曼滤波]]的关系**：
   - [[Wiener Filter|维纳滤波]]是[[卡尔曼滤波]]的前身和理论基础
   - [[卡尔曼滤波]]克服了[[Wiener Filter|维纳滤波]]的诸多局限性
   - [[卡尔曼滤波]]可以在时域中递归[[计算]]，更适合[[计算]]机实现
