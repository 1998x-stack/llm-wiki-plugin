# VS Code

## 概述
轻量级但功能强大的源代码编辑器，支持多种编程语言，具有丰富的插件生态系统。

## 关键内容
1. **特性**：VS Code提供智能代码补全(IntelliSense)、语法高亮、括号匹配、代码片段等功能，内置Git命令，支持调试器，拥有强大的搜索替换功能。
2. **扩展性**：通过丰富的扩展市场可以增强编辑器功能，支持各种编程语言、主题、代码片段、排版、调试器和其他插件。
3. **跨平台**：支持Windows、macOS和Linux[[操作系统]]，在不同平台上提供一致的用户体验。
