# 张居正

## 概述
明朝政治家（1525-1582），万历年间首辅，推行清丈土地、一条鞭法等改革，在[[黄仁宇]][[大历史观]]中被视为试图将帝国推向更可操作、更财政化方向的典型案例。

## 关键内容

1. **改革举措**：清丈土地、整顿财政、推进一条鞭法、强化中央对地方控制。这些措施试图将帝国治理推向更可操作、更财政化、更可量化的方向。
2. **[[黄仁宇]]的解读**：张居正不只是"能臣"，而是想把帝国推向更可操作、更财政化、更可量化方向的人。他的失败说明问题不只是政敌反扑，而是整个政治文化和官僚结构都不支持这种方向。
3. **结构性失败**：改革触碰的是结构，不只是利益集团。明朝的政治文化和官僚结构从根本上不支持财政化、可量化的治理方向。
4. **历史意义**：在[[黄仁宇]]看来，张居正改革是明朝最能暴露中国传统政治结构优点与上限的典型案例——形式上的中央集权不等于真正的治理能力提升。
