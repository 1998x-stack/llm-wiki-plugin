# Ronald J. Williams

## 概述 (50-200字符)
Ronald J. Williams，计算机科学家，1986 年与[[David E. Rumelhart]]和[[Geoffrey E. Hinton]]共同在 *Nature* 发表[[反向传播]]里程碑论文《[[Learning Representations by Back-propagating Errors]]》，是[[反向传播]]算法的共同发明者之一。

## 关键内容 (≥300字符, 用[[双链]])
1. **[[反向传播]]论文**：1986 年，Williams 作为第三作者与 Rumelhart、[[Geoffrey E. Hinton|Hinton]] 在 *Nature* 发表《[[Learning Representations by Back-propagating Errors]]》。论文给出了[[反向传播]]算法的完整数学推导，用[[链式法则]]计算每个权重对误差的贡献，使[[多层感知机]]的训练成为可能。
2. **学术背景**：Williams 在[[反向传播]]论文发表期间任职于加州大学圣地亚哥分校（UCSD）的 Institute for Cognitive Science，与 Rumelhart 和 [[Geoffrey E. Hinton|Hinton]] 同属一个研究团队。他的贡献在于算法的数学推导和实现细节。
3. **后续研究**：Williams 后续在递归神经网络（RNN）领域也有重要贡献，包括 Real-Time Recurrent Learning (RTRL) 算法（1989 年与 Zipser 共同提出），这是早期 RNN 训练的在线算法，与[[反向传播]]通过时间（BPTT）形成对比。
4. **历史地位**：相比 [[Geoffrey E. Hinton|Hinton]] 和 Rumelhart，Williams 的公众知名度较低，但作为[[反向传播]]论文的三位作者之一，他对深度学习的奠基性贡献不可忽视。[[反向传播]]至今仍是所有深度学习架构的训练引擎。
