# 区分

## 概述
[[皮埃尔·布尔迪厄]]1979年出版的批判[[社会学]]经典，通过大规模实证调查揭示"品味"的阶级性，提出[[文化资本]]/[[社会资本]]/经济资本三位一体理论。

## 关键内容
1. **品味的阶级性**：通过大规模问卷调查揭示"品味"并非个人偏好而是阶级区隔的工具——文化消费（音乐、艺术、饮食、休闲）是社会等级的再生产机制。
2. **[[文化资本]]**：扩展[[卡尔·马克思]]的经济资本概念，提出[[文化资本]]（知识、品味、教育资格）与[[社会资本]]（人脉网络）同样是不平等再生产的关键机制。
3. **[[惯习]]（habitus）**：内化的社会结构，表现为持久的性情倾向系统，既结构化（被社会塑造）又具有结构化能力（塑造实践），解释了阶级品味的代际传递。
4. **[[场域理论]]**：将社会空间划分为相对自主的"场域"（如艺术场、学术场、政治场），每个场域有自身的规则与资本形式，行动者在场域中争夺支配权。
