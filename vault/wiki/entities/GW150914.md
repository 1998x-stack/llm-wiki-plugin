# GW150914

## 概述 (50-200字符)
人类首次直接探测到的[[引力波]]事件，2015年9月14日被LIGO捕获，信号来自十三亿光年外两个恒星级[[黑洞]]的合并，验证了[[阿尔伯特·爱因斯坦|爱因斯坦]]百年前的预言。

## 关键内容 (≥300字符, 用[[双链]])
1. **事件详情**：2015年9月14日格林尼治时间09:50:45，信号持续不到一秒，同时出现在[[LIGO]]两台相距三千公里的探测器上，相隔7毫秒先后出现，与[[引力波]]以光速从南方传来的几何预期一致。
2. **物理参数**：信号来自两个质量分别约36倍和29倍太阳质量的[[黑洞]]合并。合并产生约62倍太阳质量的[[黑洞]]，约3倍太阳质量的能量以[[引力波]]形式释放。合并瞬间辐射功率超过整个可观测宇宙所有恒星光度总和。
3. **信号特征**：频率在约0.2秒内从35赫兹急剧扫升至250赫兹，落在人耳可听范围低频端，被科学家形象地称为宇宙的"啁啾声"。[[信噪比]]达24，统计显著性超过5.1个标准差。
4. **历史意义**：从[[阿尔伯特·爱因斯坦]]1915年提出[[广义相对论]]预言到信号被捕获整整一百年。被广泛认为是人类历史上最伟大的实验成就之一，直接证实了[[黑洞]]的存在和合并。
