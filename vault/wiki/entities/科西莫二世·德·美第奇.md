# 科西莫二世·德·美第奇

## 概述
托斯卡纳大公，[[伽利略]]的资助人，[[伽利略]]将木星四颗卫星命名为"[[伽利略卫星|美第奇之星]]"献给他，以此换取托斯卡纳宫廷首席数学家和哲学家职位。

## 关键内容
1. **资助关系**：科西莫二世·德·美第奇是托斯卡纳大公，担任[[伽利略]]的重要资助人。这种赞助关系在文艺复兴时期的意大利学术界十分常见，为科学家提供了经济保障和研究自由。
2. **[[伽利略卫星|美第奇之星]]命名**：1610年[[伽利略]]发现木星四颗卫星后，将其命名为"[[伽利略卫星|美第奇之星]]"（[[伽利略卫星|Medicean Stars]]），以献给科西莫二世。这一策略展现了[[伽利略]]敏锐的政治嗅觉。
3. **政治回报**：通过将木星卫星献给美第奇家族，[[伽利略]]赢得了托斯卡纳宫廷首席数学家和哲学家的职位，从一位地方大学教授跃升为全欧洲瞩目的学术明星。
4. **历史意义**：这一命名策略不仅是科学发现的记录，更反映了科学与政治权力之间的复杂互动。四颗卫星今天被统称为[[伽利略卫星]]（木卫一伊奥、木卫二欧罗巴、木卫三盖尼米德、木卫四卡利斯托）。
