# bencium UX Designer

## 概述
bencium UX Designer是一套专为[[Claude Code]]设计的UX设计[[Skills|技能]]集合，包含两个不同行为模式的AI助手，用于处理不同的设计需求。

## 关键内容

1. **双模式架构**：
   - `bencium-innovative-ux-designer`：大胆、独特、出人意料的设计风格，适用于创意机构、作品集、新产品
   - `bencium-controlled-ux-designer`：系统化、可控、符合规范的设计方法，适用于企业应用、受监管行业、设计系统

2. **版本演进**：v2.0.0 "Creative Liberation"更新解禁了阴影和渐变，加入了Design Thinking Protocol，并将无障碍定位为"创意的使能者，而非限制者"

3. **设计系统规范**：提供完整的响应式设计、动效规范、无障碍标准等四个参考文档

4. **深度定制**：28,000字的[[SKILL.md]]文档，远超官方[[Skills|Skill]]的内容量
