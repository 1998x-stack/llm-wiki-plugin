# 哥德尔

## 概述
[[库尔特·哥德尔]]（Kurt Godel，1906-1978）是奥裔美籍数学家和逻辑学家，以其不完备定理闻名于世，对数学基础和数理逻辑做出了革命性贡献。

## 关键内容
1. **生平简介**：
   - 生于1906年，逝于1978年
   - 奥地利裔，后移居美国
   - 普林斯顿高等研究院研究员，长期与[[阿尔伯特·爱因斯坦|爱因斯坦]]共事

2. **主要贡献**：
   - **不完备定理**（1931年）：
     - 第一不完备定理：任何足够强大的、一致的形式系统中，都存在既不能被证明也不能被反驳的命题
     - 第二不完备定理：这样的系统无法证明自身的一致性
   - **连续统假设的相容性**：证明了连续统假设与ZFC公理系统的相容性
   - **[[经典力学]]中的时间旅行解**：提出了[[爱因斯坦场方程]]的一个解，允许闭合类时曲线

3. **对[[希尔伯特纲领]]的影响**：
   - 1931年的不完备定理彻底粉碎了[[希尔伯特纲领]]中关于完备性和一致性证明的期望
   - 证明了数学真理的范围永远超出任何单一形式系统的证明能力
   - 但不完备定理并没有直接回答[[判定问题]]（可判定性）

4. **历史意义**：
   - 改变了人们对数学基础和形式系统的认识
   - 揭示了数学系统的内在局限性
   - 为[[Alan Turing|图灵]]和[[丘奇]]解决[[判定问题]]铺平了道路
