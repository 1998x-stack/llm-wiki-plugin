# 关系模型论文

## 概述

[[E.F. Codd]] 于1970年发表的《A [[关系模型|Relational Model]] of Data for Large Shared Data Banks》，是数据库领域最具影响力的论文，首次提出用数学关系（二维表）作为数据的统一逻辑表示。

## 关键内容

### 论文信息

| 条目 | 内容 |
|------|------|
| **标题** | A [[关系模型|Relational Model]] of Data for Large Shared Data Banks |
| **作者** | Edgar Frank "Ted" Codd（1923–2003） |
| **发表时间** | 1970年6月 |
| **刊物** | Communications of the ACM, Vol. 13, No. 6, pp. 377-387 |

### 核心贡献

- **关系（Relation）**：用集合论中的关系概念作为数据的统一逻辑表示
- **[[关系代数]]**：选择、投影、并、差、笛卡尔积五种基本运算
- **[[关系演算]]**：基于一阶谓词逻辑的声明式查询
- **[[规范化理论]]**：引入第一[[规范化理论|范式]]概念，为数据库设计提供科学方法
- **[[数据独立性]]**：物理[[数据独立性]]和逻辑[[数据独立性]]的系统[[区分]]

### 后续验证

- **System R**（IBM）：第一个关系数据库原型，催生了 SQL 语言
- **Ingres**（UC Berkeley）：独立的关系数据库实现，使用 QUEL 查询语言
- Codd 于1981年获得[[阿兰·图灵|图灵]]奖

### 历史影响

- 关系数据库成为全球信息基础设施的核心组件
- SQL 成为历史上使用最广泛的声明式编程语言
- 催生了"数据库理论"这一成熟的[[计算]]机科学分支
