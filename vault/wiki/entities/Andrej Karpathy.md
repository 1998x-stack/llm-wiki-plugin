# Andrej Karpathy

## 概述
Andrej Karpathy 是著名的人工智能研究员和深度学习专家，曾任 [[OpenAI]] 研究主管，在 LLM 领域有重要贡献，2024年提出"[[Context Engineering]] > [[Prompt Engineering]]"的概念转变。

## 关键内容

1. **专业身份**：
   - 前 [[OpenAI]] 研究主管
   - [[斯坦福大学]]博士毕业
   - 在[[卷积神经网络（CNN）|卷积神经网络]]、循环神经网络和深度[[强化学习]]领域有重要贡献

2. **LLM 时代的贡献**：
   - 2024年提出"[[Context Engineering]] > [[Prompt Engineering]]"的重要认知转变
   - 将 [[Context Engineering]] 概念正式推向主流视野
   - 认为[[Context Engineering|上下文工程]]是 LLM 应用的系统性工程学科

3. **教育与推广**：
   - 开源深度学习课程 CS231n 广受好评
   - 积极推广深度学习和 LLM 工程实践
   - 对 LLM 工程化方向有深刻见解
