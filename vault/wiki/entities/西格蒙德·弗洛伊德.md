# 西格蒙德·弗洛伊德

## 概述
奥地利神经学家、精神病学家，精神分析学派创始人，《[[梦的解析]]》作者，提出[[无意识]]理论和[[心理地形模型]]。

## 关键内容
1. **生平与背景**：
   - 1856年出生，1939年逝世
   - 维也纳行医多年，起初是神经科医生
   - 1900年出版《[[梦的解析]]》，奠定精神分析学基础

2. **重要贡献**：
   - 提出[[心理地形模型]]：[[意识]]、[[前意识]]、[[无意识]]三层次结构
   - 发展梦的理论：梦是被[[压抑]]愿望的伪装实现
   - 首次系统提出[[俄狄浦斯情结]]概念
   - 通过自我分析方法进行理论构建，以自身梦境为分析对象

3. **临床实践**：
   - 早期治疗癔症患者，通过谈话疗法让患者回忆创伤记忆
   - 曾师从[[夏尔科]]学习催眠术
   - 与[[布洛伊尔]]合作发展谈话疗法

4. **理论影响**：
   - 精神分析学派奠基人
   - [[无意识]]概念影响文学、哲学和日常生活
   - 心理动力学理论至今仍有影响
