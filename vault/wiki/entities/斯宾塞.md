# 斯宾塞

## 概述 (50-200字符)
[[赫伯特·斯宾塞]]（Herbert Spencer，1820–1903），英国哲学家、[[社会学]]家，[[社会达尔文主义]]创始人，受[[奥古斯特·孔德|孔德]]影响但发展出独立的社会进化理论。

## 关键内容 (≥300字符, 用[[双链]])
1. **思想渊源**：斯宾塞受到[[奥古斯特·孔德]]的[[科学等级体系]]和[[社会动力学]]思想的深刻影响，但将达尔文的进化论引入[[社会学]]，形成"[[社会达尔文主义]]"。
2. **社会进化论**：提出社会从简单到复杂、从同质到异质的进化过程，与[[奥古斯特·孔德|孔德]]的[[三阶段定律]]有相似之处，但更强调自然选择而非目的论演进。
3. **与[[奥古斯特·孔德|孔德]]的分歧**：斯宾塞反对[[奥古斯特·孔德|孔德]]的精英治理愿景和[[人道主义宗教]]计划，主张自由放任的个人主义，代表了英国自由主义传统与法国[[实证主义]]的根本分歧。
4. **影响链**：[[奥古斯特·孔德|孔德]]→斯宾塞→进化[[社会学]]，构成[[社会学]]早期发展的重要思想脉络。
