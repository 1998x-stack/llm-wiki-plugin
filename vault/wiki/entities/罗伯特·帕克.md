# 罗伯特·帕克

## 概述
美国[[社会学]]家（1864–1944），[[芝加哥学派]]核心人物，与伯吉斯合编《[[社会学科学导论]]》，提出[[城市生态学]]与人类生态学理论。

## 关键内容
1. **人类生态学**：将生态学概念引入[[社会学]]，研究人口、机构与资源在城市空间中的分布模式，奠定城市[[社会学]]基础。
2. **社会互动四过程**：提出竞争、冲突、适应、同化四个社会互动过程，成为分析群体关系的经典框架。
3. **《[[社会学科学导论]]》**：1921年与[[欧内斯特·伯吉斯]]合编，是[[芝加哥学派]]的标志性教材，系统阐述[[城市生态学]]与人类生态学。
4. **城市[[社会学]]**：研究城市作为社会实验室，关注移民、种族关系与城市社区的形成与变迁。
