# 哈尔滨工业大学深圳研究生院

## 概述
哈尔滨工业大学深圳研究生院是哈尔滨工业大学在深圳设立的研究生教育和科研机构，成立于2002年，位于深圳市南山区西丽大学城。该院在计算机科学、人工智能、推荐系统等领域有重要的研究贡献。

## 关键内容

1. **学术贡献**：
   - 在推荐系统和点击率预估领域有重要研究产出
   - 与华为诺亚方舟实验室等产业界机构开展深入合作
   - IJCAI 2017论文《DeepFM: A Factorization-Machine based Neural Network for CTR Prediction》的参与机构之一

2. **研究领域**：
   - 机器学习与深度学习
   - 推荐系统算法
   - 数据挖掘
   - 计算机视觉
   - 自然语言处理

3. **产学研合作**：
   - 与知名企业建立紧密的合作关系
   - 推动学术研究成果的产业化应用
   - 例如与华为在DeepFM模型上的合作研究

4. **地理位置**：
   - 位于深圳市南山区西丽大学城
   - 依托深圳的科技创新环境和产业优势
