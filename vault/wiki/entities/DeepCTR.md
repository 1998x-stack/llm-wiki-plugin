# DeepCTR

## 概述
开源深度学习 CTR 预估框架，将 DeepFM 作为核心模型之一提供支持，推动了 DeepFM 的工业普及。

## 关键内容

1. **核心模型支持**：将 DeepFM 作为核心模型之一提供开箱即用的实现，降低了 DeepFM 的使用门槛。
2. **工业普及推动者**：DeepFM 因其简洁架构和易于实现的特点在工业界广泛采用，DeepCTR 等开源框架进一步加速了这一趋势。
3. **模型集合**：除 DeepFM 外，还集成了 Wide & Deep、DCN、xDeepFM、DIN 等多种主流 CTR 预估模型，提供统一的 API 接口。
