# 吉姆·皮布尔斯

## 概述 (50-200字符)
吉姆·皮布尔斯（Jim Peebles, b. 1935），加拿大裔美国物理学家和宇宙学家。1960年代与[[罗伯特·迪克]]共同重新推导了[[宇宙微波背景辐射]]的理论预言，2019年获诺贝尔物理学奖。

## 关键内容 (≥300字符, 用[[双链]])
1. **CMB理论推导**：1960年代中期，皮布尔斯与[[罗伯特·迪克]]在普林斯顿大学独立重新推导了[[乔治·伽莫夫]]团队1948年的理论，预测了[[宇宙微波背景辐射]]的存在，并正着手建造探测器寻找它。
2. **命运的电话**：当[[阿诺·彭齐亚斯]]致电迪克描述那个无法解释的3.5开尔文微波噪声时，迪克和皮布尔斯立刻意识到——这正是他们正在寻找的宇宙大爆炸余辉。迪克接完电话后对同事说："伙计们，我们被人抢先了。"
3. **伴随论文**：皮布尔斯作为共同作者参与了迪克团队的理论解释论文"Cosmic Black-Body Radiation"，该论文与彭齐亚斯和威尔逊的实验论文背靠背发表于1965年《[[天体物理学]]杂志》。
4. **宇宙学贡献**：皮布尔斯此后在物理宇宙学领域做出了数十年的开创性贡献，包括大尺度结构形成、[[暗物质]]和[[暗能量]]的理论研究，是现代物理宇宙学的奠基人之一。
5. **诺贝尔奖**：2019年，皮布尔斯因"在物理宇宙学领域的理论发现"获得诺贝尔物理学奖，表彰他对人类理解宇宙演化的深远贡献。
