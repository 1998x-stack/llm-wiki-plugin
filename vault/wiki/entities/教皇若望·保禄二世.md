# 教皇若望·保禄二世

## 概述
罗马天主教教皇（1978-2005年在位），1992年正式为[[伽利略]]平反，承认教会1633年宗教裁判所判决是一个错误。

## 关键内容
1. **[[伽利略]]平反**：1992年，教皇若望·保禄二世正式为[[伽利略]]平反，承认教会当年（1633年）的判决是一个错误。这一事件距[[伽利略]]被宗教裁判所传讯已过去359年。
2. **历史背景**：1633年[[伽利略]]因发表《[[关于两大世界体系的对话]]》为[[日心说]]辩护，被宗教裁判所传讯，被迫公开否认[[日心说]]，并在软禁中度过了生命的最后九年。1616年教会曾宣布[[日心说]]为"荒谬的异端"。
3. **象征意义**：[[伽利略]]与教会的冲突是科学史上最具象征意义的事件之一，被后世视为理性与权威、实证与教条之间永恒张力的缩影。若望·保禄二世的平反标志着教会对科学与宗教关系的重新审视。
4. **科学史意义**：这一平反不仅是对[[伽利略]]个人名誉的恢复，更是对科学方法论——真理不取决于权威文本注疏，而取决于对自然本身的直接观察与测量——的间接承认。
