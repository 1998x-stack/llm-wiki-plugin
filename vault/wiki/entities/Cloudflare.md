# Cloudflare

## 概述
Cloudflare 是一家美国跨国科技企业，提供内容分发网络、DNS [[服务]]、DDoS 缓解、网页安全和负载均衡[[服务]]。

## 关键内容

1. **在 [[Agentic Commerce]] 中的角色**：
   - 与 [[Coinbase]] 共建 [[x402 Foundation]]，推动 [[x402 Protocol|HTTP 402]] 成为[[互联网]]级开放标准
   - 在 [[Agents]] SDK 内置 x402 支持
   - 在 [[Model Context Protocol]] (MCP) 集成中支持 x402 协议
   - 提出"延迟支付方案"，支持按抓取付费模式

2. **关键技术贡献**：
   - 提出延迟支付方案（Deferred Payment）针对爬虫/Agent 批量访问场景
   - 推动按抓取付费（Pay-Per-Crawl）模式的测试
