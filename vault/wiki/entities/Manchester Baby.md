# Manchester Baby

## 概述
Manchester Small-Scale Experimental Machine（曼彻斯特小型实验机器），1948年由曼彻斯特大学团队建造，是世界上第一台运行存储程序的实验性原型机。

## 关键内容

1. **历史地位**：
   - 严格意义上第一台运行存储程序的[[计算]]机
   - 1948年运行，早于[[EDSAC]]（1949年）
   - 但主要是实验性原型机，而非实用[[计算]]机

2. **建造背景**：
   - 由曼彻斯特大学团队建造
   - 受到[[冯·诺依曼]][[EDVAC报告]]的启发

3. **技术特点**：
   - 采用了[[冯·诺依曼架构|存储程序架构]]
   - 验证了存储程序概念的可行性

4. **与[[EDSAC]]的区别**：
   - Manchester Baby是实验性原型机
   - [[EDSAC]]是第一台实用的[[存储程序计算机]]
