# Urho3D

## 概述
Urho3D 是一个开源的轻量级 3D 游戏引擎，基于 C++ 开发，支持跨平台部署。[[UrhoX引擎|UrhoX]] 基于 Urho3D 1.8 版本构建，核心 API 95% 兼容。

## 关键内容
1. **与 [[UrhoX引擎|UrhoX]] 的关系**：[[UrhoX引擎|UrhoX]] 基于 Urho3D 1.8 构建，核心 API 保持 95% 兼容性，但扩展了 [[NanoVG]]、新 UI 系统、云变量等功能。
2. **技术特点**：轻量级设计，C++ 核心，支持 Lua 脚本，跨平台（Windows、macOS、Linux、Web）。
3. **社区与生态**：开源社区维护，有完善的文档和示例，是独立游戏开发者的常用选择。
