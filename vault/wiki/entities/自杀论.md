# 自杀论

## 概述 (50-200字符)
[[涂尔干]]1897年著作，[[社会学]]史上第一部系统使用统计数据进行量化分析的研究，证明连最个人化的自杀行为也受社会力量支配。

## 关键内容 (≥300字符, 用[[双链]])
1. **为什么研究自杀**：自杀似乎是最私密、最个人化的行为。如果[[社会学]]能证明连自杀也受社会力量支配，就能有力证明[[社会事实]]确实存在且具有独立的解释力。这是[[社会学]]史上第一部系统使用统计数据进行量化分析的研究著作。
2. **反驳竞争性解释**：逐一排除模仿说（[[塔尔德]]）、精神病说、气候/季节说、遗传/种族说。真正的解释变量在于社会整合程度和道德规范的调节。
3. **四种自杀类型**：根据两个维度——社会整合（integration）和道德规范（regulation）——构建四种类型：[[利己型自杀]]（整合过低）、[[利他型自杀]]（整合过高）、[[失范型自杀]]（规范过低）、[[宿命型自杀]]（规范过高）。
4. **方法论意义**：以社会率（social rates）替代个体行为研究自杀率；用统计相关揭示社会因果；以比较排除竞争性假设；将个体行为模式归因于社会力量。这套思路奠定了20世纪定量[[社会学研究]]的基本逻辑。
