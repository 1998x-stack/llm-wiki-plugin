# BM25

## 概述
BM25（Best Matching 25）是一种基于 [[TF-IDF]] 的词汇精确匹配排序函数，广泛用于[[搜索引擎架构|信息检索系统]]，擅长技术术语、错误代码等精确标识符匹配。

## 关键内容

1. **[[算法]]原理**：基于 [[TF-IDF]] 的改进版本，通过词频和逆文档频率[[计算]]文档与查询的相关性得分，是传统搜索引擎的核心[[算法]]之一。

2. **优势场景**：对精确词语或短语匹配能力强，特别适合技术术语、错误代码（如"TS-999"）等精确标识符检索。

3. **局限性**：无语义理解能力，无法捕捉查询意图的语义相似性，需与[[语义嵌入]]结合形成[[混合搜索|混合检索]]。

4. **在 RAG 中的应用**：与[[语义嵌入]]互补，形成传统 RAG 的双引擎机制。在 [[上下文检索]] 中，语境化 BM25 进一步将检索失败率降低至 2.9%（相对基准降低 49%）。
