# OpenCode

## 概述
一个开源 AI 编码工具，曾因集成 [[Claude Code]] 内部 API 而收到 [[Anthropic]] 的法律威胁。

## 关键内容

1. **核心功能**：
   - 开源 AI 编码助手工具
   - 集成了 [[Claude Code]] 的内部 API
   - 允许用户以订阅价格访问 [[Claude_Opus_4.6|Claude Opus 4.6]]

2. **争议事件**：
   - 2026 年 3 月，[[Anthropic]] 发送法律威胁
   - 问题在于允许用户以订阅价格而非按量付费访问 [[Claude_Code|Claude]] API
   - 导致 [[Anthropic]] 损失大量收入

3. **技术影响**：
   - 促使 [[Anthropic]] 开发[[客户端证明]]机制
   - 成为 [[Claude Code]] 安全防护系统的重要驱动力
   - 促进了反盗版 API 使用的技术发展
