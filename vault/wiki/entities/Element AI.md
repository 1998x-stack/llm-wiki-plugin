# Element AI

## 概述
Element AI是一家由[[Yoshua Bengio]]联合创立的蒙特利尔AI公司，专注于深度学习研究和应用，后被ServiceNow收购。该公司在[[时间序列预测]]等领域进行了重要的研究工作。

## 关键内容

1. **公司背景**：
   - 由深度学习三巨头之一、2018年[[Alan Turing|图灵]]奖得主[[Yoshua Bengio]]联合创立
   - 位于蒙特利尔，与Mila（蒙特利尔学习[[算法]]研究所）有着密切的合作关系
   - [[服务]]于大量需要[[时间序列预测]]等AI技术的企业客户

2. **重要研究成果**：
   - 开发了[[N-BEATS]][[时间序列预测]]模型，该模型在权威竞赛中击败了传统统计方法
   - 体现了工业界实战需求与学术界理论深度的结合

3. **发展历程**：
   - 作为一家专注于AI研究和应用的公司，推动了深度学习在实际业务场景中的应用
   - 后被ServiceNow收购，其技术和人才融入到更大的企业[[服务]]生态中
