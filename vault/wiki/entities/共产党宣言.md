# 共产党宣言

## 概述 (50-200字符)
1848年伦敦出版的23页政治动员小册子，由马克思与[[弗里德里希·恩格斯|恩格斯]]合著，开篇"一个幽灵，共产主义的幽灵，在欧洲游荡"，宣告"至今一切社会的历史都是[[阶级斗争]]的历史"。

## 关键内容 (≥300字符, 用[[双链]])
1. **历史现场**：1848年出版后4天法国二月革命爆发，革命浪潮席卷欧洲。虽无直接因果关系，但赋予其预言光环。与[[资本论]]性质不同——《宣言》是政治动员文件，语言如火；《[[资本论]]》是经济学批判专著，论证严密。
2. **核心命题**：资本主义社会[[阶级斗争]]简化为[[资产阶级]]（拥有工厂、机器、土地）与[[无产阶级]]（只拥有劳动力）的对立。国家被定义为"管理整个资产阶级的共同事务的委员会"。
3. **资产阶级的历史功绩与矛盾**：马克思承认资产阶级摧毁了封建关系、解放了生产力，但同时也制造了自己的掘墓人——无产阶级越来越集中、有组织，最终将革命实现生产资料公有化。
4. **[[社会学]]遗产**：提出的分析框架后来发展为完整的[[冲突理论]]传统，影响了达伦多夫（Dahrendorf）、柯林斯（Collins）、赖特·米尔斯（[[C. 赖特·米尔斯|C. Wright Mills]]）等人。
