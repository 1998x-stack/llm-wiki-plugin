# 阿诺·彭齐亚斯

## 概述 (50-200字符)
阿诺·彭齐亚斯（Arno Penzias, 1933-2024），德裔美国射电天文学家。1965年与[[罗伯特·威尔逊]]共同发现[[宇宙微波背景辐射]]，获1978年诺贝尔物理学奖。

## 关键内容 (≥300字符, 用[[双链]])
1. **发现CMB**：1965年，彭齐亚斯与[[罗伯特·威尔逊]]在新泽西州[[贝尔实验室]]霍姆德尔站点，使用一台为"回声"卫星通信计划建造的20英尺喇叭形天线进行射电天文观测校准时，发现了一个持续存在的、约3.5开尔文的各向同性微波噪声信号。
2. **严谨排查**：面对这个无法解释的"多余噪声"，彭齐亚斯和威尔逊进行了极其细致的排查工作。他们检查了天线的每一个部件，排除了大气辐射、地面辐射、电子设备热噪声等所有已知噪声来源。他们甚至发现并清理了在天线内筑巢的鸽子及其粪便，但信号依然顽固存在。
3. **命运的电话**：麻省理工学院天文学家伯纳德·伯克建议彭齐亚斯给普林斯顿大学的[[罗伯特·迪克]]打电话。迪克接完电话后对同事说："伙计们，我们被人抢先了。"这通电话确认了他们发现的正是宇宙大爆炸的余辉——[[宇宙微波背景辐射]]。
4. **克制的论文**：彭齐亚斯和威尔逊的论文《在4080兆赫频率上测得的天线温度超额》全文仅约600个英语单词，通篇未出现"大爆炸"三字。论文只在最后一段轻描淡写地提到迪克等人的理论解释。这种极度冷静克制的风格成为科学史上的经典。
5. **荣誉**：因发现[[宇宙微波背景辐射]]，彭齐亚斯与威尔逊共同获得1978年诺贝尔物理学奖。该发现被广泛认为是"二十世纪最重要的科学发现之一"。
