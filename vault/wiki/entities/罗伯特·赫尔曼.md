# 罗伯特·赫尔曼

## 概述 (50-200字符)
罗伯特·赫尔曼（Robert Herman, 1914-1997），美国物理学家。1948年与[[乔治·伽莫夫]]、[[拉尔夫·阿尔弗]]共同预言了[[宇宙微波背景辐射]]的存在。

## 关键内容 (≥300字符, 用[[双链]])
1. **CMB预言**：1948年，赫尔曼与[[乔治·伽莫夫]]及其学生[[拉尔夫·阿尔弗]]共同提出：若宇宙起源于极高温的大爆炸，原初辐射余辉应至今仍弥漫于宇宙中，已冷却至约5开尔文（零下268摄氏度），对应微波波段。该预言发表于《自然》杂志。
2. **被遗忘的预言**：在1940年代末的技术条件下，探测如此微弱的微波信号几乎不可能。这个预言很快被物理学界遗忘，到1960年代初几乎无人记得伽莫夫团队的这项工作。
3. **实验验证**：1965年，[[阿诺·彭齐亚斯]]与[[罗伯特·威尔逊]]在[[贝尔实验室]]使用喇叭形天线校准时，意外发现了约3.5开尔文的各向同性微波噪声——正是[[宇宙微波背景辐射]]，证实了赫尔曼等人17年前的预言。
4. **科学史教训**：赫尔曼的经历展示了科学发现的一个深刻面向：正确的理论预测可能因时代的技术局限而被束之高阁，直到实验证据从完全意料之外的方向到来。
5. **后续认可**：尽管赫尔曼未能因CMB预言获得诺贝尔奖，但他的贡献在科学史文献中被广泛记录和认可。
