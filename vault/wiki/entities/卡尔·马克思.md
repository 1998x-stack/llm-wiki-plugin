# 卡尔·马克思

## 概述 (50-200字符)
德国哲学家、经济学家、革命社会主义者，[[历史唯物主义]]创始人，与[[弗里德里希·恩格斯|恩格斯]]合著《[[共产党宣言]]》，独立完成《[[资本论]]》，对资本主义进行了最系统的理论解剖。

## 关键内容 (≥300字符, 用[[双链]])
1. **思想起点**：马克思翻转了黑格尔的唯心史观，提出"不是观念决定存在，而是存在决定观念"，创立了[[历史唯物主义]]——经济基础（生产力×生产关系）决定上层建筑（国家/法律/宗教/哲学/文化）。
2. **核心著作**：1848年与[[弗里德里希·恩格斯|恩格斯]]合著[[共产党宣言]]（政治动员文件），1867年出版[[资本论]]第一卷（经济学批判专著），在大英博物馆阅览室写了15年。
3. **理论贡献**：提出[[剩余价值]]理论揭示利润来源、[[异化]]理论连接个体心理与社会结构、[[商品拜物教]]概念批判资本主义幻象、[[阶级斗争]]作为历史动力的分析框架。
4. **[[社会学]]遗产**：虽从未自称"[[社会学]]家"（对[[奥古斯特·孔德|孔德]]和[[斯宾塞]]均持批评态度），但其理论体系深刻影响了[[冲突理论]]、批判理论（法兰克福学派）、[[世界体系]]论、劳动[[社会学]]、女性主义马克思主义等领域。
