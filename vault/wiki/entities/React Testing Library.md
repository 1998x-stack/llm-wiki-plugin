# React Testing Library

## 概述
一个推荐最佳实践的[[React]]测试工具库，鼓励以用户视角测试组件行为而非实现细节。

## 关键内容
1. **设计理念**：[[React]] Testing Library倡导编写更可靠、可维护和可理解的测试，通过模拟真实用户的交互方式来测试组件，而不是依赖组件的内部实现细节。
2. **功能特点**：提供了一系列查询方法来定位元素，支持异步操作测试，与Jest等测试框架无缝集成，支持DOM事件模拟和用户交互测试。
3. **优势**：测试更接近用户实际使用场景，减少因[[重构]]而破坏测试的风险，提高测试的稳定性和可靠性，促进编写更易维护的代码。
