# Nicholas Carlini

## 概述
Nicholas Carlini 是一位知名的 AI 安全和机器学习研究者，在对抗样本和 AI 系统安全性方面有重要贡献。

## 关键内容

1. **研究贡献**：
   - 进行了让 16 个 Agent 并行构建 C 编译器的重要实验
   - 强调大部分精力都花在设计 [[Claude_Code|Claude]] 周围的环境上
   - 在 AI 安全和对抗样本研究领域有重要影响力

2. **[[Harness-Engineering|Harness Engineering]] 观点**：
   - 通过并行 Agent 构建编译器的实验展示了 Harness 的重要性
   - 实验证明了精心设计的测试基础设施比简单的 prompt 更重要
   - 支持了 [[OpenAI]] 那些工程师关于环境设计重要性的观点

3. **研究意义**：
   - 证明了 [[Harness-Engineering|Harness Engineering]] 的实用价值
   - 强调了架构规范和环境设计在 AI 代理开发中的重要性
   - 与 [[OpenAI]] 的百万行代码实验结果相互印证
