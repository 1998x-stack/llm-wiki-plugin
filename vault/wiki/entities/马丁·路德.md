# 马丁·路德

## 概述 (50-200字符)
马丁·路德（Martin Luther，1483–1546），德国神学家，宗教改革发起者。提出"[[天职]]"（[[天职|Beruf]]）概念，将世俗工作神圣化，为[[马克斯·韦伯|韦伯]]的资本主义精神理论奠定神学基础。

## 关键内容 (≥300字符, 用[[双链]])
1. **[[天职]]概念（[[天职|Beruf]] / [[天职|Calling]]）**：在天主教传统中，宗教生活（修道士的祈祷、禁欲）才是神圣的，世俗工作只是谋生手段。路德主张每个人在世俗中的职业就是上帝对他的召唤，忠实履行世俗职责本身就是荣耀上帝。
2. **打破宗教与世俗的等级**：这一思想将世俗工作神圣化，打破了宗教生活与世俗生活的等级[[区分]]。任何正当职业都具有同等的宗教价值，不再需要出家修行才能获得神圣性。
3. **对资本主义精神的影响**：[[马克斯·韦伯]]在《[[新教伦理与资本主义精神]]》中将路德的[[天职]]概念视为资本主义精神的神学起点——当世俗工作被赋予神圣意义，人们才会以宗教般的投入对待职业。
4. **宗教改革的历史地位**：路德1517年发表《九十五条论纲》，挑战天主教会赎罪券制度，引发宗教改革运动。其思想直接影响了[[约翰·加尔文]]等后续改革者。
