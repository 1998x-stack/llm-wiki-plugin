# C.A.R. Hoare

## 概述
英国[[计算]]机科学家，因快速排序[[算法]]、Hoare逻辑和CSP并发理论等贡献获得1980年[[Alan Turing|图灵]]奖。

## 关键内容

1. **快速排序[[算法]]**：1962年发明的快速排序[[算法]]是[[计算]]机科学史上最著名的[[算法]]之一，至今仍广泛使用。

2. **Hoare逻辑**：1969年提出的形式化验证方法，用于推理程序的正确性，为程序验证奠定了基础。

3. **CSP并发理论**：1978年发表的《[[CSP 模型|通信顺序进程]]》([[Communicating Sequential Processes]])论文开创了[[消息传递]]并发模型，影响了后续多种编程语言和系统架构。

4. **学术影响**：其CSP理论催生了[[occam]]、[[Erlang]]、Go等多种编程语言的并发模型，提出的"不要通过共享内存来通信，而要通过通信来共享内存"成为并发编程的重要原则。
