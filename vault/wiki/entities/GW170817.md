# GW170817

## 概述 (50-200字符)
2017年8月17日探测到的双中子星合并[[引力波]]事件，首次同时观测到[[引力波]]和电磁对应体信号，标志[[多信使天文学]]的诞生。

## 关键内容 (≥300字符, 用[[双链]])
1. **事件发现**：[[LIGO]]和[[Virgo探测器]]合作组于2017年8月17日探测到该信号，这是首次观测到两颗中子星的合并事件，与[[GW150914]]的[[黑洞]]合并形成鲜明对比。
2. **多信使观测**：全球数十台[[望远镜]]几乎同时捕捉到从伽马射线到无线电波的电磁对应体信号，人类首次能够用[[引力波]]和电磁波两种截然不同的"感官"观察同一天文事件。
3. **科学意义**：标志着[[多信使天文学]]的正式诞生，为[[天体物理学]]研究开辟了全新途径，获取了前所未有的丰富信息，包括重元素核合成过程的直接证据。
4. **后续影响**：推动了[[引力波]]与电磁波联合观测的标准化流程，为后续类似事件的快速响应和多波段协同观测奠定了基础。
