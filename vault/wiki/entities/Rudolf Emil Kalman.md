# Rudolf Emil Kalman

## 概述
匈牙利裔美国数学家和工程师，因提出[[卡尔曼滤波]][[算法]]而闻名于世。

## 关键内容

1. **生平背景**：
   - 出生于1930年，匈牙利布达佩斯
   - 1943年随家人移居美国
   - 在麻省理工学院获得电气工程硕士和博士学位

2. **主要贡献**：
   - 1960年发表了著名论文《A New Approach to Linear Filtering and Prediction Problems》
   - 提出了[[卡尔曼滤波]][[算法]]，彻底改变了[[控制论视角|控制论]]、信号处理和导航领域
   - 引入了[[State-Space Model|状态空间模型]]框架，成为现代控制理论的基石

3. **职业生涯**：
   - 曾在[[斯坦福大学]]、佛罗里达大学及瑞士苏黎世联邦理工学院任职
   - 2009年获美国国家科学奖章，这是美国科学界最高荣誉之一
   - 还获得了IEEE荣誉奖章、京都奖等多项殊荣

4. **影响力**：
   - [[卡尔曼滤波]][[算法]]被广泛应用于阿波罗登月计划、GPS导航、自动驾驶等领域
   - 论文被引用超过60,000次，对工程、科学和经济系统产生根本性贡献
   - 2016年去世，享年86岁
