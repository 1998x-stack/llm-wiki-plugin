# Claude Opus 4.6

## 概述
[[Anthropic]] 开发的高级 AI 模型，属于 [[Claude_Code|Claude]] 系列中最强大的版本之一。

## 关键内容

1. **定位与能力**：
   - [[Claude_Code|Claude]] 系列中的高端模型
   - 具备强大的推理和编程能力
   - 支持复杂任务处理

2. **商业模式**：
   - 采用按量付费模式（API 调用计费）
   - 也可通过订阅方式访问（如 [[Claude Code]]）
   - [[OpenCode]] 事件中成为滥用的目标

3. **安全措施**：
   - [[Anthropic]] 采取多种技术手段防止滥用
   - [[客户端证明]]机制保护 API 不被第三方绕过
   - [[反蒸馏系统]]防止知识蒸馏攻击
