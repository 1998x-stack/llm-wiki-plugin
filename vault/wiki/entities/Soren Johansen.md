# Soren Johansen

## 概述
丹麦统计学家，哥本哈根大学数理统计学教授，以提出[[Johansen检验|Johansen协整检验]]方法闻名于世。

## 关键内容

1. **学术背景**：
   - 1939年出生于丹麦
   - 哥本哈根大学数理统计学教授
   - 学术生涯横跨纯数学与应用统计学，早年研究集中在[[概率论]]和测度论

2. **主要贡献**：
   - 1988年发表著名论文《[[统计分析|Statistical Analysis]] of [[协整分析（Cointegration）|Cointegration]] Vectors》，提出了基于[[最大似然原理|最大似然估计]]的系统性协整分析框架
   - 为协整理论提供了严格的统计推断体系，相比Engle-Granger方法更为完善
   - 该论文被引用超过18000次，成为计量经济学的标准工具

3. **学术风格**：
   - 以数学严谨著称
   - 从纯粹的统计推断角度切入协整问题
   - 将协整问题视为经典的似然推断问题，先做对数学，再谈经济应用

4. **后续工作**：
   - 1991年与[[Katarina Juselius]]合著重要论文
   - 1995年出版专著《Likelihood-Based Inference in Cointegrated Vector [[自回归模型|Autoregressive Model]]s》
   - 丹麦皇家科学与文学院院士
