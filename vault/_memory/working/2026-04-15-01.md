## 关键观察

### 观察 1：勒让德的双重身份
[[阿德里安-马里·勒让德]] 的贡献在两个独立领域里交叉：
- **最小二乘法**：1805 年首发，命名者，但被高斯抢走历史归功权
- **高斯求积公式**：他的勒让德多项式（1785年）偶然成为了高斯求积节点的数学核心
同一人的两项不直接相关的工作，分别被高斯用来构建两套方法——历史交集深藏在技术细节中。

### 观察 2：数值分析的"最优性思维"范式
[[高斯求积公式]] 开创了数值分析的一种新范式：**先用参数计数论证确定理论上限，再证明上限可以达到**。这与 Newton-Cotes 代表的"构造后分析精度"截然不同。这一"最优性思维"后来影响了从逼近论到信息基复杂性（information-based complexity）的广泛领域。

### 观察 3：DeepAgents 评估"三重分离"
本次 query 综合了评估体系、LLM-as-Judge、Harbor 分析三个来源，浮现出一个整体洞见：
DeepAgents 评估设计围绕三条分离线组织：
1. **正确性 vs 效率**（两层断言：硬失败 vs 仅记录）
2. **确定性 vs 语义**（子串/文件 vs LLM Judge）
3. **能力 vs 基础设施**（FailureCategory: CAPABILITY vs INFRA_*）
每条分离线都针对一个"混淆陷阱"：把效率当正确性、把语义等价当失败、把沙箱崩溃当模型退步。→ **已结晶为 synthesis 页面**

### 观察 4：DeepAgents 中间件顺序的设计决策
缓存中间件（AnthropicPromptCachingMiddleware）放在记忆中间件（MemoryMiddleware）前面，是为了保护 Anthropic prompt cache 前缀的稳定性——记忆注入会改变系统提示内容，若放在缓存之前，每次记忆更新都会使 cache 失效。这是一个非显而易见但影响成本的工程决策。

### 观察 5：Harbor 分析工具中的统计严谨性
Wilson 置信区间 + 最小可检测效应（MDE）的组合，体现了一种"防止在小样本上过度解读"的统计纪律。在 90 题级别的评测规模下，1~2 道题的涨跌很可能在噪声范围内——MDE 工具强制用户面对这个现实。

### 观察 6：本次 ingest 的跨领域跨度
单次会话同时处理了**19 世纪数学史**（高斯、勒让德、雅可比）和**2024 年 LLM Agent 工程**（DeepAgents、LangGraph、Harbor）。知识库开始呈现两个独立知识域（数值分析 + LLM 工程），后续可考虑建立综合分析页面连接二者（如"数值优化思想在 LLM 评估中的体现"）。
