# Episodic Memory：2026-04-15

## 事件摘要

知识库初次大规模 ingest：同一会话处理了 19 世纪数值分析史（高斯系列）和 2024 年 LLM Agent 工程（DeepAgents 生态），新增 8 个 wiki 页面，1 个 synthesis，更新 4 个已有页面。

## 关键观察（压缩自 2026-04-15-01）

**O1｜勒让德双重身份**
[[阿德里安-马里·勒让德]] 的两项独立工作（最小二乘命名/首发 1805 + 勒让德多项式 1785）分别被高斯用来构建不同方法，历史交集藏在技术细节里——优先权争议输家，却成为数学结构的隐性胜者。

**O2｜数值分析"最优性思维"范式**
[[高斯求积公式]] 开创了"先用参数计数确定上限，再证明可达"的新范式，区别于 Newton-Cotes 的"构造后分析精度"——这是数值分析从 ad-hoc 走向理论极限驱动的转折点。

**O3｜DeepAgents 评估三重分离（→ 已结晶为 synthesis）**
三条分离线，各针对一个混淆陷阱：
- 正确性 vs 效率（两层断言）→ 避免把探索性多步等同于失败
- 确定性 vs 语义（子串 vs LLM Judge）→ 按场景选择，不默认用 Judge
- 能力 vs 基础设施（FailureCategory）→ 剥离环境噪声

**O4｜中间件顺序的成本隐患**
Anthropic 缓存中间件必须在记忆中间件之前——记忆注入改变系统提示，若顺序颠倒会每次使 cache 失效，实质上是隐性的 API 成本设计决策。

**O5｜小样本统计纪律**
Wilson CI + MDE 组合：在 90 题规模下，1~2 题涨跌不能作为结论依据——MDE 工具强制面对这一现实，防止评估者在噪声上过拟合判断。

**O6｜跨域知识库形态**
知识库已有两个独立知识域成形：**数值分析**（高斯/欧拉/切比雪夫/FFT/有限元）和 **LLM Agent 工程**（DeepAgents 生态），后续 synthesis 机会：两域在"优化"和"评估"概念上的深层联系。

## 关键观察（压缩自 2026-04-15-02）

**O7｜矩阵谱理论的清晰知识谱系（→ 已结晶为 synthesis）**
1907-1966 年九个核心贡献形成紧密关联链条：Perron→Frobenius→Schur→Weyl→von Neumann→Ky Fan→Hoffman-Wielandt→Wilkinson→Kato。每步回应前人留下的精确瓶颈，为后续工作打开新路径。三种证明范式（变分/酉变换/双随机矩阵）构成方法论骨架。

**O8｜纯粹数学→意外应用：反复出现的历史模式**
本次 ingest 多次出现同一模式：纯粹动机催生广泛应用（Frobenius 鄙视应用数学却建立 PageRank 基础；Weyl 研究薄膜振动却建立数值算法误差界；Perron 研究连分数却发现正矩阵谱结构）。这与 O2（高斯求积最优性思维）在结构上类似——强理论驱动→广泛应用涌现。

**O9｜"工具分离"思维的跨域复现**
同一结构性洞见出现在完全不同领域：
- DeepAgents（O3）：评估三重分离，各针对一个混淆陷阱
- Wilkinson 后向误差分析：把"算法稳定性"与"问题条件数"清晰分开
- 两者核心都是"拒绝把不同性质的失败混为一谈"

**O10｜Hermitian/正规矩阵为谱理论"安全岛"**
四个独立定理（Weyl/Schur/Hoffman-Wielandt/后向误差分析）从不同角度确认同一事实：Hermitian/正规矩阵特征值对扰动最稳定。这种"多定理确认同一结构事实"的知识合谋是强知识的标志。

**O11｜奇异值分解（SVD）是隐形主线**
SVD 出现在几乎所有矩阵分析定理中（von Neumann 迹不等式、Ky Fan 范数、Hoffman-Wielandt 证明、Weyl 1949 等），但没有单独的 ingest 来源——它是从多个文献中"浮现"出来的隐性核心，已成独立 wiki 页面。

**O12｜"战时数学"历史模式**
加藤（肺结核隔绝）、威尔金森（弹道计算）、冯·诺依曼（曼哈顿计划）三人均在战时外部压力下完成关键工作，且该压力直接塑造了研究方向。外部约束→数学深度这一路径值得在未来历史综合中使用。

**O13｜应用收敛性**
九个不同来源/时代的数学结果，应用全部汇聚到同一场景集（Markov 链/PageRank/PCA/量子力学/数值线性代数）——说明这些结果描述的是同一底层结构的不同坐标。

**O14｜有限维→无穷维桥接模式**
Kato（1966）是唯一明确将矩阵理论与算子理论统一的工作，前两章处理有限维，后续自然过渡。这种"从已知领域拱桥"的写作策略在知识传递中极有价值。

## 关键观察（压缩自 2026-04-15-03）

**O15｜无穷维概率测度的首次严格化**
[[Wiener测度]]（1923）是在无穷维路径空间 C₀[0,1] 上定义严格概率测度的首次成功，解决了"如何在路径空间上赋予概率"的根本难题。形成清晰的历史层次跃迁：有限维概率（Kolmogorov 1933）→ 无穷维测度（Wiener 1923，早于 Kolmogorov 系统化）。

**O16｜巴舍利耶：应用动机→需纯粹理论路径才获认可**
[[路易·巴舍利耶]] 1900 年首次将随机过程用于股价建模，比 Wiener 早 23 年，但被数学界忽视（庞加莱未重视），60 年后经纯粹数学路径重新发现。这是 O8（纯粹动机→意外应用）的反例：应用动机出发的工作，反而需要先经过纯粹理论的"认证"才能被接受。

**O17｜随机积分三层发展链**
随机积分形成清晰的层次：**随机游走**（离散）→ **Wiener积分**（确定性被积函数）→ **Itô随机积分**（随机被积函数）。每步扩展的核心技术障碍：离散→连续需要测度论；确定性→随机被积函数需要放弃 Riemann 路径改用均方极限（Itô 1944 核心贡献）。

**O18｜Itô公式：经典链式法则 + 一阶修正**
Itô 公式比经典链式法则多出 $\frac{1}{2}f''(B_t)dt$ 项（源于布朗运动的二次变差）。"经典结果 + 低阶修正"这一结构在量子场论（正规乘积）等多个领域复现，是随机分析连接经典分析的核心接口。

**O19｜概率论知识域纵向完整性达成**
知识库概率论知识域已从离散到连续随机过程纵向贯通：[[马尔可夫链]]（离散）→ [[随机游走]] → [[Wiener过程]]（连续时间/连续状态）→ [[Itô随机积分]]（随机微积分）。历史主干从 Bernoulli（大数定律）→ Gauss（正态分布）→ Wiener/Itô（随机分析）已全部覆盖。知识库规模：121→128页面（实体46→48，概念71→76）。
