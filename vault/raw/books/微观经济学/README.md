## 发展主线

```
斯密 (1776): 劳动分工 + 看不见的手
    |
边际革命 (1871-74): 主观价值论取代劳动价值论
    |
马歇尔 (1890): 供需综合 + 局部均衡
    |
希克斯/艾伦 (1934): 序数效用 --> 萨缪尔森 (1938): 显示性偏好
    |
科斯 (1937): 交易成本 --> 企业理论
冯·诺依曼 (1944): 博弈论 --> 纳什 (1950): 纳什均衡
    |
阿罗-德布鲁 (1954): 一般均衡存在性的严格证明
    |
贝克尔 (1964): 微观分析扩展至非市场行为
阿克洛夫 (1970): 信息不对称 --> 信息经济学
    |
卡尼曼/特沃斯基 (1979): 前景理论 --> 行为经济学
```

每一个阶段都是对前一阶段假设的挑战或拓展，构成了微观经济学 250 年来不断自我革新的内在逻辑。
