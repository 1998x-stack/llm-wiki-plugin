# 微观经济学发展史：完整时间线（1776—2017）

> 从亚当·斯密到行为经济学，250 年的思想演进

---

## 第一阶段：萌芽期（1776—1870）

> 古典经济学时代：劳动价值论占据主导

| 年份 | 人物 | 里程碑事件 |
|------|------|----------|
| **1776** | **亚当·斯密** (Adam Smith) | 出版《国富论》(*The Wealth of Nations*)，提出"看不见的手"、劳动分工、自由市场理论，奠定古典经济学基石 |
| **1780** | 杰里米·边沁 (Jeremy Bentham) | 《道德与立法原理导论》，定义效用原则（"最大多数人的最大幸福"），为功利主义经济学奠基 |
| **1817** | 大卫·李嘉图 (David Ricardo) | 《政治经济学及赋税原理》，系统阐述劳动价值论、比较优势理论、地租理论 |
| **1838** | 安托万·古诺 (Antoine Cournot) | 《财富理论的数学原理研究》，首次将数学引入经济分析，提出寡头竞争模型（古诺均衡——纳什均衡的前身） |
| **1844** | 朱尔·杜普伊 (Jules Dupuit) | 提出消费者剩余概念的雏形，被后世学者称为"现代微观经济学的秘密起源" |
| **1848** | 约翰·穆勒 (J.S. Mill) | 《政治经济学原理》，古典经济学的集大成之作 |
| **1854** | 赫尔曼·戈森 (H.H. Gossen) | 提出效用递减定律（戈森第一定律）和效用均等化法则（戈森第二定律），但著作完全被忽视，直到1878年才被杰文斯偶然发现 |

### 时代特征

- **价值理论**：劳动价值论——商品价值由生产它所需的劳动决定
- **分析方法**：文字论述为主，几乎不使用数学
- **核心关注**：国民财富的来源与分配

---

## 第二阶段：边际革命与新古典奠基期（1871—1910）

> 价值论的哥白尼式革命：从客观劳动价值到主观边际效用

| 年份 | 人物 | 里程碑事件 |
|------|------|----------|
| **1871** | **威廉·杰文斯** (W.S. Jevons) | 《政治经济学理论》，独立提出边际效用理论，将效用数学化 |
| **1871** | **卡尔·门格尔** (Carl Menger) | 《国民经济学原理》，同年独立提出边际效用理论，创立奥地利学派 |
| **1874** | **莱昂·瓦尔拉斯** (Leon Walras) | 《纯粹经济学要义》(第一部分)，建立一般均衡理论的数学框架，被誉为"一般均衡理论之父" |
| **1877** | 瓦尔拉斯 | 《纯粹经济学要义》(第二部分)完成 |
| **1881** | 弗朗西斯·埃奇沃思 (F.Y. Edgeworth) | 引入无差异曲线和埃奇沃思盒图，分析交换效率 |
| **1890** | **阿尔弗雷德·马歇尔** (Alfred Marshall) | 《经济学原理》，综合供给与需求理论，创立局部均衡分析，定义弹性、消费者剩余、短期与长期等核心概念，成为数十年间标准教科书 |
| **1906** | 维尔弗雷多·帕累托 (Vilfredo Pareto) | 推广序数效用理论和帕累托最优概念，为福利经济学奠基 |

### 时代特征

- **价值理论**：主观边际效用论取代劳动价值论
- **分析方法**：数学工具大量引入（微积分、方程组）
- **两大传统**：瓦尔拉斯的一般均衡 vs. 马歇尔的局部均衡
- **核心命题**：价格如何在市场中被决定

---

## 第三阶段：理论体系的完善期（1915—1960s）

> 数学化、公理化：微观经济学获得严格的理论基础

| 年份 | 人物 | 里程碑事件 |
|------|------|----------|
| **1915** | 尤金·斯勒茨基 (Eugen Slutsky) | 推导出价格效应的分解（替代效应 + 收入效应），但论文被忽视近20年 |
| **1928** | 冯·诺依曼 (John von Neumann) | 在《数学年鉴》发表极小极大定理证明，博弈论数学基础初建 |
| **1933** | 拉格纳·弗里希 (Ragnar Frisch) | 首次区分"微观动态"与"宏观动态"分析，为micro/macro划分奠基 |
| **1933** | 琼·罗宾逊 (Joan Robinson) | 《不完全竞争经济学》 |
| **1933** | 爱德华·张伯伦 (E. Chamberlin) | 《垄断竞争理论》，同年独立提出垄断竞争理论 |
| **1934** | **希克斯 & 艾伦** (Hicks & Allen) | "价值理论的重新审视"，建立序数效用论和无差异曲线分析法，首创"基数效用""序数效用"术语，重新推导斯勒茨基方程 |
| **1937** | **罗纳德·科斯** (Ronald Coase) | **"企业的性质"**(*The Nature of the Firm*)，提出交易成本概念，解释企业存在的原因，引用超59,000次 |
| **1938** | **保罗·萨缪尔森** (Paul Samuelson) | "消费者行为的纯粹理论笔记"，提出显示性偏好理论 |
| **1939** | 约翰·希克斯 (John Hicks) | 《价值与资本》(*Value and Capital*)，系统化序数效用论、替代效应与收入效应，建立跨期均衡分析 |
| **1941** | 皮特·德·沃尔夫 (Pieter de Wolff) | 首次在出版物中使用"microeconomics"一词 |
| **1944** | **冯·诺依曼 & 摩根斯坦** | **《博弈论与经济行为》**(*Theory of Games and Economic Behavior*)，创立博弈论作为独立学科，被称为"20世纪社会科学最重要的里程碑之一" |
| **1947** | 萨缪尔森 | 《经济分析基础》(*Foundations of Economic Analysis*)，将数学方法系统引入经济学理论，定义了"做经济理论的方式" |
| **1950** | **约翰·纳什** (John Nash) | **"N人博弈的均衡点"**，仅一页论文定义了纳什均衡，成为博弈论核心概念 |
| **1951** | 肯尼斯·阿罗 (Kenneth Arrow) | 《社会选择与个人价值》，阿罗不可能定理 |
| **1954** | **阿罗 & 德布鲁** (Arrow & Debreu) | **"竞争经济均衡的存在性"**，严格证明一般均衡的存在性，成为价格理论的标准模型 |
| **1957** | 加里·贝克尔 (Gary Becker) | 《歧视经济学》，将微观分析扩展至种族歧视问题 |

### 时代特征

- **公理化**：经济理论获得数学上的严格基础
- **博弈论兴起**：从零和博弈到一般策略互动
- **完美竞争 vs. 不完全竞争**：垄断竞争理论挑战完美竞争假设
- **核心成就**：一般均衡存在性的证明

## 第四阶段：拓展与深化期（1960s—至今）

> 突破"理性经济人"的边界：信息、制度与行为

| 年份 | 人物 | 里程碑事件 |
|------|------|----------|
| **1961** | 乔治·斯蒂格勒 (George Stigler) | "信息经济学"论文，研究搜寻成本对市场的影响 |
| **1964** | **加里·贝克尔** (Gary Becker) | **《人力资本》**(*Human Capital*)，将教育和培训视为经济投资，拓展微观分析边界 |
| **1966** | 莱宾斯坦 (H. Leibenstein) | 提出"X非效率"概念，质疑厂商必然成本最小化的假设 |
| **1968** | 贝克尔 | "犯罪与惩罚"，用理性选择理论分析犯罪行为 |
| **1970** | **乔治·阿克洛夫** (George Akerlof) | **"柠檬市场"**(*The Market for Lemons*)，开创信息不对称经济学，揭示逆向选择机制 |
| **1972** | 雨果·索南沙因 (Hugo Sonnenschein) | "市场超额需求函数"，揭示一般均衡理论对总需求预测能力的局限 |
| **1973** | 迈克尔·斯宾塞 (Michael Spence) | 劳动力市场信号传递理论，学历作为生产力信号 |
| **1976** | 格罗斯曼 & 斯蒂格利茨 | "信息与竞争价格体系"，分析信息对市场均衡的影响 |
| **1977** | 威廉·鲍莫尔 (William Baumol) | 给出自然垄断的现代正式定义 |
| **1979** | **卡尼曼 & 特沃斯基** | **"前景理论"**(*Prospect Theory*)，开创行为经济学，挑战理性经济人假设，*Econometrica* 历史上被引最多文章 |
| **1981** | 贝克尔 | 《家庭论》(*A Treatise on the Family*)，经济学分析扩展至家庭决策 |
| **1982** | 鲍莫尔 | 定义"可竞争市场"(contestable market) 概念 |
| **1986** | 赫伯特·西蒙 (Herbert Simon) | "有限理性"理论获广泛认可，根本性修正"经济人"假设 |
| **1991** | 科斯获诺贝尔奖 | "发现和阐明了交易成本和产权在经济体制中的重要性" |
| **1992** | 贝克尔获诺贝尔奖 | "将微观经济分析的领域扩展到广泛的人类行为" |
| **1994** | 纳什/海萨尼/泽尔腾获诺贝尔奖 | 博弈论在经济学中的核心地位获最高认可 |
| **2001** | 阿克洛夫/斯宾塞/斯蒂格利茨获诺贝尔奖 | 信息不对称研究获最高认可 |
| **2002** | 卡尼曼获诺贝尔奖 | 将心理学洞见纳入经济科学 |
| **2017** | 理查德·塞勒 (Richard Thaler) 获诺贝尔奖 | 行为经济学贡献，"助推"(Nudge)理论进入政策实践 |

### 时代特征

- **信息经济学**：放松"完全信息"假设，研究信息不对称下的市场行为
- **行为经济学**：放松"完全理性"假设，引入心理学实证证据
- **制度经济学**：放松"零交易成本"假设，研究制度对经济的影响
- **经济学帝国主义**：微观分析扩展至犯罪、家庭、歧视等非传统领域
