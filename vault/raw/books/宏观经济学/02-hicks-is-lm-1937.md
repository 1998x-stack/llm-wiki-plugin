# IS-LM 模型：希克斯对凯恩斯革命的数学化诠释（1937）

## 论文信息

- **作者**：John R. Hicks（约翰·理查德·希克斯）
- **题目**：*Mr. Keynes and the "Classics": A Suggested Interpretation*
- **发表**：*Econometrica*, Vol. 5, No. 2, 1937, pp. 147-159
- **诺贝尔奖**：1972 年（与 Kenneth Arrow 共同获得）

---

## 一、历史背景与学术动因

### 1.1 凯恩斯革命的冲击

1936 年，约翰·梅纳德·凯恩斯（John Maynard Keynes）出版了划时代的《就业、利息与货币通论》
（*The General Theory of Employment, Interest and Money*）。这部著作从根本上挑战了古典经济学的
核心命题——萨伊定律（"供给创造其自身的需求"），提出有效需求不足可以导致持续的非自愿失业。

然而，《通论》本身的论述方式极其复杂且充满歧义。凯恩斯采用了大量散文式的论证、反复的类比与隐喻，
不同章节之间甚至存在逻辑张力。当时的经济学家们对这本书的核心主张究竟是什么产生了激烈争论。正如
保罗·萨缪尔森后来所说："这是一本写得很差的书，组织混乱……充满了困惑与混乱。"

### 1.2 希克斯的"翻译"工程

约翰·希克斯在 1936 年的计量经济学会牛津会议上发表了一篇论文，试图将凯恩斯的思想与古典经济学
进行系统性的对比。他的目标不是创造新理论，而是提供一个统一的分析框架，使凯恩斯理论与古典理论
能够在同一套坐标体系中被比较和评判。

这篇论文于 1937 年发表在 *Econometrica* 上，仅有 12 页，却催生了宏观经济学中最持久、最具影响
力的分析工具之一——IS-LM 模型。

### 1.3 同期的竞争性诠释

值得注意的是，希克斯并非唯一试图形式化凯恩斯理论的学者。几乎同时期：

| 学者 | 贡献 | 年份 |
|------|------|------|
| James Meade | 简化的凯恩斯模型 | 1937 |
| Roy Harrod | IS-LM 的早期变体 | 1937 |
| Franco Modigliani | 引入劳动力市场的完整模型 | 1944 |
| Alvin Hansen | 推广 IS-LM 到美国教科书 | 1949 |

希克斯的版本最终胜出，部分原因在于其几何直觉的优美性和分析的简洁性。Alvin Hansen 在美国的
大力推广使得该模型也被称为 Hicks-Hansen 模型。

## 二、模型的核心结构

### 2.1 基本设定

IS-LM 模型将宏观经济均衡分解为两个市场的联立均衡：

1. **商品市场**（IS 曲线）：投资（Investment）等于储蓄（Savings）
2. **货币市场**（LM 曲线）：流动性偏好（Liquidity preference）等于货币供给（Money supply）

两条曲线在利率（r）与产出（Y）的二维空间中交叉，交点即为宏观经济的一般均衡。

### 2.2 IS 曲线：商品市场均衡

IS 曲线描述使商品市场达到均衡的所有（r, Y）组合。其推导如下：

**均衡条件**：Y = C(Y - T) + I(r) + G

其中：
- C(Y - T)：消费函数，随可支配收入递增（0 < MPC < 1）
- I(r)：投资函数，随利率递减（dI/dr < 0）
- G：政府支出（外生）
- T：税收（外生或比例税）

**IS 曲线的斜率为负**：利率上升 -> 投资下降 -> 总需求下降 -> 均衡产出下降。

**IS 曲线的位移因素**：
- 政府支出 G 增加 -> IS 右移
- 税收 T 增加 -> IS 左移
- 消费者信心提升 -> IS 右移
- 投资者预期改善 -> IS 右移

### 2.3 LM 曲线：货币市场均衡

LM 曲线描述使货币市场达到均衡的所有（r, Y）组合。其推导如下：

**均衡条件**：M/P = L(r, Y)

其中：
- M/P：实际货币供给（名义货币供给除以价格水平）
- L(r, Y)：实际货币需求，随产出递增、随利率递减

**LM 曲线的斜率为正**：产出上升 -> 交易性货币需求增加 -> 在货币供给不变的情况下，
利率必须上升以抑制投机性货币需求 -> 货币市场重新均衡。

**LM 曲线的位移因素**：
- 货币供给 M 增加 -> LM 右移（下移）
- 价格水平 P 上升 -> LM 左移（上移）
- 货币需求减少（如金融创新） -> LM 右移

### 2.4 IS-LM 图示

```
    r (利率)
    |
    |        LM
    |       /
    |      /
    |     /
r*  |----*-----------
    |   /|
    |  / |
    | /  |    IS
    |/   |   /
    |    |  /
    |    | /
    |    |/
    +----+-----------> Y (产出/收入)
         Y*

    图 1：IS-LM 均衡
    * 点为宏观经济一般均衡
    r* = 均衡利率
    Y* = 均衡产出
```

## 三、政策分析：三种经典情景

### 3.1 情景一：财政扩张（IS 右移）

政府增加支出或减税，IS 曲线右移：

```
    r
    |        LM
    |       /
    |      /
r'  |-----*'--------
    |    /|
r*  |---*-|---------
    |  /| |
    | / | |   IS'
    |/  | |  /
    |   | | / IS
    +---+-+-------> Y
        Y* Y'

    图 2：财政扩张效果
    IS -> IS' (右移)
    均衡从 (Y*, r*) 移至 (Y', r')
    产出增加，但利率也上升
    （利率上升导致部分私人投资被挤出）
```

**关键洞察**：财政乘数效应被"挤出效应"（crowding-out effect）部分抵消。利率上升压制了
私人投资，使最终产出增幅小于简单乘数预测的幅度。

挤出效应的大小取决于：
- LM 曲线的斜率（货币需求的利率弹性）
- IS 曲线的斜率（投资的利率弹性）

### 3.2 情景二：货币扩张（LM 右移）

中央银行增加货币供给，LM 曲线右移（下移）：

```
    r
    |       LM  LM'
    |       /  /
    |      /  /
r*  |----*/ /
    |   /| /
r'  |--/-|*'---------
    | /  |/
    |/   /   IS
    |   /|  /
    +--/-+-------> Y
       Y*  Y'

    图 3：货币扩张效果
    LM -> LM' (右移/下移)
    均衡从 (Y*, r*) 移至 (Y', r')
    利率下降，产出增加
```

**传导机制**：货币供给增加 -> 利率下降 -> 投资增加 -> 总需求增加 -> 产出增加。

### 3.3 情景三：流动性陷阱（水平的 LM 段）

这是凯恩斯最具争议性的情景。当利率降至某一极低水平时，公众对持有货币的偏好变得无限大
（因为预期利率只会上升、债券价格只会下跌），LM 曲线变为水平：

```
    r
    |
    |          LM (正常段)
    |         /
    |        /
    |       /
    r_min ===*==*'============ LM (流动性陷阱段)
    |        |  |
    |     IS | IS'
    |       \| /
    +--------+-------> Y
             Y*=Y'

    图 4：流动性陷阱
    在 r_min 处 LM 变为水平
    IS 右移至 IS' 不改变利率
    财政政策完全有效，货币政策完全失效
```

**政策含义**：
- 货币政策失效：无论增加多少货币供给，利率都不会进一步下降
- 财政政策完全有效：没有挤出效应（利率不上升）
- 这一情景在 2008 年全球金融危机后重获关注（零利率下限问题）

## 四、希克斯的三个"模型"

希克斯在原文中实际上构建了三个模型进行比较：

| 模型 | 投资函数 | 货币需求 | 特征 |
|------|---------|---------|------|
| 古典模型 | I = I(r) | M = kY | 货币中性，产出由供给决定 |
| 凯恩斯特例 | I = I(r) | 流动性陷阱 | 货币政策失效 |
| 一般理论 | I = I(r, Y) | L = L(r, Y) | IS-LM 的一般形式 |

希克斯的核心论点是：凯恩斯的"一般理论"实际上并不比古典理论更"一般"——两者都是更一般的
IS-LM 框架的特例，取决于参数的具体取值。

## 五、历史影响与扩展

### 5.1 教科书中的统治地位

IS-LM 模型从 1940 年代起主导了宏观经济学教学长达半个多世纪：

- **1944 年**：Modigliani 增加劳动力市场，构建完整的凯恩斯体系
- **1949 年**：Hansen 的《货币理论与财政政策》将 IS-LM 引入美国课堂
- **1960-70 年代**：大规模计量经济模型（如 MIT-Penn-SSRC 模型）以 IS-LM 为理论基础
- **至今**：Mankiw、Blanchard 等中级宏观经济学教科书仍以 IS-LM 为核心框架

### 5.2 模型的演进

IS-LM 并非静态工具，它经历了多次重要演化：

1. **Mundell-Fleming 模型（1960s）**：引入开放经济（加入国际收支均衡 BP 曲线）
2. **AD-AS 模型**：将 IS-LM 从固定价格推广到可变价格水平
3. **IS-MP 模型（Romer, 2000）**：用货币政策规则（如泰勒规则）替代 LM 曲线
4. **新凯恩斯 DSGE 模型**：微观基础化的"三方程模型"（IS 曲线 + Phillips 曲线 + 货币政策规则）

### 5.3 对政策实践的影响

IS-LM 直接塑造了二战后西方国家的宏观经济政策思维：

- 提供了财政政策与货币政策相对效力的分析框架
- 为"凯恩斯主义共识"（1945-1970）提供了理论支柱
- 帮助政策制定者理解经济衰退时货币政策可能失效的场景

## 六、批评与争议

### 6.1 希克斯本人的反思

最具戏剧性的批评来自模型的创造者本人。1980 年，已获诺贝尔奖的希克斯发表了
*IS-LM: An Explanation*，对自己四十多年前的工作提出了深刻的自我批评：

> "我把《通论》中最不应该被形式化的部分形式化了。"

希克斯的主要批评包括：

1. **时间维度的缺失**：IS-LM 是静态的均衡分析，而凯恩斯的核心关切是动态的不确定性
2. **预期的简化**：模型忽略了凯恩斯最重视的"动物精神"和不确定性
3. **存量与流量的混淆**：IS 是流量均衡，LM 是存量均衡，两者的时间尺度不同
4. **价格水平的固定**：原始模型假设价格不变，这本身就是一个极端假设

### 6.2 后凯恩斯主义的批判

后凯恩斯主义经济学家（如 Joan Robinson, Paul Davidson, Hyman Minsky）对 IS-LM 的批评
更为激烈，认为它"背叛"了凯恩斯的革命性洞察：

- **内生货币供给**：LM 曲线假设外生货币供给，但现代货币体系中货币供给是内生的
- **根本不确定性**：IS-LM 用概率可计算的风险取代了凯恩斯强调的不可计算的不确定性
- **均衡导向**：凯恩斯关心的是非均衡动态，IS-LM 将其压缩为比较静态分析
- **综合的悖论**：新古典综合（Neoclassical Synthesis）通过 IS-LM 将凯恩斯的革命
  重新驯化为古典框架的特例，正是凯恩斯本人所反对的

### 6.3 新古典宏观经济学的挑战

1970 年代，Robert Lucas 领导的理性预期革命从另一个方向攻击 IS-LM：

- **卢卡斯批判**：IS-LM 的结构参数在政策变化下不稳定
- **微观基础的缺乏**：模型缺乏个体最优化行为的基础
- **理性预期的缺失**：模型中没有前瞻性的预期形成机制

## 七、现代意义与复兴

### 7.1 全球金融危机后的复兴

2008 年全球金融危机后，IS-LM 模型经历了意想不到的复兴：

- **零利率下限**（ZLB）使"流动性陷阱"从教科书概念变为现实
- Paul Krugman 频繁使用 IS-LM 分析危机期间的政策辩论
- 模型的直觉性使其在公共政策讨论中比 DSGE 模型更有影响力

### 7.2 教学价值的持久性

尽管前沿研究已经超越了 IS-LM，但作为教学工具，它仍然具有不可替代的价值：

- 提供了宏观经济思维的基本框架
- 是理解更复杂模型（DSGE、新凯恩斯模型）的必要阶梯
- 帮助学生建立关于财政政策和货币政策交互效应的直觉

### 7.3 评价

IS-LM 模型的历史地位是矛盾的。它是经济学史上最成功的"翻译"工程——将一部晦涩的著作
转化为一代又一代经济学家可以操作的工具。但它也可能是最成功的"误读"——通过形式化的过程，
恰恰丢掉了凯恩斯最想传达的关于不确定性、动物精神和资本主义内在不稳定性的核心信息。

正如 Axel Leijonhufvud 在其经典著作《论凯恩斯经济学与凯恩斯的经济学》（1968）中所区分的：
IS-LM 代表的是"凯恩斯经济学"（Keynesian Economics），而非"凯恩斯的经济学"
（the Economics of Keynes）。这个区分至今仍然重要。
