# 菲利普斯曲线：通胀与失业的权衡及其瓦解（1958）

## 论文信息

- **作者**：Alban William Housego Phillips（奥尔班·威廉·菲利普斯）
- **题目**：*The Relation between Unemployment and the Rate of Change of Money Wage Rates in the United Kingdom, 1861-1957*
- **发表**：*Economica*, Vol. 25, No. 100, 1958, pp. 283-299

---

## 一、作者背景：从工程师到经济学家

### 1.1 非凡的人生轨迹

A.W. 菲利普斯的人生经历在经济学家中极为罕见。1914 年生于新西兰，少年时代辍学打工，
做过猎鳄者、电影院放映员和矿工。二战期间在英国皇家空军服役，被日军俘虏后在战俘营中
学会了电气工程——他用偷来的零件制作了一台隐藏的收音机。

战后，菲利普斯进入伦敦政治经济学院（LSE）攻读社会学，但很快转向经济学。他的工程背景
使他用一种独特的"系统论"视角看待经济问题。

### 1.2 MONIAC：液压经济学

1949 年，菲利普斯建造了一台名为 MONIAC（Monetary National Income Analogue Computer）的
液压计算机。这台用水管、水箱和阀门构成的机器模拟了货币在经济体中的流动——收入、支出、
税收、储蓄分别由不同的水管和水箱表示。

MONIAC 并非玩具。它能够准确地模拟财政政策和货币政策的效果，被多所大学和中央银行采购
使用。这台机器体现了菲利普斯一贯的方法论特征：用工程师的直觉处理经济学问题。

### 1.3 控制论视角

菲利普斯对经济学的另一重要贡献是将控制论（Cybernetics）引入宏观经济政策分析。他在
1954 年和 1957 年的论文中，用反馈控制理论分析了稳定化政策的时滞问题——这一工作
远远领先于时代，直到后来理性预期革命才得到充分重视。

## 二、原始论文的内容与方法

### 2.1 研究问题

菲利普斯的研究问题非常具体：英国近一个世纪的数据中，失业率与名义工资变化率之间是否
存在稳定的统计关系？

注意：原始论文研究的是**名义工资变化率**（而非价格通胀率），这一区别后来证明十分重要。

### 2.2 数据与方法

菲利普斯使用了三个时段的英国数据：

| 时段 | 数据年限 | 用途 |
|------|---------|------|
| 第一时段 | 1861-1913 | 主要估计期 |
| 第二时段 | 1913-1948 | 验证（含两次世界大战） |
| 第三时段 | 1948-1957 | 近期验证 |

他对 1861-1913 年的数据进行了分组平均，然后用目测法（而非最小二乘法）拟合了一条曲线。
这一方法论在今天看来相当粗糙，但拟合效果却令人印象深刻。

### 2.3 核心发现

菲利普斯发现了一条稳定的负向非线性关系：

```
    dW/W (名义工资
    变化率 %)
    |
  10|
    |  *
   8|   *
    |
   6|     *
    |
   4|       *
    |         *
   2|            *
    |                 *
   0|---------------------*--------*--------
    |                                  *
  -2|
    |
  -4|
    +--+--+--+--+--+--+--+--+--+----> U (失业率 %)
       0  1  2  3  4  5  6  7  8

    图 1：菲利普斯曲线的原始形态
    纵轴：名义工资年变化率（%）
    横轴：失业率（%）
    曲线呈非线性负相关
    当失业率约 5.5% 时，工资变化率为零
    当失业率约 2.5% 时，工资变化率约为 2%
```

**拟合方程**（菲利普斯的原始形式）：

    dW/W + a = b * U^c

其中 a, b, c 为拟合参数。

### 2.4 菲利普斯的解释

菲利普斯对这一关系的解释基于简单的供求逻辑：

1. **需求拉动**：当失业率低时，劳动力市场紧张，雇主竞相加薪以吸引工人
2. **非线性**：工资在劳动力短缺时上涨很快，但在劳动力过剩时下降很慢（向下刚性）
3. **需求变化率效应**：不仅失业水平，失业的变化方向也影响工资变化（滞后效应）
4. **生活成本效应**：进口价格变动通过生活成本影响工资谈判

值得强调的是，菲利普斯本人的表述相当谨慎。他将这一关系视为一种经验规律，并未赋予其
过强的政策含义。

## 三、Samuelson 与 Solow 的美国化改造（1960）

### 3.1 从工资到价格

1960 年，保罗·萨缪尔森和罗伯特·索洛在美国经济学会年会上发表了一篇论文，将菲利普斯的
发现进行了两个关键的转换：

1. **地域转换**：从英国数据推广到美国数据
2. **变量转换**：从名义工资变化率转换为价格通胀率

**转换逻辑**：如果工资增长率超过劳动生产率增长率，超出部分就会转化为价格上涨。即：

    价格通胀率 = 工资增长率 - 劳动生产率增长率

### 3.2 "政策菜单"的诞生

萨缪尔森和索洛正式将菲利普斯曲线命名为"Phillips Curve"，并赋予其一个菲利普斯本人
从未明确表述的政策含义——通胀与失业之间存在一个**稳定的政策权衡菜单**：

```
    pi (通胀率 %)
    |
   6|  A
    |   \
   5|    \
    |     \
   4|      \     菲利普斯曲线
    |       \   （"政策菜单"）
   3|        \
    |         \
   2|          B
    |           \
   1|            \
    |             \
   0|              C
    +--+--+--+--+--+--+---> U (失业率 %)
       1  2  3  4  5  6

    图 2：Samuelson-Solow 版菲利普斯曲线
    政策制定者可以"选择"曲线上的任意一点：
    A 点：低失业、高通胀
    B 点：中等权衡
    C 点：高失业、低通胀
```

这一"菜单"解释在 1960 年代的美国政策界产生了巨大影响。肯尼迪和约翰逊政府的经济顾问
（包括萨缪尔森本人）明确地将菲利普斯曲线视为政策制定的指南，认为可以通过容忍稍高的
通胀来"购买"更低的失业率。

## 四、弗里德曼-费尔普斯批判（1967-1968）

### 4.1 预期增强型菲利普斯曲线

1967 年，米尔顿·弗里德曼在美国经济学会主席演说中，以及 1968 年，埃德蒙·费尔普斯在
一篇独立的论文中，分别对原始菲利普斯曲线提出了毁灭性的理论批评。

**核心论点**：工人和企业关心的不是名义工资，而是**实际工资**。因此，菲利普斯曲线
关系中必须考虑通胀预期。

**预期增强型菲利普斯曲线**：

    pi = pi_e - beta * (U - U_n)

其中：
- pi：实际通胀率
- pi_e：预期通胀率
- U：实际失业率
- U_n：自然失业率（Natural Rate of Unemployment）
- beta：正的系数

### 4.2 自然失业率假说

弗里德曼提出了"自然失业率"概念——由经济的实际结构因素（劳动力市场摩擦、信息不完全、
工会力量等）决定的失业率。在自然失业率下，实际通胀等于预期通胀，劳动力市场处于均衡。

**关键推论**：

| 情景 | 短期效果 | 长期效果 |
|------|---------|---------|
| 扩张性政策降低 U < U_n | 通胀上升 | 预期调整，U 回到 U_n |
| 持续试图维持 U < U_n | 需要不断加速的通胀 | 通胀螺旋 |
| 长期菲利普斯曲线 | -- | 垂直线，位于 U_n 处 |

```
    pi (通胀率)
    |
    |     LRPC (长期菲利普斯
    |      |    曲线 = 垂直线)
    |      |
    |      |        SRPC_3 (pi_e = 6%)
   6|- - - * - - - /
    |      |      /
    |      |     /
    |      |    /    SRPC_2 (pi_e = 4%)
   4|- - - * - /- -/
    |      |  /   /
    |      | /   /
    |      |/   /    SRPC_1 (pi_e = 2%)
   2|- - - * - /- -/
    |      |  /   /
    |      | /   /
    |      |/   /
   0|------+-------+----------> U
          U_n

    图 3：预期增强型菲利普斯曲线
    SRPC：短期菲利普斯曲线（每条对应一个预期通胀水平）
    LRPC：长期菲利普斯曲线（垂直，位于自然失业率 U_n 处）
    沿垂直线向上的箭头表示加速主义动态
```

### 4.3 加速主义假说

弗里德曼-费尔普斯框架产生了一个强有力的预测——**加速主义假说**（Accelerationist Hypothesis）：

如果政府持续试图将失业率维持在自然率以下，通胀不会稳定在某个更高的水平，而是会
**持续加速**上升。这是因为：

1. 扩张政策 -> 通胀上升（比如从 2% 到 4%）
2. 公众调高通胀预期（从 2% 到 4%）
3. 短期菲利普斯曲线上移
4. 维持低失业需要更高的通胀（比如 6%）
5. 预期再次调整......
6. 通胀无限加速

## 五、1970 年代的经验检验：滞胀

### 5.1 历史验证

1970 年代是菲利普斯曲线历史上最戏剧性的时期。两次石油危机（1973、1979）引发了
西方世界的"滞胀"（Stagflation）——高通胀与高失业同时出现。

**美国关键数据**：

| 年份 | 失业率 (%) | 通胀率 (%) | 菲利普斯曲线预测 |
|------|-----------|-----------|----------------|
| 1969 | 3.5 | 5.5 | 曲线上方 |
| 1974 | 5.6 | 11.0 | 严重偏离 |
| 1975 | 8.5 | 9.1 | 严重偏离 |
| 1980 | 7.1 | 13.5 | 严重偏离 |

### 5.2 范式转换

滞胀的出现对凯恩斯主义经济学构成了沉重打击：

1. **原始菲利普斯曲线**的稳定性被证伪
2. **弗里德曼-费尔普斯的预测**得到惊人的验证
3. **政策含义**发生根本转变：不存在长期的通胀-失业权衡
4. 为**理性预期革命**和**货币主义**提供了经验弹药

罗伯特·卢卡斯在此基础上走得更远：如果预期是理性的（而非适应性的），那么即使在短期内，
**预期到的**货币政策也不会产生实际效果——这就是"政策无效性命题"。

## 六、现代新凯恩斯主义菲利普斯曲线

### 6.1 微观基础化

1990 年代以来，新凯恩斯主义经济学家重新构建了具有微观基础的菲利普斯曲线——
新凯恩斯主义菲利普斯曲线（New Keynesian Phillips Curve, NKPC）：

    pi_t = beta * E_t[pi_{t+1}] + kappa * x_t

其中：
- pi_t：当期通胀
- E_t[pi_{t+1}]：对下期通胀的理性预期（前瞻性）
- x_t：产出缺口（实际产出与潜在产出之差）
- beta：贴现因子（接近 1）
- kappa：斜率系数（取决于价格调整频率等微观参数）

### 6.2 与原始菲利普斯曲线的关键差异

| 特征 | 原始菲利普斯曲线 | 预期增强型 | 新凯恩斯 NKPC |
|------|----------------|-----------|---------------|
| 预期 | 无 | 适应性（后顾） | 理性（前瞻） |
| 微观基础 | 无 | 无 | 有（Calvo 定价） |
| 权衡 | 长期存在 | 仅短期 | 取决于央行可信度 |
| 失业/产出 | 失业率 | 失业率 | 产出缺口 |
| 供给冲击 | 未考虑 | 可添加 | 内含成本推动项 |

### 6.3 "扁平化"之谜（2008 年后）

全球金融危机以来，菲利普斯曲线面临新的经验挑战——曲线似乎变得异常"扁平"：

- **2009-2013 年**：失业率大幅上升，但通胀并未像预期那样大幅下降（"失踪的通缩"）
- **2015-2019 年**：失业率降至历史低位，但通胀却持续低迷（"失踪的通胀"）
- **2021-2023 年**：通胀突然飙升，但与失业率的关系不明确

**可能的解释**：

1. **通胀预期被锚定**：央行信誉使长期通胀预期稳定在目标值附近
2. **全球化效应**：全球供应链和国际竞争压平了国内通胀对本国失业率的敏感度
3. **劳动力市场结构变化**：零工经济、工会弱化改变了工资议价动态
4. **测量问题**：传统失业率可能不再准确反映劳动力市场松紧

## 七、评价与遗产

### 7.1 方法论贡献

菲利普斯的论文示范了一种重要的经济学研究方法——从长期历史数据中提取经验规律。
尽管具体结论被后来的研究修正甚至推翻，但这种方法论传统影响了后续的大量研究。

### 7.2 政策思维的永久改变

菲利普斯曲线——尽管经历了多次形态变化——永久地改变了宏观经济政策的思考方式：

- 政策制定者不再能够忽视通胀与就业之间的复杂关系
- 通胀预期管理成为货币政策的核心任务
- "可信度"和"透明度"成为央行制度设计的关键词

### 7.3 菲利普斯本人的结局

A.W. 菲利普斯本人并未看到围绕其名字展开的这些宏大争论的全貌。他于 1967 年离开 LSE
前往澳大利亚国立大学，转向研究中国经济。1975 年，菲利普斯因中风在奥克兰去世，年仅 60 岁。

他从未获得诺贝尔奖，但他的名字——通过"菲利普斯曲线"——成为了宏观经济学中被引用
最频繁、争论最激烈的概念之一。弗里德曼（1976）和费尔普斯（2006）都因与菲利普斯曲线
相关的工作而获得诺贝尔奖，而菲利普斯本人只是提供了那条最初的经验曲线。

### 7.4 持续的研究议题

菲利普斯曲线的研究至今仍然是宏观经济学最活跃的前沿之一：

1. **非线性菲利普斯曲线**：曲线的斜率是否随经济周期而变化？
2. **区域异质性**：不同国家/地区的菲利普斯曲线是否具有不同的特征？
3. **通胀预期的形成机制**：适应性、理性、还是混合？信息摩擦如何影响？
4. **全球菲利普斯曲线**：全球化是否使国内菲利普斯曲线"平坦化"？
5. **后疫情通胀**：2021-2023 年的通胀飙升是否复活了陡峭的菲利普斯曲线？

正如 N. Gregory Mankiw 所言："菲利普斯曲线是宏观经济学中最重要、也最令人困惑的关系。
每当我们以为理解了它，现实就会给我们一个新的惊喜。"
