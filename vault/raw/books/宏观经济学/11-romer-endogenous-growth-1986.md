# 内生增长理论：Paul Romer 与经济增长的知识革命 (1986)

## 一、引言

1986年，年仅30岁的 Paul Romer 在 *Journal of Political Economy* 上发表了题为 **"Increasing Returns and Long-Run Growth"** 的论文。这篇脱胎于他在芝加哥大学博士论文的研究，从根本上改变了经济学家思考长期经济增长的方式。

在 Romer 之前，主流增长理论——以 Robert Solow (1956) 的新古典增长模型为代表——将技术进步视为 **外生的 (Exogenous)**：模型可以描述给定技术进步速率下经济如何增长，却无法解释技术进步本身从何而来。这就好比一个关于汽车速度的理论，将发动机的马力视为给定的常数，放弃解释为什么有些发动机更强劲。

Romer 的根本贡献在于将技术进步 **内生化 (Endogenize)**——将知识的生产和积累纳入经济增长模型的核心，从而回答了一个古老而根本的问题：**为什么有些国家比其他国家富裕得多，而这种差距似乎不会自动消失？**

这一思想最终演化为 **内生增长理论 (Endogenous Growth Theory)**，成为现代增长经济学的两大支柱之一（另一支柱是制度经济学），并使 Romer 于2018年获得诺贝尔经济学奖（与 William Nordhaus 共享）。

## 二、历史背景与知识谱系

### 2.1 Solow 模型的成就与困境

Robert Solow 在1956年发表的新古典增长模型是20世纪经济学最重要的理论成就之一。其核心框架可以简要概括如下：

```
  Solow 模型基本结构:

  Y = A * F(K, L) = A * K^alpha * L^(1-alpha)

  资本积累方程:
  dK/dt = s * Y - delta * K

  其中:
    Y     = 总产出
    A     = 全要素生产率 (TFP), 外生给定并以固定速率增长
    K     = 物质资本存量
    L     = 劳动力
    s     = 储蓄率 (外生)
    delta = 资本折旧率
    alpha = 资本的产出弹性 (0 < alpha < 1)
```

Solow 模型的关键预测是 **资本的边际报酬递减**：在劳动力和技术不变的情况下，持续增加资本投入带来的额外产出会越来越少。这意味着：

- **资本积累本身无法维持长期增长**——人均产出最终趋于稳态
- **长期人均增长率完全由外生技术进步率决定**——储蓄率、人口增长率只影响稳态水平，不影响稳态增长率
- **条件收敛 (Conditional Convergence)**——在技术和偏好相同的假设下，穷国应该比富国增长得更快，最终收敛到相同的人均收入水平

Solow 模型面临的核心困境在于：

**第一，增长核算的残差过大。** Solow 自己的增长核算研究发现，美国1909-1949年人均产出增长中，只有约12.5%可以归因于资本深化，剩余87.5%都是 "Solow 残差"——即无法由要素投入增加解释的技术进步。换言之，模型将增长最重要的来源放在了模型之外。

**第二，无条件收敛并未发生。** 跨国数据显示，穷国并没有系统性地比富国增长得更快。相反，许多撒哈拉以南非洲国家在战后数十年中几乎没有任何人均收入增长，与发达国家的差距不断扩大。

**第三，资本流动方向之谜。** 如果穷国的资本边际产出更高（因为资本稀缺），那么资本应该从富国流向穷国。但 Lucas (1990) 在 **"Why Doesn't Capital Flow from Rich to Poor Countries?"** 中指出，实际的国际资本流动方向恰恰相反。

### 2.2 增长理论的"黑暗年代"

从1960年代到1980年代初，增长理论经历了一段学术史上所谓的 "黑暗年代"。由于 Solow 模型将长期增长归因于外生技术进步，经济学家似乎对增长本身无话可说。增长理论的研究近乎停滞，宏观经济学的注意力转向了商业周期和通货膨胀问题。

### 2.3 Romer 的芝加哥岁月

Paul Romer 于1983年在芝加哥大学完成博士论文，导师是数学经济学家 Jose Scheinkman，委员会成员包括 Robert Lucas。芝加哥的学术环境对 Romer 的思想形成产生了深远影响：一方面，Lucas 关于理性预期和微观基础的方法论要求促使 Romer 为增长理论构建严格的均衡模型；另一方面，芝加哥学派对市场机制的信仰使 Romer 认识到，理解增长必须理解 **激励**——是什么激励人们投资于新知识的创造。

## 三、核心思想：知识作为非竞争性商品

### 3.1 物品的分类学

Romer 理论的出发点是对经济物品进行一个根本性的重新分类。传统经济学按照 **排他性 (Excludability)** 和 **竞争性 (Rivalry)** 两个维度来分类物品：

```
+-------------------+--------------------+--------------------+
|                   |    竞争性 (Rival)   | 非竞争性(Non-rival)|
+-------------------+--------------------+--------------------+
|                   |                    |                    |
| 可排他            |  私人物品          |  知识/技术         |
| (Excludable)      |  (苹果、汽车)      |  (专利保护的       |
|                   |                    |   软件、药方)      |
+-------------------+--------------------+--------------------+
|                   |                    |                    |
| 不可排他          |  公共资源          |  纯公共物品        |
| (Non-excludable)  |  (渔场、牧场)      |  (国防、基础       |
|                   |                    |   科学知识)        |
+-------------------+--------------------+--------------------+
```

**关键洞见：知识和技术从根本上不同于物质资本和劳动。**

**竞争性** 意味着一个人的使用会减少其他人可使用的数量。一台机器被A工厂使用时就不能同时被B工厂使用——物质资本是竞争性的。

**非竞争性** 意味着一个人的使用不影响其他人的使用。微积分的发明一旦发生，全世界所有人都可以同时使用微积分，而不会因为使用的人多了就减少其效用——知识是非竞争性的。

这一区分看似简单，实则具有深远的经济含义。

### 3.2 非竞争性与递增报酬

Romer 指出，非竞争性必然导致 **递增报酬 (Increasing Returns)**。推理如下：

假设一个生产函数包含竞争性投入（资本K、劳动L）和非竞争性投入（知识/技术A）：

```
  Y = F(A, K, L)
```

对于竞争性投入，标准的复制论证 (Replication Argument) 成立：如果将 K 和 L 同时翻倍，产出至少翻倍（因为可以简单地复制现有的生产设施）：

```
  F(A, 2K, 2L) >= 2 * F(A, K, L)
```

注意，A 不需要翻倍——因为知识是非竞争性的，新工厂可以使用与旧工厂完全相同的技术。但这意味着，如果将所有投入（包括A）都翻倍：

```
  F(2A, 2K, 2L) > 2 * F(A, K, L)
```

即生产函数对 **所有投入** 呈递增报酬。

递增报酬的存在意味着完全竞争市场无法作为均衡框架。在完全竞争下，每种要素按其边际产出获得报酬，但在递增报酬条件下，所有要素按边际产出分配后所需的报酬总额将超过总产出——这在数学上不可能。因此，Romer 模型需要引入 **不完全竞争**，特别是 **垄断竞争**。

### 3.3 知识溢出与外部性

Romer 1986年论文的核心模型依赖于 **知识溢出 (Knowledge Spillovers)** 这一外部性。基本思想是：

- 单个企业进行研发投资以提高自身的生产效率
- 但新知识的创造不可避免地会"溢出"到其他企业
- 从单个企业的角度看，报酬递减（企业自身的研发存在边际报酬递减）
- 从整个经济的角度看，由于溢出效应，报酬递增

用数学语言表达：

```
  单个企业 i 的生产函数:
  Y_i = F(k_i, K) = k_i^alpha * K^(1-alpha)

  其中:
    k_i = 企业 i 自身的知识/资本投资 (企业可控)
    K   = 经济中全部企业的知识总量 (企业不可控, 外部性)

  对企业 i 而言:
    alpha < 1, 关于 k_i 报酬递减 (标准的竞争性均衡)

  对整个经济而言:
    由于 K = SUM(k_i), 总量层面报酬递增
```

这一结构精巧地解决了两个问题：

1. **微观层面**：单个企业面临报酬递减，竞争性均衡可以存在
2. **宏观层面**：由于溢出效应，总量经济呈递增报酬，可以维持长期增长

## 四、模型结构与经济含义

### 4.1 Solow 模型 vs Romer 内生增长模型

以下表格总结了两种模型的核心差异：

```
+---------------------------+---------------------------+---------------------------+
|         特征              |     Solow 模型 (1956)     |   Romer 模型 (1986/1990)  |
+---------------------------+---------------------------+---------------------------+
| 技术进步                  | 外生给定                  | 内生决定                  |
+---------------------------+---------------------------+---------------------------+
| 报酬性质                  | 资本报酬递减              | 知识报酬不递减            |
|                           |                           | (可能递增)                |
+---------------------------+---------------------------+---------------------------+
| 长期增长源泉              | 外生技术进步              | 知识积累和创新            |
+---------------------------+---------------------------+---------------------------+
| 收敛预测                  | 条件收敛                  | 不一定收敛                |
|                           | (穷国追赶富国)            | (差距可能持续甚至扩大)    |
+---------------------------+---------------------------+---------------------------+
| 政策对长期增长的影响      | 无                        | 有                        |
|                           | (只影响稳态水平)          | (政策影响增长率本身)      |
+---------------------------+---------------------------+---------------------------+
| 市场结构                  | 完全竞争                  | 垄断竞争                  |
|                           |                           | (1990年论文)              |
+---------------------------+---------------------------+---------------------------+
| 知识的性质                | 公共物品                  | 部分可排他的              |
|                           | (免费可得)                | 非竞争性物品              |
+---------------------------+---------------------------+---------------------------+
| 均衡效率                  | 帕累托最优                | 低于最优                  |
|                           |                           | (知识溢出导致研发不足)    |
+---------------------------+---------------------------+---------------------------+
| 人口规模效应              | 无                        | 有                        |
|                           |                           | (更多人 = 更多创意)       |
+---------------------------+---------------------------+---------------------------+
```

### 4.2 AK 模型诠释

Romer 1986年模型的一个简化理解方式是所谓的 **AK 模型**。在标准 Solow 模型中：

```
  Y = A * K^alpha * L^(1-alpha),  alpha < 1

  人均形式: y = A * k^alpha

  资本的边际产出: MPK = alpha * A * k^(alpha-1) --> 0  (当 k --> 无穷)

  结论: 资本边际报酬递减, 增长最终停滞
```

而在 AK 模型中，如果将 K 广义地理解为包含物质资本和人力资本/知识的综合资本：

```
  Y = A * K,   A 为常数

  人均形式: y = A * k

  资本的边际产出: MPK = A = 常数

  结论: 资本边际报酬恒定, 增长可以永续
```

关键的直觉是：当 "资本" 包含知识维度时，报酬递减不再成立。一个工人配备更多物质资本可能面临报酬递减，但如果这个工人同时获得了更好的知识和技能，他的生产率可以持续提高。

在 Solow 模型中，资本的边际产出随资本积累而下降，最终增长停滞。在 AK 模型中，广义资本的边际产出恒定，增长可以永续进行。这一差异用图形表示如下：

```
  人均产出增长率
  ^
  |
  |  Solow 模型:
  |  ======\
  |         \
  |          \
  |           \
  |            \__________ (趋向外生技术进步率)
  |
  |  AK/Romer 模型:
  |  ==================== (恒定增长率, 取决于储蓄率和知识生产效率)
  |
  +---------------------------------> 时间/人均资本
```

### 4.3 不收敛的世界

AK 模型最引人注目的含义之一是 **收敛不必然发生**。在 Solow 模型中，穷国（资本稀缺）的资本边际产出高，增长快，因此会追赶富国。但在内生增长模型中：

- 富国拥有更多知识积累 → 创新效率更高 → 增长更快
- 穷国知识基础薄弱 → 难以吸收外部技术 → 增长缓慢
- 差距可能持续甚至扩大

这一预测与跨国数据的大图景高度一致：

```
  人均GDP (对数尺度, 示意)
  ^
  |
  |  发达国家 ___________________________/
  |                                    /
  |                                   /
  |                      ____________/
  |                     /
  |                    /
  |  中等收入国家 ____/___________________________
  |                  /                 /
  |                 /                 /
  |                /                 /  (少数追赶成功)
  |               /                 /
  |  最贫穷国家 _/_____________________ (持续停滞)
  |
  +-------------------------------------------------> 时间
       1960               1990               2020
```

## 五、1990年论文：正式的研发模型

### 5.1 从外部性到垄断竞争

1986年论文依赖知识溢出（外部性）来产生递增报酬，但这种处理方式在理论上不够令人满意——它没有回答谁在为知识创造买单，以及为什么。

1990年，Romer 在 *Journal of Political Economy* 上发表了更为完善的论文 **"Endogenous Technological Change"**。这篇论文建立了一个包含三个部门的正式模型：

```
+-----------------------------------------------------------+
|                     Romer (1990) 模型                     |
+-----------------------------------------------------------+
|                                                           |
|  部门1: 研发部门 (R&D Sector)                             |
|  +-----------------------+                                |
|  | 投入: 人力资本 (H_A)   |                                |
|  |       现有知识存量 (A) |                                |
|  | 产出: 新设计/蓝图      |                                |
|  | dA/dt = delta*H_A*A   |                                |
|  +-----------------------+                                |
|         |                                                 |
|         | 新设计 (非竞争性, 部分可排他 -- 专利)             |
|         v                                                 |
|  部门2: 中间产品部门 (Intermediate Goods)                  |
|  +-----------------------+                                |
|  | 每个设计对应一种       |                                |
|  | 独特的中间产品         |                                |
|  | 垄断竞争定价           |                                |
|  | 利润 = 创新的回报      |                                |
|  +-----------------------+                                |
|         |                                                 |
|         | 中间产品 (竞争性, 可排他)                         |
|         v                                                 |
|  部门3: 最终产品部门 (Final Goods)                         |
|  +-----------------------+                                |
|  | 投入: 劳动 (L)         |                                |
|  |       人力资本 (H_Y)   |                                |
|  |       中间产品 {x_i}   |                                |
|  | 完全竞争               |                                |
|  +-----------------------+                                |
|                                                           |
+-----------------------------------------------------------+
```

### 5.2 知识生产函数

模型的核心是知识（新设计）的生产函数：

```
  dA/dt = delta * H_A * A

  其中:
    dA/dt  = 新知识的生产速率
    delta  = 研发生产率参数
    H_A    = 投入研发部门的人力资本
    A      = 现有知识存量
```

这个方程蕴含了一个关键假设：**站在巨人的肩膀上 (Standing on the Shoulders of Giants)**。现有知识存量 A 出现在知识生产函数中，意味着前人的发现使后人的研发更加高效。牛顿能够发现万有引力定律，部分是因为他能够利用开普勒、伽利略等前人的知识。

### 5.3 激励结构

1990年论文的理论贡献在于它为知识创造提供了一个基于 **激励 (Incentives)** 的解释：

- 研发活动是有目的的经济行为，由利润动机驱动
- 发明者通过专利获得对其创新的暂时性垄断权
- 垄断定价产生的利润是创新的回报
- 利润的存在要求不完全竞争的市场结构

这一框架将知识创造从"天上掉馅饼"的外生过程变成了对激励做出反应的经济决策——可以被税收、补贴、知识产权制度等政策工具所影响。

## 六、Lucas 的人力资本版本 (1988)

### 6.1 人力资本与经济增长

几乎与 Romer 同时，Robert Lucas 在1988年发表了 **"On the Mechanics of Economic Development"**。Lucas 的模型从不同的角度切入内生增长问题——他强调的不是 R&D 和技术创新，而是 **人力资本积累**。

在 Lucas 的模型中：

- 个人将时间在工作和学习（人力资本积累）之间分配
- 个人的人力资本投资具有外部性——整个社会的平均人力资本水平影响所有人的生产率
- 更多时间用于学习 → 更高的人力资本 → 更高的未来生产率 → 永续增长

### 6.2 内生增长理论的两条路径

Romer 和 Lucas 的工作代表了内生增长理论的两条互补路径：

```
+-------------------+        +-------------------+
| Romer 路径        |        | Lucas 路径        |
| (1986, 1990)      |        | (1988)            |
+-------------------+        +-------------------+
| 焦点: 技术创新    |        | 焦点: 人力资本    |
| 机制: R&D + 溢出  |        | 机制: 学习 + 溢出 |
| 驱动力: 新设计    |        | 驱动力: 教育培训  |
| 政策: R&D 补贴    |        | 政策: 教育投资    |
|   知识产权保护    |        |   人才培养        |
|   贸易开放        |        |   干中学          |
+-------------------+        +-------------------+
         \                          /
          \                        /
           v                      v
    +-----------------------------+
    |   共同结论:                  |
    |   知识/人力资本投资          |
    |   是长期增长的关键           |
    |   政策可以影响增长率         |
    +-----------------------------+
```

## 七、政策含义

### 7.1 内生增长理论的政策处方

内生增长理论的一个革命性意义在于，它赋予了政策影响 **长期增长率** 的可能性——而不仅仅是像 Solow 模型那样只影响收入水平。这直接衍生出一系列具体的政策建议：

**第一，教育投资。** 人力资本是知识生产和技术吸收的基础投入。提高教育质量和覆盖面可以通过两个渠道促进增长：直接增加人力资本存量，以及间接提高研发部门的人力资本投入。

**第二，研发税收优惠与补贴。** 由于知识溢出的存在，私人部门的研发投资从社会角度看系统性地不足。政府通过研发税收抵免、直接资助基础研究等方式，可以缩小私人回报和社会回报之间的差距，将研发活动推向社会最优水平。

**第三，知识产权保护。** 适度的知识产权保护（专利、版权）使创新者能够从其发明中获得回报，从而激励研发投资。但保护力度需要在激励创新和允许知识扩散之间取得平衡——过强的知识产权保护可能阻碍知识的传播和后续创新。

**第四，贸易开放。** 国际贸易扩大了市场规模，使创新的固定成本可以在更大的市场上分摊，从而提高了创新的私人回报。同时，贸易也是知识跨国传播的重要渠道。

**第五，竞争政策。** 模型中垄断竞争的市场结构意味着，进入壁垒的降低和竞争的强化可以刺激 "创造性破坏"，推动技术前沿的推进。但这里存在微妙的权衡：一定程度的垄断利润对于激励创新是必要的。

### 7.2 发展中国家的启示

内生增长理论对发展中国家的经济发展具有深刻启示。如果增长是内生的、可以被政策影响的，那么穷国的贫穷不是命中注定的——正确的制度和政策设计可以开启持续增长的进程。

但同时，模型也警示了一种悲观的可能性：如果穷国无法建立有效的教育体系、知识产权制度和研发基础设施，它们可能被永久地锁定在低增长陷阱中。这就是所谓的 **"中等收入陷阱"** 的理论基础之一。

## 八、批评与挑战

### 8.1 规模效应问题 (Jones, 1995)

Charles Jones 在1995年发表的 **"R&D-Based Models of Economic Growth"** 中对 Romer 模型提出了一个重要的实证质疑：**规模效应 (Scale Effects)**。

Romer 模型的知识生产函数 dA/dt = delta * H_A * A 预测，投入研发的人力资本越多，知识的生产速率越快，经济增长率越高。这意味着：

- 人口越多的国家应该增长越快（更多人可以投入研发）
- 随着时间推移，研发人员数量增加，增长率应该上升

但美国数据显示，尽管研发人员数量从1950年代到1990年代大幅增加（增长了5倍以上），全要素生产率的增长率却没有显著上升——甚至有所下降。

Jones 提出了修正方案——**半内生增长模型 (Semi-Endogenous Growth Model)**，通过在知识生产函数中引入 "踩在脚趾上 (Stepping on Toes)" 效应（即重复研发的浪费）和知识创造的递减效率，消除了规模效应。但代价是，政策对长期增长率的影响再次变为零——长期增长率重新由人口增长率等外生因素决定。

这一争论至今尚未完全解决。Romer 阵营的回应是：规模效应在理论上是合理的，而实证上的不一致可能反映了度量问题或调整期的复杂性。

### 8.2 实证检验的困难

内生增长理论在实证检验方面面临根本性的困难：

**第一，知识存量难以度量。** 专利数量、研发支出、教育年限等常用代理变量都只能捕捉知识积累的某些维度。

**第二，因果关系识别。** 研发投资与经济增长之间存在双向因果：研发促进增长，但增长也刺激研发投资。在实证上分离这两个方向极其困难。

**第三，知识溢出的度量。** 知识溢出是模型的核心机制，但其规模和范围在实证上非常难以估计。

### 8.3 制度学派的挑战

以 Daron Acemoglu 和 James Robinson 为代表的 **制度经济学** 对内生增长理论提出了另一种挑战。他们认为，解释跨国收入差距的关键不在于知识或人力资本的差异，而在于 **制度的差异**——产权保护、法治、政治包容性等。

Acemoglu, Johnson & Robinson (2001) 的殖民地研究提供了有力的实证证据：即使控制了地理、文化等因素，制度质量对经济发展的影响仍然是压倒性的。

不过，内生增长理论和制度经济学并非不可调和。好的制度可以被视为促进知识创造和人力资本积累的 **前提条件**——它们解释的是增长过程中不同层次的因素。

## 九、Romer 的后续影响与学术生涯

### 9.1 从学术到政策

Paul Romer 的职业生涯本身就是理论与实践结合的范例。在学术成就的基础上，他积极参与公共政策讨论：

- **特许城市 (Charter Cities)**：Romer 提出了在发展中国家建立具有特殊治理规则的新城市的构想，作为突破制度障碍、启动经济发展的途径。虽然这一构想在洪都拉斯的实践引发了争议，但它反映了 Romer 将增长理论应用于发展实践的雄心。

- **世界银行首席经济学家 (2016-2018)**：Romer 于2016年被任命为世界银行首席经济学家。他在任期间对世界银行的数据质量和研究方法论提出了尖锐批评（特别是关于 "营商环境" 排名的方法论问题），最终于2018年辞职。

### 9.2 诺贝尔奖 (2018)

2018年，Paul Romer 与 William Nordhaus 共同获得诺贝尔经济学奖。Nordhaus 的贡献是将气候变化纳入经济增长分析（综合评估模型 DICE），与 Romer 的工作形成了完美的互补：Romer 解释了为什么经济会增长，Nordhaus 则分析了这种增长对自然环境的影响。

诺贝尔委员会的颁奖词指出：

> "Romer 展示了知识如何能够成为驱动长期经济增长的力量......他的研究指出了一条以新的方式促进繁荣的道路。"

## 十、现代意义与遗产

### 10.1 数字经济时代的验证

Romer 关于非竞争性物品和递增报酬的理论在数字经济时代获得了前所未有的现实验证。软件、数据、算法——这些数字时代的核心资产完美地契合了 Romer 对知识属性的描述：

- **边际复制成本接近于零**（非竞争性的极端表现）
- **网络效应创造递增报酬**
- **平台经济体现知识溢出**

科技巨头（苹果、谷歌、微软）的崛起可以被视为 Romer 理论的一个宏大验证——它们的巨大市值来源于非竞争性知识资产的积累和垄断性使用。

### 10.2 对当代政策辩论的影响

内生增长理论继续深刻影响着当代政策辩论：

- **全球化争论**：贸易是否促进知识传播和增长？
- **产业政策回归**：政府是否应该选择性地支持特定技术部门？
- **数据治理**：作为非竞争性资源，数据应如何分配和利用？
- **人工智能与增长**：AI 是否代表了一种根本性的新型知识生产技术，能够改变增长前景？
- **气候技术创新**：如何激励绿色技术的研发和扩散？

### 10.3 开放的问题

Romer 的工作留下了许多至今仍在探索的问题：

- 知识生产的效率是在提高还是在降低？（Bloom et al. 2020, "Are Ideas Getting Harder to Find?"）
- 制度、文化和知识积累如何相互作用？
- 人工智能是否会改变知识生产函数的形态？
- 如何在激励创新和促进知识传播之间找到最优的知识产权政策？

---

## 十一、结论

Paul Romer 1986年的论文开启了经济增长理论的新纪元。它将长期经济增长从一个外生给定的神秘过程，变成了一个可以用经济学工具分析、理解和影响的内生现象。知识的非竞争性、递增报酬、知识溢出——这些在 Romer 之前散落在经济思想各处的概念，被他整合为一个连贯的理论框架，并以严格的数学模型呈现。

Romer 的遗产不仅在于他的具体模型——这些模型已经被后续研究者大幅发展和修正——更在于他提出了一个根本性的洞见：**思想和知识是经济增长的终极源泉，而思想的创造是人类有目的的经济行为的结果。** 这一洞见改变了我们理解繁荣与贫困的方式，也为追求持续、包容的经济发展提供了理论指引。
