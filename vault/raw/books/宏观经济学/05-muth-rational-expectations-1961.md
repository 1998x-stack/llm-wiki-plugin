# 理性预期假说：穆思被忽视的革命（1961）

## 论文信息

- **作者**：John F. Muth（约翰·弗雷泽·穆思）
- **题目**：*Rational Expectations and the Theory of Price Movements*
- **发表**：*Econometrica*, Vol. 29, No. 3, 1961, pp. 315-335

---

## 一、历史背景：预期问题的困境

### 1.1 预期在经济学中的核心地位

经济行为本质上是面向未来的。投资决策取决于预期回报，消费决策取决于预期收入，价格设定
取决于预期成本——几乎所有重要的经济决策都依赖于对未来的判断。然而，在穆思之前，经济学
对预期的建模一直处于一种尴尬的状态。

### 1.2 既有预期模型的缺陷

1960 年代初，经济学中主要使用以下几种预期建模方式：

| 预期类型 | 描述 | 代表人物 | 问题 |
|---------|------|---------|------|
| 静态预期 | 预期值 = 当前值 | 最简单形式 | 系统性错误 |
| 外推预期 | 基于过去趋势外推 | -- | 无学习机制 |
| 适应性预期 | 根据过去预测误差修正 | Cagan (1956), Nerlove (1958) | 缓慢调整，持续偏差 |
| 回归预期 | 预期回归"正常"水平 | -- | "正常"水平如何确定？ |

**适应性预期**是当时最流行的形式，其公式为：

    x_e_t = x_e_{t-1} + lambda * (x_{t-1} - x_e_{t-1})

其中 0 < lambda < 1 为调整系数。

适应性预期的根本问题在于它是**纯粹后顾的**（backward-looking）：即使经济结构发生了
根本变化（如新的货币政策体制），预期仍然基于过去数据缓慢调整。这意味着经济主体会
犯**系统性的、可预见的错误**——这与经济学的基本理性假设相矛盾。

### 1.3 穆思的知识背景

约翰·穆思当时是卡内基理工学院（今卡内基梅隆大学）工业管理研究所的年轻教授。该研究所
是 1950-60 年代美国经济学方法论创新的重要中心，Herbert Simon（有限理性）、Franco
Modigliani（生命周期假说）和 Robert Lucas（后来加入）都曾在此工作。

穆思的研究兴趣最初是微观层面的库存管理和农产品价格波动——特别是所谓的"蛛网模型"
（Cobweb Model）。正是在分析这一经典的微观经济问题时，他提出了理性预期的概念。

## 二、论文的核心内容

### 2.1 核心假说的陈述

穆思在论文第 316 页给出了理性预期假说的经典表述：

> "...expectations, since they are informed predictions of future events, are essentially
> the same as the predictions of the relevant economic theory."
>
> "预期，由于它们是关于未来事件的知情预测，本质上与相关经济理论的预测相同。"

用数学语言表述：

    x_e_t = E[x_t | I_{t-1}]

其中：
- x_e_t：经济主体对变量 x 在 t 时期的预期
- E[x_t | I_{t-1}]：基于 t-1 时期所有可用信息集 I_{t-1} 的条件数学期望
- 该期望是基于"正确的"（即均衡的）经济模型计算的

### 2.2 三个核心论证

穆思为其假说提供了三个支撑论证，每一个都值得详细分析：

**论证一：信息是稀缺的，不会被浪费**

经济主体获取和处理信息是有成本的。正因如此，他们不会对已经掌握的信息视而不见。如果存在
一种系统性地改善预测的方法，且使用这种方法的收益超过成本，理性的经济主体就会采用它。
因此，在均衡状态下，经济主体的预测不应存在可被廉价利用的系统性偏差。

**论证二：预期取决于整个经济系统的结构**

预期不是独立于经济运行方式的心理现象。如果经济结构发生变化（如政府改变了货币政策规则），
理性的经济主体会相应地调整其预期形成方式。这一论证后来成为卢卡斯批判的理论基础。

**论证三：公开的预测不会实质性地改变系统的运行**

如果一个公开发布的预测会导致经济主体改变行为，从而使预测自我实现或自我否定，那么理性
预期假说要求预期本身就已经将这种反馈效应纳入考虑。换言之，理性预期是一个**不动点**
（fixed point）——它与经济模型的预测一致。

### 2.3 蛛网模型中的应用

穆思将理性预期概念应用于农产品市场的蛛网模型。传统蛛网模型假设农民根据上期价格决定
本期种植量（天真预期），导致价格振荡甚至发散：

```
    价格 P
    |
    |    D (需求)        S (供给)
    |     \             /
    |      \           /
    |       \    3    /
    |        \  .---./
    |         \/    /\
    |   1 .....\../...\ 2
    |          /\/     \
    |         / /\      \
    |        / /  \      \
    |       / /    4      \
    +------+-+------+-----> Q (产量)

    图 1：传统蛛网模型（发散型）
    天真预期下的价格路径：1 -> 2 -> 3 -> 4
    价格振幅逐渐增大（发散）
    农民永远犯系统性错误
```

穆思论证了：如果农民使用理性预期，他们会认识到价格的均衡水平，直接预期均衡价格。
蛛网振荡将不会出现——至少不会作为系统性模式出现。价格偏离均衡只会因为**真正不可
预见的随机冲击**，而不是因为预期的系统性失误。

### 2.4 正式模型

穆思构建的市场模型由三个方程组成：

**需求方程**：

    D_t = -beta * P_t

**供给方程**（生产决策基于预期价格）：

    S_t = gamma * P_e_t + u_t

其中 u_t 为随机供给冲击。

**市场出清条件**：

    D_t = S_t

**理性预期解**：

在理性预期下，P_e_t = E[P_t | I_{t-1}]。穆思证明了均衡价格为：

    P_t = -(gamma / beta) * E[u_t | I_{t-1}] / (1 + gamma/beta) - u_t / beta

**预期误差的性质**：

    P_t - P_e_t = -u_t / (beta + gamma)

预测误差仅来自于**不可预见的随机冲击** u_t，没有系统性分量。换言之：

- E[P_t - P_e_t] = 0（无偏性）
- P_t - P_e_t 与 I_{t-1} 中的任何信息无关（正交性）

## 三、被忽视的十年（1961-1972）

### 3.1 为什么被冷落？

穆思的论文发表后，在整整十年间几乎没有引起任何反响。这一"被忽视"的事实本身就是
科学社会学的一个引人入胜的案例。可能的原因包括：

1. **微观背景的局限**：穆思将理性预期应用于农产品市场价格——这在当时被视为一个
   相对边缘的微观经济学问题，没有引起宏观经济学家的注意。

2. **数学难度**：论文使用了时间序列分析和信号提取理论，数学难度在当时偏高。

3. **与主流的紧张关系**：理性预期假说暗含了一个激进的推论——凯恩斯主义的需求管理
   政策可能是无效的——但穆思本人并未明确地推导出这一政策含义。

4. **穆思的学术风格**：穆思不是一个善于推销自己思想的学者。他发表论文的数量很少，
   也不热衷于学术社交和自我推广。

### 3.2 穆思的其他贡献

值得一提的是，穆思在理性预期之外还有其他重要贡献：

- **最优预测与控制**：将控制论方法应用于库存管理
- **贝叶斯决策理论**：在不确定性下的决策分析
- **时间序列分析**：对 ARMA 模型的应用

但穆思在 1960 年代中期之后逐渐淡出学术界前沿，未能亲自推动理性预期的范式革命。

## 四、卢卡斯革命：理性预期进入宏观经济学

### 4.1 Robert Lucas 的发现

1969 年前后，卡内基梅隆大学的罗伯特·卢卡斯（Robert Lucas）——穆思的同事——重新发现了
理性预期假说的宏观经济学含义。卢卡斯意识到，如果将理性预期引入标准的宏观经济模型，
将产生革命性的政策结论。

### 4.2 卢卡斯的核心贡献

**卢卡斯供给函数（Lucas Supply Function, 1972, 1973）**：

    Y_t = Y_n + alpha * (P_t - E[P_t | I_{t-1}]) + epsilon_t

产出只偏离自然水平当且仅当价格水平出现**未预期到的**变动。如果货币政策扩张被公众
完全预见，它只会导致价格水平等比例上升，不会影响实际产出。

**卢卡斯批判（Lucas Critique, 1976）**：

这是理性预期最具政策影响力的推论。卢卡斯论证了：传统的宏观计量经济模型（如大规模
凯恩斯主义模型）的结构参数不是"深层参数"（deep parameters），而是依赖于政策体制。
当政策规则改变时，这些参数也会改变——因为经济主体会理性地调整他们的行为。

**含义表**：

| 政策评估方法 | 假设 | 卢卡斯批判 |
|------------|------|-----------|
| 传统计量模型 | 结构参数稳定 | 参数随政策变化而变化 |
| 历史模拟 | 过去的关系可外推 | 新政策改变行为规则 |
| 菲利普斯曲线权衡 | 稳定的通胀-失业关系 | 关系取决于货币政策体制 |

### 4.3 Sargent-Wallace 政策无效性命题

1975 年，Thomas Sargent 和 Neil Wallace 将理性预期推到逻辑极端，提出了"政策无效性
命题"（Policy Ineffectiveness Proposition, PIP）：

**核心结论**：在理性预期和完全信息下，系统性的（即可预见的）货币政策对实际产出**完全
没有影响**。只有**未预期到的**货币政策冲击才能影响实际变量。

**推论**：

| 政策类型 | 对实际产出的影响 | 原因 |
|---------|----------------|------|
| 系统性的（规则型） | 无 | 被完全预见，价格即时调整 |
| 随机的（出其不意） | 有，但不可持续 | 未被预见，造成暂时的信号提取误差 |
| 最优政策 | 稳定的规则 | 减少不确定性，而非制造惊喜 |

这一结论在 1970 年代引起了巨大的学术和政策争论。如果政策无效性命题成立，凯恩斯主义的
需求管理就失去了理论基础。

## 五、理性预期与适应性预期的对比

### 5.1 形式化比较

**适应性预期**：

    x_e_t = x_e_{t-1} + lambda * (x_{t-1} - x_e_{t-1})
          = lambda * x_{t-1} + lambda(1-lambda) * x_{t-2} + ...

特征：纯粹后顾，只使用被预测变量自身的过去值，信息利用不充分。

**理性预期**：

    x_e_t = E[x_t | I_{t-1}]

特征：前瞻性，使用所有可用信息（包括经济模型的结构信息），信息利用充分。

### 5.2 关键差异

```
    预测值
    |
    |         实际值路径
    |        /\      /\
    |       /  \    /  \
    |      /    \  /    \
    |  ---/------\/------\---  适应性预期
    |    /                 \   （滞后追踪）
    |   /                   \
    |
    |         理性预期
    |        ..*..   ..*..     （围绕实际值对称波动，
    |       *    *..*    *      无系统性偏差）
    |
    +----------------------------> t (时间)

    图 2：两种预期机制的比较
    适应性预期：系统性地滞后于实际值变化
    理性预期：预测误差无系统性偏差，仅包含不可预见的随机成分
```

| 性质 | 适应性预期 | 理性预期 |
|------|-----------|---------|
| 信息利用 | 仅使用过去的被预测变量 | 使用所有可用信息 |
| 无偏性 | 不保证 | 保证 |
| 预测误差的序列相关 | 存在 | 不存在（正交条件） |
| 对结构变化的反应 | 缓慢适应 | 即时调整 |
| 与理性行为的一致性 | 不一致 | 一致 |
| 计算复杂度 | 低 | 高（需要知道模型结构） |

## 六、批评与反思

### 6.1 Herbert Simon 的有限理性批判

穆思在卡内基理工学院的同事 Herbert Simon（1978 年诺贝尔奖）早在 1950 年代就提出了
"有限理性"（Bounded Rationality）概念，与理性预期形成鲜明对比。

Simon 的核心论点是：人类的认知能力和信息处理能力是有限的。经济主体不会（也无法）
计算复杂模型的条件期望值。他们使用的是"满意化"（satisficing）策略，而非"最优化"
（optimizing）策略。

**有限理性的论证**：

1. **信息获取成本**：获取和处理"所有可用信息"的成本可能超过收益
2. **模型不确定性**：经济主体不知道"正确的模型"是什么（模型不确定性/Knightian 不确定性）
3. **认知局限**：人类计算条件概率分布的能力有限
4. **异质性**：不同个体拥有不同的信息集和认知能力

### 6.2 行为经济学的挑战

1970 年代以来，Kahneman 和 Tversky 的研究揭示了大量系统性的认知偏差，对理性预期的
现实适用性提出了严峻挑战：

| 认知偏差 | 与理性预期的冲突 |
|---------|----------------|
| 代表性启发（Representativeness） | 忽略先验概率 |
| 可得性启发（Availability） | 过度权重容易回忆的信息 |
| 锚定效应（Anchoring） | 预期受到无关初始值影响 |
| 过度自信（Overconfidence） | 概率判断系统性偏差 |
| 损失厌恶（Loss Aversion） | 非对称地处理好消息和坏消息 |

### 6.3 学习与实验经济学的证据

实验经济学和学习理论从另一个角度审视理性预期：

- **实验室实验**：受试者在简单的经济环境中往往无法立即形成理性预期，但经过重复互动
  后可能逐渐逼近理性预期（"学习趋向理性预期"）
- **自适应学习**（Adaptive Learning, Evans & Honkapohja 2001）：用统计学习取代理性
  预期的"即时"假设，研究经济主体是否以及何时能"学会"理性预期
- **异质预期**模型（Heterogeneous Expectations）：不同类型的主体使用不同的预期规则

### 6.4 为理性预期辩护

尽管存在上述批评，理性预期假说的支持者提出了有力的辩护：

1. **方法论论证**：理性预期是一种"纪律约束"（discipline device），避免模型构建者
   在预期方面引入临时性（ad hoc）假设
2. **市场论证**：即使个体不理性，市场竞争和套利力量会消除系统性错误
3. **进化论证**：使用更好预期策略的主体会在市场中生存下来（选择效应）
4. **渐近论证**：作为长期均衡的描述，理性预期可能是合理的近似
5. **最小偏差原则**：在没有更好的替代方案时，假设无系统性偏差是最审慎的选择

## 七、方法论遗产

### 7.1 改变了整个学科

理性预期假说对经济学方法论的影响是全方位的：

**宏观经济模型构建**：
- 所有主流宏观模型（DSGE、新凯恩斯模型）都采用理性预期作为基准
- "偏离理性预期"需要提供明确的理论论证和实证支持

**资产定价理论**：
- 有效市场假说（EMH）本质上是理性预期在金融市场中的应用
- 资产价格反映所有可用信息

**政策设计**：
- 货币政策规则（如泰勒规则）的设计考虑了预期的反馈效应
- 央行沟通和前瞻性指引（Forward Guidance）基于理性预期的逻辑
- 时间不一致性（Kydland & Prescott 1977）和规则 vs. 相机抉择的辩论

**计量经济学**：
- 广义矩估计法（GMM, Hansen 1982）部分受理性预期正交条件的启发
- 向量自回归（VAR）和结构 VAR 方法的发展

### 7.2 诺贝尔奖的传承

穆思本人从未获得诺贝尔经济学奖，但他的思想通过后来者获得了最高的学术认可：

| 年份 | 获奖者 | 相关贡献 |
|------|-------|---------|
| 1995 | Robert Lucas | 理性预期在宏观经济学中的应用 |
| 2004 | Finn Kydland & Edward Prescott | 时间不一致性与经济周期 |
| 2011 | Thomas Sargent | 宏观经济中因果关系的实证研究 |
| 2013 | Lars Peter Hansen | 理性预期模型的计量方法 |

### 7.3 穆思的历史地位

约翰·穆思于 2005 年去世，终年 75 岁。他一生只发表了约 20 篇论文，但其中一篇——
1961 年的理性预期论文——改变了整个经济学科。

穆思的案例提出了一个关于学术评价的深刻问题：思想的提出者与思想的传播者，谁更值得
获得荣誉？卢卡斯在 1995 年的诺贝尔演讲中坦诚地指出，理性预期的核心思想完全属于穆思。
但正是卢卡斯、萨金特和华莱士等人将这一思想从微观经济学的一个角落推广到了整个宏观
经济学，引发了一场方法论革命。

这一历史提醒我们：在知识的生产和传播过程中，"发明"与"应用"同样重要，有时甚至
更重要的是认识到一个已有思想在新领域中的深远含义。穆思种下了种子，卢卡斯使之开花结果。
这不是减损穆思的贡献，而是说明了科学进步的合作性本质。

## 八、当代发展与展望

### 8.1 后理性预期时代

近二十年来，经济学正在探索"后理性预期"的多种路径：

1. **理性疏忽（Rational Inattention, Sims 2003）**：信息处理有成本，经济主体理性地
   选择关注哪些信息
2. **诊断性预期（Diagnostic Expectations, Bordalo et al. 2018）**：预期系统性地
   过度反应于近期信息
3. **自然预期（Natural Expectations, Fuster et al. 2010）**：经济主体使用简化模型
   形成预期
4. **异质信念（Heterogeneous Beliefs）**：不同主体拥有不同的模型和信息

### 8.2 大数据与机器学习时代的新问题

在信息爆炸的当代，理性预期面临新的理论挑战：

- 当"所有可用信息"的规模超越了人类认知极限时，理性预期意味着什么？
- 算法交易和 AI 预测是否使金融市场更接近理性预期？
- 社交媒体如何改变信息传播和预期形成的动态？

这些问题将穆思 1961 年提出的框架延伸到了他无法想象的技术和社会环境中，但核心问题
仍然是同一个：经济主体如何利用信息来预测未来？这一问题的答案仍然在塑造着经济学的方向。
