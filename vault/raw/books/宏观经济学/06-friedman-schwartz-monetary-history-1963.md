## 导言

1963年，米尔顿·弗里德曼（Milton Friedman）与安娜·雅各布森·施瓦茨（Anna Jacobson Schwartz）合著的《美国货币史，1867-1960》（*A Monetary History of the United States, 1867-1960*）由普林斯顿大学出版社出版。这部长达860页的鸿篇巨制，历时十二年以上的艰苦研究方告完成，它不仅是二十世纪最具影响力的经济学著作之一，更从根本上改变了经济学界对货币政策、经济周期乃至大萧条成因的理解。

这部著作的核心命题简洁而有力：**货币供应量的变动是驱动美国经济周期波动的首要力量**。在凯恩斯主义占据主流的1960年代，这一论断如同一枚重磅炸弹，引发了持续数十年的学术论战，并深刻影响了此后各国央行的政策实践。

## 历史背景与写作历程

### 二战后的经济学格局

二十世纪五六十年代，凯恩斯主义经济学在西方学术界和政策界处于无可争议的统治地位。凯恩斯在《就业、利息和货币通论》（1936）中提出的理论框架，将大萧条归因于有效需求不足和投资者"动物精神"的崩溃，强调财政政策在稳定经济中的核心作用。在这一范式下，货币政策被视为相对次要的工具——所谓"推绳子"（pushing on a string）的比喻广为流传。

### 国家经济研究局（NBER）项目

弗里德曼与施瓦茨的合作始于1948年，依托国家经济研究局（NBER）的研究框架。NBER素以严谨的实证研究传统著称，由韦斯利·米切尔（Wesley Mitchell）和亚瑟·伯恩斯（Arthur Burns）奠定了经济周期研究的方法论基础。弗里德曼和施瓦茨在这一传统之上，开展了对美国近百年货币数据的系统性搜集、整理与分析工作。

### 十二年磨一剑

从1948年项目启动到1963年最终出版，这部著作耗时超过十二年。施瓦茨承担了绝大部分的数据搜集、整理和初步分析工作，她的贡献在学术史上长期被低估。两位作者梳理了从南北战争后（1867年）到肯尼迪时代（1960年）将近一个世纪的货币统计数据，包括货币存量（M1和M2口径）、银行准备金、货币乘数、利率等指标，工作量之浩大在计算机尚未普及的时代几乎难以想象。

## 研究方法论

### 叙事方法与统计分析的结合

弗里德曼与施瓦茨采用了一种独特的"叙事性实证"方法（narrative approach combined with statistical analysis）。他们并非简单地运行回归模型或进行计量检验，而是将定量数据分析嵌入详细的历史叙事之中，逐年、逐阶段地追踪货币供应变动与经济产出之间的关系。

这一方法论选择具有深刻的认识论意涵。弗里德曼深知，在宏观经济领域，受控实验几乎不可能进行；而纯粹的时间序列计量分析又面临内生性和反向因果等难题。历史叙事方法允许研究者利用丰富的制度细节和历史情境来识别因果方向——即判断究竟是货币变动引起了产出变动，还是相反。

### 外生性识别策略

为解决因果识别问题，弗里德曼和施瓦茨特别关注那些货币供应变动可以被视为"外生"的历史事件——即那些并非由经济活动本身引起，而是由政策失误、制度变迁或纯粹偶然因素（如联储官员的去世）导致的货币变动。这些"自然实验"为他们的因果论断提供了关键支撑。

```
┌─────────────────────────────────────────────────────┐
│         弗里德曼-施瓦茨方法论框架                       │
├─────────────────────────────────────────────────────┤
│                                                     │
│   历史叙事     +    统计数据    =    因果推断         │
│   (制度细节)        (货币存量)       (外生事件)       │
│                                                     │
│   ┌──────┐      ┌──────────┐     ┌──────────┐      │
│   │政策决策│      │ M1/M2    │     │联储失误  │      │
│   │制度变迁│  +   │银行准备金 │ →   │银行恐慌  │      │
│   │人事变动│      │货币乘数  │     │黄金流动  │      │
│   └──────┘      └──────────┘     └──────────┘      │
│                                                     │
│   目的：将货币供应变动确认为经济波动的"原因"          │
│         而非"结果"                                   │
└─────────────────────────────────────────────────────┘
```

## 核心论点：货币供应与经济周期

### 货币主义的基石

弗里德曼与施瓦茨的中心论点可以概括为以下命题链：

1. **货币供应量的变动在美国经济史上与名义收入的变动高度相关**。货币供应的加速增长通常先于经济扩张，而货币供应的减速或收缩则先于经济衰退。

2. **这种相关性反映的是从货币到收入的因果方向**，而非相反。通过考察大量历史事件，可以证明许多关键的货币变动源于可识别的外生因素。

3. **联邦储备系统的政策行为是货币供应变动的最重要决定因素**，而联储的政策记录充斥着严重的判断失误。

4. **因此，经济周期在很大程度上是货币现象**——不是说货币是唯一因素，但它是最重要的系统性因素。

### 长时段的证据

全书覆盖的近百年历史被划分为若干关键时段，每个时段的分析都围绕货币供应变动展开：

| 时段 | 货币特征 | 经济表现 |
|------|---------|---------|
| 1867-1879 | 战后通货紧缩、恢复金本位 | 实际增长强劲但物价下跌 |
| 1879-1897 | 黄金供应不足、货币增长缓慢 | 长期物价下降 |
| 1897-1914 | 黄金发现（南非、阿拉斯加）、货币扩张 | 物价上涨、经济繁荣 |
| 1914-1921 | 联储成立、一战融资、战后紧缩 | 剧烈波动 |
| 1921-1929 | 相对稳定的货币增长 | "咆哮的二十年代" |
| **1929-1933** | **货币供应收缩1/3** | **大萧条** |
| 1933-1941 | 货币恢复、1937年再次紧缩 | 缓慢复苏、1937年二次衰退 |
| 1941-1960 | 战时扩张、战后调整 | 总体稳定增长 |

## 第七章：大收缩（1929-1933）

### 最具影响力的一章

第七章"大收缩"（*The Great Contraction, 1929-33*）无疑是全书最具影响力的部分，后被单独出版发行。这一章以精密的历史叙事和数据分析，重新讲述了大萧条的故事——不再是资本主义固有不稳定性的悲剧，而是中央银行政策失败的灾难。

### 四波银行恐慌

弗里德曼与施瓦茨详细记录了1930年至1933年间发生的四波银行恐慌：

```
美国银行体系崩溃的四波恐慌
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

      银行数量
      (千家)
  30 ┤■■■■■■■■■■■■■■■■■■  (1929: ~25,000家)
     │
  25 ┤
     │        第一波恐慌
  20 ┤        (1930.10-12)
     │           ↓
  15 ┤     第二波恐慌          第三波恐慌
     │     (1931.3-8)         (1931.9-12)
  10 ┤                  英国脱离金本位 ↑
     │
   5 ┤                              第四波恐慌
     │                              (1933.1-3)
   0 ┤■■■■■■■■■  (1933: ~14,000家)
     └──────────────────────────────────────→ 时间
      1929    1930    1931    1932    1933

  四年间约 11,000 家银行倒闭
  货币供应量（M2）收缩约 33%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**第一波（1930年10月-12月）**：以合众国银行（Bank of United States）的倒闭为标志性事件。弗里德曼和施瓦茨特别指出，纽约联邦储备银行曾试图组织救援行动，但因反犹偏见和其他联储分行的不合作而失败。

**第二波（1931年3月-8月）**：银行挤兑蔓延至更广泛的地区，公众对银行体系的信心进一步瓦解。

**第三波（1931年9月-12月）**：英国于1931年9月脱离金本位制，引发国际金融恐慌。黄金大量外流美国，联储为保卫金本位而大幅提高贴现率——这在国内经济已然崩溃的背景下无异于雪上加霜。

**第四波（1933年1月-3月）**：最终导致罗斯福总统于1933年3月6日宣布全国银行假日（bank holiday），暂停所有银行业务。

### 联储的失职

弗里德曼和施瓦茨对联邦储备系统的批评尖锐而具体。他们指出，联储在整个大收缩期间犯下了三重失误：

1. **未能履行最后贷款人职能**：面对银行恐慌，联储没有向流动性困难的银行提供紧急贷款，听任恐慌蔓延。

2. **允许货币供应量剧烈收缩**：从1929年到1933年，美国的货币供应量（M2）下降了约33%。联储不仅未采取行动遏制这一收缩，在某些时段甚至通过紧缩政策加剧了它。

3. **内部权力斗争瘫痪了决策能力**：纽约联储银行行长本杰明·斯特朗（Benjamin Strong）于1928年去世后，联储系统内部失去了强有力的领导核心，各地区储备银行之间的分歧使得果断行动变得不可能。

### 反事实推理

弗里德曼和施瓦茨提出了一个关键的反事实论断：**如果本杰明·斯特朗没有在1928年去世，大萧条很可能不会发生——或至少不会演变到如此极端的程度**。斯特朗此前曾在1924年和1927年的金融紧张时期果断实施了扩张性公开市场操作，有效稳定了局势。他的去世使联储失去了理解并愿意运用这些工具的领导者。

## 对大萧条的重新诠释

### 从市场失灵到政策失败

弗里德曼与施瓦茨对大萧条成因的重新诠释，构成了二十世纪经济思想史上最重要的范式转换之一：

| 维度 | 凯恩斯主义解释 | 弗里德曼-施瓦茨解释 |
|------|-------------|-----------------|
| **根本原因** | 有效需求崩溃 | 货币供应收缩 |
| **关键机制** | 投资者信心崩溃 → 支出下降 | 银行恐慌 → 货币乘数下降 → M2收缩 |
| **责任归属** | 资本主义固有不稳定性 | 联储政策失误 |
| **政策含义** | 需要积极财政政策 | 需要稳定的货币政策规则 |
| **对市场的看法** | 市场本身会产生灾难 | 政府干预（不当的）制造了灾难 |

这一重新诠释的深远意义在于：大萧条不再被视为自由市场经济制度的失败证据和国家干预的正当性依据，而是被重新理解为**中央银行政策失误的后果**。讽刺的是，恰恰是为了稳定金融体系而创建的联邦储备系统，通过其不作为和错误行动，导致了金融体系最为灾难性的崩溃。

## 伯南克的道歉与2008年金融危机

### "我们做了那件事。我们非常抱歉。"

2002年11月，在弗里德曼九十岁生日庆典上，时任联邦储备委员会理事的本·伯南克（Ben Bernanke）发表了一段著名的致辞：

> "关于大萧条，你们是对的。我们做了那件事。我们非常抱歉。但多亏了你们，我们不会再犯同样的错误了。"
>
> （*Regarding the Great Depression, you're right. We did it. We're very sorry. But thanks to you, we won't do it again.*）

这段话的分量在2008年金融危机爆发后得到了充分体现。此时已担任联储主席的伯南克，深受弗里德曼-施瓦茨分析框架的影响，在危机应对中采取了截然不同于1930年代联储的策略。

### 2008年的"弗里德曼-施瓦茨方案"

```
弗里德曼-施瓦茨教训在2008年危机中的应用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    1930年代的错误              2008年的纠正
    ─────────────              ─────────────
    拒绝救助银行    ──→    TARP（7000亿美元问题资产救助）
    听任货币收缩    ──→    量化宽松（QE1, QE2, QE3）
    提高贴现率      ──→    联邦基金利率降至接近零
    无最后贷款人    ──→    紧急贷款便利（TAF, PDCF等）
    各自为政        ──→    与全球央行协调行动

    结果对比:
    1929-33: GDP下降30%, 失业率25%, 持续4年
    2007-09: GDP下降4.3%, 失业率10%, 衰退18个月
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

伯南克领导下的联储实施了史无前例的扩张性货币政策：将联邦基金利率降至接近零的水平，实施多轮量化宽松（QE），并通过一系列创新的紧急贷款便利工具向金融体系注入流动性。这些举措的思想源头可以直接追溯到弗里德曼与施瓦茨的分析。

## 批评与局限

### 反向因果性争论

对《美国货币史》最根本的批评来自内生货币理论的支持者。他们认为，弗里德曼和施瓦茨混淆了因果方向：并非货币供应变动导致了产出变动，而是经济活动的扩张和收缩导致了货币需求的变动，银行信贷随之扩张或收缩，货币供应只是被动地适应实体经济的需要。

詹姆斯·托宾（James Tobin）在其著名的"后此谬误"（*post hoc ergo propter hoc*）批评中指出，即使货币变动在时间上先于产出变动，也不能据此推断因果方向。货币的领先性可能反映的是经济主体的预期行为，而非货币对实体经济的因果影响。

### 信贷渠道与货币渠道之争

伯南克本人虽然高度认同弗里德曼-施瓦茨关于联储政策失误的判断，但在传导机制上提出了重要的补充和修正。伯南克（1983）提出的"金融加速器"理论强调，大萧条中银行体系崩溃的破坏性主要不在于它导致了货币供应收缩，而在于它摧毁了银行的信息资本和信贷中介功能，从而使得信贷配置效率急剧下降。这是"信贷渠道"（credit channel）对"货币渠道"（money channel）的挑战。

### 对货币数量的过度强调

彼得·特明（Peter Temin，1976）在《大萧条的货币力量是否起了作用？》一文中指出，弗里德曼和施瓦茨过于关注货币总量的变动，而忽视了利率作为货币政策松紧程度指标的信息。在大萧条期间，名义利率确实很低，但实际利率（经通货紧缩调整后）却非常之高——这一事实暗示需求端的萎缩可能比货币供给端的收缩更为关键。

### 国际维度的缺失

作为一部关于美国货币史的著作，弗里德曼-施瓦茨分析不可避免地以美国的国内因素为焦点。然而，大萧条本质上是一个全球性事件，金本位制度下的国际传导机制——巴里·艾肯格林（Barry Eichengreen）后来将其概括为"黄金镣铐"（golden fetters）——在危机的跨国传播中发挥了核心作用。弗里德曼和施瓦茨对这一国际维度的关注相对有限。

## 现代意义与遗产

### 对央行理论与实践的永久改变

《美国货币史》从根本上改变了中央银行在经济稳定中的角色认知。在此之前，央行被许多经济学家视为相对次要的制度安排；在此之后，货币政策的重要性获得了广泛承认。

这一影响体现在多个层面：

- **学术层面**：催生了货币主义学派，推动了货币经济学的发展，为后来的理性预期革命和新凯恩斯主义经济学提供了重要的理论资源。

- **政策层面**：央行独立性、通货膨胀目标制、最后贷款人原则等当代央行制度的核心要素，都可以在弗里德曼-施瓦茨的分析中找到思想渊源。

- **危机应对层面**：2008年金融危机的处置方式——特别是美联储和其他主要央行的激进扩张政策——直接受到了这部著作的启发。

### 量化宽松的思想源头

当代各国央行在零利率下限（zero lower bound）环境中实施的量化宽松（QE）政策，其思想根基可以追溯到弗里德曼。弗里德曼在2000年代初期明确建议日本银行通过大规模购买国债来增加货币供应，以应对通货紧缩和经济停滞。这一建议的理论基础正是《美国货币史》中关于货币供应量与经济活动因果关系的论证。

### 1976年诺贝尔经济学奖

弗里德曼于1976年获得诺贝尔经济学奖，表彰他在"消费分析、货币史和货币理论方面的成就，以及他对稳定政策复杂性的阐释"。《美国货币史》是其获奖的最重要支撑之一。施瓦茨虽未获诺贝尔奖，但她的贡献在经济学史上获得了越来越多的承认。

---

## 结语

《美国货币史，1867-1960》是经济学文献中罕见的那一类作品——它不仅在学术层面产生了深远影响，更直接改变了现实世界的政策实践。从1963年出版至今的六十余年间，这部著作的核心洞见——货币政策对经济稳定至关重要，央行的政策失误可能导致灾难性后果——已经从一种"异端"观点演变为政策共识。

然而，2008年金融危机及其后的长期低增长，也暴露了纯粹货币主义视角的局限性。在利率接近零、量化宽松规模空前的背景下，通货膨胀长期低于央行目标，经济复苏步伐缓慢——这些现象提醒我们，弗里德曼和施瓦茨的分析框架虽然强大，但远非对宏观经济运行的完整描述。货币确实重要（money matters），但它并非唯一重要的因素。
