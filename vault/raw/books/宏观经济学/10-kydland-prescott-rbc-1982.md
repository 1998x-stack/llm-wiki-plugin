# 真实商业周期理论：Kydland 与 Prescott 的范式革命 (1982)

## 一、引言

1982年，挪威经济学家 Finn E. Kydland 与美国经济学家 Edward C. Prescott 在顶级经济学期刊 *Econometrica* 上发表了题为 **"Time to Build and Aggregate Fluctuations"** 的论文。这篇论文从根本上重新定义了宏观经济学家理解经济波动的方式，开创了 **真实商业周期理论 (Real Business Cycle Theory, RBC)**，并因此于2004年荣获诺贝尔经济学奖。

在此之前，宏观经济学界的主流观点——无论是凯恩斯主义还是货币主义——都将经济衰退视为某种形式的 **市场失灵**。凯恩斯主义者将其归因于有效需求不足，货币主义者则强调货币供给的不当收缩。Kydland 和 Prescott 提出了一个截然不同的命题：**经济波动并非市场失灵，而是理性经济主体对真实冲击的最优反应。**

这一命题在当时犹如石破天惊，引发了长达数十年的学术争论，并最终重塑了现代宏观经济学的方法论基础。

---

## 二、历史背景与学术脉络

### 2.1 宏观经济学的危机年代

20世纪70年代是宏观经济学的一个转折点。西方发达国家同时经历了高通胀与高失业的 **滞胀 (Stagflation)** 现象，这一现象直接挑战了当时占主导地位的凯恩斯主义菲利普斯曲线框架——该框架预测通胀与失业之间存在稳定的反向替代关系。

与此同时，Robert Lucas 在1976年发表的 **"卢卡斯批判 (Lucas Critique)"** 对传统宏观计量模型提出了根本性质疑：如果政策规则发生改变，经济主体的决策规则也会随之改变，因此基于历史数据估计的结构参数无法用于评估新政策的效果。

### 2.2 新古典宏观经济学的兴起

卢卡斯批判催生了 **新古典宏观经济学** 的兴起。这一学派坚持三个核心原则：

1. **理性预期 (Rational Expectations)**：经济主体充分利用所有可得信息形成预期
2. **持续出清的市场 (Continuously Clearing Markets)**：价格具有完全弹性
3. **最优化行为 (Optimizing Behavior)**：所有行为主体在约束条件下追求效用或利润最大化

Kydland 和 Prescott 的 RBC 理论正是在这一思想潮流中应运而生的，但他们走得比 Lucas 更远——不仅仅是方法论上的革新，而是对经济波动的 **本质** 提出了全新的理解。

### 2.3 学术渊源

RBC 理论的思想源头可以追溯到更早的文献：

- **Ramsey (1928)**：最优储蓄模型，提供了动态最优化的分析框架
- **Solow (1956) 和 Swan (1956)**：新古典增长模型，强调技术进步对经济增长的核心作用
- **Kydland & Prescott (1977)**：二人更早的合作论文"Rules Rather than Discretion"讨论了时间不一致性问题
- **Long & Plosser (1983)**：几乎同时独立发展的真实商业周期模型

## 三、核心思想与模型结构

### 3.1 核心命题

RBC 理论的核心命题可以概括为以下几点：

**第一，经济波动是 "好的" 波动。** 产出的周期性波动不是市场失灵的表征，而是竞争性市场经济对真实冲击的帕累托最优反应。换言之，即使存在一个无所不知的社会计划者，他也无法做得比市场更好。

**第二，驱动经济波动的是真实冲击，而非名义冲击。** 最重要的冲击来源是 **技术冲击 (Technology Shocks)**，即全要素生产率 (TFP) 的随机变动。与凯恩斯主义和货币主义不同，RBC 理论认为货币因素对实际经济活动几乎没有影响。

**第三，经济波动的传播依赖于跨期替代机制。** 当正向技术冲击发生时，劳动的边际产出暂时性提高，理性的工人选择在高工资时期多工作、少休闲，在低工资时期少工作、多休闲——这就是 **劳动的跨期替代 (Intertemporal Substitution of Leisure)**。

### 3.2 "建造时间" 机制

论文标题中的 **"Time to Build"（建造时间）** 指的是投资项目从启动到完成需要多个时期。例如，建设一座工厂可能需要四个季度。这意味着：

```
时期 1: 投入资金 → 项目启动，尚未产出
时期 2: 继续投入 → 项目在建
时期 3: 继续投入 → 项目在建
时期 4: 项目完工 → 形成生产性资本
```

这一设定并非仅仅是对现实的描述，它在模型中扮演着关键的 **放大机制 (Amplification Mechanism)** 角色。多期投资的存在使得当期的投资决策取决于对未来多个时期技术状态的预期，从而增加了投资的波动性，进而放大了产出的波动。

### 3.3 模型的正式结构

Kydland-Prescott 模型是一个 **随机动态一般均衡 (Stochastic Dynamic General Equilibrium)** 模型，其基本结构如下：

**代表性家庭的效用函数：**

```
            inf
  max  E_0  SUM  beta^t * U(C_t, L_t)
            t=0

  其中:
    beta  = 主观时间贴现因子 (0 < beta < 1)
    C_t   = 第 t 期的消费
    L_t   = 第 t 期的闲暇
    U(.)  = 瞬时效用函数，关于 C 和 L 递增且凹
```

**技术（生产函数）：**

```
  Y_t = A_t * F(K_t, N_t) = A_t * K_t^alpha * N_t^(1-alpha)

  其中:
    Y_t   = 第 t 期的产出
    A_t   = 全要素生产率 (TFP)
    K_t   = 第 t 期的资本存量
    N_t   = 第 t 期的劳动投入
    alpha = 资本的产出弹性
```

**技术冲击过程（关键驱动力）：**

```
  ln(A_t) = rho * ln(A_{t-1}) + epsilon_t

  其中:
    rho       = 自回归系数 (通常取 0.95，表示高度持续性)
    epsilon_t = 独立同分布的正态随机冲击, ~ N(0, sigma^2)
```

**多期投资约束 (Time to Build)：**

```
  一个投资项目需要 J 个时期完成 (论文中 J = 4):

  K_{t+1} = (1 - delta) * K_t + S_{J,t}

  其中:
    S_{j,t} 表示第 t 期处于第 j 阶段的在建项目
    S_{1,t} 为新启动的项目
    S_{J,t} 为完工的项目
    delta   为资本折旧率
```

**资源约束：**

```
  Y_t = C_t + I_t

  其中 I_t 包括所有在建阶段的投资支出
```

### 3.4 传导机制图解

技术冲击在模型中的传导路径可以概括如下：

```
  正向技术冲击 (A_t 上升)
       |
       v
  +--------------------+
  | 劳动边际产出上升    |
  | 资本边际产出上升    |
  +--------------------+
       |               |
       v               v
  +-----------+  +-----------+
  | 劳动供给  |  | 投资增加  |
  | 增加      |  | (多期     |
  | (跨期     |  |  建造)    |
  |  替代)    |  +-----------+
  +-----------+       |
       |               |
       v               v
  +-----------+  +-----------+
  | 产出上升  |  | 未来资本  |
  |           |  | 存量增加  |
  +-----------+  +-----------+
       |               |
       v               v
  +-----------+  +-----------+
  | 消费上升  |  | 产出持续  |
  | (平滑)    |  | 增长      |
  +-----------+  +-----------+
```

注意一个关键特征：由于消费平滑（永久收入假说），消费对冲击的反应幅度小于产出；而投资由于多期建造的放大效应和资本存量的调整需求，其波动幅度远大于产出。这与现实中的经济数据高度一致。

## 四、校准方法论

### 4.1 从估计到校准

Kydland 和 Prescott 在方法论上的一个重大创新是引入了 **校准方法 (Calibration)**，以区别于传统的计量经济学估计 (Estimation)。

传统方法是：
1. 设定模型结构
2. 利用时间序列数据估计参数
3. 检验模型的统计拟合度

校准方法则是：
1. 设定模型结构
2. 利用微观研究、长期平均值和国民账户数据**直接赋予参数值**
3. 检验模型生成的人工数据是否在关键统计特征上与真实数据匹配

### 4.2 参数校准

以下是 Kydland-Prescott 原始模型中关键参数的校准值及其依据：

```
+--------------------+----------+----------------------------------+
|       参数         |  校准值  |         依据                     |
+--------------------+----------+----------------------------------+
| beta (贴现因子)    |  0.99    | 匹配年化4%的实际利率             |
|                    |          | (季度数据)                       |
+--------------------+----------+----------------------------------+
| alpha (资本份额)   |  0.36    | 美国国民收入中资本报酬的         |
|                    |          | 长期平均份额                     |
+--------------------+----------+----------------------------------+
| delta (折旧率)     |  0.025   | 匹配年化10%的资本折旧率          |
|                    |          | (季度数据)                       |
+--------------------+----------+----------------------------------+
| rho (TFP持续性)    |  0.95    | Solow残差的自回归估计            |
+--------------------+----------+----------------------------------+
| sigma (冲击标准差) |  0.007   | Solow残差的残差标准差            |
+--------------------+----------+----------------------------------+
| J (建造期)         |  4       | 工业投资项目平均完工时间         |
|                    |          | (4个季度)                        |
+--------------------+----------+----------------------------------+
```

### 4.3 模型预测与美国数据的比较

RBC 理论的一个引人注目之处在于，这个只有少数几个参数的简约模型，在匹配美国宏观经济数据的关键统计特征方面取得了出人意料的成功。以下是模型预测与实际数据的比较（均为 HP 滤波后的波动成分，1954-1991年季度数据）：

```
+---------------------+----------+----------+
|     统计量          | 美国数据 | RBC模型  |
+---------------------+----------+----------+
|                    标准差 (%)              |
+---------------------+----------+----------+
| 产出 (Y)            |   1.76   |   1.76   |
| 消费 (C)            |   1.29   |   0.55   |
| 投资 (I)            |   8.60   |   5.71   |
| 劳动时间 (N)        |   1.66   |   0.91   |
| 劳动生产率 (Y/N)    |   0.90   |   1.14   |
+---------------------+----------+----------+
|             相对标准差 (相对于 Y)          |
+---------------------+----------+----------+
| 消费 (C)            |   0.73   |   0.31   |
| 投资 (I)            |   4.89   |   3.24   |
| 劳动时间 (N)        |   0.94   |   0.52   |
+---------------------+----------+----------+
|            与产出的相关系数                |
+---------------------+----------+----------+
| 消费 (C)            |   0.85   |   0.94   |
| 投资 (I)            |   0.92   |   0.99   |
| 劳动时间 (N)        |   0.76   |   0.97   |
| 劳动生产率 (Y/N)    |   0.42   |   0.98   |
+---------------------+----------+----------+
```

从上表可以看出几个重要结论：

**模型的成功之处：**
- 消费波动小于产出波动（消费平滑）
- 投资波动远大于产出波动（投资加速器效应）
- 各变量与产出正相关（顺周期性）

**模型的不足之处：**
- 消费波动幅度不够大（模型0.55% vs 数据1.29%）
- 劳动时间波动严重不足（模型0.91% vs 数据1.66%）
- 劳动生产率与产出的相关系数过高（模型0.98 vs 数据0.42）
- 各变量与产出的相关系数普遍偏高

劳动时间波动不足这一缺陷尤为关键，它成为了后续批评者攻击 RBC 理论的主要靶点。

## 五、Prescott 的诺贝尔演讲：繁荣与萧条

2004年，Prescott 在其诺贝尔演讲中进一步阐发了 RBC 的核心洞见。他指出：

> "Prosperity and depression are not the result of some market failure... They are, rather, the optimal response of the economy to shocks in the rate of technological change."
>
> （繁荣与萧条并非市场失灵的结果......它们是经济体对技术变革速率冲击的最优反应。）

这一立场意味着，政府试图通过反周期政策来"稳定"经济的做法，在最好的情况下是无效的，在最坏的情况下是有害的——因为它干扰了经济主体对真实冲击的最优调整过程。

## 六、批评与争论

### 6.1 Mankiw 的新凯恩斯主义批评 (1989)

Gregory Mankiw 在1989年发表的 **"Real Business Cycle Theory: A New Keynesian Perspective"** 中对 RBC 理论提出了系统性的批评：

**第一，技术冲击的规模问题。** Mankiw 指出，要生成与数据匹配的产出波动，RBC 模型需要假设全要素生产率的季度标准差约为0.7%-1%。这意味着每隔几年就会发生一次重大的技术进步或技术退步。经济中真的存在如此频繁且剧烈的技术冲击吗？

**第二，跨期劳动替代的实证基础薄弱。** RBC 理论的传导机制严重依赖工人根据暂时性工资变化大幅调整劳动供给的意愿。然而，微观经济学的实证文献普遍发现，劳动供给的跨期替代弹性很低——远低于 RBC 模型所需的水平。

**第三，"真实"冲击的度量问题。** Prescott 使用 Solow 残差来度量技术冲击，但 Solow 残差实际上是一个 "无知的度量 (measure of our ignorance)"——它包含了所有未被资本和劳动投入解释的产出变动，其中很大一部分可能反映的是要素利用率的变化、市场势力的周期性变动，而非真正的技术变革。

### 6.2 Summers 的怀疑论 (1986)

Lawrence Summers 在1986年的评论文章 **"Some Skeptical Observations on Real Business Cycle Theory"** 中提出了更为尖锐的质疑：

**负向技术冲击意味着什么？** 如果经济衰退是由负向技术冲击引起的，那就意味着社会偶尔会 "忘记" 如何高效生产——这在直觉上是荒谬的。1982年的深度衰退难道是因为美国经济突然遭遇了技术退步？

**失业是自愿的？** RBC 理论中没有非自愿失业——所有的就业变动都反映了工人在工资变化下的自愿选择。大萧条期间25%的失业率是工人 "自愿" 选择休闲的结果，这一含义显然与常识不符。

### 6.3 劳动市场的核心困境

RBC 理论在劳动市场方面面临一个深层困境，可以概括为以下的不可能三角：

```
         模型需要高劳动波动
              /        \
             /          \
            /            \
  微观证据表明        数据显示劳动
  跨期替代弹性低      生产率与劳动
                      时间弱相关

  -----> 三者不可能同时成立 <-----
```

为了产生足够大的劳动时间波动，模型需要很高的跨期替代弹性；但微观证据不支持这一假设。后续研究者提出了各种修补方案——如 Hansen (1985) 的 **不可分劳动模型 (Indivisible Labor)** 和 Rogerson (1988) 的彩票经济——通过将就业决策从连续的工时选择变为离散的就业/失业选择，在宏观层面产生了更高的有效劳动供给弹性。

### 6.4 货币中性的争议

RBC 理论假设货币是中性的——货币供给的变化只影响价格水平，不影响实际产出。然而，大量实证研究（如 Friedman & Schwartz 1963, Romer & Romer 1989, Christiano, Eichenbaum & Evans 1999）都发现货币政策冲击对实际经济活动具有显著影响。

这一争议从未完全解决，但它推动了后续 **新凯恩斯主义 DSGE 模型** 的发展——在 RBC 框架中加入名义刚性，使得货币政策获得实际效果。

## 七、理论演化：从 RBC 到新凯恩斯主义 DSGE

### 7.1 融合的逻辑

RBC 理论的最大遗产或许不在于其具体的经济周期解释，而在于它为宏观经济学提供了一个 **统一的建模框架**。这个框架的核心要素包括：

```
RBC 方法论遗产
+---------------------------------------------+
|                                             |
|  1. 微观基础 (Microfoundations)              |
|     - 代表性家庭最优化                       |
|     - 代表性企业最优化                       |
|                                             |
|  2. 一般均衡 (General Equilibrium)           |
|     - 所有市场同时出清或部分出清             |
|                                             |
|  3. 动态随机 (Dynamic & Stochastic)          |
|     - 跨期决策                               |
|     - 随机冲击驱动                           |
|                                             |
|  4. 校准/贝叶斯估计                          |
|     - 参数有微观/长期数据支撑                |
|     - 检验商业周期统计特征                   |
|                                             |
+---------------------------------------------+
```

### 7.2 新凯恩斯主义 DSGE 的兴起

从1990年代中期开始，一系列研究者——包括 Julio Rotemberg, Michael Woodford, Jordi Gali, Mark Gertler, Christiano, Eichenbaum 等——在 RBC 框架中逐步加入凯恩斯主义元素：

```
+------------------+         +------------------+
|    RBC 框架      |         |  凯恩斯元素      |
+------------------+         +------------------+
| 理性预期         |   +     | 粘性价格         |
| 微观基础         |   +     | 垄断竞争         |
| 一般均衡         |   +     | 名义刚性         |
| 随机冲击         |   +     | 不完全竞争       |
| 校准方法         |   +     | 货币政策有效性   |
+------------------+         +------------------+
         |                           |
         +---------------------------+
                     |
                     v
         +------------------+
         | 新凯恩斯 DSGE    |
         | (Smets-Wouters   |
         |  2003, 2007)     |
         +------------------+
```

**Smets 和 Wouters (2003, 2007)** 的模型成为新凯恩斯 DSGE 的标杆。他们的模型在 RBC 核心框架上加入了：

- **价格粘性 (Calvo pricing)**：企业不能每期自由调整价格
- **工资粘性**：名义工资调整存在摩擦
- **垄断竞争**：企业拥有一定的市场势力
- **投资调整成本**：改变投资水平需要付出额外成本
- **习惯形成 (Habit Formation)**：消费效用取决于消费水平相对于过去的变化
- **多种冲击**：不仅包含技术冲击，还包括需求冲击、成本推动冲击、货币政策冲击等

### 7.3 方法论的胜利

值得注意的是，即使 RBC 理论关于经济周期由技术冲击驱动的核心假说被许多经济学家拒绝，其 **方法论** 却获得了压倒性的胜利。到2000年代，几乎所有主要中央银行——包括美联储、欧洲中央银行、英格兰银行——都建立了自己的 DSGE 模型用于政策分析和预测。

正如 Mankiw (2006) 所言：

> "新古典和新凯恩斯经济学家可能在结论上分歧很大，但他们使用的语言和工具箱是相同的——而这个工具箱正是 Kydland 和 Prescott 打造的。"

## 八、现代评价与影响

### 8.1 对 2008 年金融危机的反思

2008年全球金融危机对 DSGE 模型（包括其 RBC 内核）提出了严峻挑战。标准 DSGE 模型缺乏金融部门和金融摩擦，无法预测也无法解释由金融市场崩溃引发的深度衰退。

这引发了对宏观经济学方法论的新一轮反思。后危机时代的 DSGE 模型纷纷加入金融摩擦（如 Gertler & Kiyotaki 2010, Brunnermeier & Sannikov 2014），但一些批评者（如 Stiglitz 2018, Romer 2016）则对整个 DSGE 范式提出了更根本的质疑。

### 8.2 Prescott 命题的持续影响

尽管面临诸多批评，RBC 理论的某些核心洞见在现代宏观经济学中仍然具有深远影响：

**供给侧冲击的重要性。** 2020年新冠疫情引发的经济衰退在很大程度上是一个供给侧冲击——生产能力的突然中断。这一事件为 RBC 理论关于真实冲击驱动经济波动的命题提供了新的支持。

**方法论标准的确立。** 微观基础、一般均衡、校准/估计、与数据矩匹配——这些由 Kydland 和 Prescott 确立的方法论标准已成为现代宏观经济学不可或缺的组成部分。

**政策评估框架。** DSGE 模型——RBC 的直系后裔——至今仍是中央银行进行反事实政策分析的主要工具。

### 8.3 当代研究前沿

RBC 方法论的当代延伸包括：

- **异质性主体模型 (Heterogeneous Agent Models)**：Kaplan, Moll & Violante (2018) 的 HANK 模型
- **网络模型 (Production Networks)**：Acemoglu et al. (2012) 研究部门间冲击传导
- **不确定性冲击 (Uncertainty Shocks)**：Bloom (2009) 将不确定性本身作为商业周期的驱动力
- **气候经济学**：将气候变化作为长期真实冲击纳入 DSGE 框架

---

## 九、结论

Kydland 和 Prescott 1982年的论文是20世纪下半叶最具影响力的宏观经济学研究之一。它提出的核心命题——经济波动可能是对真实冲击的最优反应——即使在今天仍然充满争议。然而，它在方法论上的贡献是无可争辩的：它创建了一个将微观经济学理论、计算方法和宏观经济数据有机结合的分析框架，这个框架至今仍是宏观经济学研究的基础设施。

Prescott 在诺贝尔演讲中曾说，RBC 理论的意义在于它 "将商业周期研究从艺术变成了科学"。虽然这一判断或许过于乐观，但不可否认的是，正是这一理论为宏观经济学走向更加严谨和系统的方向奠定了不可替代的基石。
