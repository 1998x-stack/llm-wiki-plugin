# 03 | Richard Sutton《Learning to Predict by the Methods of Temporal Differences》(1988)

## 时序差分学习：连接动态规划与蒙特卡洛的桥梁

---

## 1. 论文基础信息

- **标题**: Learning to Predict by the Methods of Temporal Differences
- **作者**: Richard S. Sutton
- **发表时间**: 1988 年
- **期刊**: Machine Learning, Vol. 3, No. 1, pp. 9-44 (Kluwer Academic Publishers)
- **研究领域**: 强化学习 (Reinforcement Learning)、机器学习 (Machine Learning)、序列预测 (Sequential Prediction)
- **作者机构**: GTE Laboratories Incorporated, Waltham, Massachusetts
- **引用量**: 截至目前超过 8000 次，是强化学习领域被引用最多的论文之一
- **论文类型**: 理论奠基性论文，同时包含实验验证

Richard S. Sutton 是强化学习领域公认的奠基人之一，后来与 Andrew Barto 合著了经典教材《Reinforcement Learning: An Introduction》。这篇论文是他在 GTE 实验室期间完成的工作，正式将时序差分 (Temporal Difference, TD) 方法确立为一类独立的学习算法家族，为后续整个强化学习领域的发展奠定了理论基石。

---

## 2. 一句话总结

Sutton 提出了 TD(lambda) 学习方法，这是一类全新的增量式预测学习算法，它无需环境的完整模型（区别于动态规划），也无需等到最终结果揭晓才更新预测（区别于蒙特卡洛方法），而是通过比较相邻时刻的预测差异来驱动学习，从而在计算效率与学习效果之间实现了精妙的平衡，开创了强化学习三大方法论支柱之一。

---

## 3. 当时的时代问题

1980 年代的机器学习领域，正处于一个方法论上的"真空地带"。当时主流的学习范式面临着一系列深层次的困境，这些困境共同催生了对新型学习方法的迫切需求。

**监督学习 (Supervised Learning) 的局限性。** 当时最成熟的学习范式是监督学习，它要求每个输入都有一个明确的"正确答案"作为训练标签。然而在大量真实场景中，这种即时的、精确的反馈并不存在。以 Samuel 的跳棋程序为例：一个棋手在对弈过程中做出的每一步棋，其"好坏"并不能立即确定，只有到棋局结束时才知道最终的胜负。在这种多步决策问题中，传统监督学习无法有效地将最终反馈信号分配 (credit assignment) 到中间的每一个决策步骤上。

**动态规划 (Dynamic Programming, DP) 需要完整的环境模型。** 动态规划方法（如 Bellman 方程的迭代求解）在理论上可以优雅地解决序列决策问题，但它要求事先知道环境的完整转移概率模型 P(s'|s, a) 和奖励函数 R(s, a)。在绝大多数实际应用中，这种完整的模型是不可获得的。一个机器人在未知环境中导航时，它不可能预先知道每一步行动会导致什么后果。

**蒙特卡洛方法 (Monte Carlo, MC) 的低效性。** 蒙特卡洛方法通过完整采样一个 episode（一次完整的经历从头到尾），然后用实际的累积回报来更新估计。它不需要环境模型，但有两个致命弱点：第一，必须等到整个 episode 结束才能更新，这意味着学习信号的反馈极度延迟；第二，对于持续性任务 (continuing tasks)，即没有自然终止点的任务，蒙特卡洛方法根本无法直接应用。

**信用分配问题 (Credit Assignment Problem) 的悬而未决。** 当一个智能体经历了一连串状态和动作后获得了一个最终奖励，如何将这个奖励"归功"于（或"归咎"于）序列中的每一个中间步骤？这个问题是当时 AI 领域最核心的开放问题之一。Minsky (1961) 早已指出这一问题的重要性，但始终缺乏一个优雅的、计算上可行的解决方案。

正是在这样的背景下，Sutton 提出了时序差分学习——一种既不需要完整模型、也不需要等到终局、还能在线逐步更新的学习方法，填补了动态规划与蒙特卡洛之间的方法论空白。

## 4. 核心问题定义

Sutton 在这篇论文中精准地锚定了一个看似简单却极其深刻的问题：**多步预测问题 (Multi-step Prediction Problem)**。

具体来说，问题可以形式化为：一个学习系统观察到一个随时间展开的序列 x_1, x_2, ..., x_m, z，其中 x_t 是每一步的观测向量，z 是序列结束时才揭晓的最终结果。系统的目标是在观测到 x_t 时，尽可能准确地预测最终结果 z 的值（或某种与 z 相关的函数）。

**预测问题 vs 控制问题的关键区分。** Sutton 做出了一个对整个领域具有深远影响的概念区分：他将学习任务分解为"预测问题"和"控制问题"。预测问题关注的是"世界将会怎样"——即学习一个准确的价值函数；控制问题关注的是"该怎么做"——即学习一个最优策略。Sutton 敏锐地意识到，预测问题是控制问题的基础，许多控制算法的核心都依赖于一个准确的预测（价值估计）。因此，他选择先攻克预测问题，这一策略上的精准定位，为后续的 Q-learning、SARSA 等控制算法铺平了道路。

**对问题边界的重新定义。** 传统的监督学习框架将多步预测问题处理为"给定输入 x_t，预测输出 z"的标准回归任务。Sutton 颠覆了这一框架：他指出，既然我们在序列中的每一步 t 都会产生一个预测 P_t，那么时刻 t+1 的预测 P_{t+1} 就比 P_t 拥有更多的信息（因为它离最终结果更近了一步），因此 P_{t+1} 本身就可以作为 P_t 的学习目标。这一看似简单的观察，实际上从根本上改变了学习信号的来源：从"等待最终真值"变为"利用下一步的预测差异"。

## 5. 核心方法与思想

### 5.1 TD(0) 的基本更新规则

TD 学习的最简形式是 TD(0)，其核心更新规则为：

```
V(s_t) <- V(s_t) + alpha * [r_{t+1} + gamma * V(s_{t+1}) - V(s_t)]
```

其中：
- `V(s_t)` 是状态 s_t 的当前价值估计
- `alpha` 是学习率 (learning rate)，控制更新步长
- `r_{t+1}` 是从 s_t 转移到 s_{t+1} 时获得的即时奖励
- `gamma` 是折扣因子 (discount factor)，控制对未来奖励的重视程度
- `V(s_{t+1})` 是下一状态的当前价值估计

这个公式的精髓在于：它用 `r_{t+1} + gamma * V(s_{t+1})` 这个"更好的估计"来修正当前估计 `V(s_t)`。与蒙特卡洛方法需要等到 episode 结束才能获得真实回报不同，TD(0) 在每一步转移后就立即进行更新。

### 5.2 TD 误差 (TD Error, delta)

TD 方法的核心概念是 TD 误差 (Temporal Difference Error)：

```
delta_t = r_{t+1} + gamma * V(s_{t+1}) - V(s_t)
```

这个 delta_t 衡量的是"实际发生的事情"（获得了奖励 r_{t+1} 并到达了估值为 V(s_{t+1}) 的新状态）与"之前的预期"（V(s_t)）之间的差距。如果 delta_t > 0，说明实际结果比预期更好，应该上调 V(s_t)；反之则下调。这与心理学中 Rescorla-Wagner 模型描述的动物学习机制惊人地相似——后来在神经科学中被证实与多巴胺神经元的放电模式高度吻合。

### 5.3 资格迹 (Eligibility Traces)

资格迹是 Sutton 在这篇论文中引入的一个精巧机制，用于解决信用分配问题。对于每个状态 s，维护一个资格迹变量 e(s)：

```
e_t(s) = gamma * lambda * e_{t-1}(s) + 1   (如果 s = s_t)
e_t(s) = gamma * lambda * e_{t-1}(s)       (如果 s != s_t)
```

资格迹记录了一个状态"最近被访问过"的程度。刚刚访问过的状态资格迹值最高，随着时间推移呈指数衰减。当 TD 误差 delta_t 产生时，所有状态都按其资格迹的大小进行更新：

```
V(s) <- V(s) + alpha * delta_t * e_t(s)    (对所有状态 s)
```

这意味着 TD 误差不仅更新当前状态，还会"回溯"更新最近访问过的状态，且更新幅度随时间距离衰减。

### 5.4 lambda 参数的统一框架

lambda 参数是 TD(lambda) 方法的灵魂，它在 [0, 1] 之间取值，提供了一个连续的谱系：

- **lambda = 0（纯 TD）**: 只使用一步预测差异，完全依赖 bootstrapping（自举），更新最快但偏差最大
- **lambda = 1（等价于蒙特卡洛）**: 使用从当前步到 episode 结束的完整实际回报，无偏但方差最大
- **0 < lambda < 1**: 在偏差和方差之间取得权衡

Sutton 展示了 TD(lambda) 的一个优美等价性：TD(lambda) 的更新等价于对 n 步回报进行指数加权平均，权重为 `(1-lambda) * lambda^{n-1}`。这意味着 lambda 控制着我们在多大程度上信任"远期的实际经历"vs"近期的自举估计"。

### 5.5 Bootstrapping（自举）的概念

Bootstrapping 是 TD 方法最核心的思想特征，指的是用一个估计值来更新另一个估计值。在 TD(0) 的更新规则中，V(s_{t+1}) 本身就是一个估计值（而非真实值），但它被用来构造 V(s_t) 的学习目标。这种"用猜测更新猜测"的做法乍看似乎不靠谱，但 Sutton 通过理论分析和实验证明，在适当条件下，这种自举过程是收敛的，而且往往比等待真实回报的蒙特卡洛方法收敛更快。

### 5.6 与动态规划和蒙特卡洛的三角关系

Sutton 通过 TD 方法架起了动态规划和蒙特卡洛之间的桥梁：

| 特征 | 动态规划 (DP) | 蒙特卡洛 (MC) | TD 学习 |
|------|-----------|------------|---------|
| 需要环境模型 | 是 | 否 | 否 |
| 需要完整 episode | 否 | 是 | 否 |
| 使用 Bootstrapping | 是 | 否 | 是 |
| 在线逐步更新 | 是 | 否 | 是 |
| 无偏估计 | 是（精确） | 是 | 否（有偏但一致） |

TD 方法从 DP 继承了 bootstrapping 的思想，从 MC 继承了无需模型的采样学习，从而集两家之长。

## 6. 创新点

### 创新点一：确立了一类全新的学习算法家族

在 Sutton 之前，虽然 Samuel (1959) 的跳棋程序和 Witten (1977) 的工作中隐含了时序差分的思想，但没有人将其明确地形式化为一类独立的、有理论基础的算法家族。Sutton 不仅提出了完整的 TD(lambda) 算法族，还给出了统一的数学框架、收敛性分析和实验验证。这是从零散的直觉到系统理论的质的飞跃。TD 方法不是对已有方法的简单改进，而是一种全新的学习范式。

### 创新点二：lambda 参数实现了 TD 与 MC 的连续统一

通过引入 lambda 参数，Sutton 创造了一个优雅的数学框架，使得 TD(0) 和蒙特卡洛方法成为同一算法族的两个端点。这不仅具有理论上的美感，更具有实践上的巨大价值：研究者可以通过调节 lambda 在偏差-方差权衡 (bias-variance tradeoff) 的谱系上自由滑动，为不同的应用场景选择最优的平衡点。这种参数化的统一思想后来被广泛应用于 GAE (Generalized Advantage Estimation) 等现代方法中。

### 创新点三：资格迹机制优雅地解决了信用分配问题

资格迹 (eligibility traces) 是一个精巧的计算机制，它将"最近访问过的状态应该获得更多信用"这一直觉形式化为一个指数衰减的权重函数。当一个正的 TD 误差（好消息）出现时，所有最近访问过的状态都会被上调估值，且越近期的状态被上调得越多。这既解决了信用分配的"在哪里分配"问题，又解决了"分配多少"的问题，并且计算复杂度仅为 O(n)（n 为状态数），极其高效。

### 创新点四：证明了"用猜测更新猜测"在理论上的合法性

Bootstrapping 的概念在直觉上令人不安——用一个不准确的估计去更新另一个估计，怎么能保证收敛到正确答案？Sutton 在这篇论文中为 TD(0) 和 TD(lambda) 提供了收敛性的理论保证（在查表表示、线性函数逼近等条件下），从而为自举学习奠定了理论基础。这一结论深刻地改变了人们对学习算法的认知：学习并不一定需要"ground truth"，利用结构化的中间信号就足够了。

### 创新点五：提出了增量式在线学习的实用框架

与需要存储完整 episode 并在结束后批量更新的蒙特卡洛方法不同，TD 方法可以在每一步观测后立即更新，且只需要常数级的额外存储空间。这使得 TD 方法天然适合在线学习 (online learning)、实时系统和持续性任务，在工程实践上具有巨大优势。

## 7. 结果、实验与验证

### 7.1 随机游走实验 (Random Walk Experiment)

Sutton 设计了一个经典的随机游走实验来验证 TD 方法的有效性。这个实验后来成为强化学习教材中最常被引用的实验之一。

实验设置如下：考虑一个 5 状态的线性马尔科夫链 {A, B, C, D, E}，两端各有一个终止状态。智能体从中间状态 C 出发，每步等概率地向左或向右移动一步。到达最右端获得奖励 1，到达最左端获得奖励 0。每个状态的真实价值可以精确计算为 {1/6, 2/6, 3/6, 4/6, 5/6}。

**关键实验结果一：TD 方法的收敛性。** 实验表明，TD(lambda) 在不同 lambda 值下都能收敛到正确的价值估计，验证了算法的理论正确性。

**关键实验结果二：中间 lambda 值的优越性。** Sutton 系统地比较了不同 lambda 值下的学习性能（以均方根误差衡量），发现在有限数据条件下，中间值的 lambda（如 lambda 约等于 0.3）往往表现最好，既优于 lambda=0（纯 TD，偏差较大），也优于 lambda=1（蒙特卡洛，方差较大）。这一发现为 lambda 参数的实践调优提供了指导。

**关键实验结果三：TD 方法优于传统监督学习。** Sutton 将 TD 方法与 Widrow-Hoff (LMS) 等传统监督学习方法进行对比。在监督学习框架下，中间状态的预测误差只能在 episode 结束后才能计算和反向传播。实验证明，TD 方法利用时序差分信号进行增量更新，在学习速度和样本效率上显著优于传统方法。

### 7.2 理论分析

除了实验验证，Sutton 还提供了严格的理论分析：

- **TD(0) 的收敛性证明**: 在查表表示 (tabular representation) 下，TD(0) 以概率 1 收敛到真实价值函数（前提是学习率满足 Robbins-Monro 条件）。
- **TD(lambda) 的前向视角与后向视角等价性**: Sutton 证明了从前向看（n 步回报的加权平均）和从后向看（资格迹机制）得到的更新量在数学上是等价的，这一结论不仅优美，而且为实现高效的在线算法提供了理论保障。

## 8. 局限性

### 局限性一：函数逼近下的收敛性问题

Sutton 在论文中主要分析了查表表示 (tabular) 情况下的收敛性。然而在实际应用中，状态空间往往是巨大甚至连续的，必须使用函数逼近 (function approximation)。后来的研究（包括 Sutton 自己以及 Tsitsiklis 和 Van Roy 等人的工作）发现，TD 方法在非线性函数逼近（如神经网络）下并不保证收敛，甚至可能发散。这个被称为"致命三角" (deadly triad) 的问题——bootstrapping + 函数逼近 + off-policy 学习——至今仍是强化学习理论中最核心的开放问题之一。

### 局限性二：仅限于预测问题

这篇论文只解决了预测问题（估计价值函数），并未直接涉及控制问题（学习最优策略）。虽然 Sutton 明确指出预测是控制的基础，但从 TD 预测到 TD 控制（如 SARSA、Q-learning）之间还有不小的理论和算法鸿沟。特别是，将 TD 方法用于控制时引入的 off-policy 学习带来了新的稳定性挑战。

### 局限性三：lambda 的选择缺乏系统指导

虽然实验表明中间值的 lambda 通常表现最好，但论文并未给出如何在实际问题中系统选择 lambda 的方法论。最优的 lambda 值高度依赖于具体问题的特性（如状态转移的随机性、奖励的稀疏程度等），至今仍主要依靠经验调参或使用自适应方法。

### 局限性四：对非马尔科夫环境的局限

TD 方法的理论分析建立在马尔科夫假设 (Markov property) 之上，即当前状态包含了预测未来所需的全部信息。在部分可观测 (partially observable) 的环境中，这一假设不成立，TD 方法的性能可能显著退化。论文未深入讨论这种情况下的应对策略。

### 局限性五：计算开销与状态空间规模

在查表表示下，完整的资格迹方法需要为每个状态维护一个迹变量，每步更新的计算复杂度为 O(|S|)（|S| 为状态数）。对于大规模状态空间，这在 1988 年的硬件条件下是一个实际的限制因素。虽然后来的替换迹 (replacing traces) 等变体缓解了这一问题，但在原始论文中这是一个明显的实践局限。

## 9. 历史意义

这篇论文的历史意义怎么强调都不为过。它不仅仅是提出了一个新算法，而是开创了一种全新的思维方式，深刻地重塑了整个强化学习领域的面貌。

**确立了强化学习的三大方法论支柱。** 在 Sutton 之前，求解序列决策问题只有两条路：要么用动态规划（需要模型），要么用蒙特卡洛（需要完整 episode）。TD 方法的出现确立了第三条路，自此强化学习形成了 DP、MC、TD 三足鼎立的方法论格局。这三种方法之间的关系——它们的统一与差异——成为理解整个强化学习领域的概念框架。

**直接催生了 Q-learning 等里程碑算法。** 仅仅一年后，Watkins (1989) 就在 TD 方法的基础上提出了 Q-learning，将 TD 思想从预测扩展到控制，实现了无需模型的最优策略学习。可以说，没有 TD 方法，就没有 Q-learning，也就没有后来 DeepMind 的 DQN 和 AlphaGo 的基础。

**为神经科学提供了理论预言。** TD 误差的概念后来被 Schultz, Dayan 和 Montague (1997) 发现与大脑中多巴胺神经元的放电模式惊人一致。多巴胺信号编码的正是"预期之外的奖励"——这与 TD 误差的定义在数学上完全对应。这一发现被誉为计算神经科学最重要的成果之一，而其理论根源正是 Sutton 的这篇论文。

**建立了"从经验中增量学习"的范式。** TD 方法证明了一个深刻的原理：有效的学习不需要等待最终的"正确答案"，只需要利用"相邻时刻的预测差异"这种更弱但更及时的信号就足够了。这一原理的影响远远超出了强化学习本身，渗透到了在线学习、自适应控制、机器人学等多个领域。

## 10. 今天的视角再看

从 2020 年代的视角回望这篇 1988 年的论文，TD 思想不仅没有过时，反而在深度学习时代焕发出了更强大的生命力。

**DQN (Deep Q-Network, 2013/2015)。** DeepMind 的 DQN 本质上就是 TD(0) + 深度神经网络函数逼近。DQN 的核心更新规则 `Q(s,a) <- Q(s,a) + alpha * [r + gamma * max_a' Q(s',a') - Q(s,a)]` 直接继承了 TD 误差的思想。DQN 在 Atari 游戏上超越人类水平的表现，是 TD 方法在深度学习时代最引人注目的成功案例。可以说，DQN 的全部理论根基都可以追溯到 Sutton 1988 年的这篇论文。

**Actor-Critic 方法。** 现代 Actor-Critic 架构（如 A2C、A3C、PPO、SAC 等）中的 Critic 网络本质上就是一个 TD 学习器。Critic 使用 TD 误差来评估 Actor 的策略质量，为 Actor 提供梯度信号。TD 误差在这里扮演了"优势信号" (advantage signal) 的角色，指导策略朝着更好的方向更新。

**GAE (Generalized Advantage Estimation, 2015)。** Schulman 等人提出的 GAE 直接继承了 TD(lambda) 中资格迹的思想。GAE 使用参数 lambda 在偏差和方差之间取得权衡，其数学形式：`A^{GAE} = sum_{l=0}^{infty} (gamma * lambda)^l * delta_{t+l}` 与 TD(lambda) 的资格迹公式本质上是同一个东西。GAE 是当前最主流的策略梯度方法 PPO 的核心组件。

**AlphaGo 和 AlphaZero。** AlphaGo 的价值网络训练过程中使用了 TD 学习来从自我对弈的结果中学习状态评估。AlphaZero 更是将蒙特卡洛树搜索 (MCTS) 与 TD 学习结合，实现了从零开始学习围棋、象棋和将棋的超人水平。

**大语言模型的 RLHF。** 近年来将大语言模型与人类偏好对齐的 RLHF (Reinforcement Learning from Human Feedback) 技术中，PPO 算法的 Critic 部分同样依赖 TD 学习来估计价值函数。可以说，从 ChatGPT 到 Claude，每一个经过 RLHF 训练的大语言模型背后，都隐含着 Sutton 在 1988 年提出的 TD 思想。

**TD 思想的持久生命力表明**，Sutton 在这篇论文中抓住的不是某个特定问题的特定解法，而是序列学习中的一个基本原理：利用时间结构中的差分信号来驱动学习。这个原理在任何涉及时序预测和决策的问题中都具有根本性的适用价值。

## 11. 通俗科普版解释

**通勤时间预估的比喻。**

想象你每天开车上班，路上要经过几个标志性地点：家门口 -> 加油站 -> 学校 -> 商场 -> 公司。你想学会准确预测"从当前位置到公司还需要多少分钟"。

**蒙特卡洛方法就像一个"事后总结型"学习者。** 它的做法是：每天到公司后，回忆整趟旅程，用实际花费的时间来更新每个地点的预测。比如今天从加油站到公司花了 35 分钟，就把"加油站的预测"往 35 分钟方向调整。问题是，你得等到每天到公司后才能学习，中途无法更新——如果路上交通有变化，你无法实时响应。

**TD 方法就像一个"随时修正型"学习者。** 当你到达加油站时，你预测"还要 40 分钟"。当你到达学校时，你发现"还要 25 分钟"。但你之前预测从加油站到学校要 20 分钟，实际只用了 15 分钟。TD 方法会立即在加油站这个位置学到："嗯，从这里出发比我想的要快，因为接下来的路段通畅了。"它不需要等到你到达公司，而是用"到达学校时的最新预测"来修正"在加油站时的旧预测"。

**lambda 参数就像你的"回忆窗口"。** lambda=0 意味着你只看最近一个路段的信息来更新；lambda=1 意味着你等到终点后用全程信息来更新；中间的 lambda 值意味着你兼顾近期路况和远期实际经验，在两者之间取得平衡。

**TD 误差就像"惊喜程度"。** 如果你预测某段路要 20 分钟，实际只用了 10 分钟，这个 10 分钟的差距就是 TD 误差。正的 TD 误差代表"好消息"（比预期快），负的代表"坏消息"（比预期慢）。你的大脑用这些"惊喜"来不断修正对各路段的预估。有趣的是，这恰好就是人脑中多巴胺信号的工作原理：多巴胺编码的正是"预期之外的奖励"。

**Bootstrapping 就像"借力打力"。** 你从未真正知道从加油站到公司"精确"要多少分钟（因为每天都不同），但你可以用"从学校到公司的估计"加上"加油站到学校的实际时间"来得到一个更好的估计。虽然"从学校到公司"本身也是一个估计（不是精确值），但它比"从加油站到公司的旧估计"更准确——因为它离终点更近，包含了更多实际信息。用一个更好的猜测来修正一个更差的猜测，这就是 bootstrapping 的精髓。

## 12. 可引用摘要

**1.** Sutton 的 TD(lambda) 方法开创了强化学习的第三条道路——它既不需要动态规划所要求的完整环境模型，也不需要蒙特卡洛方法所要求的完整 episode 回报，而是通过比较相邻时刻的预测差异来增量式地学习，填补了两大经典方法之间的理论与实践空白。

**2.** TD 误差 `delta_t = r_{t+1} + gamma * V(s_{t+1}) - V(s_t)` 不仅是一个优雅的数学构造，更被神经科学证实与大脑多巴胺系统的放电模式高度吻合，成为连接计算理论与生物智能的罕见桥梁。

**3.** lambda 参数将 TD(0) 和蒙特卡洛方法统一为同一算法族的两个端点，创造了一个可以在偏差-方差谱系上连续滑动的参数化框架，这一设计思想在 30 多年后的 GAE 等现代方法中依然是核心组件。

**4.** 从 DQN 击败 Atari 到 AlphaGo 征服围棋，从 Actor-Critic 架构到 RLHF 对齐大语言模型，几乎所有现代深度强化学习的突破都可以追溯到 Sutton 1988 年提出的 TD 学习思想——"用猜测更新猜测"这一看似简单的原理，最终被证明是智能系统从经验中学习的基本机制之一。

**5.** 这篇论文的持久影响力证明了一个深刻的方法论启示：真正革命性的贡献往往不是解决某个特定问题，而是发现一个基本原理——序列预测中，"时间差分"本身就蕴含着足以驱动学习的信号，无需等待最终的真相揭晓。
