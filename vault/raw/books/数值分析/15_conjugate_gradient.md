# 共轭梯度法：从被遗忘到被重新发现的线性方程组求解革命

## 1. 标题

**Methods of Conjugate Gradients for Solving Linear Systems**（求解线性方程组的共轭梯度法）

这篇论文由赫斯坦尼斯和施蒂费尔于 1952 年发表，提出了一种求解对称正定线性方程组的迭代方法，被誉为"二十世纪数值分析中最优美的算法之一"。该方法经历了从诞生到被忽视、再到被重新发现并大放异彩的曲折历程，至今仍是大规模科学计算中最核心的算法之一。

## 2. 作者/作者群

**马格努斯·赫斯坦尼斯**（Magnus Rudolph Hestenes, 1906--1991）与**爱德华·施蒂费尔**（Eduard Stiefel, 1909--1978）。

赫斯坦尼斯是美国数学家，长期在加州大学洛杉矶分校（UCLA）任教。他的研究兴趣横跨变分法（calculus of variations）、最优控制和数值分析。在 1950 年代初，他在美国国家标准局（National Bureau of Standards, NBS，即现在的 NIST）的计算实验室工作期间，独立地发展了共轭梯度法的思想。赫斯坦尼斯也因后来与施蒂费尔一起提出的赫斯坦尼斯-施蒂费尔公式（Hestenes-Stiefel formula）而闻名于优化理论界。

施蒂费尔是瑞士数学家，苏黎世联邦理工学院（ETH Zurich）教授。他在代数拓扑学（algebraic topology）方面有重要贡献——施蒂费尔-惠特尼类（Stiefel-Whitney classes）就以他的名字命名。在 1950 年代初期，施蒂费尔对数值方法产生了浓厚的兴趣，特别是在 ETH 的新计算中心（Zurich 的 Z4 计算机是欧洲最早的电子计算机之一）开展数值计算研究期间。

两人独立地发展了共轭梯度法的核心思想，后在交流中发现了工作的相似性，决定合著发表。这是数学史上多次出现的"独立发现"现象的又一典型案例。

值得一提的是，康尼利厄斯·朗佐斯（Cornelius Lanczos, 1893--1974）几乎在同一时期独立提出了密切相关的 Lanczos 算法，该算法与共轭梯度法有深刻的数学联系。

## 3. 发表时间

1952 年。论文发表于《美国国家标准局研究杂志》（Journal of Research of the National Bureau of Standards），第 49 卷第 6 期，第 409--436 页。

## 4. 发表载体/文献背景

《Journal of Research of the National Bureau of Standards》是美国国家标准局出版的学术期刊，在当时是一份重要的科学出版物，涵盖物理学、化学、工程学和数学等多个学科。

1950 年代初是计算科学发展的早期阶段。电子计算机刚刚问世不久（UNIVAC I 于 1951 年成为首台商用计算机），计算机的内存极为有限（通常只有几千字），运算速度按今天标准极慢。在这一背景下，数值方法的设计面临着严峻的存储和速度约束。

线性方程组 Ax = b 的求解是当时最重要的计算任务之一。直接方法（如高斯消元法）需要存储整个 n x n 矩阵，并需要 O(n^3) 次运算。对于大规模稀疏系统（sparse systems），这既浪费存储空间（因为大部分矩阵元素为零），又浪费计算时间。人们迫切需要一种能够利用矩阵稀疏性、节省存储空间和计算时间的新方法。

共轭梯度法正是在这一需求驱动下诞生的。它只需要存储少量向量（而非整个矩阵），每次迭代只需要一次矩阵-向量乘法（matrix-vector product），这对稀疏矩阵来说是非常高效的操作。

## 5. 一句话总结

共轭梯度法通过构造一组关于矩阵 A 共轭（A-conjugate）的搜索方向，在对称正定线性方程组的解空间中进行高效搜索，理论上在至多 n 步内精确求解 n 维方程组（作为直接方法），但在实践中通常远在 n 步之前就给出了足够精确的近似解（作为迭代方法），尤其是当矩阵的特征值聚集时。

## 6. 历史背景

### 6.1 线性方程组求解的核心地位

线性方程组的求解是科学计算中最基本、最普遍的任务。从结构工程（有限元分析）到电路设计（节点分析），从流体力学（离散化方程）到统计学（最小二乘问题），几乎所有数值计算最终都归结为求解一个或多个线性方程组。

在 1950 年代，随着工程和科学问题规模的增大，人们需要求解的线性方程组的阶数（方程个数和未知数个数）也在迅速增长。对于小规模问题（n < 100），高斯消元法已经足够高效。但对于来自偏微分方程离散化的大规模稀疏系统（n 可达数千甚至更多），高斯消元法的 O(n^3) 复杂度和 O(n^2) 存储需求变得不可接受。

### 6.2 经典迭代方法的局限

在共轭梯度法出现之前，求解大规模线性方程组的主要迭代方法是：

- **雅可比迭代法**（Jacobi iteration, 1845）：简单但收敛速度慢
- **高斯-赛德尔迭代法**（Gauss-Seidel iteration）：比雅可比法稍快但仍然较慢
- **逐次超松弛法**（Successive Over-Relaxation, SOR）：杨（David Young）于 1950 年提出，通过引入松弛因子加速收敛

这些经典迭代方法的一个共同特点是：它们的收敛速度强烈依赖于矩阵的谱性质（spectral properties），特别是条件数。对于条件数大的矩阵，这些方法的收敛速度非常缓慢。此外，SOR 方法中最优松弛参数的选择需要了解矩阵的谱半径，这本身就是一个困难的计算问题。

### 6.3 最优化与线性代数的交叉

共轭梯度法的一个重要思想来源是最优化理论（optimization theory）中的梯度下降法（gradient descent）。对于对称正定矩阵 A，求解 Ax = b 等价于最小化二次函数 f(x) = (1/2) x^T A x - b^T x。梯度下降法沿着函数的负梯度方向逐步下降，最终到达最小值点。

然而，纯梯度下降法的收敛速度在实践中通常很慢，因为连续的梯度方向之间存在"锯齿形"振荡（zigzagging）。赫斯坦尼斯和施蒂费尔的关键洞察是：通过选择关于矩阵 A 共轭的搜索方向（而非简单的梯度方向），可以消除这种振荡，大幅加速收敛。

### 6.4 朗佐斯算法的平行发展

几乎与赫斯坦尼斯和施蒂费尔同时，朗佐斯在 1950 年提出了用于特征值计算的 Lanczos 算法。后来人们认识到，共轭梯度法和 Lanczos 算法在数学上有着深刻的联系——两者本质上是同一种 Krylov 子空间方法的不同表现形式。朗佐斯 1952 年的论文"Solution of Systems of Linear Equations by Minimized Iterations"也阐述了类似的迭代求解思想。

## 7. 核心问题定义

### 7.1 基本问题

给定一个 n x n 的对称正定矩阵（symmetric positive definite matrix, SPD matrix）A 和一个 n 维向量 b，求解线性方程组：

```
Ax = b
```

要求：
- 算法的存储需求远小于 O(n^2)（即不需要存储整个矩阵）
- 算法能利用矩阵 A 的稀疏性（每次迭代只需要计算 Ax 的能力）
- 算法的收敛速度远快于经典迭代方法

### 7.2 等价的最优化问题

上述线性方程组的求解等价于以下二次优化问题：

```
最小化 f(x) = (1/2) x^T A x - b^T x
```

由于 A 是对称正定的，f(x) 是一个严格凸函数（strictly convex function），有唯一的最小值点 x* = A^{-1} b，它恰好就是线性方程组 Ax = b 的解。

### 7.3 关键挑战

设计一种迭代方法，在每次迭代中：
- 只需要执行一次矩阵-向量乘法 Ap（而不需要显式访问 A 的元素）
- 存储仅需几个 n 维向量（与 n^2 的存储相比是巨大的节省）
- 在理论上保证有限步内精确收敛
- 在实践中对于良态矩阵能够快速收敛

## 8. 主要结论/方法/定理

### 8.1 共轭梯度算法

共轭梯度法的完整算法可以用以下紧凑形式描述：

```
给定初始猜测 x_0，计算 r_0 = b - A x_0，令 p_0 = r_0

对 k = 0, 1, 2, ..., n-1：
    alpha_k = (r_k^T r_k) / (p_k^T A p_k)           # 步长
    x_{k+1} = x_k + alpha_k p_k                       # 更新解
    r_{k+1} = r_k - alpha_k A p_k                     # 更新残差
    如果 ||r_{k+1}|| 足够小，停止
    beta_k = (r_{k+1}^T r_{k+1}) / (r_k^T r_k)       # 共轭系数
    p_{k+1} = r_{k+1} + beta_k p_k                    # 更新搜索方向
```

这个算法每次迭代只需要一次矩阵-向量乘法（Ap_k），两次内积（r_k^T r_k 和 p_k^T A p_k），以及若干次向量加法和标量乘法。存储需求仅为四个 n 维向量（x, r, p, 和 Ap）。

### 8.2 A-共轭性

算法的核心性质是搜索方向 {p_0, p_1, ..., p_{n-1}} 是关于矩阵 A 共轭的（A-conjugate），即：

```
p_i^T A p_j = 0，当 i 不等于 j
```

这意味着不同方向上的搜索是"互不干扰"的——沿一个方向的最优化不会破坏沿其他方向已经取得的进展。这就是共轭梯度法能够消除梯度下降法中锯齿振荡的根本原因。

### 8.3 有限终止性（作为直接方法）

**定理**：在精确算术（exact arithmetic）下，共轭梯度法至多在 n 步后给出精确解。

这是因为 n 个 A-共轭方向构成 R^n 的一组基（在精确算术下），因此 n 步搜索覆盖了整个解空间。

然而，在有限精度浮点算术下，A-共轭性会被舍入误差逐渐破坏，导致有限终止性失效。这是共轭梯度法早期被视为不太可靠的原因之一。

### 8.4 早期收敛性（作为迭代方法）

共轭梯度法的真正威力在于它作为迭代方法的早期收敛特性：

**定理**：在第 k 步迭代后，共轭梯度法的误差满足：

```
||x_k - x*||_A <= 2 * [(sqrt(kappa) - 1) / (sqrt(kappa) + 1)]^k * ||x_0 - x*||_A
```

其中 kappa = kappa(A) = lambda_max / lambda_min 是矩阵 A 的条件数，||v||_A = sqrt(v^T A v) 是 A-范数。

这个界表明收敛速率主要取决于条件数的平方根。与经典迭代方法（收敛速率取决于条件数本身）相比，共轭梯度法获得了平方根级别的加速。

更重要的是，上述界仅仅是最坏情况估计。在实践中，如果矩阵 A 的特征值聚集（clustered eigenvalues），共轭梯度法的收敛速度会比理论界预测的快得多。直觉上，共轭梯度法在 k 步内实际上消除了 k 个不同特征值方向上的误差分量。如果只有少数几个不同的（或接近的）特征值组，则只需要少数几步就能达到高精度。

### 8.5 Krylov 子空间最优性

共轭梯度法在 Krylov 子空间中具有最优性：

**定理**：在第 k 步，x_k 是所有 Krylov 子空间 K_k(A, r_0) = span{r_0, Ar_0, A^2 r_0, ..., A^{k-1} r_0} 中元素的 A-范数最优近似。

这意味着共轭梯度法在每一步都给出了"最好可能"的近似解——在给定的信息（通过矩阵-向量乘法获得的 k 个向量）的约束下，不可能找到更好的近似。

### 8.6 残差的正交性

共轭梯度法还具有一个优美的性质：不同迭代步的残差向量是正交的：

```
r_i^T r_j = 0，当 i 不等于 j
```

这个性质与搜索方向的 A-共轭性一起，赋予了共轭梯度法强大的理论结构。

## 9. 核心思想的直觉解释

### 9.1 梯度下降的困境

考虑在一个椭圆形的山谷中寻找最低点。梯度下降法总是沿着当前位置最陡下降的方向走。问题在于：如果山谷很狭长（对应于条件数大的矩阵），最陡下降方向会不断地来回穿越山谷，形成锯齿形路径，而不是直接朝着最低点走。就像一个人在一条狭窄的峡谷中行走，每次都走向最陡的方向，结果就是不断地从一侧墙壁走向另一侧墙壁，缓慢地蛇行前进。

### 9.2 共轭方向的智慧

共轭梯度法的解决方案是：不要总是走最陡的方向，而是走一个经过"修正"的方向，使得每一步的搜索不会破坏前几步已经取得的进展。

用更直观的方式来说：想象你在一个高维的房间里找一个隐藏的目标点。梯度下降法就像一个不断改变方向的人，每次都朝"看起来最好"的方向走，但经常走回头路。共轭梯度法则像一个系统的搜索者——他先确定一个方向，在这个方向上走到最优位置，然后选择一个"不会干扰第一个方向上已取得进展"的新方向继续搜索。n 步之后（在 n 维空间中），他已经检查了所有可能的方向，因此必定找到了目标。

### 9.3 "不会干扰"的数学含义

"不会干扰"的精确数学含义就是 A-共轭性。两个方向 p_i 和 p_j 是 A-共轭的意味着：沿 p_j 方向的最优化不会改变沿 p_i 方向已经达到的最优值。这就像在两个正交坐标轴上独立地最小化——只不过"正交"的概念从标准的欧几里得正交推广为关于矩阵 A 定义的正交（A-正交）。

### 9.4 特征值聚集与快速收敛

为什么当特征值聚集时共轭梯度法收敛特别快？因为共轭梯度法在 k 步内本质上"解决"了 k 个不同的特征值方向。如果矩阵有 n 个特征值但只有 m << n 个不同的聚集组，那么大约 m 步就足以获得高精度解——远少于理论上限 n 步。

这就像在一个有 1000 间房间但只有 5 种不同颜色的酒店中找一间特定的房间。你不需要检查所有 1000 间房间；只需要确定每种颜色中哪一间是目标，这只需要大约 5 步。

## 10. 为什么这篇文献重要

### 10.1 开创了 Krylov 子空间方法家族

共轭梯度法是 Krylov 子空间方法（Krylov subspace methods）的第一个也是最重要的代表。这个方法家族后来扩展到包括：

- **GMRES**（Generalized Minimal Residual, 1986）：用于非对称线性方程组
- **BiCGSTAB**（Bi-Conjugate Gradient Stabilized, 1992）：另一种非对称求解器
- **Lanczos 算法**：用于对称矩阵的特征值计算
- **Arnoldi 算法**：用于非对称矩阵的特征值计算
- **MINRES**（Minimal Residual）：用于对称不定系统

所有这些方法都继承了共轭梯度法的核心思想：通过矩阵-向量乘法生成 Krylov 子空间，然后在这个子空间中寻找最优近似。

### 10.2 使大规模稀疏系统的高效求解成为可能

共轭梯度法使得求解大规模稀疏对称正定线性方程组变得实际可行。由于每次迭代只需要一次矩阵-向量乘法和少量的向量操作，对于稀疏矩阵来说，每次迭代的成本仅为 O(nnz)（其中 nnz 是非零元素数），远低于直接方法的 O(n^3)。加上预处理技术的配合，共轭梯度法已经成为求解来自有限元、有限差分和有限体积离散化的大规模线性方程组的标准工具。

### 10.3 连接了线性代数、最优化和逼近论

共轭梯度法处于三个数学分支的交汇处：

- **线性代数**：它求解 Ax = b
- **最优化理论**：它最小化二次函数
- **逼近论**：它在 Krylov 子空间中构造最佳多项式逼近

这种多重身份使得共轭梯度法成为数学中最具交叉学科性质的算法之一。

### 10.4 算法设计的美学典范

共轭梯度法被广泛认为是算法设计中美学和效率完美结合的典范。整个算法只有不到十行伪代码，却蕴含了深刻的数学结构——A-共轭性、残差正交性、Krylov 子空间最优性——这些性质的完美协调使得算法既简洁又高效。

## 11. 它解决了当时什么瓶颈

### 11.1 存储瓶颈

1950 年代的计算机内存极为有限。求解一个 1000 阶的线性方程组，高斯消元法需要存储一百万个矩阵元素——这在当时的计算机上是完全不可能的。共轭梯度法只需要存储几个 1000 维的向量和矩阵的稀疏表示，使得大规模问题的求解成为可能。

### 11.2 计算时间瓶颈

高斯消元法对 n 阶矩阵需要 O(n^3) 次运算。对于 n = 10000，这意味着 10^{12} 次浮点运算——即使在现代计算机上也需要相当的时间。共轭梯度法（配合预处理）通常只需要 O(n * sqrt(kappa)) 次迭代，每次迭代 O(nnz) 次运算。对于来自 PDE 离散化的稀疏矩阵，总运算量可以低至 O(n^{1.5}) 甚至 O(n log n)。

### 11.3 矩阵结构利用的瓶颈

经典迭代方法（雅可比、高斯-赛德尔）虽然也能利用稀疏性，但收敛速度太慢。SOR 方法需要知道最优松弛参数，而参数的确定本身就是一个难题。共轭梯度法不需要任何手动参数调节——它自动适应矩阵的结构，利用矩阵的谱信息加速收敛。

## 12. 它与前人工作的关系

### 12.1 与最速下降法的关系

共轭梯度法可以被看作最速下降法（steepest descent method）的"改良版"。最速下降法每步选择负梯度方向 -r_k 作为搜索方向。共轭梯度法将搜索方向从 -r_k 修正为 p_k = r_k + beta_k p_{k-1}，使得连续的搜索方向关于 A 共轭。这个简单的修正带来了收敛速度的质的飞跃。

### 12.2 与 Lanczos 算法（1950）的关系

朗佐斯在 1950 年提出的 Lanczos 算法与共轭梯度法有着深刻的数学联系。两者都基于 Krylov 子空间，都生成一组正交（或共轭）向量。Lanczos 算法的目标是计算矩阵的特征值，共轭梯度法的目标是求解线性方程组，但两者的数学核心是相同的。

具体来说，共轭梯度法产生的三项递推关系与 Lanczos 算法产生的三对角矩阵之间存在精确的对应关系。这种联系在 1970 年代被完全阐明，成为理解两种算法的关键。

### 12.3 与经典迭代法的对比

| 方法 | 每步成本 | 收敛速率 | 参数选择 | 适用范围 |
|------|---------|---------|---------|---------|
| 雅可比 | O(nnz) | ~ 1 - O(h^2) | 无 | 对角占优 |
| 高斯-赛德尔 | O(nnz) | ~ 1 - O(h^2) | 无 | 对角占优/SPD |
| SOR | O(nnz) | ~ 1 - O(h) | 需要 omega_opt | SPD，需知谱半径 |
| CG | O(nnz) | ~ 1 - 2/sqrt(kappa) | 无 | SPD |

表中 h 是 PDE 离散化步长，kappa 是条件数。可以看到，CG 的收敛速率远优于经典方法，且不需要手动参数调节。

### 12.4 与切比雪夫迭代的关系

共轭梯度法与切比雪夫迭代（Chebyshev iteration）之间也存在密切联系。切比雪夫迭代利用切比雪夫多项式（Chebyshev polynomials）的最优逼近性质来加速迭代，但需要预先知道矩阵特征值的范围。共轭梯度法可以被解释为一种"自适应的切比雪夫迭代"——它自动适应矩阵的谱分布，无需预先知道特征值信息。

## 13. 它对后续哪些方向产生了影响

### 13.1 预处理共轭梯度法（PCG）

共轭梯度法的一个重大发展是预处理技术（preconditioning）的引入。基本思想是：将原方程组 Ax = b 变换为 M^{-1}Ax = M^{-1}b，其中预处理矩阵 M 满足 M^{-1}A 的条件数远小于 A 的条件数。

预处理共轭梯度法（Preconditioned Conjugate Gradient, PCG）是实际计算中使用最广泛的线性方程组求解器之一。常用的预处理策略包括：

- **不完全 Cholesky 分解**（Incomplete Cholesky, IC）
- **不完全 LU 分解**（Incomplete LU, ILU）
- **代数多重网格**（Algebraic Multigrid, AMG）
- **领域分解**（Domain Decomposition）

预处理技术的发展是 1970 年代至今数值线性代数中最活跃的研究方向之一。

### 13.2 非线性共轭梯度法

赫斯坦尼斯和施蒂费尔的线性共轭梯度法后来被弗莱彻（R. Fletcher）和里夫斯（C.M. Reeves）于 1964 年推广到非线性优化问题。非线性共轭梯度法（Nonlinear Conjugate Gradient, NCG）成为无约束优化中最重要的方法之一，广泛应用于机器学习、计算化学和图像处理等领域。

### 13.3 Krylov 子空间方法家族的扩展

共轭梯度法催生了整个 Krylov 子空间方法家族，包括用于非对称系统的方法：

- **BiCG**（Bi-Conjugate Gradient, Fletcher 1976）
- **CGS**（Conjugate Gradient Squared, Sonneveld 1989）
- **BiCGSTAB**（van der Vorst 1992）
- **GMRES**（Saad and Schultz 1986）
- **QMR**（Quasi-Minimal Residual, Freund and Nachtigal 1991）

这些方法在现代科学计算中无处不在。

### 13.4 有限元方法的大规模求解

共轭梯度法（尤其是预处理版本）成为有限元方法（Finite Element Method, FEM）中标准的线性方程组求解器。有限元离散化产生的矩阵通常是大规模、稀疏、对称正定的——正是共轭梯度法最擅长处理的类型。从结构力学到电磁场模拟，从热传导到地震波传播，有限元分析的成功在很大程度上依赖于共轭梯度法的高效性。

### 13.5 机器学习与深度学习

在现代机器学习中，共轭梯度法的思想以多种形式出现：

- **训练大规模线性模型**：线性回归、支持向量机等问题最终归结为求解线性方程组或二次优化问题
- **自然梯度法**（Natural Gradient）：使用共轭梯度法求解Fisher信息矩阵相关的线性方程组
- **Hessian-Free 优化**：使用共轭梯度法在神经网络训练中近似求解牛顿方程

### 13.6 1970--80 年代的复兴

共轭梯度法经历了一段从被忽视到被重新发现的曲折历程。在 1952 年发表后，由于舍入误差会破坏有限终止性，且当时的计算机规模较小（直接方法仍然可行），共轭梯度法一度被视为一种"有缺陷的直接方法"而受到冷落。

1970 年代至 1980 年代，随着以下几个因素的变化，共轭梯度法获得了复兴：
1. **问题规模的急剧增长**使得直接方法变得不可行
2. **预处理技术的发展**大幅提高了实际收敛速度
3. **人们对其作为迭代方法的重新认识**——有限终止性不重要，重要的是早期收敛

Reid（1971）的综述论文和 Golub 与 O'Leary（1989）的历史回顾对共轭梯度法的复兴起到了重要推动作用。

## 14. 今天回看它的价值

### 14.1 大规模计算的基石

在今天的高性能计算中，共轭梯度法（及其预处理变体）是求解对称正定线性方程组的事实标准。从气候模拟到石油勘探，从汽车碰撞仿真到量子化学计算，PCG 都是不可或缺的核心算法。

### 14.2 算法简洁性的持久价值

共轭梯度法的算法描述仅需不到十行伪代码，但其性能在很多情况下优于更复杂的方法。这种简洁性使其易于实现、调试和并行化，这些实际优势在现代计算环境中尤为重要。

### 14.3 理论与实践的完美结合

共轭梯度法是一个罕见的例子，其中优美的数学理论直接转化为高效的实际算法。A-共轭性、Krylov 子空间最优性等理论性质不仅具有数学上的美感，还直接解释了算法的实际性能。

### 14.4 并行计算的适应性

共轭梯度法的基本操作——矩阵-向量乘法、向量内积、向量加法——都很容易并行化。这使得它非常适合现代的并行计算架构（多核处理器、GPU、分布式集群），进一步增强了其在大规模计算中的实用价值。

### 14.5 教育价值

共轭梯度法是数值分析和科学计算课程中最重要的教学内容之一。它完美地展示了如何将抽象数学（内积空间、正交性、多项式逼近）转化为实用算法，是培养学生"计算思维"的理想教材。

## 15. 面向普通读者的通俗解释

### 15.1 找最低点的挑战

想象你被蒙住了眼睛，站在一座碗形山谷中，需要找到最低点。你唯一能做的是感受脚下的坡度——知道"向哪个方向走是下坡"。

最简单的策略是：每次沿着最陡下坡的方向走一步。这就是"梯度下降法"。它听起来很合理，但有一个问题：如果山谷是狭长的椭圆形（像一条峡谷），你会不断地从一侧走到另一侧，走出一条锯齿形的路线，非常缓慢地才能到达最低点。

### 15.2 共轭梯度法的聪明策略

共轭梯度法采用了一种更聪明的策略：每走一步后，下一步的方向不仅考虑当前的坡度，还考虑之前走过的方向，确保新的一步不会"撤销"之前已经取得的进展。

更具体地说：如果你在第一步中已经在"东-西"方向上找到了最优位置，那么第二步应该沿着一个"不会改变东-西方向上位置"的方向走。这样，每一步的进展都是"永久性"的——不会被后续步骤所破坏。

在 n 维空间中（n 个独立方向），至多走 n 步就一定能找到最低点。而且，如果山谷的形状比较"规则"（数学上的表达是"特征值聚集"），可能远少于 n 步就能找到。

### 15.3 为什么这很重要？

在现实世界中，科学家和工程师经常需要求解包含数百万个未知数的方程组。这些方程组描述了天气系统如何演变、桥梁在荷载下如何弯曲、地下石油如何流动等问题。

共轭梯度法使得高效求解这些巨型方程组成为可能。没有它（以及它的后续发展），今天的天气预报、工程设计、石油勘探和许多其他依赖大规模计算的活动都将无法实现。

### 15.4 一段曲折的历史

有趣的是，共轭梯度法在 1952 年发表后，曾经被忽视了将近二十年。当时的人们把它看作一种"有缺陷的精确方法"——因为在实际计算中，由于浮点运算的近似性，它无法在恰好 n 步内给出精确解。

直到 1970 年代，人们才重新认识到它的价值——不是作为一种精确方法，而是作为一种迭代方法。即使不能在 n 步内给出精确解，它通常在远少于 n 步时就给出了足够好的近似解。这种认识的转变使得共轭梯度法焕发了新生，成为科学计算中最重要的算法之一。

## 17. 局限性/历史局限

### 17.1 仅适用于对称正定矩阵

共轭梯度法在其原始形式中仅适用于对称正定（SPD）矩阵。对于非对称矩阵或不定矩阵，不能直接使用。这一局限导致了后续大量推广方法的开发（BiCG、GMRES 等）。

### 17.2 舍入误差对有限终止性的影响

在有限精度浮点算术中，A-共轭性和残差正交性会逐渐丧失，导致有限终止性失效。在最坏情况下，算法可能需要远超过 n 步才能收敛。这个问题在 1950--60 年代导致共轭梯度法被冷落。

后来人们认识到，尽管精确的有限终止性失效了，但通过适当的实现技术（如偶尔的重正交化）和预处理，实际收敛速度仍然令人满意。

### 17.3 对预处理的依赖

裸的共轭梯度法（without preconditioning）对于条件数很大的矩阵收敛缓慢。在实际应用中，预处理几乎是必不可少的。然而，选择合适的预处理策略本身就是一个困难的问题——没有普适的最优预处理。

### 17.4 论文的时代局限

赫斯坦尼斯和施蒂费尔最初将共轭梯度法视为一种直接方法（有限步精确求解），而不是迭代方法（近似求解）。这种定位在一定程度上限制了他们对算法实际价值的认识。直到 1970 年代，人们才充分认识到共轭梯度法作为迭代方法的巨大潜力。

### 17.5 收敛理论的局限

基于条件数的经典收敛界在很多情况下过于悲观。实际收敛速度取决于矩阵特征值的完整分布（而不仅仅是条件数），但精确的收敛分析在一般情况下非常困难。
