# 示例项目解析（examples/）

## 文档来源与路径

| 类型 | 路径 |
|------|------|
| 示例索引 | `examples/README.md` |
| 各示例子目录 | `examples/*/`（各自 `README.md`、`pyproject.toml`、`uv.lock`） |

---

## 概述

`examples/` 收集基于 Deep Agents **可运行的应用形态**：从 **深度检索**、**内容生产** 到 **异步子智能体服务**、**GPU 场景** 等。每个示例 **独立依赖锁文件**，便于复制到自己的环境；共同点是以 **`create_deep_agent()`** 为核心入口，并按领域挂载 **自定义 tools**、**system prompt**、**skills / 子智能体** 或 **自定义 backend**。

官方索引另含 **`text-to-sql-agent`**（自然语言转 SQL）；本书表侧重下列与用户指定清单一致的项目，并在文末简要对照索引中的其他示例。

---

## 各示例概要

### 1. `deep_research/` — 深度研究智能体

| 项 | 说明 |
|----|------|
| 包布局 | `research_agent/` 子包（工具、提示常量等） |
| 入口 | 根目录 `agent.py` 与 `research_agent/` 内模块协同 |
| 能力 | **网络检索**（如 Tavily）、**并行子智能体**、**反思/策略** 等多步研究流程 |
| 模式 | `create_deep_agent` + **自定义 tools** + 领域 prompts（见 `research_agent/prompts.py` 等） |

### 2. `content-builder-agent/` — 内容构建智能体

| 项 | 说明 |
|----|------|
| 文档 | 自带 **`AGENTS.md`**，约定该项目内的 AI/人协作说明 |
| 能力 | 博客、LinkedIn、推文等内容形态，结合 **memory、skills、subagents**（见 `subagents.yaml`、`skills/`） |
| 模式 | 展示 **长内容工作流** 与 **多技能组合** |

### 3. `async-subagent-server/` — 异步子智能体服务

| 项 | 说明 |
|----|------|
| 关键文件 | `server.py`、`supervisor.py`；**`test_server.py`** 用于测试服务端行为 |
| 能力 | **远程异步子智能体** 模式：服务端托管 agent，客户端异步交互 |
| 模式 | 与「本地单进程 CLI」相对，强调 **网络边界上的 agent hosting** |

### 4. `nvidia_deep_agent/` — GPU 加速场景

| 项 | 说明 |
|----|------|
| 源码 | `src/agent.py`、`src/backend.py`、`src/prompts.py`、`src/tools.py` |
| 文档 | **`src/AGENTS.md`** 提供 NVIDIA/GPU 相关项目内指引 |
| 能力 | 与 **GPU 计算栈** 结合的 deep agent（如 RAPIDS/cuML 等技能说明见 `skills/`） |
| 模式 | **自定义 backend + tools + prompts** 三位一体，贴近企业 GPU 流水线 |

### 5. `downloading_agents/` —「下载即用」智能体

| 项 | 说明 |
|----|------|
| 能力 | 强调智能体即 **文件夹/压缩包**：下载、解压、配置后即可运行 |
| 模式 | 教学意义：**分发与安装体验**，而非单一算法技巧 |

### 6. `ralph_mode/` — Ralph 模式

| 项 | 说明 |
|----|------|
| 入口 | `ralph_mode.py` |
| 能力 | **自主循环**：每轮 **全新上下文**，依赖 **文件系统持久化** 状态与产出 |
| 模式 | 与「单会话长上下文」对照，突出 **迭代 + 外存** 的代理范式 |

## 跨示例的共性模式

1. **独立工程**：各自 **`pyproject.toml` + `uv.lock`**，版本范围常 **pin 到 deepagents 小版本区间**（见 README 贡献指南）。
2. **核心构造**：**`create_deep_agent()`** 统一创建图/智能体。
3. **扩展点**：
   - **`tools=`**：领域 API、检索、文件、SQL 等。
   - **系统提示 / prompts**：把角色、输出格式、安全约束写死到提示层。
   - **Skills / Subagents**（部分示例）：用文件系统约定（`SKILL.md`、`subagents.yaml`）组织复杂能力。
   - **自定义 backend**（如 NVIDIA 示例）：对接特殊运行环境或数据面。

---

## 设计取舍（架构视角）

- **示例之间不共享一个巨型依赖**：每个示例锁自己的 `uv.lock`，避免「跑通 A 示例却破坏 B 示例」的依赖地狱。
- **AGENTS.md 下沉到子项目**：在 monorepo 全局 `AGENTS.md` 之外，再给 **高专用度示例**（content-builder、nvidia）提供 **局部规范**，降低无关噪音。
- **服务器型示例单独成目录**：`async-subagent-server` 与 CLI/脚本式示例分离，读者可按部署模型选型。

---

## 小结

`examples/` 是 Deep Agents **从 API 到产品形态** 的桥梁：以 **`create_deep_agent`** 为轴，通过 **tools、prompts、skills、backend、服务化** 等组合表达不同场景；阅读时建议 **先读该目录 `README.md`**，再进入各子目录的 **`README.md` 与 `AGENTS.md`**。
