# Part A：A3C（A-01）
## Asynchronous Methods for Deep Reinforcement Learning

**论文信息**
- 作者：Volodymyr Mnih, Adrià Puigdomènech Bard 等（DeepMind）
- 发表：ICML 2016
- arXiv：1602.01783

---

## A.1 核心问题：打破经验回放的依赖

**DQN 的路线**：经验回放 + 目标网络 → 解决训练不稳定

**A3C 的洞察**：
- 经验回放使 DQN 只能用 off-policy 方法（Q-learning）
- 多个并行 Agent 同时与不同环境实例交互，天然产生**不相关的数据**
- 异步更新 ≈ 随机采样的效果，无需回放缓冲区

**核心创新**：用**异步并行Actor**代替经验回放来解决数据相关性问题。

---

## A.2 A3C 架构

### A.2.1 全局网络 + 并行 Worker

```
全局共享网络（参数 θ, θ_v）
    ├── Actor 头：π_θ(a|s)
    └── Critic 头：V_{θ_v}(s)

并行 Worker 1 ~ N：
  各自持有局部网络副本（参数 θ', θ_v'）
  各自与独立环境实例交互
  
  每个 Worker 的工作循环：
    1. 从全局网络复制参数：θ' ← θ，θ_v' ← θ_v
    2. 执行 t_max 步（或到 episode 结束）
    3. 计算局部梯度：dθ，dθ_v
    4. 异步更新全局网络：θ += dθ，θ_v += dθ_v
    5. 返回步骤 1
```

**"异步"的含义**：各 Worker 独立运行，不等待其他 Worker，全局参数的更新是**锁自由（lock-free）**的。

### A.2.2 为什么异步有效？

| 并行度效果 | 说明 |
|-----------|------|
| **数据去相关** | 不同 Worker 处于环境的不同状态，数据相关性自然降低 |
| **探索多样性** | 不同 Worker 可采用不同 ε（探索率），覆盖更广状态空间 |
| **无需回放缓冲区** | 降低内存需求，支持 on-policy 方法 |
| **线性加速** | 理论上 N 个 Worker 提供近似 N 倍吞吐量 |

---

## A.3 算法：n步回报的 Actor-Critic

```
每个 Worker 的更新步骤：
============================
1. 执行 t_max 步，收集：{(s_t, a_t, r_t)}_{t=t_start}^{t_start+t_max-1}

2. 计算 n步回报（从当前状态向前看）：
   if terminal:  R = 0
   else:         R = V_{θ_v'}(s_{t_max})   ← bootstrapped value

   对 i = t_max-1, ..., t_start:
     R = r_i + γ·R   ← 递推计算折扣回报

3. 计算策略梯度（带熵正则化）：
   dθ ← Σ_t ∇_θ log π_{θ'}(a_t|s_t) · (R_t - V_{θ_v'}(s_t))
       + β · ∇_θ H(π_{θ'}(·|s_t))     ← 熵正则，β=0.01

4. 计算价值梯度：
   dθ_v ← Σ_t ∇_{θ_v} (R_t - V_{θ_v'}(s_t))²

5. 异步更新全局网络（RMSprop，无锁）：
   θ  += α_policy · dθ
   θ_v += α_value · dθ_v
```

**A2C（同步版本）**：等待所有 Worker 完成一轮后再更新全局网络，梯度更稳定，是现代 PPO 实现的基础。

---

## A.4 支持的算法家族

A3C 框架支持多种基础算法：
- **A3C + n步Q-learning**：在离散动作空间
- **A3C + Sarsa**
- **A3C + Actor-Critic**（主流）
- 连续动作：使用高斯策略参数化

---

## A.5 实验结果

| 维度 | A3C | DQN（单GPU）|
|------|-----|-----------|
| Atari 平均得分 | 接近 | 接近 |
| 训练时间（Atari）| **1天（16 CPU）** | 8-10天（1 GPU）|
| 内存占用 | 低（无回放缓冲区）| 高（1M经验）|
| 连续控制（MuJoCo）| ✅（天然支持）| ❌（需离散化）|

**A3C 创造了用 CPU 集群替代 GPU 的可行路线**，对资源受限的研究者极具吸引力。

# Part B：DDPG（A-02）
## Continuous Control with Deep Reinforcement Learning

**论文信息**
- 作者：Timothy P. Lillicrap, Jonathan J. Hunt 等（DeepMind）
- 发表：ICLR 2016
- arXiv：1509.02971

---

## B.1 核心问题：DQN 无法处理连续动作

**DQN 的根本限制**：需要在每步计算 `argmax_a Q(s,a)`，当动作空间连续时不可行。

**DDPG 的解决方案**：使用**确定性策略**（Deterministic Policy）直接输出动作：

```
随机策略（REINFORCE/PPO）：a_t ~ π_θ(·|s_t)
确定性策略（DDPG）：        a_t = μ_θ(s_t)   ← 直接映射
```

**理论基础**：确定性策略梯度定理（DPG，Silver et al. 2014）：
```
∇_θ J(μ_θ) = E_{s~ρ^μ} [ ∇_θ μ_θ(s) · ∇_a Q^μ(s,a)|_{a=μ_θ(s)} ]
```

**与随机策略梯度的关系**：确定性策略梯度是随机策略梯度在策略方差→0时的极限。

---

## B.2 DDPG 架构

### B.2.1 四网络结构

```
Actor（在线）：    μ_θ(s)         → 输出连续动作
Actor（目标）：    μ_{θ̄}(s)      → 计算目标值
Critic（在线）：   Q_φ(s,a)       → 评估 (s,a) 价值
Critic（目标）：   Q_{φ̄}(s,a)    → 计算目标值（稳定）

目标网络软更新（τ=0.005，而非 DQN 的硬复制）：
θ̄ ← τ θ + (1-τ) θ̄
φ̄ ← τ φ + (1-τ) φ̄
```

**软更新的优势**：参数变化更平滑，目标网络更稳定，无需选择硬更新频率 C。

### B.2.2 探索策略

确定性策略本身没有随机性，需要外部添加噪声：

```
探索动作：a_t = μ_θ(s_t) + N_t

Ornstein-Uhlenbeck（OU）过程：
dN_t = θ_OU(μ_OU - N_t)dt + σ dW_t

特点：时间相关的连续噪声，适合物理控制任务
实践中也常用高斯噪声：N_t ~ N(0, σ²)
```

---

## B.3 完整算法

```
DDPG 算法
==========
初始化：
  在线 Actor μ_θ，在线 Critic Q_φ（随机初始化）
  目标 Actor μ_{θ̄} ← μ_θ，目标 Critic Q_{φ̄} ← Q_φ
  回放缓冲区 D，容量 N

每步训练：
  1. 选择动作（带OU噪声探索）：
     a_t = μ_θ(s_t) + N_t

  2. 执行动作，存储 transition：
     D ← D ∪ {(s_t, a_t, r_t, s_{t+1})}

  3. 从 D 中均匀采样 B 个 transition

  4. 计算 Critic 目标（使用目标网络）：
     y_i = r_i + γ Q_{φ̄}(s_{i+1}, μ_{θ̄}(s_{i+1}))

  5. 更新 Critic（最小化 Bellman 误差）：
     L_φ = (1/B) Σ (y_i - Q_φ(s_i, a_i))²
     φ ← φ - α_φ · ∇_φ L_φ

  6. 更新 Actor（最大化期望Q值，策略梯度）：
     ∇_θ J = (1/B) Σ ∇_a Q_φ(s_i, a)|_{a=μ_θ(s_i)} · ∇_θ μ_θ(s_i)
     θ ← θ + α_θ · ∇_θ J

  7. 软更新目标网络：
     θ̄ ← τ θ + (1-τ) θ̄
     φ̄ ← τ φ + (1-τ) φ̄
```

---

## B.4 关键超参数

| 超参数 | 值 |
|--------|-----|
| 软更新系数 τ | 0.005 |
| 折扣因子 γ | 0.99 |
| Actor 学习率 | 1e-4 |
| Critic 学习率 | 1e-3 |
| Batch size | 64-256 |
| 回放缓冲区 | 1,000,000 |
| OU噪声 θ_OU | 0.15 |
| OU噪声 σ | 0.2 |

---

## B.5 局限性（TD3 要解决的问题）

| 问题 | 具体表现 |
|------|---------|
| **Q值过估计** | Critic 系统性高估 Q(s,a)，导致 Actor 过度利用 |
| **Actor 过拟合 Critic 错误** | Critic 过估计的区域 Actor 会过度优化 |
| **训练不稳定** | 在某些任务上难以收敛 |
| **超参数敏感** | OU噪声参数难以调整 |

# Part C：TD3（A-03）
## Addressing Function Approximation Error in Actor-Critic Methods

**论文信息**
- 作者：Scott Fujimoto, Herke van Hoof, David Meger（McGill University）
- 发表：ICML 2018
- arXiv：1802.09477

---

## C.1 诊断 DDPG 的三大失效机制

### C.1.1 失效机制一：Critic 过估计

**原因**：Critic 使用目标网络的 max 操作（类似 DQN），在连续动作空间中放大了过估计。

**量化**：论文实验显示 DDPG 的 Q 估计比真实值高 **200-600%**。

### C.1.2 失效机制二：策略和值函数的相互强化

Actor 被训练去最大化 Critic 的输出，当 Critic 过估计时，Actor 会不断放大这种过估计，形成**正反馈循环**。

### C.1.3 失效机制三：策略更新频率过高

频繁的 Actor 更新导致 Critic 没有足够时间收敛，进一步加剧过估计。

---

## C.2 TD3 的三大修复

### C.2.1 修复一：双 Critic（Clipped Double Q-learning）

**灵感**：Double DQN 的双网络思想扩展到连续动作空间。

```
维护两个独立的 Critic：Q_{φ₁}，Q_{φ₂}

目标值取最小值（悲观估计）：
y = r + γ · min(Q_{φ̄₁}(s', ã), Q_{φ̄₂}(s', ã))

两个 Critic 分别用相同目标更新：
L(φ₁) = (y - Q_{φ₁}(s,a))²
L(φ₂) = (y - Q_{φ₂}(s,a))²

Actor 用第一个 Critic 计算梯度：
∇_θ J = ∇_a Q_{φ₁}(s,a)|_{a=μ_θ(s)} · ∇_θ μ_θ(s)
```

**为什么取 min 而非 max？**
- 两个独立训练的 Critic 在不同区域分别有过/低估计
- 取 min 是悲观策略：宁可低估也不过估计（避免 Actor 利用错误高估）
- 实验证明 min 比 max 好得多，虽然引入了低估偏差，但比过估计危害更小

### C.2.2 修复二：目标策略平滑化（Target Policy Smoothing）

**问题**：确定性策略梯度可能放大 Q 函数的窄峰（sharp peaks），导致次优策略。

**解决**：在目标动作上添加截断噪声：
```
ã = clip(μ_{θ̄}(s') + clip(ε, -c, c), a_min, a_max)

ε ~ N(0, σ)
c = 0.5（噪声截断范围）

效果：对目标 Q 值进行隐式正则化，平滑 Q 函数
    Q(s', ã) ≈ (1/|N(ã)|) Σ_{a'∈N(ã)} Q(s', a')
```

**直觉**：类似监督学习中的 Label Smoothing，防止 Q 函数在局部点过拟合。

### C.2.3 修复三：延迟策略更新（Delayed Policy Updates）

**观察**：Critic 的误差比 Actor 更容易修复，但 Actor 的频繁更新会干扰 Critic 的收敛。

**解决**：Actor 和目标网络的更新频率降低（每 2 步 Critic 更新才更新 1 次 Actor）：

```
对每步 t：
  // 每步更新 Critic
  更新 Q_{φ₁}，Q_{φ₂}

  // 每 d=2 步才更新 Actor 和目标网络
  if t % d == 0:
    更新 μ_θ
    软更新：θ̄ ← τθ + (1-τ)θ̄，φ̄₁ ← τφ₁ + (1-τ)φ̄₁，φ̄₂ ← τφ₂ + (1-τ)φ̄₂
```

---

## C.3 完整算法

```
TD3 算法
=========
超参数：d=2（Actor更新频率），σ=0.2（目标噪声），c=0.5（噪声截断），τ=0.005

初始化：μ_θ，Q_{φ₁}，Q_{φ₂}（在线）；μ_{θ̄}，Q_{φ̄₁}，Q_{φ̄₂}（目标）
回放缓冲区 D

每步 t 训练：
  1. a_t = μ_θ(s_t) + ε，ε ~ N(0, σ_explore²)   ← 探索噪声
  2. D ← D ∪ {(s_t, a_t, r_t, s_{t+1})}

  3. 采样 B 个 transition

  4. 计算目标动作（带截断噪声）：
     ε' = clip(N(0,σ), -c, c)
     ã = clip(μ_{θ̄}(s') + ε', a_min, a_max)

  5. 计算目标值（取两个 Critic 的 min）：
     y = r + γ · min(Q_{φ̄₁}(s', ã), Q_{φ̄₂}(s', ã))

  6. 更新两个 Critic：
     φ₁ ← argmin_φ Σ(y - Q_{φ₁}(s,a))²
     φ₂ ← argmin_φ Σ(y - Q_{φ₂}(s,a))²

  7. if t % d == 0（延迟更新）：
     Actor：θ ← θ + α ∇_θ [Σ Q_{φ₁}(s, μ_θ(s))]
     目标网络软更新（全部四个目标网络）
```

---

**MuJoCo 6 个任务**（HalfCheetah, Hopper, Walker2D, Ant, Reacher, InvertedPendulum）：

| 方法 | 平均奖励（相对）|
|------|--------------|

| TD3 | **+50-100%**（多数任务）|
| SAC（同期）| 接近TD3 |

**消融**：三个修复均有正贡献，缺一不可。

# Part D：SAC（A-04）
## Soft Actor-Critic: Off-Policy Maximum Entropy Deep RL with a Stochastic Actor

**论文信息**
- 作者：Tuomas Haarnoja, Aurick Zhou, Pieter Abbeel, Sergey Levine（UC Berkeley）
- 发表：ICML 2018 / arXiv 1801.01290（v1）；SAC v2（自动温度）arXiv 1812.05905

---

## D.1 最大熵强化学习框架

### D.1.1 标准 RL vs 最大熵 RL

**标准 RL 目标**：
```
J(π) = E_π [ Σ_t r(s_t, a_t) ]   ← 只最大化累积奖励
```

**最大熵 RL 目标**：
```
J(π) = E_π [ Σ_t r(s_t, a_t) + α · H(π(·|s_t)) ]

其中：
H(π(·|s_t)) = -E_{a~π}[ log π(a|s_t) ]   ← 策略的信息熵
α > 0                                       ← 温度参数（探索的权重）
```

**直觉**：在最大化累积奖励的同时，**最大化策略的随机性（熵）**。

### D.1.2 最大熵的好处

| 好处 | 说明 |
|------|------|
| **自动探索** | 高熵 = 高随机性 = 自然探索，无需手动设计探索策略 |
| **多模式保持** | 不会过早收敛到某一个局部最优策略（多解并存）|
| **鲁棒性** | 学到的策略对扰动更鲁棒（不是尖锐的确定性策略）|
| **组合能力** | 在迁移学习场景中，高熵策略更容易适应新任务 |

### D.1.3 软贝尔曼方程

最大熵框架改变了贝尔曼方程：

**软 Q 函数**：
```
Q_soft(s,a) = r(s,a) + γ E_{s'~P} [ V_soft(s') ]

V_soft(s) = E_{a~π} [ Q_soft(s,a) - α log π(a|s) ]
           = E_{a~π} [ Q_soft(s,a) ] + α H(π(·|s))
```

**软贝尔曼算子**：
```
T^π Q(s,a) = r(s,a) + γ E_{s'} [ E_{a'~π} [Q(s',a') - α log π(a'|s')] ]
```

## D.2 SAC 架构

### D.2.1 三网络结构（SAC v1）

```
1. 软 Q 函数（2个，类似TD3）：Q_{φ₁}(s,a)，Q_{φ₂}(s,a) + 对应目标网络
2. 随机 Actor：π_θ(a|s)（高斯策略，输出均值μ和方差σ）
（v1 还有独立 V 函数，v2 移除了 V 函数）
```

### D.2.2 随机策略参数化（重参数化技巧）

**问题**：对 E_{a~π}[Q(s,a)] 求关于 θ 的梯度时，期望内包含随机采样 a，不可直接求导。

**重参数化（Reparameterization trick）**：
```
a = μ_θ(s) + σ_θ(s) ⊙ ε，ε ~ N(0, I)

E_{a~π_θ} [Q(s,a)] = E_{ε~N(0,I)} [Q(s, μ_θ(s) + σ_θ(s) ⊙ ε)]
```

现在梯度可以直接传入网络参数 θ（ε 是外部随机源）！

**Squashed 高斯策略**（限制动作范围）：
```
a = tanh(μ_θ(s) + σ_θ(s) ⊙ ε)

对数概率（需要 Jacobian 校正）：
log π_θ(a|s) = N(a; μ_θ(s), σ_θ(s)²) - Σ_i log(1 - tanh²(a_i))
```

---

## D.3 SAC 更新规则

### D.3.1 Critic 更新（软贝尔曼误差）

```
// 采样目标动作（从当前策略，不是目标网络策略）
ã_{t+1} ~ π_θ(·|s_{t+1})

// 目标值（取两个目标Critic的min，减去熵项）
y = r_t + γ [min(Q_{φ̄₁}(s_{t+1}, ã_{t+1}), Q_{φ̄₂}(s_{t+1}, ã_{t+1}))
           - α log π_θ(ã_{t+1}|s_{t+1})]    ← ★ 熵项在目标值中！

// 更新两个Critic
L(φ_i) = E [(Q_{φ_i}(s_t, a_t) - y)²]，i=1,2
```

### D.3.2 Actor 更新（最大化软Q值）

```
// 重参数化采样
ã_t = μ_θ(s_t) + σ_θ(s_t) ⊙ ε，ε ~ N(0,I)

// Actor 损失（最小化负的软Q值）
L(θ) = E_{s_t, ε} [ α log π_θ(ã_t|s_t) - min(Q_{φ₁}(s_t, ã_t), Q_{φ₂}(s_t, ã_t)) ]
     = E [ α log π - min Q ]

梯度：让 π 最大化 Q - α·entropy
```

### D.3.3 温度 α 的自动调整（SAC v2 的关键改进）

**问题**：手动调整 α 极其困难（不同任务最优 α 差异巨大）。

**自动调整**：将目标熵 H̄ 作为约束，自动学习 α：

```
目标：找 α 使期望熵约等于目标熵 H̄
α* = argmin_α E_{a~π} [-α log π(a|s) - α H̄]

梯度下降更新 log α（确保 α > 0）：
L(α) = E_{a~π_θ} [-α log π_θ(a|s) - α H̄]
∇_{log α} L = E_{a~π_θ} [-log π_θ(a|s) - H̄]
```

**目标熵 H̄ 的选择**：
```
H̄ = -dim(A)   ← 连续：动作空间维度的负值
H̄ = -log(1/|A|) ← 离散：均匀分布熵的负值
```

**物理意义**：α 自动增大（鼓励探索）当当前策略比目标熵更确定性时，反之自动减小。

## D.4 完整算法（SAC v2）

```
SAC v2 算法
============
初始化：
  随机 Actor π_θ
  两个 Critic Q_{φ₁}，Q_{φ₂} + 对应目标网络 Q_{φ̄₁}，Q_{φ̄₂}
  温度参数 log α（可学习）
  回放缓冲区 D

超参数：τ=0.005，γ=0.99，batch=256，H̄=-dim(A)，lr=3e-4

每步训练：
  1. a_t ~ π_θ(·|s_t)   ← 随机采样（无需额外探索噪声）
  2. D ← D ∪ {(s_t, a_t, r_t, s_{t+1}, done)}

  3. 采样 B 个 transition

  4. // 更新 Critic
     ã_{t+1} ~ π_θ(·|s_{t+1})
     y = r + γ·(1-done)·[min Q̄(s', ã') - α log π(ã'|s')]
     L(φ_i) = (Q_{φ_i}(s,a) - y)²，更新 φ₁，φ₂

  5. // 更新 Actor
     ã ~ π_θ(·|s)（重参数化）
     L(θ) = α log π_θ(ã|s) - min Q_{φ₁,φ₂}(s, ã)
     更新 θ

  6. // 更新温度
     L(α) = -α (log π_θ(ã|s) + H̄)
     更新 log α

  7. // 软更新目标网络
     φ̄_i ← τ φ_i + (1-τ) φ̄_i
```

SAC 在多数连续控制任务上是 **State-of-the-Art**，并且：
- 比 TD3 **更稳定**（自动调温）
- 比 PPO **样本效率高得多**（off-policy + 经验回放）
- 比 DDPG **收敛更稳定**（随机策略 + 最大熵）

## D.6 SAC 的理论优势

| 理论性质 | 说明 |
|---------|------|
| **off-policy** | 使用经验回放，样本效率高 |
| **最大熵** | 自动探索，多解保持 |
| **随机策略** | 避免确定性策略的局部过拟合 |
| **自动调温** | 免去最难调的超参数 |

## 总结

```
Actor-Critic 演化路线：

A3C (2016)   → 异步并行替代经验回放，证明并行AC可行
               问题：无经验回放，样本低效
     ↓
DDPG (2016)  → 确定性策略梯度+经验回放，首个实用连续控制方案
               问题：过估计、不稳定、探索困难
     ↓
TD3 (2018)   → 双Critic min、目标平滑、延迟更新，修复DDPG三大问题
               问题：确定性策略仍然探索困难、超参数多
     ↓
SAC (2018)   → 最大熵框架+随机策略+自动温度，
               实现稳定性、探索性、样本效率三者统一
               ← 目前连续控制的默认选择
```

SAC 代表了 Actor-Critic 方法在理论框架上的一次重大升级：**不再把探索和利用视为对立，而是通过最大化熵统一成一个优化目标**。
