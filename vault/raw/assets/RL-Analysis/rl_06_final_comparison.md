## 三、三大范式核心对比

### 3.1 优化目标差异

| 范式 | 优化什么 | 梯度来源 | 策略如何获得 |
|------|---------|---------|------------|
| **Value-Based** | Bellman 误差：`(y - Q(s,a))²` | 监督学习梯度 | 隐式：`argmax_a Q(s,a)` |
| **Policy-Based** | 期望回报：`J(θ) = E[R]` | 策略梯度定理 | 显式：`π_θ(a|s)` |
| **Actor-Critic** | 两者联合：TD误差 + 策略梯度 | 两路梯度 | 显式：`π_θ(a|s)` |

### 3.2 方差-偏差权衡

```
方差（高→低）         偏差（高→低）
REINFORCE    ←→        DQN
    │                    │
   [高方差              [高偏差
    低偏差]              低方差]
    │                    │
    └──── Actor-Critic ──┘
           （折中）
```

**方差来源**：
- MC 回报（REINFORCE）：对整条轨迹求和，方差为单步方差的 T 倍
- TD 更新（DQN）：单步Bootstrap，方差小，但依赖于当前Q函数的准确性

**偏差来源**：
- 函数逼近误差（所有深度RL方法都有）
- Bootstrapping偏差（TD方法：用当前不准确的Q函数估计目标）
- 过估计偏差（max 操作引入，Double DQN缓解）

### 3.3 探索策略对比

| 算法 | 探索方式 | 探索的本质 |
|------|---------|-----------|
| DQN/Rainbow | ε-greedy | 随机动作，与状态无关 |
| REINFORCE/PPO | 策略随机性（Categorical/高斯）| 状态相关，策略驱动 |
| TRPO | 策略随机性 + 约束 | 受控探索 |
| A3C | 多 Worker + 熵正则 | 并行多样性 |
| DDPG | OU 噪声 | 外加时序相关噪声 |
| TD3 | 高斯噪声 | 外加白噪声 |
| SAC | 最大熵策略 | 内嵌于目标函数 |
| Rainbow | NoisyNets | 可学习参数化噪声 |

**最优探索**：SAC 的最大熵探索是目前最系统、最理论完备的方法。

## 四、关键技术点横向对比

### 4.1 目标网络策略

| 算法 | 目标网络策略 | 更新方式 |
|------|-----------|---------|
| DQN | 硬复制 | 每 C=10000 步 |
| DDPG/TD3/SAC | 软更新 | 每步 θ̄ ← τθ + (1-τ)θ̄，τ=0.005 |
| A3C/PPO | 无目标网络 | 直接用当前网络 |

**硬更新 vs 软更新**：软更新更平滑，但每步都有微小变化；硬更新更稳定但有周期性跳变。

### 4.2 经验回放策略

| 算法 | 经验回放 | 采样策略 |
|------|---------|---------|
| DQN | ✅ 均匀 | P(i) = 1/N |
| PER/Rainbow | ✅ 优先 | P(i) ∝ |δ_i|^α |
| DDPG/TD3/SAC | ✅ 均匀 | P(i) = 1/N |
| REINFORCE/TRPO/PPO/A3C | ❌ | 在线数据 |

**Off-policy 的代价**：需要额外的重要性采样修正，引入额外偏差；好处是数据复用率高。

### 4.3 Critic 架构

| 算法 | Critic 数量 | 输出类型 |
|------|-----------|---------|
| DQN | 1（即是Critic）| Q(s, a₁...a_|A|)（所有动作）|
| DDPG | 1 | Q(s, a)（单一动作输入）|
| TD3 | 2（取min）| Q(s, a)（单一动作输入）|
| SAC | 2（取min）| Q(s, a)（单一动作输入）|
| A3C/PPO | 1 | V(s)（不输入动作）|
| Rainbow | 1（分布式）| Z(s,a)（51个原子）|

### 4.4 Actor（策略）架构

| 算法 | 策略参数化 | 输出 |
|------|----------|------|
| DQN/Rainbow | 无显式Actor | argmax Q |
| REINFORCE/PPO | Categorical（离散）/ 高斯（连续）| 概率分布 |
| DDPG/TD3 | 确定性 μ_θ(s) | 直接动作值 |
| SAC | Squashed 高斯 | (μ, log σ)，采样后 tanh |
| A3C | Softmax（离散）/ 高斯（连续）| 概率分布 |

## 五、算法选型决策树

```
你的任务是什么？
│
├── 动作空间是离散的（游戏、棋类、NLP）？
│   ├── 状态空间是高维像素/图像？
│   │   ├── 追求最高性能 → Rainbow
│   │   └── 简单实现 → DQN / Double DQN
│   ├── 状态空间是低维向量？
│   │   ├── 追求样本效率 → DQN + PER
│   │   └── 追求稳定性 → PPO（离散版本）
│   └── 稀疏奖励 / 探索困难？
│       → PPO + 内在奖励（ICM, RND）
│
└── 动作空间是连续的（机器人、物理仿真）？
    ├── 需要稳定性 + 自动调参 → SAC（推荐首选）
    ├── 需要高性能 + 可控探索 → TD3
    ├── 需要多任务 / RLHF → PPO（连续版本）
    └── 资源受限 / 快速原型 → DDPG
    
特殊情况：
├── 需要保证单调改进（安全RL）→ TRPO
├── 多智能体 / 分布式计算 → A3C / IMPALA
├── 有人类反馈 → PPO + RLHF
└── 学术研究（方法论）→ SAC（最优理论框架）
```

## 六、核心数学对比：梯度估计

### 6.1 各算法的策略梯度估计形式

**REINFORCE**：
```
ĝ = (1/N) Σ_{τ} [ Σ_t ∇_θ log π_θ(a_t|s_t) · G_t ]   ← Monte-Carlo，高方差
```

**Actor-Critic（A3C/PPO）**：
```
ĝ = (1/N) Σ_t [ ∇_θ log π_θ(a_t|s_t) · Â_t^GAE ]      ← 用GAE估计优势，方差降低
```

**DDPG/TD3（确定性）**：
```
ĝ = (1/N) Σ_s [ ∇_θ μ_θ(s) · ∇_a Q_φ(s,a)|_{a=μ_θ(s)} ]  ← 链式法则，无随机采样
```

**SAC（随机+重参数化）**：
```
ĝ = (1/N) Σ_{s,ε} [ ∇_θ ( α log π_θ(ã_θ(s,ε)|s) - Q_φ(s, ã_θ(s,ε)) ) ]  ← 重参数化，低方差
```

### 6.2 方差比较

定性排序（方差由高到低）：

```
REINFORCE >> A3C ≈ PPO > SAC > DDPG ≈ TD3 > DQN
```

- REINFORCE：完整轨迹MC，无基线
- A3C/PPO：GAE减方差，但仍然是随机策略梯度
- SAC：重参数化技巧，比蒙特卡洛估计方差更低
- DDPG/TD3：确定性策略，无随机性，方差来源仅为批采样噪声
- DQN：监督式Bellman误差，最低方差，但最高偏差

## 十一、常见误区与正确认识

### 误区 1："Policy Gradient 一定比 Value-Based 差"
**正确**：在 Atari 上，经过优化的 Rainbow 超过 PPO；在 MuJoCo 上，SAC（AC方法）超过 PPO（Policy方法）。性能取决于具体问题。

### 误区 2："Off-policy 一定样本效率更高"
**正确**：Off-policy 可以复用历史数据，通常样本效率更高。但 on-policy 方法（PPO）训练更稳定，在复杂环境（长时程、探索难）中可能最终表现更好。

### 误区 3："Double DQN 只是小改进"
**正确**：Double DQN 在某些任务上提升超过 38%，且几乎零额外计算成本。其理论意义远超代码改动量。

### 误区 4："TRPO 理论最好，实践最好"
**正确**：TRPO 的单调改进保证建立在严格的前提条件上（精确策略评估、无函数逼近误差）。实践中 PPO 通常表现相近或更好，且易用性远超 TRPO。

### 误区 5："SAC 适合所有问题"
**正确**：SAC 针对连续动作空间设计，在离散动作空间需要修改。Rainbow 在 Atari 等离散动作问题上仍然是更好的选择。

## 十二、总结矩阵

```
                    ┌─────────────────────────────────────────────────┐
                    │              最终选型建议                         │
                    ├──────────────────┬──────────────────────────────┤
                    │ 离散动作 + 视觉   │ → Rainbow                   │
                    │ 离散动作 + 向量   │ → DQN(+PER) 或 PPO          │
                    │ 连续动作 + 稳定   │ → SAC（首选）                │
                    │ 连续动作 + 极限性能│ → TD3                       │
                    │ 人类反馈 RLHF    │ → PPO                        │
                    │ 安全约束 RL      │ → TRPO / CPO                 │
                    │ 多智能体         │ → MAPPO / MADDPG             │
                    │ 分布式训练       │ → IMPALA / Ape-X             │
                    │ 快速原型验证      │ → PPO / SAC                  │
                    └──────────────────┴──────────────────────────────┘
```

---

**一句话总结三大范式**：

- **Value-Based**：相信"评价是关键"，把策略隐藏在价值函数的极值里，工程导向，离散动作的霸主。
- **Policy-Based**：相信"直接才是最优"，梯度穿透策略直接优化目标，理论优美，RLHF 的选择。
- **Actor-Critic**：相信"取长补短"，评价者降低方差，行动者保持策略灵活性，连续控制的王者。

三者不是竞争关系，而是在不同问题结构下各自发光的工具。**深刻理解每种范式的核心张力，才是选择与创新的基础。**
