可以用一个 **从右往左读** 的办法，一眼就能拆开。

先记 3 个符号的核心意思：

- `*` ：指针，表示“存一个地址”
- `&` ：引用，表示“某个对象的别名”
- `const` ：只读，修饰它 **左边** 的东西；如果左边没有，就修饰右边

---

## 一把梭的读法

看类型时，先抓变量名，再往两边读。

比如：

```markdown
const T* p;
```

先看 `p` ， `p` 左边有 `*` ，所以 `p` 是“指针”；再看 `*` 左边是 `const T` ，所以它指向“只读的 T”。

读作：

**`p` 是一个指向 `const T` 的指针**

---

## 这四个分别是什么

### 1) const T&

```markdown
const T& x
```

意思：

**只读引用 / 常量引用**

你能通过 `x` 读这个对象，但不能通过 `x` 改它。

```markdown
void print(const std::string& s) {
    std::cout << s;
    // s += "!";   // 不行，s 是 const 引用
}
```

常见用途：

- 传大对象，避免拷贝
- 又不希望函数修改它

---

### 2) T\*

```markdown
T* p
```

意思：

**指向 T 的指针**

你可以改 `p` 指向哪里，也可以通过 `p` 改那个对象。

```markdown
int a = 10;
int b = 20;
int* p = &a;

*p = 15;   // 改 a
p = &b;    // 改 p 的指向
```

---

### 3) const T\*

```markdown
const T* p
```

也常写成：

```markdown
T const* p
```

这俩完全一样。

- `p` 是一个指针
- 指向 `const T`

意思：

**指向只读 T 的指针**

你可以改 `p` 指向哪里， **但不能通过 `p` 改它指向的对象**

```markdown
int a = 10;
int b = 20;
const int* p = &a;

p = &b;      // 可以，p 本身可改
//*p = 30;   // 不行，不能通过 p 改值
```

---

### 4) T&

```markdown
T& x
```
- `x` 是一个引用
- 引用到 `T`

意思：

**可修改引用**

它就是原对象的别名，可以直接改原对象。

```markdown
int a = 10;
int& x = a;

x = 99;   // a 也变成 99
```

---

## 最容易混的点：到底谁是 const？

关键是看 **const 修饰谁** 。

### const T\* p

`const` 修饰 `T` ，所以：

- `*p` 不能改
- `p` 自己能改

即：

**“指向常量的指针”**

---

如果是：

```markdown
T* const p
```

那 `const` 修饰的是 `p` 这个指针本身，因为它在 `*` 后面。

所以：

- `p` 不能改指向
- `*p` 能改

即：

**“常量指针”**

例子：

```markdown
int a = 10;
int b = 20;
int* const p = &a;

*p = 30;   // 可以，改 a
// p = &b; // 不行，p 不能改指向
```

---

再进一步：

```markdown
const T* const p
```

就是：

- `p` 不能改指向
- `*p` 也不能改

即：

**“指向常量的常量指针”**

---

## 一张速记表

| 写法 | 中文直觉 | 能不能改值 | 能不能改绑定/指向 |
| --- | --- | --- | --- |
| `T&` | 可写引用 | 可以 | 不行，引用一旦绑定不能改绑 |
| `const T&` | 只读引用 | 不可以 | 不行 |
| `T*` | 可写指针 | 可以通过 `*p` 改 | 可以 |
| `const T*` | 指向只读对象的指针 | 不可以通过 `*p` 改 | 可以 |

---

## 一眼看懂口诀

你可以直接背这个：

- `T&` ： **可改的别名**
- `const T&` ： **只读的别名**
- `T*` ： **可改对象、可改指向**
- `const T*` ： **不可改对象、可改指向**

如果再加上 `T* const` ：

- `T* const` ： **可改对象、不可改指向**

---

## 为什么引用没有“改指向”一说？

因为引用不是“像指针那样存了个可变地址”的语义。  
引用一旦绑定到某个对象，就一直是那个对象的别名。

```markdown
int a = 1;
int b = 2;
int& r = a;

r = b;   // 这不是让 r 改绑到 b
         // 而是把 b 的值赋给 a
```

执行后：

- `a == 2`
- `r` 还是 `a` 的别名

---

## 函数参数里怎么理解最实用

### void f(T x)

传值：拷贝一份，函数里怎么改都不影响外面

### void f(T& x)

传可写引用：不拷贝，函数里能改外面对象

### void f(const T& x)

传只读引用：不拷贝，函数里不能改外面对象

### void f(T\* p)

传指针：可以为空，要写 `*p` 才能访问对象

### void f(const T\* p)

传只读指针：可以为空，但不能通过它改对象

---

## 你真正该优先形成的脑内翻译

看到它们时，不要死盯语法，直接翻译成人话：

- `T&` → “我拿到这个对象本体的别名，而且能改”
- `const T&` → “我拿到这个对象本体的只读别名”
- `T*` → “我拿到一个地址，可以换指向，也能改对象”
- `const T*` → “我拿到一个地址，可以换指向，但不能改对象”

---

## 最后给你一个秒判练习

```markdown
int a = 1;
int b = 2;

int& r1 = a;
const int& r2 = a;
int* p1 = &a;
const int* p2 = &a;
```

判断：

- `r1 = 3;` ✅ 可以
- `r2 = 3;` ❌ 不可以
- `*p1 = 3;` ✅ 可以
- `*p2 = 3;` ❌ 不可以
- `p1 = &b;` ✅ 可以
- `p2 = &b;` ✅ 可以
