# 通过 MCP 的代码执行：构建更高效的 Agent

> **原文**：[Code execution with MCP: Building more efficient agents](https://www.anthropic.com/engineering/code-execution-with-mcp)
> **发布日期**：2025 年 11 月 4 日
> **类别**：MCP · 代码执行 · Agent 工具

---

## 摘要

本文探讨了如何通过 Model Context Protocol（MCP）为 Agent 提供安全的代码执行能力，以及这种能力如何改变 Agent 的问题解决策略。代码执行是 Agent 从"对话式"转向"计算式"解决问题的关键能力——Agent 可以写代码来验证假设、处理数据、自动化重复计算，而不只是用语言描述解决方案。

---

## 一、代码执行能力对 Agent 的意义

### 1.1 从"描述"到"实践"的跃迁

没有代码执行能力的 Agent：
> "你可以用 Python 的 pandas 库读取 CSV 文件，然后使用 groupby 按照日期聚合销售数据..."

有代码执行能力的 Agent：
```python
import pandas as pd
df = pd.read_csv('sales.csv')
monthly = df.groupby('month')['revenue'].sum()
print(monthly.to_string())
# [实际执行并显示结果]
```

区别不只是便利——代码执行允许 Agent 处理 Agent 本身无法处理的大规模数据，并用结果验证推理，而非依赖语言描述。

### 1.2 代码作为"工具"的独特性

与其他工具（如网络搜索、数据库查询）相比，代码执行工具的独特之处：
- **无限组合性**：代码可以组合任意逻辑
- **自验证性**：代码执行结果是直接的事实反馈
- **精确性**：消除了语言模糊性

---

## 二、通过 MCP 实现代码执行

### 2.1 安全沙箱设计

代码执行的最大风险是安全性——任意代码执行可能导致：
- 文件系统破坏
- 网络泄露
- 资源耗尽

MCP 代码执行服务器的安全架构：
```
MCP Client (Claude) 
  → 发送代码字符串
  → MCP Server 
    → 在隔离容器中执行（Docker/gVisor）
    → 文件系统访问受限（仅沙箱目录）
    → 网络访问可控（白名单或完全隔离）
    → 执行超时（防止无限循环）
    → 内存限制（防止资源耗尽）
  → 返回标准输出/错误
```

### 2.2 工具定义示例

```json
{
  "name": "execute_python",
  "description": "在安全的 Python 3.11 环境中执行代码。可以使用 numpy、pandas、matplotlib 等预安装库。代码在隔离沙箱中运行，没有网络访问。最大执行时间 30 秒。",
  "input_schema": {
    "type": "object",
    "properties": {
      "code": {
        "type": "string",
        "description": "要执行的 Python 代码"
      }
    },
    "required": ["code"]
  }
}
```

## 三、代码执行改变 Agent 的问题解决策略

### 3.1 数据分析场景

**传统方式（语言描述）**：
Agent 描述如何分析数据，用户需要自己执行

**代码执行方式**：
Agent 直接执行分析，展示实际结果，根据结果调整分析方向

优势：用户立即看到结果，Agent 可以迭代改进分析

### 3.2 假设验证

**场景**：Agent 不确定某个 API 的行为

**传统**：基于文档推断，给出可能正确的答案

**代码执行**：写测试代码验证实际行为，结果确定无疑

### 3.3 批量处理

**场景**：需要对 1000 个文件做相同操作

**传统**：给出手动操作步骤

**代码执行**：直接写并执行批量处理脚本

## 四、效率提升的量化

### 4.1 减少往返次数

代码执行使 Agent 能够在一次交互中验证和修正假设：

无代码执行：用户 → 描述 → 用户测试 → 反馈错误 → 修正 → 再测试（3-5 轮）

有代码执行：用户 → 执行验证 → 直接修正（1-2 轮）

### 4.2 准确性提升

代码执行将"语言准确性"转化为"逻辑准确性"：
- 语言描述可能有歧义
- 代码执行结果是绝对确定的

---

## 五、最佳实践

### 5.1 代码生成的提示策略

好的代码执行 prompt 设计：
- 明确告知 Agent 可以执行代码
- 说明可用的库
- 指明输入数据的位置和格式
- 说明期望的输出格式

### 5.2 安全使用原则

- 始终在沙箱中执行，不允许直接的文件系统写入（除沙箱目录）
- 对超时和内存设置合理限制
- 审查 Agent 生成的代码（特别是涉及外部系统时）

### 5.3 与其他工具的组合

代码执行与文件读写工具的组合极为强大：
- 读取文件 → 代码处理 → 写入结果
- 一次交互完成完整的数据转换工作流

---

## 六、结论

代码执行能力将 AI Agent 从"顾问"升级为"实践者"——不只是建议，而是实际完成工作。通过 MCP 提供安全的代码执行，是让 Agent 真正走向生产可用的关键一步。

这项能力的价值将随 Agent 被赋予更多自主权而指数级增长——当 Agent 可以写代码、执行、看结果、再修改，整个问题解决循环不再需要人类作为"执行桥梁"。
