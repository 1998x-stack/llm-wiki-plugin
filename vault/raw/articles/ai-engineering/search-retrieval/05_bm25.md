# BM25 深度解析
> Best Match 25 (Okapi BM25) — 深度解析系列 第 5 篇

## 1. BM25 的历史背景

BM25（Best Matching 25）诞生于 Robertson 和 Walker 等人在 1994 年 TREC-3 竞赛中的工作，基于**概率检索框架（Probabilistic Retrieval Framework）**推导而来。

**"25" 的含义：** 这是该系列实验中第 25 个变体，并非特殊数字含义。

**发展历程：**
```
1976: Sparck Jones 提出 IDF 概念
1977: Robertson-Sparck Jones 概率权重公式（RSJ）
1988: BIM（二元独立模型，Binary Independence Model）
1994: BM25（TREC-3，加入文档长度归一化）
1999: BM25F（处理多字段文档）
2009: BM25+（修复 BM25 的低 TF 异常）
2015: BM25L（进一步改进）
现今: Lucene/Elasticsearch 默认排序算法
```

## 2. BM25 完整推导

### 2.1 从概率框架出发

**核心问题：** 文档 d 与查询 q 相关的概率 P(R|d, q)？

**Robertson-Sparck Jones 权重（RSJ，基础形式）：**
```
RSJ(t, q, D) = log[ P(t=1|R) × P(t=0|NR) ]
                   [ ─────────────────────── ]
                   [ P(t=0|R) × P(t=1|NR) ]

其中:
  P(t=1|R)  = 已知相关文档中含有词条t的概率
  P(t=0|NR) = 已知不相关文档中不含词条t的概率
  ...

当无相关性判断数据时，近似估计:
  P(t=1|R) ≈ 0.5（保守估计：相关文档中50%含t）
  P(t=1|NR) ≈ df / N

则 RSJ ≈ log((N - df + 0.5) / (df + 0.5))  ← BM25 IDF 项
```

### 2.2 引入词频（TF）的 BM11

加入文档内词频信息：
```
BM11(t, d, q) = IDF(t) × (k₁+1)×tf / (k₁ + tf)

特性:
  tf → ∞ 时: BM11 → IDF(t) × (k₁+1)  ← 有上界！
  tf = 0:     BM11 = 0
  tf = k₁:    BM11 = IDF(t) × (k₁+1)/2  ← 半饱和点

k₁ 控制 TF 饱和速度:
  k₁ = 0: 布尔模型（只看有无）
  k₁ → ∞: 原始 TF（线性增长，无上界）
  k₁ = 1.2: 快速饱和（推荐用于短查询）
  k₁ = 2.0: 较慢饱和（推荐用于长文档）
```

### 2.3 引入文档长度归一化 → BM25

BM11 的问题：长文档 TF 天然较高 → 引入长度归一化因子：

```
规范化后的有效 TF:
  tf_norm = tf / (1 - b + b × dl/avgdl)
          = tf / normalization_factor

其中:
  dl    = 当前文档长度（词条数）
  avgdl = 语料库平均文档长度
  b     = 长度归一化参数 ∈ [0, 1]
  
b 的含义:
  b = 0: 完全不考虑文档长度（BM11）
  b = 1: 完全按比例归一化（将长文档的 TF 缩减）
  b = 0.75: 标准默认值（折中）
```

**完整 BM25 公式：**

```
            (k₁ + 1) × tf(t, d)
BM25(t,d) = ──────────────────────────────────────
            k₁ × (1 - b + b × dl/avgdl) + tf(t,d)

查询得分（所有查询词条之和）:
                                    N - df(t) + 0.5
score_BM25(q, d) = Σ_{t∈q}  log(───────────────────) × BM25(t, d)
                                    df(t) + 0.5
                   └──────────────────┘   └──────────┘
                         IDF 项              TF 饱和项
```

## 3. BM25 参数深度解析

### 3.1 k₁ 参数（TF 饱和速度）

```
BM25-TF(t, d) = (k₁ + 1) × tf / (k₁ + tf)   [b=0时简化]

k₁ = 0:
  BM25-TF = tf / (0 + tf) = 1  ← 所有非零TF都等于1（布尔模式）

k₁ = 1.2（快速饱和）:
  tf=1: 1.2×1/(1.2+1) = 0.545
  tf=2: 1.2×2/(1.2+2) = 0.750
  tf=5: 1.2×5/(1.2+5) = 0.968
  tf=10: 1.2×10/(1.2+10) = 1.071 ≈ 饱和（最大值=k₁+1=2.2）

k₁ = 2.0（较慢饱和）:
  tf=1: 2×1/(2+1) = 0.667
  tf=2: 2×2/(2+2) = 1.000
  tf=5: 2×5/(2+5) = 1.429
  tf=10: 2×10/(2+10) = 1.667
  tf=∞: → 2+1 = 3.0（上界）

k₁ 取值指南:
  k₁ ∈ [1.2, 2.0]: 最常用范围
  短文档/短查询: k₁ 偏低（1.2）
  长文档/长查询: k₁ 偏高（2.0）
  问答系统: k₁ ≈ 0（有无词条最重要）
```

**k₁ 对 TF 饱和曲线的影响：**
```
BM25-TF
  3.0│                                    ╔══════ k₁=2.0 (上界=3.0)
     │                             ╔══════╝
     │                      ╔══════
  2.2│               ╔══════       ─────── k₁=1.2 (上界=2.2)
     │          ╔════╝
     │      ╔═══
  1.0│  ╔═══
     │╔═
     └─────────────────────────→ tf
        1  2  3  4  5  6  7  8
```

### 3.2 b 参数（文档长度归一化强度）

```
长度归一化因子: norm = 1 - b + b × dl/avgdl

b = 0（不归一化）:
  norm = 1  → BM25-TF = (k₁+1)×tf / (k₁+tf)
  所有文档长度被同等对待

b = 0.5（中等归一化）:
  短文档(dl = 0.5×avgdl): norm = 1-0.5+0.5×0.5 = 0.75
  中等文档(dl = avgdl):   norm = 1-0.5+0.5×1.0 = 1.00
  长文档(dl = 2×avgdl):   norm = 1-0.5+0.5×2.0 = 1.50

b = 1（完全归一化）:
  norm = dl/avgdl
  → BM25-TF = (k₁+1)×tf / (k₁×dl/avgdl + tf)
  → 等价于按文档长度完全归一化

b 取值指南:
  b = 0.75: 标准默认值
  b = 0: 文档长度可信（自然包含更多词条不算缺点）
  b = 1: 文档长度完全是填充（应严格归一化）
  标题/短文: b 偏小（0.3-0.5）
  正文/长文: b 偏大（0.75）
```

### 3.3 参数可视化理解

```
b 对长文档的影响示例:

文档A（短，dl=50，avgdl=100）:  tf("cat")=3
文档B（长，dl=200，avgdl=100）: tf("cat")=3

b=0（不归一化）:
  BM25-TF(A) = BM25-TF(B)  ← 长文档不受惩罚

b=0.75:
  norm_A = 1-0.75+0.75×0.5 = 0.625
  norm_B = 1-0.75+0.75×2.0 = 1.75

  BM25-TF(A) = 2.2×3/(1.2×0.625+3) = 6.6/3.75 = 1.76
  BM25-TF(B) = 2.2×3/(1.2×1.75+3)  = 6.6/5.10 = 1.29
  
  → 短文档A(1.76) > 长文档B(1.29)
  → 相同TF下，短文档得到更高分 ✓

b=1（完全归一化）:
  BM25-TF(A) = 2.2×3/(1.2×0.5+3)  = 6.6/3.60 = 1.83
  BM25-TF(B) = 2.2×3/(1.2×2.0+3)  = 6.6/5.40 = 1.22
  归一化效果最强
```

## 4. BM25 完整代码实现

```python
import math
from collections import defaultdict, Counter
from typing import List, Dict, Tuple, Optional
import numpy as np

class BM25:
    """
    完整 BM25 实现（Okapi BM25）
    
    支持:
    - 标准 BM25（Robertson et al., 1994）
    - BM25+ 变体（避免零分问题）
    - 批量查询
    - 字段权重
    """
    
    def __init__(
        self,
        k1: float = 1.5,
        b: float = 0.75,
        epsilon: float = 0.25,   # BM25+ 的下界参数
        variant: str = "bm25",   # "bm25" 或 "bm25+"
    ):
        """
        Args:
            k1: TF 饱和参数（通常 1.2-2.0）
            b:  文档长度归一化参数（0-1，通常 0.75）
            epsilon: BM25+ 的最低 TF 权重下界
            variant: 使用 BM25 还是 BM25+
        """
        self.k1 = k1
        self.b = b
        self.epsilon = epsilon
        self.variant = variant
        
        # 内部状态
        self.n_docs: int = 0
        self.avgdl: float = 0.0
        self.doc_lengths: List[int] = []
        self.df: Dict[str, int] = defaultdict(int)
        # corpus: 原始词条列表（用于计算TF）
        self.corpus: List[List[str]] = []
    
    def fit(self, corpus: List[List[str]]) -> "BM25":
        """
        从语料库构建 BM25 索引
        
        Args:
            corpus: 已分词的文档列表
        """
        self.corpus = corpus
        self.n_docs = len(corpus)
        self.doc_lengths = [len(doc) for doc in corpus]
        self.avgdl = sum(self.doc_lengths) / max(self.n_docs, 1)
        
        # 统计文档频率（DF）
        self.df = defaultdict(int)
        for doc in corpus:
            for term in set(doc):  # set 去重
                self.df[term] += 1
        
        return self
    
    def _idf(self, term: str) -> float:
        """
        计算 BM25 IDF
        公式: log((N - df + 0.5) / (df + 0.5) + 1)
        """
        df = self.df.get(term, 0)
        if df == 0:
            return 0.0
        
        # Lucene 5+ 使用的版本（加 +1 保证结果为正）
        return math.log((self.n_docs - df + 0.5) / (df + 0.5) + 1)
    
    def _tf_weight(self, tf: int, doc_length: int) -> float:
        """
        计算 BM25 TF 权重（含文档长度归一化）
        """
        # 文档长度归一化因子
        norm = (1 - self.b) + self.b * (doc_length / self.avgdl)
        
        if self.variant == "bm25+":
            # BM25+: 添加下界 δ×(k₁+1)/norm，防止零TF
            delta = self.epsilon
            tf_weight = ((self.k1 + 1) * tf / (self.k1 * norm + tf)) + \
                        (delta * (self.k1 + 1) / norm)
        else:
            # 标准 BM25
            tf_weight = (self.k1 + 1) * tf / (self.k1 * norm + tf)
        
        return tf_weight
    
    def score(self, query: List[str], doc_idx: int) -> float:
        """计算单个文档对查询的 BM25 得分"""
        doc = self.corpus[doc_idx]
        doc_length = self.doc_lengths[doc_idx]
        
        # 统计查询词在该文档中的词频
        doc_tf = Counter(doc)
        
        score = 0.0
        for term in set(query):  # 查询词去重
            tf = doc_tf.get(term, 0)
            if tf == 0:
                continue
            
            idf = self._idf(term)
            tf_weight = self._tf_weight(tf, doc_length)
            score += idf * tf_weight
        
        return score
    
    def search(
        self, 
        query: List[str], 
        top_k: int = 10
    ) -> List[Tuple[int, float]]:
        """
        BM25 检索，返回 top-k 相关文档
        
        Returns:
            [(doc_idx, score), ...] 按分数降序排列
        """
        # 先过滤：只考虑包含至少一个查询词的文档
        # （优化：避免对所有文档打分）
        candidate_docs = set()
        for term in query:
            if term in self.df:
                # 实际实现中这里会查倒排索引
                for doc_idx, doc in enumerate(self.corpus):
                    if term in doc:
                        candidate_docs.add(doc_idx)
        
        # 对候选文档打分
        scores = [
            (doc_idx, self.score(query, doc_idx))
            for doc_idx in candidate_docs
        ]
        
        # 按分数降序排列，返回 top-k
        scores.sort(key=lambda x: x[1], reverse=True)
        return scores[:top_k]
    
    def score_all(self, query: List[str]) -> np.ndarray:
        """
        计算查询对所有文档的 BM25 得分（向量化）
        适用于评估和批量打分
        """
        scores = np.zeros(self.n_docs)
        
        for term in set(query):
            idf = self._idf(term)
            if idf == 0:
                continue
            
            for doc_idx in range(self.n_docs):
                doc_tf = Counter(self.corpus[doc_idx])
                tf = doc_tf.get(term, 0)
                if tf > 0:
                    scores[doc_idx] += idf * self._tf_weight(
                        tf, self.doc_lengths[doc_idx]
                    )
        
        return scores
    
    def explain(self, query: List[str], doc_idx: int) -> Dict:
        """
        解释 BM25 得分的各个组成部分（调试用）
        """
        doc = self.corpus[doc_idx]
        doc_length = self.doc_lengths[doc_idx]
        doc_tf = Counter(doc)
        
        explanation = {
            "query": query,
            "doc_idx": doc_idx,
            "doc_length": doc_length,
            "avgdl": self.avgdl,
            "norm_factor": (1 - self.b) + self.b * (doc_length / self.avgdl),
            "terms": {},
            "total_score": 0.0,
        }
        
        for term in set(query):
            tf = doc_tf.get(term, 0)
            idf = self._idf(term)
            tf_weight = self._tf_weight(tf, doc_length) if tf > 0 else 0.0
            term_score = idf * tf_weight
            
            explanation["terms"][term] = {
                "tf": tf,
                "df": self.df.get(term, 0),
                "idf": round(idf, 4),
                "tf_weight": round(tf_weight, 4),
                "contribution": round(term_score, 4),
            }
            explanation["total_score"] += term_score
        
        explanation["total_score"] = round(explanation["total_score"], 4)
        return explanation


# ─── 演示 ─────────────────────────────────────────────────────────────
if __name__ == "__main__":
    corpus = [
        ["machine", "learning", "algorithms", "classification"],
        ["deep", "learning", "neural", "networks", "training"],
        ["machine", "learning", "python", "programming"],
        ["natural", "language", "processing", "transformers"],
        ["reinforcement", "learning", "reward", "policy"],
        ["machine", "learning", "deep", "reinforcement", "reward"],
    ]
    
    bm25 = BM25(k1=1.5, b=0.75)
    bm25.fit(corpus)
    
    query = ["machine", "learning"]
    results = bm25.search(query, top_k=3)
    
    print(f"查询: {query}")
    for rank, (doc_id, score) in enumerate(results, 1):
        print(f"  [{rank}] Doc{doc_id} (score={score:.4f}): {corpus[doc_id]}")
    
    # 得分解释
    print("\n=== 得分解释 (Doc0) ===")
    exp = bm25.explain(query, 0)
    for term, info in exp["terms"].items():
        print(f"  {term}: tf={info['tf']}, df={info['df']}, "
              f"idf={info['idf']}, tf_weight={info['tf_weight']}, "
              f"贡献={info['contribution']}")
    print(f"  总分: {exp['total_score']}")
```

## 5. BM25+ 变体（修复 BM25 的理论缺陷）

### 5.1 BM25 的长文档异常

**BM25 的问题：** 对于查询词在文档中 TF=0 的情况，贡献为 0。这会导致：

```
场景:
  查询: "cat dog"
  文档A（短，100词）: 含 "cat"(tf=1)，不含 "dog"
  文档B（长，1000词）: 含 "cat"(tf=10)，不含 "dog"

BM25计算（b=0.75, k₁=1.5, avgdl=200）:
  norm_A = 1-0.75+0.75×(100/200) = 0.625
  norm_B = 1-0.75+0.75×(1000/200) = 4.0

  BM25-TF(A) = 2.5×1/(1.5×0.625+1) = 2.5/1.9375 ≈ 1.290
  BM25-TF(B) = 2.5×10/(1.5×4.0+10) = 25/16 = 1.5625

  BM25-TF(B) > BM25-TF(A) 只因为文档B更长？

更极端情况：
  文档C（超长，10000词）: 含 "cat"(tf=1) 和 "dog"(tf=1)
  文档D（中等，100词）: 含 "cat"(tf=1)，不含 "dog"

  BM25(C) = IDF(cat)×TF(cat) + IDF(dog)×TF(dog)  [两词都有分]
  BM25(D) = IDF(cat)×TF(cat)                       [只有cat的分]

  理论上C应该排名更高（包含两个查询词）
  但如果C很长，BM25-TF(cat in C)可能极低，
  导致 BM25(C) < BM25(D)！  ← 违反直觉！
```

### 5.2 BM25+ 公式

```
BM25+(t, d) = IDF(t) × [BM25-TF(t, d) + δ]

其中:
  BM25-TF(t, d) = (k₁+1)×tf / (k₁×norm + tf)
  δ ∈ [0, 1]（通常 δ=1 或 δ=0.5）

BM25+ 保证：即使文档很长，只要词条出现，就有下界贡献
  → 解决了长文档中稀有词条贡献趋零的问题
```

**BM25 vs BM25+ 对比：**

```
k₁=1.5, b=0.75, avgdl=200, δ=1

                dl=50    dl=200   dl=1000
tf=1 BM25:      1.684    1.200    0.357   ← 长文档TF极低！
tf=1 BM25+:     2.684    2.200    1.357   ← 增加下界，不会太低
tf=5 BM25:      2.188    1.923    0.858
tf=5 BM25+:     3.188    2.923    1.858
```

## 6. BM25F：多字段 BM25

BM25F（BM25 with Fields）由 Robertson 等在 2004 年提出，专为处理多字段文档设计。

### 6.1 直觉：字段合并策略

**错误做法：** 对每个字段独立计算 BM25，然后加权平均

```
❌ score(q, d) = w_title × BM25_title(q, d) + w_body × BM25_body(q, d)

问题：title 中 TF=5 与 body 中 TF=5 权重相同，
      但 title 更短，title 中 TF=5 意味着更高的集中度
```

**正确做法：BM25F 先加权合并 TF，再计算 BM25**

```
✓ 伪 TF（Pseudo TF）:
   tf̃(t, d) = Σ_f wf × tf(t, d, f) / norm_f(d)

  其中 norm_f(d) = 1 - b_f + b_f × dl_f(d) / avgdl_f

然后用 tf̃ 计算 BM25:
  BM25F(t, d) = (k₁ + 1) × tf̃ / (k₁ + tf̃)
```

### 6.2 BM25F 完整公式

```
             (k₁ + 1) × tf̃(t, d)
BM25F(t, d) = ─────────────────────
              k₁ + tf̃(t, d)

其中:
              wf × tf(t, d, f)
tf̃(t, d) = Σ_f ──────────────────────────────
              1 - b_f + b_f × (dl_f(d) / avgdl_f)

字段参数:
  wf: 字段权重（title=3, anchor=2, body=1 等）
  b_f: 字段特定的长度归一化参数
  dl_f(d): 文档 d 在字段 f 的长度
  avgdl_f: 所有文档在字段 f 的平均长度
```

### 6.3 BM25F 代码实现

```python
class BM25F:
    """
    BM25F 多字段 BM25 实现
    """
    
    def __init__(
        self,
        k1: float = 1.5,
        field_weights: Dict[str, float] = None,
        field_b: Dict[str, float] = None,
    ):
        self.k1 = k1
        self.field_weights = field_weights or {
            "title": 3.0,
            "body": 1.0,
            "anchor": 2.0,
        }
        self.field_b = field_b or {
            "title": 0.3,    # 标题较短，b 较小
            "body": 0.75,    # 正文标准归一化
            "anchor": 0.5,
        }
        self.avgdl: Dict[str, float] = {}
        self.n_docs = 0
        self.df: Dict[str, int] = defaultdict(int)
        self.corpus: List[Dict[str, List[str]]] = []
    
    def fit(self, corpus: List[Dict[str, List[str]]]) -> "BM25F":
        """
        corpus: [{"title": [...], "body": [...], "anchor": [...]}, ...]
        """
        self.corpus = corpus
        self.n_docs = len(corpus)
        
        # 计算各字段平均长度
        for field in self.field_weights:
            total_len = sum(len(doc.get(field, [])) for doc in corpus)
            self.avgdl[field] = total_len / max(self.n_docs, 1)
        
        # 统计 DF（跨字段去重）
        for doc in corpus:
            all_terms = set()
            for field_tokens in doc.values():
                all_terms.update(field_tokens)
            for term in all_terms:
                self.df[term] += 1
        
        return self
    
    def _pseudo_tf(self, term: str, doc: Dict[str, List[str]]) -> float:
        """计算伪词频（加权多字段TF）"""
        pseudo_tf = 0.0
        
        for field, weight in self.field_weights.items():
            field_tokens = doc.get(field, [])
            tf = field_tokens.count(term)
            if tf == 0:
                continue
            
            dl = len(field_tokens)
            avgdl = self.avgdl.get(field, 1)
            b = self.field_b.get(field, 0.75)
            
            norm = (1 - b) + b * (dl / avgdl)
            pseudo_tf += weight * tf / norm
        
        return pseudo_tf
    
    def score(self, query: List[str], doc_idx: int) -> float:
        """计算 BM25F 得分"""
        doc = self.corpus[doc_idx]
        total_score = 0.0
        
        for term in set(query):
            df = self.df.get(term, 0)
            if df == 0:
                continue
            
            # IDF（与 BM25 相同）
            idf = math.log((self.n_docs - df + 0.5) / (df + 0.5) + 1)
            
            # 伪 TF
            pseudo_tf = self._pseudo_tf(term, doc)
            if pseudo_tf == 0:
                continue
            
            # BM25F 打分
            bm25f_tf = (self.k1 + 1) * pseudo_tf / (self.k1 + pseudo_tf)
            total_score += idf * bm25f_tf
        
        return total_score
```

## 7. BM25 参数调优指南

### 7.1 通用参数范围

| 参数 | 典型范围 | Elasticsearch 默认 | 含义 |
|------|---------|------------------|------|
| k₁ | 1.0 - 2.0 | 1.2 | TF 饱和速度 |
| b | 0.0 - 1.0 | 0.75 | 长度归一化强度 |

### 7.2 按场景调整

| 场景 | k₁ 建议 | b 建议 | 原因 |
|------|---------|-------|------|
| 网页搜索 | 1.2-1.5 | 0.75 | 标准设置 |
| 短查询（1-2词） | 1.2 | 0.75 | 快速饱和 |
| 长查询（问答） | 1.5-2.0 | 0.75 | 词频更重要 |
| 文档标题检索 | 1.0-1.2 | 0.3-0.5 | 标题短，弱化长度归一化 |
| 法律/医疗文档 | 1.5-2.0 | 0.5-0.75 | 长文档，需要归一化 |
| 代码搜索 | 1.0-1.5 | 0.5 | 代码长度差异大 |

### 7.3 调参方法：网格搜索

```python
def tune_bm25_parameters(
    train_queries: List[Tuple[List[str], List[int]]],  # (query, relevant_doc_ids)
    corpus: List[List[str]],
    k1_range: List[float] = [0.5, 1.0, 1.2, 1.5, 2.0],
    b_range: List[float] = [0.0, 0.25, 0.5, 0.75, 1.0],
) -> Tuple[float, float]:
    """
    使用网格搜索调优 BM25 参数
    评估指标: MAP (Mean Average Precision)
    """
    best_map = -1
    best_k1, best_b = 1.5, 0.75
    
    for k1 in k1_range:
        for b in b_range:
            bm25 = BM25(k1=k1, b=b).fit(corpus)
            
            # 计算 MAP
            ap_scores = []
            for query, relevant_ids in train_queries:
                results = bm25.search(query, top_k=20)
                retrieved_ids = [doc_id for doc_id, _ in results]
                ap = average_precision(retrieved_ids, set(relevant_ids))
                ap_scores.append(ap)
            
            mean_ap = sum(ap_scores) / len(ap_scores)
            
            if mean_ap > best_map:
                best_map = mean_ap
                best_k1, best_b = k1, b
    
    print(f"最佳参数: k₁={best_k1}, b={best_b}, MAP={best_map:.4f}")
    return best_k1, best_b

def average_precision(retrieved: List[int], relevant: set) -> float:
    """计算平均精度（AP）"""
    if not relevant:
        return 0.0
    precisions = []
    num_relevant = 0
    for i, doc_id in enumerate(retrieved):
        if doc_id in relevant:
            num_relevant += 1
            precisions.append(num_relevant / (i + 1))
    return sum(precisions) / len(relevant)
```

## 8. BM25 与 TF-IDF 深度对比

| 维度 | TF-IDF (VSM) | BM25 |
|------|-------------|------|
| **理论基础** | 代数/启发式 | 概率检索框架 |
| **TF 上界** | 无上界（线性） | 有上界（k₁+1） |
| **长度归一化** | 通过 L2 归一化（全局） | 显式 b 参数（局部） |
| **多字段支持** | 需要手动加权 | BM25F 原生支持 |
| **参数数量** | 0（无需调参） | 2（k₁, b） |
| **实现复杂度** | 低 | 中等 |
| **实际效果** | 良好 | 更好（尤其长文档）|
| **工业应用** | 历史遗留系统 | 现代搜索引擎默认 |
| **Elasticsearch** | 历史默认(5.0前) | 当前默认(5.0+) |

## 9. BM25 的局限性

```
1. 词袋模型（Bag of Words）
   忽略词序："cat ate mouse" = "mouse ate cat"

2. 词汇鸿沟（Vocabulary Mismatch）
   查询 "car" 无法匹配文档 "automobile"
   解决：同义词扩展、Dense Retrieval

3. 无语义理解
   "bank"（银行 vs 河岸）无法区分
   解决：上下文感知模型（BERT等）

4. 短查询效果有限
   单词查询时 k₁ 几乎不起作用
   解决：查询扩展（PRF）

5. 独立性假设
   假设词条独立，忽略词条间相关性
   解决：基于神经网络的交互式排序

总结：BM25 是传统检索的天花板，现代混合系统中
通常作为"第一阶段检索（First-stage Retrieval）"，
之后由神经网络模型进行"重排序（Re-ranking）"
```
