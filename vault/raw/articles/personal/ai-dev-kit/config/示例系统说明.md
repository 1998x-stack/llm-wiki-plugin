# UrhoX 示例系统使用说明

## 快速开始

### 第一次使用

```bash
# 1. 验证配置（确保一切正常）
python tools/process_examples.py --validate

# 2. 生成示例和文档
python tools/process_examples.py
```

运行后会自动：
- ✅ 复制 25 个示例文件到 `ai-dev-kit/examples/`
- ✅ 生成示例索引文档 `examples/index.md`
- ✅ 生成 API 索引文档 `examples/api-index.md`

### 查看示例

生成后可以：
1. 打开 `ai-dev-kit/examples/index.md` 浏览所有示例
2. 按分类查找（3D图形、2D图形、物理、UI等）
3. 按难度筛选（初级🌱、中级🌿、高级🌳）
4. 在 `examples/api-index.md` 中按 API 查找

## 系统结构

```
配置文件 (config/examples-config.yaml)
    ↓
处理脚本 (tools/process_examples.py)
    ↓
    ├─→ 复制示例文件
    ├─→ 生成主索引
    └─→ 生成API索引
```

## 主要文件

| 文件 | 说明 | 用途 |
|------|------|------|
| `config/examples-config.yaml` | 核心配置文件 | 定义所有示例的信息 |
| `tools/process_examples.py` | 处理脚本 | 自动生成文档 |
| `examples/index.md` | 示例索引 | 浏览所有示例 |
| `examples/api-index.md` | API索引 | 查找API用法 |
| `examples/*.lua` | 示例代码 | Lua示例文件 |

## 添加新示例

### 步骤

1. **编辑配置文件** `config/examples-config.yaml`

```yaml
examples:
  - source: "99_NewExample.lua"        # 源文件
    target: "26-new-example.lua"       # 目标文件名
    metadata:
      title:
        en: "New Example"
        zh: "新示例"
      category: "3d-graphics"          # 分类
      difficulty: "intermediate"       # 难度
      description: "这是一个新示例"    # 描述
      features:                        # 功能列表
        - "功能1"
        - "功能2"
      apis:                            # 使用的API
        - "Scene"
        - "Node"
      concepts:                        # 核心概念
        - "概念1"
      tags:                            # 标签
        - "3d"
        - "example"
```

2. **验证配置**

```bash
python tools/process_examples.py --validate
```

3. **预览效果**（不实际写文件）

```bash
python tools/process_examples.py --dry-run
```

4. **正式生成**

```bash
python tools/process_examples.py
```

### 填写指南

#### 分类 (category)

可选值：
- `3d-graphics` - 3D图形
- `2d-graphics` - 2D图形
- `physics` - 3D物理
- `physics-2d` - 2D物理
- `ui` - 用户界面
- `audio` - 音频
- `network` - 网络
- `animation` - 动画
- `navigation` - 导航与AI
- `advanced` - 高级特性

#### 难度 (difficulty)

- `beginner` 🌱 - 初级（< 200行，单一功能）
- `intermediate` 🌿 - 中级（200-400行，多个功能）
- `advanced` 🌳 - 高级（> 400行，复杂系统）

#### 文件命名

格式：`{序号}-{名称}.lua`

✅ 正确：
- `01-hello-world.lua`
- `07-physics-3d.lua`
- `18-2d-platformer-game.lua`

❌ 错误：
- `1-HelloWorld.lua`
- `07_Physics3D.lua`

## 常见问题

### Q: 如何更新示例？

A: 修改 `config/examples-config.yaml` 后重新运行处理脚本。

### Q: 为什么要运行处理脚本？

A: 配置文件只是描述，需要运行脚本才能生成实际的文件和文档。

### Q: 可以手动编辑生成的文档吗？

A: 不建议。手动修改会在下次运行脚本时被覆盖。应该修改配置文件后重新生成。

### Q: 源文件变化了怎么办？

A: 重新运行处理脚本会复制最新的源文件。

### Q: 如何添加新的分类？

A: 在 `config/examples-config.yaml` 的 `categories` 部分添加新分类定义。
