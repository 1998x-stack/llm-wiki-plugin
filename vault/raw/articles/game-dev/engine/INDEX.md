# UrhoX 文档索引

## 目录结构

| 目录 | 类型 | 生命周期 | 防腐策略 | 说明 |
|------|------|----------|----------|------|
| [design/](design/INDEX.md) | 架构设计 | 长期维护 | 代码变更时交叉检查；定期巡检 | 系统架构、技术方案 |
| [plans/](plans/INDEX.md) | 实施计划 | 短期（周~月） | 完成后转 design/ 或删除；超期提醒 | 进行中的开发计划 |
| [guides/](guides/INDEX.md) | 操作手册 | 持续维护 | 与代码同步更新 | API 参考、开发指南、工具手册 |
| [research/](research/INDEX.md) | 调研参考 | 只读 | 标注分析日期；不需主动维护 | 技术调研、优化分析 |
| [gotchas/](gotchas/) | 开发陷阱 | 持续维护 | 遇到新问题时补充 | 开发经验库 |

## 文件命名规范

- 统一 **kebab-case**: 全小写 + 连字符，如 `animation-system-design.md`
- 英文命名，无中文文件名

## 文档生命周期

```
plans/ (实施中) ──完成──> design/ (长期维护)
                 └─过期──> 删除
```
