## 一、历史背景：词的"意义"如何编码？

Word2Vec 之前，NLP 中的词通常用 **one-hot 编码**：

```
词汇表：[猫, 狗, 汽车, 苹果]（共 4 个词）

"猫" → [1, 0, 0, 0]
"狗" → [0, 1, 0, 0]

问题一：维度爆炸（10 万个词 → 10 万维稀疏向量）
问题二：无法表达语义关系
  cosine("猫", "狗") = 0
  cosine("猫", "汽车") = 0    ← 完全相同！
```

语言学早有共识（Firth, 1957）：

> **"A word is characterized by the company it keeps."**  
> （词的意义由其上下文决定）

Word2Vec 将这个语言学直觉变成了可学习的神经网络——用**上下文预测词**或**用词预测上下文**，训练出稠密、低维、语义丰富的词向量。

---

## 二、两种模型架构

### 2.1 Skip-gram：用中心词预测上下文（主要模型）

```
上下文窗口 = 2：

句子：我 爱 [北京] 天安门
                ↑ 中心词

目标：最大化 P(我|北京) · P(爱|北京) · P(天安门|北京)

网络：
  北京 → [Embedding 层, 300维] → 隐向量 v
     → [输出层 + Softmax] → 词表上的概率分布
```

### 2.2 CBOW：用上下文预测中心词

```
句子：我 爱 [?] 天安门

输入：{我, 爱, 天安门} 的词向量平均
目标：预测 "北京"

CBOW 训练更快，但对低频词效果较差
Skip-gram 对低频词和生僻词效果更好（本文重点）
```

---

## 三、负采样（Negative Sampling）：让训练变得可行

**原始 Softmax 的问题**：

```
P(上下文词 w_o | 中心词 w_c) = exp(v'ᵀ v) / Σ_{w=1}^{V} exp(v'_w ᵀ v)
                                                  ↑
                                         对所有 V≈10万个词求和
                                         → 每步更新 10 万个参数！
```

**负采样**：每次只更新正样本 + K 个随机负样本（K=5~20）：

```
目标函数（代替 Softmax）：
  log σ(v'ᵀ_wo · vc) + Σₖ₌₁ᴷ E_{wₖ~Pₙ}[log σ(-v'ᵀ_wₖ · vc)]

正样本 (北京, 天安门)：输出接近 1
负样本 (北京, 随机词₁) ... K 个：输出接近 0

每步只更新 K+1 个词向量！速度提升 1000 倍以上
```

**负样本采样策略**：按词频的 3/4 次方采样 `P(w) ∝ freq(w)^(3/4)`，这一魔法数字让高频词采样概率适度降低，低频词适度提升。

---

## 四、词向量的神奇语义性质

训练后的 300 维向量空间中出现了令人惊叹的线性关系：

```
king - man + woman ≈ queen     （性别类比）
Paris - France + Italy ≈ Rome  （国家-首都关系）
walked - walk + swim ≈ swam    （动词时态变化）
China - Chinese + Japanese ≈ Japan  （语言-国家关系）
```

**几何解释**：向量空间中存在**语义方向（Semantic Direction）**：

```
         queen ●
        ↗
king ●     ← "king - man + woman" 这个向量差
        ↘       正好指向 queen 的方向
         man ●

某个维度方向编码"皇室"
某个方向编码"国家→首都"
某个方向编码"动词时态"
```

---

## 五、高频词下采样

训练时对高频词做降采样，减少 "the"、"a" 等无信息词的影响：

```
丢弃概率：P(wᵢ) = 1 - √(t / freq(wᵢ))

其中 t = 1e-5（阈值参数）
freq(wᵢ) 是词 wᵢ 的频率

高频词（如 "the"）：频率高 → 丢弃概率高
低频词（如 "量子纠缠"）：频率低 → 几乎不丢弃
```

## 六、完整代码实现

```python
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
from collections import Counter
from typing import List, Tuple, Dict, Optional
import re


# ── 数据预处理 ────────────────────────────────────────

class Vocabulary:
    """词汇表构建与管理"""

    def __init__(self, min_freq: int = 5, max_size: int = 50000):
        self.min_freq = min_freq
        self.max_size = max_size
        self.word2idx: Dict[str, int] = {}
        self.idx2word: Dict[int, str] = {}
        self.word_freq: Dict[str, int] = {}

    def build(self, corpus: List[List[str]]) -> "Vocabulary":
        """从语料库构建词汇表"""
        counter = Counter(word for sent in corpus for word in sent)
        # 过滤低频词，按频率排序
        words = [w for w, f in counter.most_common(self.max_size)
                 if f >= self.min_freq]
        self.word2idx = {w: i for i, w in enumerate(words)}
        self.idx2word = {i: w for w, i in self.word2idx.items()}
        self.word_freq = {w: counter[w] for w in words}
        print(f"  词汇表大小：{len(self.word2idx)} 个词")
        return self

    def __len__(self) -> int:
        return len(self.word2idx)

    def get_negative_sample_probs(self) -> np.ndarray:
        """按词频 3/4 次方计算负采样概率"""
        freqs = np.array([self.word_freq[self.idx2word[i]]
                          for i in range(len(self))])
        probs = freqs ** 0.75
        return probs / probs.sum()


class SkipGramDataset(Dataset):
    """Skip-gram 训练数据集"""

    def __init__(self, corpus: List[List[str]], vocab: Vocabulary,
                 window_size: int = 5, n_negatives: int = 5,
                 subsample_t: float = 1e-5):
        self.vocab = vocab
        self.n_neg = n_negatives
        self.neg_probs = vocab.get_negative_sample_probs()

        # 构建 (中心词, 上下文词) 对
        self.pairs: List[Tuple[int, int]] = []
        for sent in corpus:
            ids = [vocab.word2idx[w] for w in sent if w in vocab.word2idx]
            # 高频词下采样
            ids = [w for w in ids
                   if np.random.random() > 1 - np.sqrt(
                       subsample_t / (vocab.word_freq.get(vocab.idx2word[w], 1)
                                      / sum(vocab.word_freq.values())))]
            for i, center in enumerate(ids):
                # 动态窗口：每次随机减小窗口大小
                win = np.random.randint(1, window_size + 1)
                for j in range(max(0, i - win), min(len(ids), i + win + 1)):
                    if j != i:
                        self.pairs.append((center, ids[j]))

    def __len__(self) -> int:
        return len(self.pairs)

    def __getitem__(self, idx: int) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
        center, context = self.pairs[idx]
        # 负采样
        negatives = np.random.choice(len(self.vocab), self.n_neg,
                                     p=self.neg_probs, replace=False)
        return (torch.tensor(center, dtype=torch.long),
                torch.tensor(context, dtype=torch.long),
                torch.tensor(negatives, dtype=torch.long))


# ── Skip-gram 模型 ───────────────────────────────────

class Word2VecSkipGram(nn.Module):
    """
    Skip-gram Word2Vec（Mikolov et al., 2013）
    使用负采样目标函数（Negative Sampling Loss）
    """

    def __init__(self, vocab_size: int, embed_dim: int = 300):
        """
        Args:
            vocab_size: 词汇表大小
            embed_dim:  词嵌入维度（论文使用 100~300）
        """
        super().__init__()
        # 中心词嵌入矩阵（输入矩阵）
        self.center_embed = nn.Embedding(vocab_size, embed_dim, sparse=True)
        # 上下文词嵌入矩阵（输出矩阵）
        self.context_embed = nn.Embedding(vocab_size, embed_dim, sparse=True)

        # 初始化（均匀分布，范围小）
        nn.init.uniform_(self.center_embed.weight, -0.5 / embed_dim, 0.5 / embed_dim)
        nn.init.zeros_(self.context_embed.weight)

    def forward(self, center: torch.Tensor,
                context: torch.Tensor,
                negatives: torch.Tensor) -> torch.Tensor:
        """
        负采样损失计算

        Args:
            center:    (B,)    中心词 ID
            context:   (B,)    正样本上下文词 ID
            negatives: (B, K)  负样本 ID

        Returns:
            loss: 标量，负采样损失
        """
        v_c   = self.center_embed(center)          # (B, D)
        v_pos = self.context_embed(context)         # (B, D)
        v_neg = self.context_embed(negatives)        # (B, K, D)

        # 正样本：最大化 log σ(v_c · v_pos)
        pos_score = (v_c * v_pos).sum(dim=1)        # (B,)
        pos_loss  = -torch.log(torch.sigmoid(pos_score) + 1e-10)

        # 负样本：最大化 Σ log σ(-v_c · v_neg)
        neg_score = torch.bmm(v_neg, v_c.unsqueeze(2)).squeeze(2)  # (B, K)
        neg_loss  = -torch.log(torch.sigmoid(-neg_score) + 1e-10).sum(dim=1)

        return (pos_loss + neg_loss).mean()

    def get_word_vector(self, word_id: int) -> np.ndarray:
        """获取词向量（推荐使用中心词嵌入矩阵）"""
        with torch.no_grad():
            return self.center_embed.weight[word_id].numpy()

    def most_similar(self, word_id: int, vocab: Vocabulary, topn: int = 5) -> List[Tuple[str, float]]:
        """找到最相似的词"""
        with torch.no_grad():
            all_vecs = self.center_embed.weight.numpy()          # (V, D)
            target   = all_vecs[word_id]                          # (D,)
            # 余弦相似度
            norms = np.linalg.norm(all_vecs, axis=1, keepdims=True) + 1e-10
            sims  = (all_vecs @ target) / (norms.ravel() * np.linalg.norm(target))
            sims[word_id] = -1  # 排除自身
            top_ids = np.argsort(sims)[::-1][:topn]
            return [(vocab.idx2word[i], float(sims[i])) for i in top_ids]

    def analogy(self, a: int, b: int, c: int, vocab: Vocabulary) -> str:
        """词类比：a - b + c ≈ ?"""
        with torch.no_grad():
            W = self.center_embed.weight.numpy()
            target = W[b] - W[a] + W[c]
            norms  = np.linalg.norm(W, axis=1, keepdims=True) + 1e-10
            sims   = (W @ target) / (norms.ravel() * np.linalg.norm(target))
            for idx in [a, b, c]:
                sims[idx] = -1
            best = np.argmax(sims)
            return vocab.idx2word[best]


# ── 训练函数 ─────────────────────────────────────────

def train_word2vec(corpus: List[List[str]],
                   embed_dim: int = 100,
                   window_size: int = 5,
                   n_negatives: int = 5,
                   epochs: int = 3,
                   batch_size: int = 512,
                   lr: float = 0.025) -> Tuple[Word2VecSkipGram, Vocabulary]:
    """Word2Vec Skip-gram 完整训练流程"""
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

    # 构建词汇表
    vocab = Vocabulary(min_freq=2).build(corpus)

    # 构建数据集
    dataset = SkipGramDataset(corpus, vocab, window_size, n_negatives)
    loader  = DataLoader(dataset, batch_size=batch_size, shuffle=True, num_workers=0)

    # 模型
    model = Word2VecSkipGram(len(vocab), embed_dim).to(device)
    # 论文使用 SGD，学习率线性衰减
    optimizer = optim.SparseAdam(model.parameters(), lr=lr)

    print(f"  训练对数：{len(dataset):,}  批次：{len(loader):,}")
    for epoch in range(1, epochs + 1):
        total_loss = 0.0
        for step, (center, context, neg) in enumerate(loader):
            center, context, neg = center.to(device), context.to(device), neg.to(device)
            optimizer.zero_grad()
            loss = model(center, context, neg)
            loss.backward()
            optimizer.step()
            total_loss += loss.item()
            if (step + 1) % 500 == 0:
                print(f"    Epoch {epoch} Step {step+1}/{len(loader)} | "
                      f"Loss {total_loss/(step+1):.4f}")
        print(f"  Epoch {epoch} 完成，平均 Loss {total_loss/len(loader):.4f}")

    return model, vocab


# ── 演示 ──────────────────────────────────────────────
if __name__ == "__main__":
    # 小规模语料演示（实际使用应替换为 Wikipedia/BooksCorpus）
    sample_corpus = [
        "国王在宫殿里生活 国王娶了王后 王后是女性".split(),
        "巴黎是法国的首都 北京是中国的首都 东京是日本的首都".split(),
        "猫和狗是宠物 猫喜欢鱼 狗喜欢骨头".split(),
    ] * 100   # 重复以便有足够训练数据

    print("=== Word2Vec Skip-gram 训练 ===")

    # 使用 gensim 预训练模型（实际工作中）
```

## 七、Word2Vec 的演化谱系

```
Word2Vec（2013，Google）
  Skip-gram + CBOW + 负采样
  ↓
GloVe（2014，Stanford）
  全局词共现矩阵分解 + 局部上下文窗口
  ↓
FastText（2016，Facebook）
  子词嵌入（character n-gram）→ 处理未登录词
  ↓
ELMo（2018，AllenNLP）
  深层双向 LSTM → 上下文相关的词向量（同一词在不同语境有不同表示）
  ↓
BERT（2018，Google）
  Transformer + 预训练 → 完全上下文化的表示
  ↓
当今大模型内置的词嵌入层（仍然是 Word2Vec 的直系后裔）
```
