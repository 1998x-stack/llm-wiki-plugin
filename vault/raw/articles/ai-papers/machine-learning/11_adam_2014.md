## 一、历史背景：梯度下降的困境

神经网络训练本质是在高维损失曲面上寻找最低点。最基本的随机梯度下降（SGD）：

```
θ ← θ - η · ∇L(θ)
```

实际使用中存在四大痛点：

```
问题 1：学习率 η 难以选取
  η 太大 → 震荡不收敛
  η 太小 → 收敛极慢

问题 2：所有参数共用同一学习率
  词嵌入的高频词梯度大，低频词梯度近乎 0
  用同一 η 更新：高频词步子太大，低频词几乎不动

问题 3：鞍点（Saddle Point）
  高维空间中鞍点极多，梯度为 0 但不是局部最优
  SGD 在鞍点附近梯度极小，更新极慢

问题 4：梯度尺度差异巨大
  不同层、不同参数的梯度量级可能相差千倍
  统一 η 无法照顾所有参数
```

Adam（Adaptive Moment Estimation）结合了两种成熟技术的优点，几乎完美地解决了上述问题。

---

## 二、Adam 的前身：两项关键技术

### Momentum（动量）

```
mₜ = β₁ · mₜ₋₁ + (1-β₁) · gₜ     ← 梯度的指数移动平均（一阶矩）
θ  ← θ - η · mₜ

直觉：给梯度下降加"惯性"
  方向一致时：动量累积，步子越迈越大（加速）
  方向震荡时：动量相互抵消，步子缩小（减速）
类比：一个球在碗里滚，有惯性就不容易被噪声偏转
```

### RMSProp（自适应学习率）

```
vₜ = β₂ · vₜ₋₁ + (1-β₂) · gₜ²   ← 梯度平方的指数移动平均（二阶矩）
θ  ← θ - η / (√vₜ + ε) · gₜ

直觉：梯度大的参数 → vₜ 大 → 有效学习率 η/√vₜ 小（自动减速）
      梯度小的参数 → vₜ 小 → 有效学习率 η/√vₜ 大（自动加速）
→ 每个参数有自适应的有效学习率
```

---

## 三、Adam = Momentum + RMSProp + 偏差修正

```
算法（每步更新）：

gₜ  ← ∇θ L(θ)                        1. 计算当前梯度

mₜ  ← β₁ · mₜ₋₁ + (1-β₁) · gₜ      2. 更新一阶矩（梯度均值）
vₜ  ← β₂ · vₜ₋₁ + (1-β₂) · gₜ²     3. 更新二阶矩（梯度方差）

m̂ₜ  ← mₜ / (1 - β₁ᵗ)                4. 偏差修正：一阶矩
v̂ₜ  ← vₜ / (1 - β₂ᵗ)                5. 偏差修正：二阶矩

θₜ  ← θₜ₋₁ - η · m̂ₜ / (√v̂ₜ + ε)   6. 参数更新
```

**论文推荐默认超参数**：

| 参数 | 默认值 | 含义 |
|------|--------|------|
| η | 0.001 | 学习率 |
| β₁ | 0.9 | 一阶矩衰减率（动量系数） |
| β₂ | 0.999 | 二阶矩衰减率 |
| ε | 1e-8 | 防止除零的小常数 |

这组默认值在绝大多数任务上**开箱即用，无需调整**。

---

## 四、偏差修正的必要性

初始时 m₀ = v₀ = 0，不修正会导致早期严重低估：

```
设 β₁ = 0.9，第 1 步：
  m₁ = 0.9 × 0 + 0.1 × g₁ = 0.1 × g₁    ← 仅为真实梯度的 10%！

偏差修正后：
  m̂₁ = m₁ / (1 - 0.9¹) = m₁ / 0.1 = g₁  ← 恢复真实梯度

→ 训练初期更新幅度合理，收敛更快
```

随着 t 增大，(1 - β₁ᵗ) → 1，修正项自动消失，后期几乎无影响。

---

## 五、Adam 的自适应直觉

```
参数 θⱼ 的梯度在最近 10 步均为 +1（稳定方向）：
  m̂ ≈ 1，v̂ ≈ 1
  有效学习率 ≈ η / √1 = η（正常步长）

参数 θₖ 的梯度在最近 10 步为 ±10（剧烈震荡）：
  m̂ ≈ 0，v̂ ≈ 100
  有效学习率 ≈ η / √100 = η/10（自动减速！）

→ Adam 为震荡参数降速，为稳定参数保持正常速度
→ 无需手动调整每个参数的学习率
```

## 六、完整代码实现

```python
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
from typing import List, Optional, Tuple


class AdamOptimizer:
    """
    Adam 优化器完整实现（Kingma & Ba, 2014）
    从零手写，展示完整数学细节
    """

    def __init__(self, params: List[np.ndarray],
                 lr: float = 1e-3,
                 betas: Tuple[float, float] = (0.9, 0.999),
                 eps: float = 1e-8,
                 weight_decay: float = 0.0):
        """
        Args:
            params:       参数列表（NumPy 数组）
            lr:           学习率 η
            betas:        (β₁, β₂) 一阶/二阶矩衰减率
            eps:          数值稳定项 ε
            weight_decay: L2 正则化系数（AdamW 风格解耦）
        """
        self.params = params
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.weight_decay = weight_decay

        # 为每个参数初始化一阶矩 m 和二阶矩 v
        self.m = [np.zeros_like(p) for p in params]   # 一阶矩（动量）
        self.v = [np.zeros_like(p) for p in params]   # 二阶矩（自适应学习率）
        self.t = 0                                      # 时间步（用于偏差修正）

    def step(self, grads: List[np.ndarray]) -> None:
        """
        执行一步 Adam 更新

        Args:
            grads: 与 params 对应的梯度列表
        """
        self.t += 1
        lr_t = self.lr * (np.sqrt(1 - self.beta2 ** self.t)
                          / (1 - self.beta1 ** self.t))
        # 注：lr_t 已含偏差修正，等价于 η · m̂ / (√v̂ + ε)

        for i, (param, grad) in enumerate(zip(self.params, grads)):
            # 权重衰减（L2 正则化）
            if self.weight_decay != 0.0:
                grad = grad + self.weight_decay * param

            # 一阶矩更新（梯度的指数移动平均）
            self.m[i] = self.beta1 * self.m[i] + (1 - self.beta1) * grad

            # 二阶矩更新（梯度平方的指数移动平均）
            self.v[i] = self.beta2 * self.v[i] + (1 - self.beta2) * grad ** 2

            # 参数更新（lr_t 已含偏差修正）
            param -= lr_t * self.m[i] / (np.sqrt(self.v[i]) + self.eps)

    def get_effective_lr(self, param_idx: int) -> float:
        """计算当前参数的有效学习率（调试用）"""
        v_hat = self.v[param_idx] / (1 - self.beta2 ** self.t)
        return float(np.mean(self.lr / (np.sqrt(v_hat) + self.eps)))


class AdamWOptimizer(AdamOptimizer):
    """
    AdamW（Loshchilov & Hutter, 2019）
    修正了 Adam 中权重衰减的实现方式
    
    Adam 中的权重衰减：grad += λ·w（等价于 L2 正则，但与自适应学习率耦合）
    AdamW 中的权重衰减：w -= η·λ·w（直接对参数做衰减，与梯度解耦）
    
    Transformer 系列模型推荐使用 AdamW。
    """

    def step(self, grads: List[np.ndarray]) -> None:
        self.t += 1
        lr_t = self.lr * (np.sqrt(1 - self.beta2 ** self.t)
                          / (1 - self.beta1 ** self.t))

        for i, (param, grad) in enumerate(zip(self.params, grads)):
            # AdamW：先做权重衰减（与梯度步骤解耦）
            if self.weight_decay != 0.0:
                param *= (1 - self.lr * self.weight_decay)

            # 正常 Adam 更新（不加 L2 梯度）
            self.m[i] = self.beta1 * self.m[i] + (1 - self.beta1) * grad
            self.v[i] = self.beta2 * self.v[i] + (1 - self.beta2) * grad ** 2
            param -= lr_t * self.m[i] / (np.sqrt(self.v[i]) + self.eps)


def optimizer_comparison_demo():
    """
    对比 SGD / SGD+Momentum / RMSProp / Adam 在 Rosenbrock 函数上的收敛速度
    Rosenbrock：f(x,y) = (1-x)² + 100(y-x²)²，全局最小值在 (1,1)
    """
    def rosenbrock(x): return (1 - x[0])**2 + 100 * (x[1] - x[0]**2)**2
    def rosenbrock_grad(x):
        return np.array([
            -2*(1 - x[0]) - 400*x[0]*(x[1] - x[0]**2),
             200*(x[1] - x[0]**2)
        ])

    results = {}
    start = np.array([-1.5, 2.0])

    # SGD
    x = start.copy()
    for i in range(2000):
        x -= 1e-3 * rosenbrock_grad(x)
    results["SGD"] = rosenbrock(x)

    # SGD + Momentum
    x, v = start.copy(), np.zeros(2)
    for i in range(2000):
        g = rosenbrock_grad(x)
        v = 0.9 * v + g
        x -= 1e-3 * v
    results["SGD+Momentum"] = rosenbrock(x)

    # RMSProp
    x, sq = start.copy(), np.zeros(2)
    for i in range(2000):
        g = rosenbrock_grad(x)
        sq = 0.999 * sq + 0.001 * g**2
        x -= 1e-3 / (np.sqrt(sq) + 1e-8) * g
    results["RMSProp"] = rosenbrock(x)

    # Adam
    x = start.copy()
    opt = AdamOptimizer([x], lr=1e-2)
    for i in range(2000):
        g = rosenbrock_grad(x)
        opt.step([g])
    results["Adam"] = rosenbrock(x)

    print("  2000步后各优化器的函数值（越小越好，最小值=0 at (1,1)）：")
    for name, val in results.items():
        print(f"    {name:<20}: {val:.6f}")


# ── PyTorch 中的 Adam 使用 ────────────────────────────
def pytorch_adam_examples():
    """展示 PyTorch 中 Adam 及其变体的使用"""
    model = nn.Sequential(
        nn.Linear(64, 256), nn.ReLU(),
        nn.Linear(256, 10)
    )

    # 标准 Adam
    opt_adam = optim.Adam(
        model.parameters(),
        lr=1e-3,
        betas=(0.9, 0.999),
        eps=1e-8,
        weight_decay=0.0
    )

    # AdamW（Transformer 标配）
    opt_adamw = optim.AdamW(
        model.parameters(),
        lr=1e-4,
        betas=(0.9, 0.999),
        weight_decay=0.01    # 正确解耦的权重衰减
    )

    # 带学习率调度的 AdamW（现代 LLM 训练标配）
    scheduler = optim.lr_scheduler.CosineAnnealingLR(
        opt_adamw, T_max=100, eta_min=1e-6)

    # 梯度裁剪（防止梯度爆炸，Transformer 必备）
    x = torch.randn(32, 64)
    y = torch.randint(0, 10, (32,))
    logits = model(x)
    loss = nn.CrossEntropyLoss()(logits, y)
    opt_adamw.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    opt_adamw.step()
    scheduler.step()

    print(f"  当前学习率：{scheduler.get_last_lr()[0]:.6f}")
    print(f"  Loss：{loss.item():.4f}")


# ── 演示 ──────────────────────────────────────────────
if __name__ == "__main__":
    print("=== 各优化器在 Rosenbrock 函数上的对比 ===")
    optimizer_comparison_demo()

    print("\n=== PyTorch Adam 使用示例 ===")
    pytorch_adam_examples()

    print("\n=== 手动 Adam 步骤验证 ===")
    np.random.seed(42)
    params = [np.random.randn(4, 4), np.zeros(4)]
    grads  = [np.random.randn(4, 4), np.random.randn(4)]
    opt = AdamOptimizer(params, lr=1e-3)
    opt.step(grads)
    print(f"  第 1 步后参数均值：{params[0].mean():.6f}")
    print(f"  有效学习率：{opt.get_effective_lr(0):.6f}")
```

## 七、Adam 的局限与改进

| 问题 | 说明 | 改进方案 |
|------|------|---------|
| **收敛到次优解** | 自适应方法在某些任务不如 SGD | 训练末期切换到 SGD |
| **权重衰减耦合** | Adam 的 L2 正则与自适应学习率耦合 | **AdamW**（Loshchilov 2019） |
| **二阶矩估计偏差** | 早期 v̂ 估计不准确 | AMSGrad（使用历史最大 v̂） |
| **内存占用** | 需要存储 m 和 v，是 SGD 的 3 倍 | Adafactor（内存高效版，用于 T5） |
| **训练末期震荡** | 末期学习率仍较大 | Cosine Annealing 学习率调度 |

## 八、Adam 在不同领域的默认设置

| 任务 | 优化器 | lr | 备注 |
|------|--------|----|------|
| CNN（ImageNet） | SGD+Momentum | 0.1 | 更好的最终精度 |
| Transformer（NLP） | AdamW | 1e-4~3e-4 | 配合 Warmup+Cosine |
| GAN 训练 | Adam | 2e-4 | β₁=0.5（更稳定） |
| 强化学习 | Adam | 3e-4 | PPO/SAC 默认 |
| 图神经网络 | Adam | 1e-3 | 通用默认 |
