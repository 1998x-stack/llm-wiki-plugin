## 一、历史背景：方向性的困境

2017 年 Transformer 出现后，OpenAI 在 2018 年发布了 **GPT-1**：用 Transformer Decoder 做**单向**（从左到右）语言模型预训练。

```
单向语言模型（GPT 风格）：

  P(wₜ | w₁, w₂, ..., wₜ₋₁)

  "The bank [可以是河岸或银行]"
  → 只看左侧，无法根据右侧 "deposit" 来消歧！

  问题：自然语言理解任务（情感分析、问答、NER）
       需要**双向**理解上下文，单向天然受限
```

Google 的团队提出了一个关键问题：

> **"为什么语言模型只是单向的？能否预训练出真正双向的语言表示？"**

BERT（**B**idirectional **E**ncoder **R**epresentations from **T**ransformers）给出了答案，并在 2018 年 10 月以一己之力刷新了 11 项 NLP 任务的最优记录。

## 二、两大预训练任务

### 任务一：掩码语言模型（Masked Language Model, MLM）

```
原始句子：The cat sat on the mat
          ↓ 随机掩盖 15% 的词
输入序列：The cat [MASK] on the mat
预训练目标：预测被遮盖的词 "sat"

→ 模型必须同时利用"The cat"（左侧）和"on the mat"（右侧）
→ 强制双向理解！

15% 中的细节分配（防止测试集分布偏移）：
  80%：替换为 [MASK]      → "The cat [MASK] on the mat"
  10%：替换为随机词        → "The cat apple on the mat"
  10%：保持不变           → "The cat sat on the mat"
```

### 任务二：下一句预测（Next Sentence Prediction, NSP）

```
输入格式：[CLS] 句子A [SEP] 句子B [SEP]

50% 情况：B 是 A 的真实下一句 → 标签 IsNext
50% 情况：B 是随机抽取的句子  → 标签 NotNext

目标：[CLS] 位置的输出向量预测 IsNext / NotNext

→ 让模型理解句子间关系（对 QA、NLI 任务有帮助）
→ 注：后续研究（RoBERTa）发现 NSP 效果有限，可去掉
```

## 三、BERT 架构

BERT 本质是**纯 Transformer Encoder 的堆叠**，无 Decoder：

```
输入 Token IDs
  ↓ Token Embedding（WordPiece 分词，30522 个 token）
  + Segment Embedding（区分句子 A / 句子 B）
  + Position Embedding（可学习，非正弦）
  ↓
┌──────────────────────────────────────┐
│ Transformer Encoder Layer × L       │
│   Multi-Head Self-Attention          │
│   + Add & LayerNorm                 │
│   Feed-Forward                       │
│   + Add & LayerNorm                 │
└──────────────────────────────────────┘
  ↓
各位置的上下文化表示（每个 token 都看到完整序列！）
```

**BERT-Base vs BERT-Large**：

| 配置 | 层数 L | 隐藏维度 H | 注意力头数 A | 参数量 |
|------|--------|-----------|------------|--------|
| BERT-Base | 12 | 768 | 12 | 110M |
| BERT-Large | 24 | 1024 | 16 | 340M |

**训练规模**：
- 语料：Wikipedia（25 亿词）+ BooksCorpus（8 亿词）
- 硬件：64 块 TPU v2，训练 4 天（BERT-Large）

## 四、微调范式："预训练 + 微调"

BERT 确立了 NLP 的主流范式：

```
第一阶段：大规模无监督预训练
  ─────────────────────────────────────
  语料：33 亿词（无需人工标注！）
  任务：MLM + NSP（自监督）
  产物：预训练模型权重（通用语言表示）

            ↓ 迁移（参数初始化）

第二阶段：小规模有监督微调
  ─────────────────────────────────────
  只需少量标注数据（几百到几万条）
  添加一个简单的任务特定输出层
  在下游任务上 fine-tune 几个 epoch

  └── 单句分类（情感分析）：
        [CLS] → Linear → 类别

  └── 句对分类（NLI，文本蕴含）：
        [CLS] 句子A [SEP] 句子B → Linear → 关系

  └── 序列标注（NER，词性标注）：
        每个 Token 位置 → Linear → 标签

  └── 阅读理解（SQuAD）：
        两个线性层分别预测答案的起止位置
```

## 六、完整代码实现

```python
import torch
import torch.nn as nn
import math
from typing import Optional, Tuple, Dict, List


# ── BERT 输入嵌入 ─────────────────────────────────────

class BertEmbedding(nn.Module):
    """
    BERT 三层叠加输入嵌入：
      Token Embedding + Segment Embedding + Position Embedding
    """

    def __init__(self, vocab_size: int = 30522,
                 hidden_size: int = 768,
                 max_position: int = 512,
                 type_vocab_size: int = 2,
                 dropout: float = 0.1,
                 layer_norm_eps: float = 1e-12):
        super().__init__()
        self.token_embed    = nn.Embedding(vocab_size, hidden_size, padding_idx=0)
        self.position_embed = nn.Embedding(max_position, hidden_size)
        self.segment_embed  = nn.Embedding(type_vocab_size, hidden_size)
        self.norm    = nn.LayerNorm(hidden_size, eps=layer_norm_eps)
        self.dropout = nn.Dropout(dropout)

    def forward(self, input_ids: torch.Tensor,
                token_type_ids: Optional[torch.Tensor] = None,
                position_ids: Optional[torch.Tensor] = None) -> torch.Tensor:
        B, T = input_ids.shape
        device = input_ids.device

        if position_ids is None:
            position_ids = torch.arange(T, device=device).unsqueeze(0).expand(B, -1)
        if token_type_ids is None:
            token_type_ids = torch.zeros_like(input_ids)

        emb = (self.token_embed(input_ids) +
               self.position_embed(position_ids) +
               self.segment_embed(token_type_ids))
        return self.dropout(self.norm(emb))


# ── BERT 预训练头 ────────────────────────────────────

class BertMLMHead(nn.Module):
    """Masked Language Model 预测头"""

    def __init__(self, hidden_size: int = 768, vocab_size: int = 30522,
                 layer_norm_eps: float = 1e-12):
        super().__init__()
        # Transform（带激活的线性层）
        self.dense  = nn.Linear(hidden_size, hidden_size)
        self.gelu   = nn.GELU()
        self.norm   = nn.LayerNorm(hidden_size, eps=layer_norm_eps)
        # 投影到词汇表
        self.decoder = nn.Linear(hidden_size, vocab_size, bias=False)
        self.bias = nn.Parameter(torch.zeros(vocab_size))
        self.decoder.bias = self.bias

    def forward(self, hidden: torch.Tensor) -> torch.Tensor:
        """hidden: (B, T, H) → logits: (B, T, vocab_size)"""
        return self.decoder(self.norm(self.gelu(self.dense(hidden))))


class BertNSPHead(nn.Module):
    """Next Sentence Prediction 头"""

    def __init__(self, hidden_size: int = 768):
        super().__init__()
        self.seq_relationship = nn.Linear(hidden_size, 2)

    def forward(self, cls_output: torch.Tensor) -> torch.Tensor:
        """cls_output: (B, H) → logits: (B, 2)"""
        return self.seq_relationship(cls_output)


# ── 简化版 BERT（教学用完整实现）────────────────────

class SimpleBert(nn.Module):
    """
    简化版 BERT，展示完整结构
    生产环境请使用 HuggingFace transformers
    """

    def __init__(self, vocab_size: int = 30522,
                 hidden_size: int = 768,
                 num_layers: int = 12,
                 num_heads: int = 12,
                 intermediate_size: int = 3072,
                 max_position: int = 512,
                 dropout: float = 0.1):
        super().__init__()
        self.embedding = BertEmbedding(vocab_size, hidden_size,
                                       max_position, dropout=dropout)

        # Transformer Encoder 层堆叠
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=hidden_size,
            nhead=num_heads,
            dim_feedforward=intermediate_size,
            dropout=dropout,
            activation='gelu',
            batch_first=True,
            norm_first=False,       # Post-LN（原论文设置）
        )
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)

        # 预训练头
        self.mlm_head = BertMLMHead(hidden_size, vocab_size)
        self.nsp_head = BertNSPHead(hidden_size)

        # Pooler（提取 [CLS] 的句级表示）
        self.pooler = nn.Sequential(
            nn.Linear(hidden_size, hidden_size),
            nn.Tanh(),
        )

        self._init_weights()

    def _init_weights(self):
        for module in self.modules():
            if isinstance(module, nn.Linear):
                nn.init.normal_(module.weight, std=0.02)
                if module.bias is not None:
                    nn.init.zeros_(module.bias)
            elif isinstance(module, nn.Embedding):
                nn.init.normal_(module.weight, std=0.02)
                if module.padding_idx is not None:
                    module.weight.data[module.padding_idx].zero_()

    def forward(self, input_ids: torch.Tensor,
                attention_mask: Optional[torch.Tensor] = None,
                token_type_ids: Optional[torch.Tensor] = None
                ) -> Dict[str, torch.Tensor]:
        """
        Args:
            input_ids:      (B, T)  Token ID 序列
            attention_mask: (B, T)  1=真实 token，0=填充
            token_type_ids: (B, T)  0=句子A，1=句子B

        Returns:
            字典包含：
              last_hidden_state: (B, T, H)
              pooler_output:     (B, H)   [CLS] 的句级表示
              mlm_logits:        (B, T, V) MLM 预测 logits
              nsp_logits:        (B, 2)   NSP 预测 logits
        """
        # 嵌入层
        x = self.embedding(input_ids, token_type_ids)

        # Transformer 编码（attention_mask 转换为 src_key_padding_mask）
        src_key_padding_mask = None
        if attention_mask is not None:
            src_key_padding_mask = (attention_mask == 0)  # True=屏蔽

        hidden = self.encoder(x, src_key_padding_mask=src_key_padding_mask)

        # [CLS] 位置（第 0 个 token）的表示
        cls_hidden = hidden[:, 0, :]           # (B, H)
        pooled     = self.pooler(cls_hidden)   # (B, H)

        return {
            'last_hidden_state': hidden,
            'pooler_output':     pooled,
            'mlm_logits':        self.mlm_head(hidden),
            'nsp_logits':        self.nsp_head(pooled),
        }


# ── 下游任务微调模板 ─────────────────────────────────

class BertForSequenceClassification(nn.Module):
    """
    BERT 文本分类（情感分析、文本蕴含等）
    在 [CLS] 输出上加一个线性分类头
    """

    def __init__(self, bert: SimpleBert, num_labels: int,
                 dropout: float = 0.1):
        super().__init__()
        self.bert = bert
        hidden_size = bert.pooler[0].out_features
        self.dropout    = nn.Dropout(dropout)
        self.classifier = nn.Linear(hidden_size, num_labels)

    def forward(self, input_ids: torch.Tensor,
                attention_mask: Optional[torch.Tensor] = None,
                token_type_ids: Optional[torch.Tensor] = None,
                labels: Optional[torch.Tensor] = None
                ) -> Dict[str, torch.Tensor]:
        outputs = self.bert(input_ids, attention_mask, token_type_ids)
        logits  = self.classifier(self.dropout(outputs['pooler_output']))

        result: Dict[str, torch.Tensor] = {'logits': logits}
        if labels is not None:
            loss = nn.CrossEntropyLoss()(logits, labels)
            result['loss'] = loss
        return result


class BertForTokenClassification(nn.Module):
    """
    BERT 序列标注（命名实体识别 NER、词性标注等）
    在每个 token 输出上加分类头
    """

    def __init__(self, bert: SimpleBert, num_labels: int,
                 dropout: float = 0.1):
        super().__init__()
        self.bert = bert
        hidden_size = bert.pooler[0].out_features
        self.dropout    = nn.Dropout(dropout)
        self.classifier = nn.Linear(hidden_size, num_labels)

    def forward(self, input_ids: torch.Tensor,
                attention_mask: Optional[torch.Tensor] = None,
                token_type_ids: Optional[torch.Tensor] = None,
                labels: Optional[torch.Tensor] = None
                ) -> Dict[str, torch.Tensor]:
        outputs = self.bert(input_ids, attention_mask, token_type_ids)
        sequence_output = outputs['last_hidden_state']            # (B, T, H)
        logits = self.classifier(self.dropout(sequence_output))   # (B, T, num_labels)

        result: Dict[str, torch.Tensor] = {'logits': logits}
        if labels is not None:
            # 忽略 padding 位置（labels=-100）
            loss = nn.CrossEntropyLoss(ignore_index=-100)(
                logits.view(-1, logits.size(-1)), labels.view(-1))
            result['loss'] = loss
        return result


class BertForQuestionAnswering(nn.Module):
    """
    BERT 阅读理解（SQuAD 风格）
    两个线性层分别预测答案的起始和结束位置
    """

    def __init__(self, bert: SimpleBert, dropout: float = 0.1):
        super().__init__()
        self.bert = bert
        hidden_size = bert.pooler[0].out_features
        self.dropout = nn.Dropout(dropout)
        self.qa_outputs = nn.Linear(hidden_size, 2)   # 2 = start + end

    def forward(self, input_ids: torch.Tensor,
                attention_mask: Optional[torch.Tensor] = None,
                token_type_ids: Optional[torch.Tensor] = None,
                start_positions: Optional[torch.Tensor] = None,
                end_positions: Optional[torch.Tensor] = None
                ) -> Dict[str, torch.Tensor]:
        outputs = self.bert(input_ids, attention_mask, token_type_ids)
        sequence_output = outputs['last_hidden_state']             # (B, T, H)

        logits = self.qa_outputs(self.dropout(sequence_output))    # (B, T, 2)
        start_logits, end_logits = logits.split(1, dim=-1)
        start_logits = start_logits.squeeze(-1)                    # (B, T)
        end_logits   = end_logits.squeeze(-1)                      # (B, T)

        result = {'start_logits': start_logits, 'end_logits': end_logits}
        if start_positions is not None and end_positions is not None:
            loss_fct  = nn.CrossEntropyLoss()
            start_loss = loss_fct(start_logits, start_positions)
            end_loss   = loss_fct(end_logits,   end_positions)
            result['loss'] = (start_loss + end_loss) / 2
        return result


# ── HuggingFace 实战（生产推荐）────────────────────

def huggingface_bert_example():
    """使用 HuggingFace transformers 进行中文情感分析微调"""
    from transformers import (BertTokenizer, BertForSequenceClassification,
                               TrainingArguments, Trainer)
    import numpy as np

    # 加载预训练中文 BERT
    model_name = "bert-base-chinese"
    tokenizer  = BertTokenizer.from_pretrained(model_name)
    model      = BertForSequenceClassification.from_pretrained(
        model_name, num_labels=2)

    # 示例数据
    texts  = ["这部电影真的太棒了！", "剧情拖沓，演技差劲。",
              "强烈推荐！感动到落泪", "浪费时间，不值得看"]
    labels = [1, 0, 1, 0]   # 1=正向，0=负向

    # Tokenize
    encodings = tokenizer(texts, padding=True, truncation=True,
                          max_length=128, return_tensors='pt')

    # 前向传播
    model.eval()
    with torch.no_grad():
        outputs = model(**encodings, labels=torch.tensor(labels))

    print(f"  损失：{outputs.loss.item():.4f}")
    print(f"  预测：{outputs.logits.argmax(dim=-1).tolist()}")
    print(f"  真实：{labels}")
```

## 七、BERT 的后继者谱系

```
BERT（2018，Google）
  双向Transformer，MLM+NSP，110M/340M参数
  ↓ 去掉NSP，更大数据，动态掩码
RoBERTa（2019，Facebook）
  更强，训练更充分
  ↓ 更小更快
DistilBERT（2019，HuggingFace）
  66%参数量，97%性能，快2×
  ↓ 中文优化
ERNIE 1.0/2.0（百度）
  实体/知识增强预训练
  ↓ 架构扩展
BERT Large → ALBert → DeBERTa（2020，微软）
  更高效的预训练，NLU 任务 SOTA

               对比方向
BERT（Encoder Only）  vs  GPT（Decoder Only）
  双向理解                   自回归生成
  分类/NER/QA               文本生成
          ↘              ↙
         T5 / BART（2020）
         Encoder+Decoder，统一框架
                 ↓
    GPT-3/4, Claude, Gemini（Scale Up Decoder）
```
