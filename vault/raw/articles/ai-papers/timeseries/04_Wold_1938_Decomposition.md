# 第四篇：Wold 分解定理——平稳时间序列的数学大一统
> **论文原名**：*A Study in the Analysis of Stationary Time Series*  
> **作者**：Herman Wold（赫尔曼·沃尔德）  
> **发表年份**：1938 年  
> **形式**：斯德哥尔摩大学博士论文（导师：Harold Cramér）

---

## 一、历史背景：AR 与 MA 之间缺少一座桥

到 1938 年为止，时间序列研究者已经拥有了两个重要工具：
- **AR 模型**（Yule 1927）：当前值 = 过去值的线性组合 + 白噪声
- **MA 模型**（Slutsky 1937）：当前值 = 过去白噪声冲击的线性组合

但这两种模型都是特殊情形，研究者们面临一个根本性的问题：

> **一般的平稳时间序列究竟"长什么样"？AR 和 MA 能覆盖所有情形吗？还是存在 AR/MA 都无法描述的平稳过程？**

解答这一问题，需要一个严格的数学定理。Herman Wold（1909—1992），瑞典统计学家，在他 29 岁的博士论文中给出了迄今为止最完整、最优雅的回答，这就是**Wold 分解定理**。

---

## 二、核心定理：任意平稳序列的结构

### 2.1 Wold 分解定理（正式表述）

设 $\{X_t\}$ 是一个**协方差平稳**（宽平稳）时间序列，且均值为零。则 $X_t$ 可以唯一分解为：

$$X_t = \underbrace{\sum_{j=0}^{\infty} \psi_j \varepsilon_{t-j}}_{\text{纯非确定性部分（MA(∞)）}} + \underbrace{V_t}_{\text{确定性部分}}$$

其中：
1. $\varepsilon_t$ 是白噪声序列，满足 $E[\varepsilon_t] = 0$，$\text{Var}(\varepsilon_t) = \sigma^2$，且 $\varepsilon_t$ 与 $V_s$ 对所有 $t, s$ 正交
2. $\psi_0 = 1$，且系数满足**平方可和**条件：$\sum_{j=0}^{\infty} \psi_j^2 < \infty$
3. $V_t$ 是确定性分量，即可以被过去值完全线性预测（预测误差为零）：$V_t = \lim_{h \to \infty} E[V_t | X_{t-1}, X_{t-2}, \ldots, X_{t-h}]$（几乎处处）

### 2.2 两个分量的直觉理解

**纯非确定性分量** $\sum \psi_j \varepsilon_{t-j}$（即 MA(∞)）：
- 这一部分包含了序列的"随机创新"——真正由随机冲击驱动的成分
- $\varepsilon_t$ 称为**新息（Innovation）**，是在时刻 $t$ 所有历史信息之外新增的信息量
- 预测误差：无论看多远的历史，对这一分量的预测都存在方差为 $\sigma^2$ 的误差

**确定性分量** $V_t$：
- 可以从无限历史中完美预测
- 例子：$V_t = A\cos(\omega_0 t + \phi)$，已知足够多历史数据就能确定 $A$、$\omega_0$、$\phi$，从而完美预测
- 对于"纯随机"序列，$V_t = 0$

---

## 三、为什么这个定理如此重要？

### 3.1 为 MA(∞) 的普遍性提供了理论保证

Wold 定理告诉我们：**任何（宽）平稳随机过程的随机部分，都可以表示为无穷阶移动平均 MA(∞)**。

这是一个非参数性质的结论——我们不需要假设序列满足任何参数化模型，仅凭平稳性假设，就能得到这个强大的结构。

### 3.2 为 Box-Jenkins ARIMA 方法论奠定理论基础

有了 Wold 定理，Box-Jenkins（1970）的 ARMA 模型建模方法才有了理论支撑：

- 既然任意平稳序列都是 MA(∞)，那我们可以用有限参数的 ARMA(p, q) 来**近似**这个无穷阶 MA
- ARMA 的 AR 部分提供了一个"有理分式近似"，用有限个极点来捕捉 MA(∞) 的无穷展开

### 3.3 定义了时间序列的"本质不可预测性"

$\varepsilon_t$ 的方差 $\sigma^2$ 是对序列**最终不可消除的预测误差下界**——即使使用全部历史信息，对 $X_t$ 的一步预测误差至少为 $\sigma^2$。

这给出了时间序列预测的信息论意义上的极限。

---

## 四、MA(∞) 与 AR(∞) 的等价性

Wold 定理本身给出的是 MA(∞) 表示。但在**可逆性**条件下，MA(∞) 也等价于 AR(∞)：

若 MA(∞) 的生成多项式 $\Psi(z) = \sum_{j=0}^{\infty} \psi_j z^j$ 的所有零点均在单位圆外，则：

$$\Psi(L) \varepsilon_t = X_t \implies \varepsilon_t = \Psi^{-1}(L) X_t = \Pi(L) X_t$$

其中 $\Pi(L) = 1 - \pi_1 L - \pi_2 L^2 - \cdots$ 是 AR(∞) 的系数多项式。

这意味着：对于可逆平稳过程，MA(∞) 和 AR(∞) 是同一过程的两种等价表示，犹如傅里叶变换与反变换——选择哪种表示取决于计算和建模的便利性。

---

## 五、新息过程与 Hilbert 空间几何

Wold 定理有一个优雅的几何诠释，基于**希尔伯特（Hilbert）空间**理论。

设随机变量构成内积空间，内积定义为 $\langle X, Y \rangle = E[XY]$，则：
- 所有 $L^2$ 随机变量构成 Hilbert 空间
- 时刻 $t$ 之前的历史信息 $\mathcal{H}_t = \overline{\text{span}}\{X_s : s \leq t\}$ 是一个闭子空间

$\varepsilon_t$（新息）是 $X_t$ 对子空间 $\mathcal{H}_{t-1}$ 的**正交补**（残差）：

$$\varepsilon_t = X_t - \hat{X}_t, \quad \hat{X}_t = P_{\mathcal{H}_{t-1}} X_t$$

其中 $P_{\mathcal{H}_{t-1}}$ 是到历史子空间的正交投影（最优线性预测）。

Wold 分解 $X_t = \sum \psi_j \varepsilon_{t-j} + V_t$ 本质上是将 Hilbert 空间分解为：
- $V_t$ 所在的子空间：$\bigcap_{n} \mathcal{H}_{t-n}$（所有过去信息的交集，即"远古历史"）
- 新息所张成的正交补子空间

这一几何视角由 Kolmogorov（1940）和 Wiener（1949）进一步发展为最优预测理论。

---

## 六、确定性分量的例子

哪些东西属于"确定性分量" $V_t$？

1. **正弦波**：$V_t = A\sin(\omega_0 t + \phi)$，可从历史完美预测
2. **多项式趋势**：$V_t = a + bt + ct^2$，可从历史完美预测（但注意：这意味着方差随时间增长，序列非平稳！）
3. **周期为整数的离散谐波**：$V_t = \sum_k A_k e^{i\omega_k t}$

在实践中，大多数"纯随机"的经济/金融时间序列几乎没有确定性分量（$V_t \approx 0$），Wold 分解退化为纯 MA(∞) 表示。

---

## 七、Wold 定理的局限性

尽管 Wold 定理极其重要，但它也有几个重要限制：

| 限制 | 说明 |
|---|---|
| **仅适用于平稳序列** | 非平稳序列（随机游走、ARIMA）需要先差分处理 |
| **仅给出线性预测** | MA(∞) 是最优**线性**预测，但若条件均值是非线性的（如 GARCH），非线性方法更优 |
| **存在性，非构造性** | 定理保证分解存在，但未给出如何从数据中估计 $\psi_j$ |
| **MA(∞) 是无穷维的** | 实际应用中需要用有限参数的 ARMA 来近似 |

## 八、与后续理论的连接

Wold 分解定理是时间序列理论大厦的地基，几乎所有后续工作都建立在它之上：

```
Wold 分解定理（1938）
    │
    ├─ AR/MA/ARMA 模型理论     → Box-Jenkins（1970）
    │
    ├─ Wiener-Hopf 最优预测    → Wiener（1949）
    │
    ├─ Kalman 滤波状态空间     → Kalman（1960）
    │
    ├─ 谱分解定理              → Cramér 谱表示
    │
    ├─ 协整理论                → Engle & Granger（1987）
    │
    └─ 长记忆过程              → ARFIMA（Granger & Joyeux 1980）
```

## 九、Herman Wold 其人

Herman Wold 的博士论文于 1938 年完成，导师是瑞典概率论大师 Harald Cramér。这篇论文在数学严格性上超越了同时代的大多数统计工作。

Wold 后来转向计量经济学，提出了著名的**递归结构方程模型**（Wold 链锁系统），并在工具变量估计方面做出重要贡献。他是第一位将严格数学概率论引入统计经济学的学者之一，于 1975 年获得 Guy Medal in Gold（皇家统计学会最高荣誉）。

---

## 十、小结

Wold 分解定理用一个精确的数学定理回答了时间序列分析的基础问题：

> **平稳时间序列 = 无穷阶移动平均（随机创新的叠加）+ 可完全预测的确定性部分。**

这个定理的三重意义：
1. **统一性**：将 AR、MA、ARMA 等所有线性模型纳入统一框架
2. **极限性**：揭示了预测的信息论下界（新息方差）
3. **指导性**：为 ARMA 建模的可行性提供了理论保证——有限参数的 ARMA 是 MA(∞) 的近似，而非任意假设
