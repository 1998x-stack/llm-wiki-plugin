> **论文原名**：*A State Space Framework for Automatic Forecasting Using Exponential Smoothing Methods*  
> **作者**：Rob J. Hyndman，Anne B. Koehler，Ralph D. Snyder，Simone Grose  
> **发表年份**：2002 年  
> **发表期刊**：*International Journal of Forecasting*

---

## 一、历史背景：实用方法的理论困境

指数平滑法（Exponential Smoothing）是 20 世纪实践中使用最广泛的预测方法之一，工业界几十年来一直在用，但它长期缺乏严格的统计理论支撑：

- **Brown（1956）**：提出单参数指数平滑（SES），用加权历史值预测，近的权重大
- **Holt（1957）**：扩展为双参数法，加入趋势的指数平滑
- **Winters（1960）**：再扩展为三参数法（Holt-Winters），包含季节成分

这三种方法极为简单，计算量小，在许多实际数据上表现出色，但：

1. **没有正式的概率模型**：无法计算置信区间（不知道预测有多大不确定性）
2. **无统一的方法论**：不同的变体（加法季节 vs 乘法季节，带趋势 vs 不带趋势）相互割裂
3. **阶数选择是手工的**：选哪种方法（SES、Holt、Holt-Winters）依赖经验判断

Harvey（1990）已经指出 SES = 局部水平模型的 Kalman 滤波，但对更复杂的变体缺少统一的状态空间推导。

Rob Hyndman（生于 1967 年）等人在 2002 年的论文中，将所有主流指数平滑变体统一在一个**状态空间框架**下，引入信息准则实现**自动模型选择**——这就是 **ETS（Error-Trend-Seasonality）框架**。

---

## 二、ETS 的命名与模型空间

### 2.1 三维分类

ETS 代表三个成分，每个成分有若干选项：

| 成分 | 选项 | 含义 |
|---|---|---|
| **E**（误差类型） | A（加法）、M（乘法） | 误差如何进入模型 |
| **T**（趋势类型） | N（无）、A（加法）、$A_d$（阻尼加法） | 趋势的形式 |
| **S**（季节类型） | N（无）、A（加法）、M（乘法） | 季节效应的形式 |

三个成分的所有组合产生 **30 种模型**（$2 \times 3 \times 3 = 18$；排除若干不合理组合后约 15 个实用模型）。

### 2.2 记号约定

完整的 ETS 模型记为 ETS(E, T, S)，例如：
- **ETS(A, N, N)**：无趋势、无季节的加法误差指数平滑 = 简单指数平滑（SES）
- **ETS(A, A, N)**：加法趋势、无季节 = Holt 双参数法
- **ETS(A, A, A)**：加法趋势 + 加法季节 = Holt-Winters 加法
- **ETS(M, A, M)**：乘法误差 + 加法趋势 + 乘法季节 = Holt-Winters 乘法（乘法误差版）
- **ETS(A, $A_d$, N)**：阻尼趋势指数平滑（Gardner & McKenzie 1985 的实用方法）

## 三、核心数学：ETS(A,A,A) 的状态空间表示

以最常用的 Holt-Winters 加法模型为例：

**观测方程**：
$$y_t = \ell_{t-1} + b_{t-1} + s_{t-m} + \varepsilon_t, \quad \varepsilon_t \sim \mathcal{N}(0, \sigma^2)$$

**状态方程**：
$$\ell_t = \ell_{t-1} + b_{t-1} + \alpha \varepsilon_t \quad \text{（水平更新）}$$
$$b_t = b_{t-1} + \beta \varepsilon_t \quad \text{（趋势更新）}$$
$$s_t = s_{t-m} + \gamma \varepsilon_t \quad \text{（季节更新）}$$

其中：
- $\ell_t$：局部水平（Level）
- $b_t$：局部趋势（Trend / Slope）
- $s_t$：季节成分（Seasonality），以 $m$ 为周期（月度数据 $m=12$）
- $\alpha, \beta, \gamma \in [0,1]$：平滑参数

**参数的直觉**：
- $\alpha$ 大：水平快速响应新观测（对新数据敏感，但记忆短）
- $\alpha$ 小：水平变化缓慢（对新数据不敏感，但记忆长）
- $\beta$ 大：趋势快速适应斜率变化
- $\gamma$ 大：季节因子快速更新

## 四、乘法误差模型（ETS 的关键扩展）

Harvey（1990）的状态空间只考虑了**加法误差**（误差的绝对大小是常数）。Hyndman 等人的重要贡献是引入了**乘法误差**：

**ETS(M, A, N) 的观测方程**：
$$y_t = (\ell_{t-1} + b_{t-1})(1 + \varepsilon_t)$$

**状态方程**：
$$\ell_t = (\ell_{t-1} + b_{t-1})(1 + \alpha \varepsilon_t)$$
$$b_t = b_{t-1} + \beta (\ell_{t-1} + b_{t-1}) \varepsilon_t$$

乘法误差意味着：误差与水平成比例（数据越大，绝对误差越大）。这对于销售额、电力需求等高增长序列更合适（相对误差稳定）。

**重要性质**：乘法误差模型的预测区间是非对称的（随预测水平扩大），比加法误差的对称区间更贴近实际分布。

## 五、自动预测：信息准则驱动的模型选择

ETS 框架最重要的实用贡献是实现了**全自动预测**：

**步骤**：
1. 对所有（约 15—30 个）ETS 变体，分别用 MLE 估计参数
2. 计算每个模型的 **AIC（赤池信息准则）**：
$$\text{AIC} = -2\ln L + 2k$$
其中 $k$ 是参数数量（$\alpha, \beta, \gamma$，初始状态，$\sigma^2$）
3. 选择 AIC 最小的模型

这一流程被 Hyndman 实现为 R 包中的 `ets()` 函数（后来也有 Python 版本），用户只需输入数据，系统自动选择最优的 ETS 变体并返回预测结果。

**Hyndman & Khandakar（2008）**进一步将同样的自动化思想应用于 ARIMA，实现了 `auto.arima()` 函数，两者合称为现代自动化时序预测的标配工具。

## 六、ETS 的预测区间

状态空间框架的一个重要优势是能够严格推导预测分布：

**$h$ 步超前预测均值**（点预测，与递推更新公式相同）：
$$\hat{y}_{T+h|T} = \hat{\ell}_T + h \hat{b}_T + \hat{s}_{T+h-m}$$

**$h$ 步预测方差**（加法误差情形）：
$$\text{Var}(y_{T+h}|y_{1:T}) = \sigma^2 \sum_{j=0}^{h-1} c_j^2$$

其中 $c_j$ 是 ETS 模型的 MA(∞) 系数（由参数 $\alpha, \beta, \gamma$ 计算）。

这使得 ETS 能够输出严格的**预测置信区间**，而早期指数平滑方法只能给出点预测。

## 七、与 ARIMA 的关系

ETS 和 ARIMA 并非相互排斥，而是从不同角度逼近同一类平稳/非平稳序列：

| | ETS | ARIMA |
|---|---|---|
| 建模视角 | 成分分解（趋势+季节+误差） | 差分 + 自回归 + 移动平均 |
| 参数数量 | 少（3—5 个平滑参数） | 视阶数而定 |
| 季节处理 | 直接建模季节成分 | 季节差分 + 季节 AR/MA |
| 长期预测 | 自然延伸趋势和季节 | 均值回复特性 |
| 乘法季节 | 直接支持（ETS M 型） | 需对数变换 |

**特殊情形等价**：
- ETS(A,N,N) ↔ ARIMA(0,1,1)
- ETS(A,A,N) ↔ ARIMA(0,2,2)
- ETS(A,$A_d$,N) ↔ ARIMA(1,1,2)（近似）

但乘法季节、乘法误差的 ETS 变体无法直接用 ARIMA 表示（需要先取对数变换），在这类情形下 ETS 更具优势。

## 八、M 竞赛中的 ETS 表现

ETS 在历届 M 竞赛（Makridakis 预测竞赛）中的表现为其奠定了工业界地位：

- **M3 竞赛（2000 年）**：ETS/Holt-Winters 类方法在 3003 条时间序列上整体表现优异，超过大多数复杂统计模型
- **M4 竞赛（2018 年）**：Smyl 的获胜方案是 ES-RNN（指数平滑 + LSTM 混合），以 ETS 为基础成分
- **M5 竞赛（2020 年）**：大规模零售预测，LightGBM 获胜，但 ETS 仍作为强力基准
- **M6 竞赛（2022 年）**：集成方法主导，ETS 是常用的基础预测器之一

一个关键教训：**简单方法（如 ETS）的集成往往能击败单一复杂模型**，这也是 M 竞赛最重要的实践启示。

## 九、`fable` 与现代 R/Python 生态

Hyndman 等人在 2021 年出版的《**预测：原理与实践（第三版）**》（Forecasting: Principles and Practice，免费在线）是时间序列预测的最流行教材之一，完整介绍了 ETS、ARIMA 及现代方法，并附有 `fable`、`tsibble` R 包的实现。

Python 中的对应实现：
- `statsmodels.tsa.holtwinters.ExponentialSmoothing`
- `skforecast` 库中的 ETS 封装
- `etspy` 实验性包

## 十、小结

Hyndman 等（2002）的 ETS 框架完成了指数平滑方法论史上最重要的整合：

> **将几十年来分散发展的经验性预测方法，统一在概率状态空间框架下，并实现了基于信息准则的自动模型选择。**

四大贡献：
1. **统一性**：所有主流指数平滑变体纳入同一 ETS(E,T,S) 分类体系
2. **严格性**：状态空间表示赋予了完整的统计推断能力（置信区间、似然估计）
3. **自动化**：AIC 驱动的自动模型选择，实现"一键预测"
4. **实用性**：在工业大规模预测任务中持续表现优异，是现代自动化预测的基准
