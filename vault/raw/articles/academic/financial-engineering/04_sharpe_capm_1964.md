## 二、历史背景：从优化到定价

### 2.1 马科维茨留下的问题

马科维茨（1952）告诉我们**如何构建有效组合**，但没有回答另一个更基本的问题：

**在市场均衡状态下，每只资产的预期收益率应该是多少？**

换句话说：承担多少风险，应该得到多少回报？**风险的"价格"是什么？**

这是夏普要解决的问题。

### 2.2 夏普的处境

夏普当时是马科维茨的学生（间接地）。他在1962年完成了这篇论文的初稿，投给金融学顶刊《金融学期刊》（Journal of Finance），**被拒稿一次**——审稿人认为"假设太强，不现实"。

修改后再投，1964年发表。这篇被拒稿一次的论文，后来成为整个资产定价理论的基础。

（同期独立得出相似结论的还有John Lintner (1965) 和 Jan Mossin (1966)，但通常以夏普的名字命名。）

## 三、CAPM的推导

### 3.1 关键假设

CAPM建立在一系列假设上：

1. **投资者都是均值-方差优化者**（马科维茨框架）
2. **投资者持有相同的预期**（homogeneous expectations）——所有人对未来收益率的均值、方差、协方差有相同估计
3. **无风险资产存在**（投资者可以以无风险利率 $r_f$ 自由借贷）
4. **完美市场**（无税、无交易成本、无卖空限制）
5. **所有资产可分割**（可以购买任意小额的资产）

### 3.2 引入无风险资产：资本市场线（CML）

当引入无风险资产（收益率 $r_f$，方差=0）后，投资者在**风险资产组合**与**无风险资产**之间分配：

设投资比例 $\alpha$ 在风险组合 $P$（期望收益 $\mu_P$，标准差 $\sigma_P$），比例 $1-\alpha$ 在无风险资产：

$$\mu_{total} = \alpha \mu_P + (1-\alpha) r_f = r_f + \alpha(\mu_P - r_f)$$
$$\sigma_{total} = \alpha \sigma_P$$

消去 $\alpha = \sigma_{total}/\sigma_P$：

$$\mu_{total} = r_f + \frac{\mu_P - r_f}{\sigma_P} \cdot \sigma_{total}$$

这是一条过点 $(0, r_f)$ 的直线，斜率为 $\frac{\mu_P - r_f}{\sigma_P}$。

为了最大化斜率（即单位风险的超额收益），所有理性投资者都会选择**使这条线斜率最大的风险组合**——这个特殊组合被称为**切线组合（Tangency Portfolio）**。

$$\text{斜率} = \frac{\mu_T - r_f}{\sigma_T} \quad \text{（最大化）}$$

最优直线（**资本市场线，CML**）：

$$\mu = r_f + \frac{\mu_T - r_f}{\sigma_T} \cdot \sigma$$

### 3.3 市场均衡：市场组合 = 切线组合

**关键洞察**：如果所有投资者：
- 持有相同预期
- 都是均值-方差优化者
- 都可以以 $r_f$ 借贷

那么他们**所有人都会持有同一个切线组合**！

在市场均衡时，供求相等意味着：所有资产都被持有，切线组合就是**按市值加权的市场组合（Market Portfolio）**，通常用大盘指数近似（如标普500）。

记市场组合为 $M$，其期望收益为 $\mu_M$，标准差为 $\sigma_M$。

### 3.4 CAPM主方程：证券市场线（SML）

现在考虑单只资产 $i$ 与市场组合 $M$ 的关系。

夏普证明，在市场均衡下，资产 $i$ 的期望收益率满足：

$$\boxed{\mu_i = r_f + \beta_i (\mu_M - r_f)}$$

其中 **$\beta_i$（贝塔系数）** 定义为：

$$\beta_i = \frac{\text{Cov}(r_i, r_M)}{\text{Var}(r_M)} = \frac{\sigma_{iM}}{\sigma_M^2}$$

这就是著名的 **CAPM公式**，也称为**证券市场线（Security Market Line，SML）**。

## 四、β系数的深度解读

### 4.1 β的经济含义

$\beta_i$ 衡量的是**资产 $i$ 相对于整个市场的系统性风险**：

| $\beta$ 值 | 含义 | 例子 |
|-----------|------|------|
| $\beta = 0$ | 与市场无关 | 无风险资产（国债） |
| $\beta = 1$ | 与市场同步 | 市场指数本身 |
| $0 < \beta < 1$ | 波动小于市场 | 公用事业、消费品 |
| $\beta > 1$ | 波动大于市场 | 科技股、成长股 |
| $\beta < 0$ | 与市场反向 | 黄金（有时）、VIX衍生品 |

### 4.2 风险的两个来源

CAPM将资产总风险 $\sigma_i^2$ 分解为两部分：

$$\sigma_i^2 = \underbrace{\beta_i^2 \sigma_M^2}_{\text{系统性风险}} + \underbrace{\sigma_{\epsilon_i}^2}_{\text{非系统性风险（可分散）}}$$

- **系统性风险（Systematic Risk）**：由市场整体波动引起，无法通过分散化消除，需要被定价补偿
- **非系统性风险（Idiosyncratic Risk）**：公司特有风险，可以通过分散化消除，**不应被市场补偿**

**CAPM的核心主张：市场只为系统性风险（$\beta$）付出溢价，不为可分散的风险付出任何溢价。**

### 4.3 α（阿尔法）的含义

在实践中，我们经常看到"投资组合创造了α"。α的定义是：

$$\alpha_i = \mu_i - [r_f + \beta_i(\mu_M - r_f)]$$

即资产的实际预期收益相对于CAPM预测值的偏差。

- $\alpha > 0$：资产"价值低估"，提供超额回报
- $\alpha < 0$：资产"价值高估"
- $\alpha = 0$：CAPM精确成立

CAPM的强预测是：**在均衡市场中，所有资产的 $\alpha = 0$**。

## 五、CAPM的数学推导（完整版）

### 5.1 最优条件推导

对于市场组合 $M$ 和单资产 $i$，构造组合：$\alpha$ 比例投 $i$，$1-\alpha$ 比例投 $M$：

$$\mu_\alpha = \alpha \mu_i + (1-\alpha)\mu_M$$
$$\sigma_\alpha^2 = \alpha^2\sigma_i^2 + (1-\alpha)^2\sigma_M^2 + 2\alpha(1-\alpha)\sigma_{iM}$$

在切线组合（$\alpha=0$，即市场组合本身），组合 $M$ 已经在资本市场线上。

要求新增加少量 $i$ 时，组合在均值-方差平面上的移动方向与资本市场线重合：

$$\left.\frac{d\mu_\alpha/d\alpha}{d\sigma_\alpha/d\alpha}\right|_{\alpha=0} = \frac{\mu_M - r_f}{\sigma_M}$$

计算：
$$\left.\frac{d\mu_\alpha}{d\alpha}\right|_{\alpha=0} = \mu_i - \mu_M$$

$$\left.\frac{d\sigma_\alpha}{d\alpha}\right|_{\alpha=0} = \frac{\sigma_{iM} - \sigma_M^2}{\sigma_M}$$

代入条件：

$$\frac{\mu_i - \mu_M}{(\sigma_{iM} - \sigma_M^2)/\sigma_M} = \frac{\mu_M - r_f}{\sigma_M}$$

整理得：

$$\mu_i - \mu_M = \frac{(\mu_M - r_f)(\sigma_{iM} - \sigma_M^2)}{\sigma_M^2}$$

$$\mu_i = r_f + \frac{\sigma_{iM}}{\sigma_M^2}(\mu_M - r_f) = r_f + \beta_i(\mu_M - r_f) \quad \square$$

## 六、对统计学的深远影响

### 6.1 时间序列回归：市场模型

CAPM给出了一个可检验的线性回归模型（市场模型）：

$$r_{it} - r_{ft} = \alpha_i + \beta_i (r_{Mt} - r_{ft}) + \epsilon_{it}$$

其中 $\epsilon_{it}$ 是均值为零、与市场收益独立的随机误差。

这是金融计量经济学中最广泛使用的回归模型，催生了：

- **OLS估计β**：普通最小二乘法估计贝塔系数
- **β的稳定性检验**：Blume(1971)发现β随时间均值回归
- **异方差检验**：$\epsilon_{it}$ 往往存在ARCH效应

### 6.2 事件研究（Event Study）方法论

CAPM为**事件研究**提供了基准模型：

1. 估计正常时期的 $\alpha_i, \beta_i$
2. 在事件窗口内计算**超常收益（Abnormal Return）**：$AR_{it} = r_{it} - (\hat{\alpha}_i + \hat{\beta}_i r_{Mt})$
3. 对超常收益进行统计检验

这成为实证公司金融学最重要的研究方法，被用于研究：
- 并购公告的市场反应
- 会计披露对股价的影响
- 政策变化对行业的冲击

### 6.3 夏普比率

夏普比率（Sharpe Ratio）是CAPM思想的简化版本：

$$SR = \frac{\mu_P - r_f}{\sigma_P}$$

衡量单位总风险的超额收益。这成为全球基金经理最广泛使用的绩效评估指标。

## 七、CAPM的实证检验：理论与现实的差距

### 7.1 经典检验

**Black, Jensen & Scholes（1972）**：用月度数据检验CAPM，发现：
- $\beta$ 与收益正相关（支持CAPM方向）
- 但低$\beta$资产收益高于CAPM预测，高$\beta$资产低于预测（"扁平的SML"）

**Fama & MacBeth（1973）**：两阶段回归检验，总体支持CAPM，但误差项存在相关性。

### 7.2 CAPM的"死亡公告"

**Fama & French（1992）**——这是CAPM最严厉的实证批评：

在美国1963-1990年数据上，控制**规模（市值）**和**账面市值比（B/M）**后，$\beta$ 对截面收益没有解释力！

这几乎宣告了CAPM在实证上的"死亡"，但也催生了Fama-French三因子模型（我们后续会详细讨论）。

### 7.3 理论仍然有效

尽管实证挑战重重，CAPM在理论层面仍然是不可替代的基准：
- 提供了理解"风险溢价"的基础框架
- 教会我们区分系统性风险与非系统性风险
- 提供了折现率（WACC中的权益成本部分）的估计方法

## 八、实际应用：估算资本成本

CAPM在实践中最重要的用途是**估算权益资本成本**，用于企业投资项目的折现：

**例**：某科技公司的 $\beta = 1.5$，无风险利率 $r_f = 3\%$，市场风险溢价 $(\mu_M - r_f) = 6\%$：

$$r_E = 3\% + 1.5 \times 6\% = 12\%$$

这意味着该公司的股权资本成本为12%——所有投资项目都必须能产生超过12%的回报才值得投资。

---

## 九、结语：一个优雅的谎言

CAPM是金融学中最优雅的理论之一。它用一个简单的线性公式，将风险与回报的关系清晰表达。诺贝尔委员会说：

> "夏普的CAPM是迄今为止在金融经济学中被使用最广泛的分析工具之一。"

但它也是金融学中被检验最多、被发现问题最多的理论。

**也许CAPM的最大价值不在于它是"对的"，而在于它为所有后续的资产定价研究设定了清晰的参照基准。**

对一切更好的定价理论（APT、三因子、五因子…）的评价标准，都是："它比CAPM解释得更好吗？"

这种设定标准的能力，本身就是科学的巨大贡献。
