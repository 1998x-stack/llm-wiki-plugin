## 二、默顿的天才特质

### 2.1 跨界的数学天才

罗伯特·默顿（1944年生）有着不同寻常的学术背景：
- 本科学习数学（哥伦比亚大学）
- 计划成为应用数学家，却在MIT师从萨缪尔森转学经济学
- 博士期间开始大量应用**伊藤随机微积分**

默顿是第一批真正将**现代随机过程数学**引入金融学的经济学家。在他之前，金融学家用随机变量（离散时间）；在他之后，随机微分方程成为标准工具。

### 2.2 与Black-Scholes的合作故事

默顿、Black和Scholes在1970年代初期在MIT同一走廊工作，频繁交流。

事实上，**默顿是第一个提出用Delta对冲消除随机项的人**。他把这个想法告诉了Black和Scholes，后者用它完成了论文。

为了不"抢先"朋友的成果，默顿刻意将自己的论文推迟发表，让B-S论文先行。他的论文后来发展出一套更一般的框架。

## 三、论文的核心贡献

Merton（1973）做了几件比Black-Scholes更"野心勃勃"的事：

### 3.1 严格化B-S公式的数学基础

Black和Scholes的原始推导在数学上有一些不严谨之处。Merton用**伊藤引理**的形式语言重新推导，使其数学上严格。

更重要的是，Merton明确引入了**连续时间自融资策略（self-financing strategy）**的概念，使得Delta对冲有了严格的数学定义。

### 3.2 推广到股息支付股票

对于支付连续股息 $q$ 的股票（价格方程 $dS = (\mu-q)S\,dt + \sigma S\,dW_t$），Merton证明买权价格修正为：

$$C = Se^{-q(T-t)}\Phi(d_1) - Ke^{-r(T-t)}\Phi(d_2)$$

其中 $d_1 = \frac{\ln(S/K) + (r - q + \sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}$。

这一公式广泛应用于：
- 股指期权（股息收益率替代 $q$）
- 外汇期权（外币利率替代 $q$）——即Garman-Kohlhagen模型的基础

### 3.3 期权的一般性质：无需模型的定理

Merton推导了一系列**不依赖任何特定价格模型**的期权性质，仅基于无套利原理：

**定理1（下界）**：欧式买权价格下界：
$$C \geq \max(S - Ke^{-r(T-t)}, 0)$$

**定理2（无红利时美式买权不提前行权）**：
无股息的美式买权 = 欧式买权。（因为提前行权放弃了时间价值）

**定理3（单调性）**：
- $\partial C / \partial S > 0$（股价越高，买权越有价值）
- $\partial C / \partial K < 0$（行权价越高，买权越便宜）
- $\partial C / \partial \sigma > 0$（波动率越高，买权越有价值）
- $\partial C / \partial T > 0$（到期时间越长，买权越有价值）

**定理4（Put-Call Parity）**：
$$C - P = S - Ke^{-r(T-t)}$$

这些定理是期权市场定价的"硬约束"，任何违反这些约束的价格都存在无风险套利机会。

## 四、连续时间资产组合选择

Merton（1973）还是他早期关于**连续时间消费-投资决策**工作（Merton 1969, 1971）的延续。

### 4.1 Merton的消费-投资问题

投资者在连续时间内选择：消费 $c(t)$ 和投资各资产的比例 $\{w_i(t)\}$，以最大化期望效用：

$$\max \mathbb{E}\left[\int_0^T U(c(t), t)\, dt + B(W(T), T)\right]$$

其中财富动态满足：
$$dW = \left(\sum_i w_i \mu_i W - c\right)dt + \sum_i w_i \sigma_i W\, dW_i$$

### 4.2 HJB方程与最优解

利用**贝尔曼最优原理（Bellman Optimality）**，Merton推导出**Hamilton-Jacobi-Bellman（HJB）方程**：

$$J_t + \max_{c,\{w_i\}}\left[U(c,t) + \mathcal{L}J\right] = 0$$

其中 $\mathcal{L}$ 是随机微分方程的生成算子。

这套框架成为**连续时间动态规划**的标准工具，被广泛应用于：
- 养老金最优配置
- 保险精算中的最优策略
- 央行外汇储备管理

## 五、伊藤引理：默顿带入金融的核心工具

伊藤引理是连续时间金融的基础，默顿将其系统性地引入金融分析。

**伊藤引理**：设 $dX = a(X,t)dt + b(X,t)dW_t$，对光滑函数 $f(X,t)$：

$$df = \left(\frac{\partial f}{\partial t} + a\frac{\partial f}{\partial x} + \frac{1}{2}b^2\frac{\partial^2 f}{\partial x^2}\right)dt + b\frac{\partial f}{\partial x}dW_t$$

**关键差异与普通微积分**：多出了 $\frac{1}{2}b^2\frac{\partial^2 f}{\partial x^2}dt$ 这一项（称为**伊藤修正项**），来源于布朗运动的二次变差 $dW_t^2 = dt$。

**应用示例**：若 $S$ 满足GBM，对 $\ln S$ 应用伊藤引理：

$$d(\ln S) = \frac{1}{S}dS - \frac{1}{2S^2}(dS)^2 = \left(\mu - \frac{\sigma^2}{2}\right)dt + \sigma dW_t$$

这说明 $\ln S$ 服从正态分布，即 $S$ 服从对数正态分布——B-S模型的基础。

## 六、Merton的后续工作：结构信用模型

Merton（1974）将期权定价思想扩展到**公司信用风险**，提出了著名的**Merton信用模型**：

**核心思想**：将公司股权看作**公司资产价值**的看涨期权！

设公司资产价值 $V$，负债面值 $D$（零息债，到期日 $T$）：
- **股权**：$E = \max(V - D, 0)$（资产价值超过负债才有价值）
- **债务**：$D_{value} = V - E$（公司资产减去股权）

因此：
$$E = V\Phi(d_1) - De^{-rT}\Phi(d_2)$$

其中 $d_1 = \frac{\ln(V/D) + (r+\sigma_V^2/2)T}{\sigma_V\sqrt{T}}$

**违约概率**（风险中性）：$\Phi(-d_2)$

**信用利差**：由违约概率和违约损失率决定

这个框架催生了整个**结构性信用模型**领域，被KMV公司商业化，后来成为穆迪公司核心信用评级模型。

## 七、对统计学和数学金融的影响

### 7.1 随机微积分的金融化

Merton系统性地将伊藤随机微积分引入金融，直接推动了：
- **随机最优控制（Stochastic Optimal Control）**在金融中的应用
- **鞅方法（Martingale Method）**的发展（Harrison-Kreps 1979年的工作）
- **数值PDE方法**（有限差分、有限元）在期权定价中的应用

### 7.2 偏微分方程在定价中的应用

B-S/Merton建立了"**定价PDE → 解析解或数值解**"的范式：
- 欧式期权：解析解（B-S公式）
- 美式期权：自由边界PDE，需要数值方法
- 路径依赖期权（亚式、障碍式）：蒙特卡洛模拟或PDE

### 7.3 等价鞅测度（Equivalent Martingale Measure）

Merton的工作为Harrison-Kreps（1979）建立无套利定价的完整理论框架铺平了道路：

任何衍生品价格 = 在等价鞅测度（风险中性测度）下到期收益的折现期望。

这将资产定价从"均衡理论"转变为更基础的"无套利理论"。

---

## 八、Merton的"天才时刻"：跳跃-扩散模型

Merton（1976）还提出了**跳跃-扩散模型（Jump-Diffusion Model）**，将GBM与泊松跳跃过程结合：

$$dS = (\mu - \lambda\bar{k})S\,dt + \sigma S\,dW_t + S\,dJ_t$$

其中 $J_t$ 是复合泊松过程，模拟价格的突然跳跃（如公司违约、政策冲击）。

这个模型更好地捕捉了实际市场中的**厚尾**和**不连续跳跃**，成为后来Heston-with-jumps等模型的前身。

---

## 九、结语：连续时间金融学之父

如果说Black和Scholes是发现了定价公式，那么Merton则构建了支撑这一公式的**整个数学大厦**。

默顿将现代随机过程理论（布朗运动、伊藤积分、随机控制）系统地引入金融学，创造了**连续时间金融学（Continuous-Time Finance）**这一全新领域。

今天，金融工程专业的学生学习的随机微积分、HJB方程、等价鞅测度……每一个概念都有默顿的深刻印记。

他的诺贝尔奖评语简洁而准确：

> "通过在经济分析中引入随机微积分，默顿从根本上改变了我们对金融风险的认知和管理方式。"
