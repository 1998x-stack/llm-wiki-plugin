# 论文②：最小二乘法与正态分布的诞生
## *Theoria Motus Corporum Coelestium in Sectionibus Conicis Solem Ambientium*
**Carl Friedrich Gauss（1809）**

---

> "在所有测量误差的分布假设中，只有一种假设使得算术平均值成为最佳估计——而这种假设的分布曲线，是一条永恒的钟形曲线。"

---

## 一、历史背景：一颗消失的行星

1801 年元旦，意大利天文学家**朱塞佩·皮亚齐（Giuseppe Piazzi）**发现了一颗新天体——**谷神星（Ceres）**。他连续观测了 41 天，记录下一系列位置数据。然而，随后谷神星运行到太阳附近，消失在观测视野中。

问题来了：几个月后，谷神星会出现在哪里？

当时欧洲最顶尖的天文学家和数学家纷纷尝试预测，大多失败或精度不足。

一个 24 岁的年轻德国数学家，用自己发明的方法，给出了惊人精准的预测。当天文学家将望远镜对准他预测的位置时，谷神星果然出现了。

这个年轻人就是**卡尔·弗里德里希·高斯（Carl Friedrich Gauss, 1777–1855）**，他使用的方法就是**最小二乘法（Method of Least Squares）**。

---

## 二、测量误差：一个古老的困境

在高斯之前，科学测量面临一个根本性困境：

**同一个量，多次测量的结果总是略有差异。取哪个值？**

比如，测量一颗星的位置，连续观测 10 次，得到 10 个略有不同的读数。天文学家该怎么处理？

**常见做法：取算术平均值**——但这只是一个经验直觉，缺乏理论依据。为什么是平均？为什么不是中位数，不是取最大最小的中点？

没有人能给出令人信服的数学解释。

---

## 三、最小二乘法：让误差的平方和最小

高斯的核心思想非常直接：

### 问题的数学化

假设我们有 n 次观测 y₁, y₂, …, yₙ，想估计真实值 μ。

每次观测的误差为：eᵢ = yᵢ − μ

我们希望找到 μ̂，使得总误差尽可能小。

**关键选择：如何定义"总误差"？**

| 方案 | 定义 | 问题 |
|------|------|------|
| 误差之和 Σeᵢ | 正负误差相消，总和可以为零，失去意义 |
| 误差绝对值之和 Σ\|eᵢ\| | 数学上不光滑，难以求导 |
| **误差平方和** Σeᵢ² | ✅ 光滑、可微、正负误差均被惩罚 |

高斯选择**最小化误差平方和**：

```
μ̂ = argmin_μ  Σᵢ (yᵢ − μ)²
```

### 求解：对 μ 求导令其为零

```
d/dμ  Σᵢ(yᵢ − μ)² = −2 Σᵢ(yᵢ − μ) = 0

⟹ Σyᵢ − nμ = 0

⟹ μ̂ = (1/n) Σyᵢ   即算术平均值
```

**结论：最小二乘法的解，正是算术平均值！**

这第一次给了"取均值"一个严格的数学理由：它让误差平方和最小。

## 四、线性回归：最小二乘法的完整形式

高斯的思想更深刻之处在于处理**多个变量之间的关系**。

### 简单线性回归

假设行星位置 y 与时间 x 有线性关系：

```
yᵢ = β₀ + β₁xᵢ + εᵢ
```

我们有 n 组观测 (xᵢ, yᵢ)，目标是估计 β₀ 和 β₁。

最小二乘法要求最小化：

```
S(β₀, β₁) = Σᵢ (yᵢ − β₀ − β₁xᵢ)²
```

联立偏导数为零的方程组，解得：

```
β̂₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²

β̂₀ = ȳ − β̂₁ x̄
```

### 矩阵形式（现代表述）

用矩阵写出来更优雅：

```
y = Xβ + ε

最小二乘解：β̂ = (XᵀX)⁻¹Xᵀy
```

这个公式今天仍然是线性回归的核心，出现在几乎所有统计软件中。

## 五、高斯的更深一步：为什么最小二乘是"最优"的？

光有方法还不够。高斯问：**在什么条件下，最小二乘法是所有无偏估计中方差最小的最优方法？**

### 高斯的误差分布假设

高斯论证说：如果测量误差服从如下分布：

```
f(ε) = (1 / σ√(2π)) · exp(−ε² / 2σ²)
```

也就是**正态分布（Normal Distribution）**，那么最大似然估计（MLE）恰好等同于最小二乘估计。

反过来，他还证明：如果要让算术平均值成为最优估计，误差必须服从正态分布。

这个互相印证的论证，确立了正态分布在统计误差理论中的中心地位。

### 高斯-马尔可夫定理（Gauss-Markov Theorem）

后来的数学家将高斯的思想精确化为**高斯-马尔可夫定理**：

> **在误差满足零均值、等方差、无相关性（但不要求正态）的条件下，OLS（普通最小二乘）估计是所有线性无偏估计中方差最小的——即 BLUE（Best Linear Unbiased Estimator）。**

这个定理是线性回归理论的基石，告诉我们什么时候最小二乘"足够好"。

## 六、正态分布：自然界的钟形曲线

高斯的论文让正态分布声名大噪，正态分布因此又被称为**高斯分布（Gaussian Distribution）**。

### 正态分布的数学形式

```
f(x; μ, σ²) = 1/(σ√(2π)) · exp(−(x−μ)² / 2σ²)
```

| 参数 | 含义 |
|------|------|
| μ | 均值，决定分布中心位置 |
| σ² | 方差，决定分布的"胖瘦" |

### 正态分布的三大神奇性质

**① 中心极限定理（Central Limit Theorem）**

无论原始数据服从什么分布，足够多独立同分布变量的**均值**，其分布都趋近正态分布。

这解释了为什么自然界中那么多现象接近正态分布：成年人的身高、测量误差、智力测试分数……因为它们都是大量微小随机因素叠加的结果。

**② 最大熵性质**

在均值和方差固定的条件下，正态分布的熵最大——它是"最不确定"、最"诚实"的分布，对数据做了最少的额外假设。

**③ 稳定性**

两个正态分布的和仍是正态分布：若 X ~ N(μ₁, σ₁²)，Y ~ N(μ₂, σ₂²)，则 X+Y ~ N(μ₁+μ₂, σ₁²+σ₂²)。

### 68-95-99.7 法则

| 范围 | 包含数据比例 |
|------|-------------|
| μ ± 1σ | 约 **68.3%** |
| μ ± 2σ | 约 **95.4%** |
| μ ± 3σ | 约 **99.7%** |

"6σ 质量管理"就来源于此——允许误差在均值 6 个标准差以内，意味着每百万次中仅有 3.4 次缺陷。

## 七、与勒让德的优先权之争

高斯在 1809 年书中发表了最小二乘法，但他声称早在 1794 或 1795 年就已发明此方法，只是没有公开发表。

然而，法国数学家**阿德里安-马里·勒让德（Adrien-Marie Legendre）**于 **1805 年**在他的著作《彗星轨道新方法》中第一次**公开发表**了最小二乘法。

这场优先权争议在数学史上颇为著名，两人都宣称自己最先发明。今天，学界普遍认为：

- **勒让德**享有**公开发表**的优先权（1805）
- **高斯**可能更早独立发现，且给出了更深的理论（通过误差分布的概率论证）

这是数学史上著名的"独立发现"案例之一，和牛顿-莱布尼茨发明微积分的争议颇为相似。

---

## 八、谷神星的故事：最小二乘法的试炼

回到开头的故事。高斯用最小二乘法处理了皮亚齐的 41 个观测数据：

1. 建立轨道方程（六个轨道参数的非线性系统）
2. 通过线性化方法，将非线性问题转化为线性最小二乘
3. 迭代求解，得到谷神星轨道的精确预测

1801 年 12 月 7 日，天文学家弗朗茨·冯·扎克按照高斯的预测，找到了谷神星。

这一事件震惊欧洲科学界。一个数学工具，凭借仅 41 个数据点，将一颗行星从天空中找回来。

## 九、影响：统计学与工程学的核心工具

**高斯的遗产**体现在几乎所有定量科学领域：

| 领域 | 应用 |
|------|------|
| 天文学 / 导航 | 卫星轨道拟合，GPS 定位 |
| 经济计量学 | OLS 线性回归，宏观经济模型估计 |
| 机器学习 | 线性回归，岭回归，高斯过程回归 |
| 信号处理 | 卡尔曼滤波（状态估计的最小二乘） |
| 测量工程 | 误差分析，仪器校准 |
| 深度学习 | 均方误差损失函数（MSE）= 最小二乘 |

---

## 十、总结：两个永恒的礼物

高斯 1809 年的著作给统计学留下了两件无价的礼物：

**礼物一：最小二乘法** — 一种在存在测量误差时估计参数的系统方法，以及它在正态误差假设下的最优性证明。

**礼物二：正态分布的中心地位** — 通过误差理论的推导，将这条钟形曲线确立为自然界变异性的数学描述，并与最优估计理论深度绑定。

两者共同构成了经典统计学的骨架，200 多年来支撑着人类对数据的全部定量理解。现代机器学习中每一次用梯度下降最小化 MSE 损失，都是高斯思想的直接延续。
