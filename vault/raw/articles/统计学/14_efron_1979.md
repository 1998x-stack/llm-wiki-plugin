## 一、历史背景：统计推断的计算瓶颈

对于简单的统计量，有解析标准误差公式（如均值：SE = s/√n）。但对于：
- 中位数的标准误差？
- 两个中位数之比的置信区间？
- 机器学习模型预测精度的置信区间？

这些情形往往没有简洁解析公式，或者依赖可能不成立的分布假设。

**布拉德利·埃弗龙（Bradley Efron, 1938–）** 的答案：**让计算机来做这件事。**

---

## 二、Bootstrap 的核心思想

### 2.1 关键洞察

**问题**：我们想知道估计量 θ̂ = T(x) 的抽样分布——如果重复从总体中抽取样本，θ̂ 的分布是什么？

**现实困境**：我们只有一个样本，无法真的重复从总体抽样。

**埃弗龙的洞察**：
> 真实总体之于我们的样本，就像我们的样本之于 Bootstrap 样本。

用样本本身模拟总体：将观测样本 {x₁, ..., xₙ} 视为经验分布（每点概率 1/n），从中**有放回地重抽**。

### 2.2 Bootstrap 算法

```
给定样本 x = {x₁, x₂, ..., xₙ}，感兴趣的统计量 T(x)

重复 B 次（B = 1000 或更多）：
    1. 从 {x₁,...,xₙ} 中有放回地抽取 n 个观测
       → Bootstrap 样本 x* = {x₁*, ..., xₙ*}
    2. 计算 θ̂* = T(x*)

得到 B 个 Bootstrap 估计值：{θ̂*₁, ..., θ̂*_B}
这 B 个值的分布 ≈ θ̂ 的抽样分布
```

### 2.3 Bootstrap 标准误差

    ŜE_boot = √[1/(B-1) · Σ_b(θ̂*_b - θ̄*)²]

其中 θ̄* = 1/B · Σ_b θ̂*_b。

这就是 Bootstrap 标准误差的估计——不需要任何解析推导，只需重复抽样和计算。

## 三、Bootstrap 置信区间的四种构造方式

| 方法 | 公式 | 特点 |
|------|------|------|
| **正态近似法** | θ̂ ± z_{α/2} · ŜE_boot | 最简单，依赖正态性假设 |
| **百分位法** | [θ̂*_{(α/2)}, θ̂*_{(1-α/2)}] | 直观，无需正态假设 |
| **枢轴法** | [2θ̂ - θ̂*_{(1-α/2)}, 2θ̂ - θ̂*_{(α/2)}] | 对百分位法的对称修正 |
| **BCa 法** | 修正偏差+加速度的分位数 | **理论性质最好，推荐使用** |

---

## 四、关键数字：36.8%

有放回抽样时，平均约有 1 - e⁻¹ ≈ 36.8% 的原始样本**不会**出现在 Bootstrap 样本中。这些样本称为该次 Bootstrap 的 **Out-of-Bag（OOB）** 样本。

这个数字是：
- **随机森林 OOB 误差估计**的基础（无需单独验证集）
- **.632 Bootstrap 误差估计**：Err^{.632} = 0.368 · err_train + 0.632 · Err_boot

## 五、Jackknife vs Bootstrap

**Jackknife 方法**：每次删去一个观测，计算 n 个"留一"估计量，用其变异估计标准误差。

| 维度 | Bootstrap | Jackknife |
|------|-----------|-----------|
| 思想 | 有放回重抽 | 系统性删除 |
| 样本数 | B 个（B 很大）| n 个（固定）|
| 适用范围 | 几乎所有统计量 | 光滑统计量效果好 |
| 非光滑统计量（中位数）| 效果好 | 效果差 |
| 理论性质 | 更强（可估计高阶误差）| 一阶近似 |

埃弗龙证明：**Bootstrap 是 Jackknife 的推广和改进**，Jackknife 是 Bootstrap 的线性近似。

## 六、Bootstrap 对机器学习的深远影响

### Bagging（Bootstrap Aggregating，Breiman 1994）

从训练集有放回地抽取 B 个 Bootstrap 样本，在每个上训练一个模型，取平均（或投票）。

**核心效果**：降低方差，减少过拟合。

**直接应用**：随机森林（Random Forests）的核心技术。

### 广泛的应用范围

| 应用 | 说明 |
|------|------|
| 任意统计量的标准误差 | 中位数、四分位距、Gini 系数等 |
| 相关系数的置信区间 | 不依赖正态假设 |
| 回归系数的稳健推断 | 不依赖残差正态性 |
| 机器学习模型的泛化误差 | .632+ Bootstrap 估计 |
| 集成学习（Bagging）| Random Forest 的核心 |
| Bootstrap 置换检验 | 假设检验 |
| Block Bootstrap | 时间序列（保留时序相关结构）|

---

## 七、Bootstrap 的局限性

| 局限 | 说明 |
|------|------|
| 需要足够大的原始样本 | 样本量极小时（n<10），效果差 |
| 对尾部估计不可靠 | 极端分位数（如 99.9%）的 Bootstrap 方差大 |
| 独立性假设 | 标准 Bootstrap 要求独立观测，时间序列需 Block Bootstrap |
| 不能外推 | 只描述样本内的不确定性，不能超出观测数据范围 |

---

## 八、总结

Bootstrap 是统计学历史上最优雅的思想之一。它的革命性在于：**将推导难题转化为计算问题**。

在计算机出现之前，统计学家必须为每个统计量单独推导抽样分布，往往需要强大的数学技巧和分布假设。Bootstrap 将这个过程自动化：

    任意统计量 T(x)  +  原始样本  +  计算机  →  抽样分布的近似

这种"用数据模拟数据"的思想，在大数据和深度学习时代变得更加重要——当模型极其复杂、解析推导完全不可能时，计算统计是唯一的出路。
