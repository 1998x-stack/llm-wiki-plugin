# 01 · Claude Code 系统总览 & Tech Stack

> **核心定位**：Claude Code 是运行在终端的自主编码智能体。
> 极简 Harness——LLM 大脑 + 真实世界身体（Shell / 文件系统 / 外部服务）。

---

## 产品哲学："The product is the model"

> *"我们想让人直接感受到模型本身。很多编码产品把 LLM 层层包裹，让模型像瘸着腿走路。"*
> — Boris Cherny，Claude Code 创始工程师

### 三代 LLM 应用演化

| 时代 | 范式 | 控制权归属 |
|------|------|-----------|
| 第一代：聊天机器人 | 无状态问答 | 人 |
| 第二代：工作流（LangChain / n8n） | 代码驱动的 DAG 链 | 代码 |
| **第三代：自主 Agent（Claude Code）** | **模型驱动的循环** | **模型** |

---

## Tech Stack

| 层 | 技术 | 选型原因 |
|----|------|---------|
| 语言 | TypeScript | 类型安全 + 模型自编率极高 |
| UI 框架 | React + Ink | 声明式终端 UI，模型可控 |
| 布局引擎 | Yoga（Meta 开源） | 约束布局，适配任意终端宽度 |
| 构建工具 | Bun | 比 Webpack/Vite 显著更快 |
| API | Anthropic Messages API | 直接暴露模型能力 |
| 协议 | MCP（Model Context Protocol） | 标准化外部服务接入 |
| 持久化 | `~/.claude/sessions/<id>/transcript.jsonl` | 会话历史，支持 /resume |

> **关键数据**：90% 的 Claude Code 代码由 Claude Code 自己编写。

## 四大能力基元（Capability Primitives）

| 基元 | 代表工具 | 能力覆盖 |
|------|---------|---------|
| **Read（读）** | View · LS · Glob · GrepTool | 理解代码库、搜索文件 |
| **Write（写）** | Edit · Write/Replace · Create | patch · 全文替换 · 新建文件 |
| **Execute（执行）** | Bash（持久 Shell 会话） | git · npm · docker · pytest |
| **Connect（连接）** | MCP 协议 | GitHub · DB · Sentry · Slack |

> **Bash 是通用适配器**：让 Claude Code 使用任何人类开发者会用的工具，无需专用集成。

## 最少业务逻辑原则

```
Client 端 = UI 渲染 + 工具路由（仅此而已）
智能      = 模型（不在客户端代码里硬编码）
添加功能  = 给模型更好的工具（而非更复杂的客户端逻辑）

结果：
  · 调试更容易 → 行为来自模型，可通过提示重现
  · 测试更快速 → 无需 mock 复杂业务逻辑层
  · 迭代更迅速 → 改工具接口比改业务逻辑快得多
```
