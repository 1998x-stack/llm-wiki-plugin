## 一、历史背景：RNN 的梯度消失困境

循环神经网络（RNN）天生适合处理序列数据，但有一个致命问题：**梯度消失（Vanishing Gradient）**。

标准 RNN 的递推公式：

```
hₜ = tanh(Wₕ · hₜ₋₁ + Wₓ · xₜ + b)
```

反向传播时，梯度从 t=T 传回 t=1 需要连乘权重矩阵：

```
∂L/∂h₁ = ∂L/∂hₜ · ∏ₜ'₌₂ᵀ (∂hₜ'/∂hₜ'₋₁)
        = ∂L/∂hₜ · ∏ₜ'₌₂ᵀ (Wₕᵀ · diag(tanh'(·)))

tanh'(x) ∈ (0, 1)，最大值 1（且通常远小于 1）
连乘 T 次后 → 指数级衰减 → 梯度 ≈ 0
```

**实际后果**：标准 RNN 几乎无法记住"10步以前发生的事"，序列建模能力严重受限。

Hochreiter 早在 1991 年的硕士论文中就分析了这一问题。1997 年，他与导师 Schmidhuber 提出了 LSTM——通过**门控机制**和**细胞状态**从根本上解决这一困境。

---

## 二、LSTM 的核心：细胞状态与门控

LSTM 引入了一条贯穿整个序列的"信息高速公路"——**细胞状态 Cₜ**，并通过三个门精确控制信息流动：

```
Cₜ₋₁ ──[遗忘门]──→──[+]──→── Cₜ ──→──[输出门]──→ hₜ
                    ↑
              [输入门] × [候选值]
```

### 遗忘门（Forget Gate）

决定从细胞状态中丢弃什么：

```
fₜ = σ(Wf · [hₜ₋₁, xₜ] + bf)    →  [0, 1]

f=0：完全遗忘（清空细胞状态）
f=1：完全保留（原封不动传递）
```

### 输入门（Input Gate）

决定将什么新信息写入细胞状态：

```
iₜ  = σ(Wi · [hₜ₋₁, xₜ] + bi)   →  控制更新量 [0,1]
C̃ₜ  = tanh(Wc · [hₜ₋₁, xₜ] + bc) →  候选新信息 [-1,1]
```

### 细胞状态更新

```
Cₜ = fₜ ⊙ Cₜ₋₁  +  iₜ ⊙ C̃ₜ
      ↑ 遗忘旧信息      ↑ 加入新信息
```

### 输出门（Output Gate）

决定输出什么：

```
oₜ = σ(Wo · [hₜ₋₁, xₜ] + bo)
hₜ = oₜ ⊙ tanh(Cₜ)
```

---

## 三、为什么 LSTM 能解决梯度消失？

细胞状态的梯度传播：

```
∂Cₜ/∂Cₜ₋₁ = fₜ

若 fₜ ≈ 1（遗忘门接近开启）：
  梯度通过加法直接传递，不衰减！

对比 RNN：∂hₜ/∂hₜ₋₁ = Wₕᵀ · diag(tanh'(·))
  需要乘以小于 1 的数，连乘后指数衰减
```

**类比**：
- **标准 RNN**：像用粉笔写黑板，每次更新都会覆盖之前的内容
- **LSTM 细胞状态 Cₜ**：像一本可以精确"写入"、"擦除"、"读取"的日记本

---

## 四、LSTM 各门的语言学直觉

以语言模型为例，处理句子"**小明**是中国人。**他**喜欢..."

| 门 | 时刻 | 行为 |
|----|------|------|
| 输入门 | 遇到"小明" | 写入主语"小明"的信息 |
| 遗忘门 | 遇到句号 | 可能清除上一句的主语 |
| 输入门 | 遇到"他" | 保留"他=小明"的关联 |
| 输出门 | 需要预测下一个词 | 输出与当前上下文相关的隐藏状态 |

## 五、完整代码实现

```python
import numpy as np
import torch
import torch.nn as nn
from typing import Tuple, Optional


# ── 方式一：从零实现（展示门控数学）──────────────────────

class LSTMCellNumpy:
    """
    LSTM 单步计算（NumPy 实现，展示数学细节）
    Hochreiter & Schmidhuber (1997)
    """

    def __init__(self, input_size: int, hidden_size: int):
        self.input_size = input_size
        self.hidden_size = hidden_size
        H, I = hidden_size, input_size

        # 所有门的权重合并为一个矩阵（提高计算效率）
        # [遗忘门 f | 输入门 i | 候选值 g | 输出门 o]
        self.W = np.random.randn(H + I, 4 * H) * 0.01   # (H+I, 4H)
        self.b = np.zeros(4 * H)

    def forward(self, x: np.ndarray,
                h_prev: np.ndarray,
                c_prev: np.ndarray) -> Tuple[np.ndarray, np.ndarray]:
        """
        LSTM 单步前向计算

        Args:
            x:      当前输入，shape (batch, input_size)
            h_prev: 上一步隐藏状态，shape (batch, hidden_size)
            c_prev: 上一步细胞状态，shape (batch, hidden_size)

        Returns:
            h_new: 新隐藏状态
            c_new: 新细胞状态
        """
        # 拼接 [h_{t-1}, x_t]
        combined = np.concatenate([h_prev, x], axis=1)  # (batch, H+I)

        # 一次性计算所有门
        gates = combined @ self.W + self.b               # (batch, 4H)
        H = self.hidden_size

        # 拆分四个门
        f = self._sigmoid(gates[:, 0:H])        # 遗忘门
        i = self._sigmoid(gates[:, H:2*H])      # 输入门
        g = np.tanh(gates[:, 2*H:3*H])          # 候选细胞（用 tanh 非 sigmoid）
        o = self._sigmoid(gates[:, 3*H:4*H])    # 输出门

        # 细胞状态更新（关键：加法保证梯度畅通）
        c_new = f * c_prev + i * g

        # 隐藏状态
        h_new = o * np.tanh(c_new)

        return h_new, c_new

    @staticmethod
    def _sigmoid(x: np.ndarray) -> np.ndarray:
        return 1.0 / (1.0 + np.exp(-np.clip(x, -500, 500)))


# ── 方式二：PyTorch 模块（实际使用）────────────────────

class LSTMLanguageModel(nn.Module):
    """
    基于 LSTM 的字符级语言模型

    结构：Embedding → LSTM（多层）→ 全连接 → Softmax
    """

    def __init__(self, vocab_size: int, embed_dim: int = 256,
                 hidden_dim: int = 512, num_layers: int = 2,
                 dropout: float = 0.3):
        """
        Args:
            vocab_size: 词汇表大小
            embed_dim:  词嵌入维度
            hidden_dim: LSTM 隐藏维度
            num_layers: LSTM 层数
            dropout:    Dropout 概率（多层 LSTM 层间）
        """
        super().__init__()
        self.hidden_dim = hidden_dim
        self.num_layers = num_layers

        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout if num_layers > 1 else 0.0,
        )
        self.dropout = nn.Dropout(dropout)
        self.fc = nn.Linear(hidden_dim, vocab_size)

        # 权重绑定（embedding 与输出层共享权重，节省参数）
        if embed_dim == hidden_dim:
            self.fc.weight = self.embedding.weight

    def forward(self, x: torch.Tensor,
                states: Optional[Tuple[torch.Tensor, torch.Tensor]] = None
                ) -> Tuple[torch.Tensor, Tuple[torch.Tensor, torch.Tensor]]:
        """
        Args:
            x:      输入 token ID，shape (batch, seq_len)
            states: (h_0, c_0)，可选初始状态

        Returns:
            logits: (batch, seq_len, vocab_size)
            states: (h_n, c_n)，用于下一批次
        """
        emb = self.dropout(self.embedding(x))           # (B, T, E)
        out, (h_n, c_n) = self.lstm(emb, states)        # out: (B, T, H)
        logits = self.fc(self.dropout(out))             # (B, T, vocab)
        return logits, (h_n, c_n)

    def init_hidden(self, batch_size: int, device: torch.device
                    ) -> Tuple[torch.Tensor, torch.Tensor]:
        """初始化隐藏状态和细胞状态为零"""
        return (torch.zeros(self.num_layers, batch_size, self.hidden_dim, device=device),
                torch.zeros(self.num_layers, batch_size, self.hidden_dim, device=device))


class LSTMClassifier(nn.Module):
    """
    基于 LSTM 的序列分类器（情感分析等）
    使用最后时间步的隐藏状态作为序列表示
    """

    def __init__(self, vocab_size: int, embed_dim: int,
                 hidden_dim: int, num_classes: int,
                 num_layers: int = 1, dropout: float = 0.3,
                 bidirectional: bool = False):
        super().__init__()
        self.bidirectional = bidirectional
        direction = 2 if bidirectional else 1

        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.lstm = nn.LSTM(
            embed_dim, hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout if num_layers > 1 else 0.0,
            bidirectional=bidirectional,
        )
        self.classifier = nn.Sequential(
            nn.Dropout(dropout),
            nn.Linear(hidden_dim * direction, hidden_dim),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, num_classes),
        )

    def forward(self, x: torch.Tensor,
                lengths: Optional[torch.Tensor] = None) -> torch.Tensor:
        emb = self.embedding(x)                          # (B, T, E)

        if lengths is not None:
            # 处理变长序列（pack padding）
            emb = nn.utils.rnn.pack_padded_sequence(
                emb, lengths.cpu(), batch_first=True, enforce_sorted=False)

        output, (h_n, c_n) = self.lstm(emb)

        if lengths is not None:
            output, _ = nn.utils.rnn.pad_packed_sequence(output, batch_first=True)

        # 取最后一步的隐藏状态（双向则拼接两个方向）
        if self.bidirectional:
            last_hidden = torch.cat([h_n[-2], h_n[-1]], dim=1)
        else:
            last_hidden = h_n[-1]                        # (B, H)

        return self.classifier(last_hidden)


# ── 演示 ─────────────────────────────────────────────
if __name__ == "__main__":
    # 展示 NumPy LSTM 单步计算
    print("=== NumPy LSTM 单步前向传播 ===")
    cell = LSTMCellNumpy(input_size=4, hidden_size=8)
    batch = 2
    x = np.random.randn(batch, 4)
    h = np.zeros((batch, 8))
    c = np.zeros((batch, 8))
    h_new, c_new = cell.forward(x, h, c)
    print(f"  h_new shape: {h_new.shape}")   # (2, 8)
    print(f"  c_new shape: {c_new.shape}")   # (2, 8)
    print(f"  h_new（前4维）: {h_new[0, :4].round(4)}")

    # PyTorch LSTM 分类器
    print("\n=== PyTorch LSTM 分类器 ===")
    model = LSTMClassifier(
        vocab_size=10000, embed_dim=128, hidden_dim=256,
        num_classes=2, num_layers=2, bidirectional=True
    )
    x = torch.randint(1, 10000, (32, 50))   # batch=32, seq_len=50
    logits = model(x)
    print(f"  输入 shape: {x.shape}")
    print(f"  输出 shape: {logits.shape}")   # (32, 2)
    total = sum(p.numel() for p in model.parameters())
    print(f"  参数量: {total:,}")

    # 语言模型
    print("\n=== PyTorch LSTM 语言模型 ===")
    lm = LSTMLanguageModel(vocab_size=256, embed_dim=128, hidden_dim=256, num_layers=2)
    x_lm = torch.randint(0, 256, (4, 100))  # batch=4, seq_len=100
    logits_lm, (h, c) = lm(x_lm)
    print(f"  logits shape: {logits_lm.shape}")   # (4, 100, 256)
    print(f"  h shape: {h.shape}")                 # (2, 4, 256)
```

## 七、LSTM 的退出与传承

2017 年 Transformer 问世后，LSTM 在 NLP 主要任务上逐步退场：

```
LSTM（1997）
  → 双向 LSTM（Bi-LSTM，2005）
  → Encoder-Decoder + Attention（2014–2015）
  → Transformer（2017，彻底替代 RNN）
  → BERT / GPT（2018+）

但 LSTM 在：时间序列、嵌入式/边缘设备、强化学习
等场景仍广泛使用（2024年仍活跃）
```
