## 一、历史背景：生成模型的困境

在 GAN 之前，生成模型（学习数据分布、生成新样本）面临根本性难题：

```
显式密度估计：
  VAE（变分自编码器）→ 需要近似推断，生成质量受限于先验假设
  受限玻尔兹曼机   → 计算复杂度极高，难以扩展

自回归模型：
  PixelRNN/CNN     → 逐像素生成，速度极慢
```

2014 年，Ian Goodfellow 在蒙特利尔一次酒吧争论后，当晚回家实现了 GAN，并在第二天测试成功。他的灵感来自一个极为简洁的博弈论框架：

> **"无需显式建模数据分布，只需让两个网络相互竞争。"**

---

## 二、核心思想：造假者与鉴别专家的博弈

```
生成器 G（Generator）—— "造假者"
  输入：随机噪声向量 z ~ N(0, I)
  输出：伪造数据 G(z)（如假图像）
  目标：生成以假乱真的样本，欺骗判别器

判别器 D（Discriminator）—— "鉴别专家"
  输入：真实数据 x 或 生成数据 G(z)
  输出：是真实数据的概率 D(·) ∈ [0, 1]
  目标：正确区分真实 vs 生成数据

博弈结果：G 的生成质量不断提高 → D 越来越难区分 → 均衡点
```

这是一个**零和博弈（Minimax Game）**：G 的收益 = D 的损失。

---

## 三、数学目标函数

```
min_G max_D V(D, G) =
  E_{x ~ p_data}[ log D(x) ]          ← D 对真实数据输出接近 1
+ E_{z ~ p_z}  [ log(1 - D(G(z))) ]   ← D 对生成数据输出接近 0
                                          （G 希望最大化 D(G(z))）
```

**直觉**：
- D 想**最大化** V（正确区分真假）
- G 想**最小化** V（让 D 犯错）

**实践中 G 的目标改为**：最大化 `log D(G(z))` 而非最小化 `log(1-D(G(z)))`，因为早期训练时后者梯度接近零（梯度饱和问题）。

---

## 四、理论保证：纳什均衡

Goodfellow 严格证明了：

**命题 1**：给定 G，最优判别器为：

```
D*_G(x) = p_data(x) / (p_data(x) + p_g(x))
```

**命题 2**：全局最优点为 p_g = p_data（生成分布等于真实分布），此时：

```
D*(x) = 1/2（无法区分真假）
C(G*) = -log 4（最小全局损失）
```

**定理**：若 G 和 D 有足够容量，且训练算法每步更新 D 至最优，则算法收敛至 p_g = p_data。

注意：现实中此理论条件无法满足，GAN 训练极不稳定。

---

## 五、训练算法

```
for 每个训练步骤：

  # ── 训练判别器（k步，通常 k=1）──
  采样 m 个真实样本 { x₁, ..., xₘ } ~ p_data
  采样 m 个噪声向量 { z₁, ..., zₘ } ~ p_z

  上升梯度（最大化 V）：
    ∇_D [ 1/m Σ(log D(xᵢ) + log(1 - D(G(zᵢ)))) ]

  # ── 训练生成器（1步）──
  采样 m 个新噪声向量 { z₁, ..., zₘ }

  下降梯度（最小化，等价于最大化 log D(G(z))）：
    ∇_G [ 1/m Σ log(1 - D(G(zᵢ))) ]
    （实践：改为 ∇_G [ 1/m Σ log D(G(zᵢ)) ]）
```

---

## 六、GAN 的常见训练问题

| 问题 | 表现 | 解决方案 |
|------|------|---------|
| **模式崩塌（Mode Collapse）** | 生成器只生成几种样本 | WGAN、MinibatchGAN |
| **训练不稳定** | 损失震荡，不收敛 | WGAN、谱归一化 |
| **梯度消失** | D 太强时 G 梯度为0 | 改用非饱和损失 |
| **超参数敏感** | 学习率略有不同效果迥异 | 仔细调参、使用 Adam β₁=0.5 |

## 七、完整代码实现

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import numpy as np
from typing import Tuple


class Generator(nn.Module):
    """
    生成器：随机噪声 z → 伪造图像
    使用 BatchNorm + LeakyReLU + Tanh 输出
    """

    def __init__(self, latent_dim: int = 100,
                 img_channels: int = 1, img_size: int = 28):
        """
        Args:
            latent_dim:   噪声向量维度（潜在空间维度）
            img_channels: 图像通道数（灰度=1，RGB=3）
            img_size:     图像边长（MNIST=28）
        """
        super().__init__()
        img_dim = img_channels * img_size * img_size

        def block(in_dim: int, out_dim: int, normalize: bool = True):
            layers = [nn.Linear(in_dim, out_dim)]
            if normalize:
                layers.append(nn.BatchNorm1d(out_dim, momentum=0.8))
            layers.append(nn.LeakyReLU(0.2, inplace=True))
            return layers

        self.net = nn.Sequential(
            *block(latent_dim, 128, normalize=False),
            *block(128, 256),
            *block(256, 512),
            *block(512, 1024),
            nn.Linear(1024, img_dim),
            nn.Tanh(),   # 输出范围 [-1, 1]，与归一化后的图像匹配
        )
        self.img_channels = img_channels
        self.img_size = img_size

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        """
        Args:
            z: 噪声向量 (B, latent_dim)
        Returns:
            img: 生成图像 (B, C*H*W)
        """
        return self.net(z)

    def generate_image(self, z: torch.Tensor) -> torch.Tensor:
        """生成并 reshape 为图像格式"""
        flat = self.net(z)
        return flat.view(-1, self.img_channels, self.img_size, self.img_size)


class Discriminator(nn.Module):
    """
    判别器：图像 → 真/假概率
    使用 LeakyReLU（防止梯度消失）+ Dropout（防止过拟合）
    注意：不使用 BatchNorm（会导致模式崩塌）
    """

    def __init__(self, img_channels: int = 1, img_size: int = 28):
        super().__init__()
        img_dim = img_channels * img_size * img_size

        self.net = nn.Sequential(
            nn.Linear(img_dim, 512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Dropout(0.3),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Dropout(0.3),
            nn.Linear(256, 1),
            nn.Sigmoid(),  # 输出真实概率
        )

    def forward(self, img: torch.Tensor) -> torch.Tensor:
        """
        Args:
            img: 图像 (B, C*H*W) 或 (B, C, H, W)
        Returns:
            validity: 真实概率 (B, 1)
        """
        if img.dim() > 2:
            img = img.view(img.size(0), -1)
        return self.net(img)


class GANTrainer:
    """
    GAN 训练器
    实现原论文的 Minimax 训练循环
    """

    def __init__(self, latent_dim: int = 100,
                 img_channels: int = 1, img_size: int = 28,
                 device: torch.device = None):
        self.latent_dim = latent_dim
        self.device = device or torch.device("cuda" if torch.cuda.is_available() else "cpu")

        self.G = Generator(latent_dim, img_channels, img_size).to(self.device)
        self.D = Discriminator(img_channels, img_size).to(self.device)

        # 论文推荐：Adam，β₁=0.5（比默认的0.9更稳定）
        self.opt_G = optim.Adam(self.G.parameters(), lr=2e-4, betas=(0.5, 0.999))
        self.opt_D = optim.Adam(self.D.parameters(), lr=2e-4, betas=(0.5, 0.999))
        self.criterion = nn.BCELoss()

        # 固定噪声用于可视化（每 epoch 生成相同的图像对比进展）
        self.fixed_z = torch.randn(16, latent_dim, device=self.device)

    def train_step(self, real_imgs: torch.Tensor) -> Tuple[float, float]:
        """
        单步训练（一个 batch）

        Returns:
            loss_D: 判别器损失
            loss_G: 生成器损失
        """
        batch_size = real_imgs.size(0)
        real_imgs = real_imgs.view(batch_size, -1).to(self.device)

        real_labels = torch.ones(batch_size, 1, device=self.device)
        fake_labels = torch.zeros(batch_size, 1, device=self.device)

        # ── 训练判别器 ──────────────────────────────
        z = torch.randn(batch_size, self.latent_dim, device=self.device)
        fake_imgs = self.G(z).detach()  # detach：阻止梯度流向 G

        loss_real = self.criterion(self.D(real_imgs), real_labels)
        loss_fake = self.criterion(self.D(fake_imgs), fake_labels)
        loss_D = (loss_real + loss_fake) / 2

        self.opt_D.zero_grad()
        loss_D.backward()
        self.opt_D.step()

        # ── 训练生成器 ──────────────────────────────
        z = torch.randn(batch_size, self.latent_dim, device=self.device)
        fake_imgs = self.G(z)
        # G 希望 D 把假图判为真 → 目标标签设为 real_labels
        loss_G = self.criterion(self.D(fake_imgs), real_labels)

        self.opt_G.zero_grad()
        loss_G.backward()
        self.opt_G.step()

        return loss_D.item(), loss_G.item()

    def train(self, dataloader: DataLoader, n_epochs: int = 50) -> None:
        for epoch in range(1, n_epochs + 1):
            d_losses, g_losses = [], []
            for batch_idx, (imgs, _) in enumerate(dataloader):
                loss_D, loss_G = self.train_step(imgs)
                d_losses.append(loss_D)
                g_losses.append(loss_G)

            if epoch % 5 == 0 or epoch == 1:
                print(f"Epoch [{epoch:3d}/{n_epochs}] | "
                      f"D_loss: {np.mean(d_losses):.4f} | "
                      f"G_loss: {np.mean(g_losses):.4f}")


# ── 演示 ──────────────────────────────────────────────
if __name__ == "__main__":
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    print(f"使用设备：{device}")

    # 数据集（MNIST）
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize([0.5], [0.5]),   # 归一化到 [-1, 1]
    ])
    # dataset = datasets.MNIST("./data", train=True, transform=transform, download=True)
    # dataloader = DataLoader(dataset, batch_size=128, shuffle=True, num_workers=2)

    # 架构验证
    print("\n=== 架构验证 ===")

    z = torch.randn(4, 100)
    fake = G(z)
    validity = D(fake)
    print(f"  噪声 z：{z.shape}")

    # 训练（取消注释以实际运行）
```

## 八、GAN 的演化谱系

```
原版 GAN（2014）
  ↓ 卷积化
DCGAN（2015）：深度卷积GAN，首次生成高质量图像
  ↓ 更好的损失函数
WGAN（2017）：Wasserstein距离，训练更稳定
  ↓ 条件控制
Pix2Pix（2017）：图像到图像的翻译
CycleGAN（2017）：无需配对数据的风格迁移
  ↓ 渐进式训练
PGGAN（2018）：4K分辨率人脸生成
StyleGAN（2019）：风格解耦，NVIDIA，以假乱真
StyleGAN2（2020）：修复伪影，业界最强
  ↓ 被扩散模型超越
Diffusion Models（2020+）：逐渐取代GAN成为生成主流
```
