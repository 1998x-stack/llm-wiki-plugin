- **这可能不仅仅*****只是*****与手机和社交媒体有关。**谈及美国人的焦虑与不幸福感，最显而易见的诱因是智能手机、社交媒体以及美国新闻周期中日益高涨的负面情绪。正如我在上个月一篇长文中所阐述的，我非常认同这样一种观点：手机和社交媒体与美国年轻人幸福感的下降息息相关，而且很可能是导致这一现象的直接原因。但年轻人痛苦感的加剧——这通常被合理地与手机和社交媒体使用量的增加联系在一起——已经持续了大约15年。而我们从综合社会调查（GSS）和密歇根大学的数据中看到的整体健康状况的突然恶化，指向的是2020年左右发生的一次情绪崩溃。因此，即便手机并非罪魁祸首（我稍后会再谈到它们），它们也不能被视为*主要*的罪魁祸首。
