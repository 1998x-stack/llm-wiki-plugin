# Q: Urhox 的 Shader 是什么，有什么用

根据提供的 Wiki 页面内容，**UrhoX 的 Shader** 是基于 **BGFX** 渲染后端的着色器程序，主要用于实现引擎的延迟渲染管线、屏幕空间特效以及地形混合等核心图形功能。

以下是关于 UrhoX Shader 的定义、用途及关键特性的详细解析：

### 1. 是什么？（定义与规范）

*   **技术基础**：UrhoX 使用 **BGFX** 作为渲染后端，Shader 代码通常编写在 `.glsl` 文件中，但遵循 BGFX 的特定语法约束（如特定的宏定义和精度约定）。
*   **文件结构**：
    *   **合并写法**：顶点着色器 (VS) 和像素着色器 (PS) 必须写在**同一个文件**中，通过 `#ifdef COMPILEVS` 和 `#ifdef COMPILEPS`进行条件编译区分。
    *   **命名规范**：文件使用大写驼峰命名（如 `HiZInit.glsl`），函数使用 PascalCase（如 `ReconstructViewPos`）。
*   **特殊的精度约定（关键陷阱）**：
    *   UrhoX 的精度约定与常规 GLSL **相反**。
    *   默认类型 `float`, `vec3` 等为 **半精度 (fp16/HALF)**。
    *   带 `h` 前缀的类型 `hfloat`, `hvec3` 等为 **全精度 (fp32/FULL)**。
    *   **注意**：深度值、矩阵运算、位置重建等必须使用 `hfloat/hvec*`，否则会出现条纹或伪影。
*   **初始化语法**：全精度向量必须使用 `_init()` 函数初始化（如 `hvec2_init(1.0, 2.0)`），不能使用构造器语法。

### 2. 有什么用？（核心功能与应用场景）

UrhoX 的 Shader 主要承担以下三大类任务：

#### A. 实现延迟渲染管线 (Deferred Rendering Pipeline)
Shader 负责执行 `CEMapDeferred.xml` 定义的 10 个渲染阶段，包括：
*   **GBuffer Pass**：将几何属性（法线、PBR参数、反照率、自发光）写入多个 RenderTarget。
*   **HiZ Generation**：生成层级深度缓冲（Closest/Farthest HiZ），为后续特效提供加速结构。
*   **Deferred Lighting**：计算直接光照和环境光漫反射，并分离输出 specular 通道。
*   **Post Process**：执行 Bloom、Tonemapping 等后处理效果。

#### B. 实现核心屏幕空间特效 (Screen Space Effects)
Shader 实现了高性能的画面增强效果，具体包括：
*   **GTAO (Ground Truth Ambient Occlusion)**：基于 Intel XeGTAO 移植，提供高质量的 ambient occlusion。
*   **SSR (Screen Space Reflections)**：实现屏幕空间反射，支持 Linear/HiZ Trace，并通过 Temporal Filter 去噪。
*   **TAA (Temporal Anti-Aliasing)**：使用时域抗锯齿消除锯齿，采用 Catmull-Rom 双三次历史采样以保持锐度。
*   **Motion Vector**：生成运动向量用于 TAA 和动态模糊。

#### C. 实现复杂材质混合 (TileTerrain Blending)
在地形系统中，Shader 负责处理多纹理平滑过渡：
*   **ID + Weight 混合**：通过读取 Control Map 纹理，在 Pixel Shader 中手动进行双线性插值。
*   **唯一 ID 筛选**：从相邻 Texel 中筛选出最多 3 个唯一的 Layer ID，并使用“优先级独占”机制累加权重，确保混合结果正确且无分支开销。
*   **避免插值错误**：使用 `texelFetch` 读取离散 ID，防止 GPU 硬件对整数 ID 进行错误的线性插值。

### 3. 开发中的关键注意事项

*   **Sampler 绑定**：Sampler 变量名必须包含**数字后缀**（如 `u_Depth0`），引擎据此绑定 register，否则会导致纹理采样全黑。
*   **Uniform 映射**：RenderPath XML 中的 parameter 会自动映射为 Shader 中的 uniform，命名需对应（如 `MyParam` -> `u_MyParam`）。
*   **矩阵乘法顺序**：UrhoX 使用**行向量**约定，即 `mul(vec, mat)`（向量在左，矩阵在右）。
*   **UV 翻转**：需根据图形 API（D3D11 vs GL）条件翻转 UV 的 Y 轴。
