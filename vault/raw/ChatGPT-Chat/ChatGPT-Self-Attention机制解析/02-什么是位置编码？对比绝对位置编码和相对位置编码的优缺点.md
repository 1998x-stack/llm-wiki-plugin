# 什么是位置编码？对比绝对位置编码和相对位置编码的优缺点

> Source: Self-Attention机制解析
> Time: 4/15/2026, 12:38:15 AM

## Question

什么是位置编码？对比绝对位置编码和相对位置编码的优缺点

## Answer

位置编码（Positional Encoding）是 Transformer 里用来补充序列顺序信息的机制。


因为 Self-Attention 本身只看 token 之间的内容相关性，不自带“先后顺序”概念。对它来说，输入如果只是一个 token 集合，词的排列顺序是感知不到的。所以必须显式加入位置信息，让模型知道：


谁在前，谁在后

两个词相隔多远

一个词处在句首、句中还是句尾


一、为什么需要位置编码


例如这两个句子：


“狗咬人”

“人咬狗”


词几乎一样，但顺序不同，语义完全不同。


如果没有位置编码，Transformer 很难区分这种差异。位置编码的作用，就是把“位置”也编码进每个 token 表示中，使模型能同时利用：


token 内容信息

token 位置信息


通常做法是把位置向量加到词向量上：


$$
x_i' = x_i + p_i
$$


其中：


$x_i$  是第  $i$  个 token 的词向量

$p_i$  是第  $i$  个位置的位置编码



二、绝对位置编码


绝对位置编码的思想是：


直接告诉模型：当前 token 位于第几个位置。


例如：


第 1 个词用位置 1 的编码

第 2 个词用位置 2 的编码

第 3 个词用位置 3 的编码


常见形式


1. 固定式位置编码


Transformer 原始论文中使用的是正弦/余弦位置编码：


$$
PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right)
$$


$$
PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)
$$


优点是不用学习参数，并且理论上可以推广到更长序列。


2. 可学习绝对位置编码


给每个位置分配一个可训练向量：


$$
p_1, p_2, \dots, p_n
$$


这在 BERT、ViT 等模型中很常见。


优点


实现简单，容易直接加到输入 embedding 上

对“当前位置是第几位”表达明确

工程上成熟，训练稳定

对中短序列任务通常效果不错


缺点


更关注“位置编号”，不直接建模 token 之间的相对距离

对长度外泛化往往较差，尤其是可学习绝对位置编码

当句子整体平移时，模型未必能自然保持相同模式
例如某个模式从位置 3-4 变到位置 8-9，绝对编码会明显变化



三、相对位置编码


相对位置编码的思想是：


模型更关心两个 token 之间相隔多远，而不是它们各自处在第几位。


例如在句子中：


token A 在 token B 前面 1 个位置

token C 在 token D 后面 2 个位置


这种“相对距离”在很多语言现象中更重要。


在 Self-Attention 中，相对位置编码通常不是简单加到输入上，而是直接加入到注意力分数计算里，让模型在计算“该关注谁”时考虑相对位置信息。


可以抽象理解为：


$$
\text{AttentionScore}_{ij} = f(q_i, k_j, i-j)
$$


这里  $i-j$  就表示第  $i$  个位置和第  $j$  个位置的相对距离。


优点


更符合序列建模本质，因为很多关系取决于相对距离
例如“前一个词”“后两个词”

对长度变化和位置平移更鲁棒

对长序列外推通常更好

更适合建模局部模式和结构关系


缺点


实现更复杂，通常要改 attention 计算公式

计算和工程优化难度更高

有些相对位置方案会增加额外参数或计算开销

不一定显式保留“这是第几个位置”的全局信息



四、两者的核心区别


可以把它概括成：


绝对位置编码：告诉模型“我在第几位”

相对位置编码：告诉模型“我和你相距多远”


前者强调位置编号，后者强调位置关系。



五、优缺点对比


绝对位置编码


优点：


简单直接

易于实现

训练稳定

很适合标准 Transformer 结构


缺点：


对长序列泛化较弱

对平移不鲁棒

不擅长直接表达相对距离关系


相对位置编码


优点：


更自然地表示 token 间距离关系

更适合长距离依赖和长度外推

对平移更稳健


缺点：


实现复杂

工程成本更高

某些方案会带来额外计算负担



六、什么时候用哪种更合适


一般来说：


中短文本、标准预训练模型：绝对位置编码常常已经够用

长序列建模、外推能力要求高：相对位置编码通常更有优势

关注结构关系而不是绝对编号：相对位置编码更合理



七、一个直观例子


假设句子里有一个模式：


“形容词 + 名词”


这个模式可能出现在：


位置 2 和 3

位置 10 和 11

位置 50 和 51


对于模型来说，真正重要的常常不是“它在第 10 位”，而是“这两个词彼此相邻，且顺序固定”。


这正是相对位置编码更擅长表达的。



八、总结


位置编码的作用是：


给 Transformer 提供序列顺序信息。


两类主要方法区别如下：


绝对位置编码：编码 token 的绝对位置，简单高效，但泛化和相对关系建模较弱

相对位置编码：编码 token 间相对距离，更适合长序列和结构建模，但实现更复杂

绝对位置编码回答“我在哪”，相对位置编码回答“我离你多远”。
