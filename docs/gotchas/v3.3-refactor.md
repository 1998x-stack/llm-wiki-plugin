# v3.3 Refactor Gotchas

> From v3.3 release: shared wiki_utils.py, qwen_ingest improvements, QA pipeline unification.

---

## 18. wiki_utils.py yaml fallback drops nested fields

**Problem**: When `pyyaml` is not installed, `parse_frontmatter()` falls back to simple `key: value` line parsing. This silently drops nested fields (`relates_to`, `tags` arrays, multiline values). Scripts appear to work but produce incomplete data.

**Impact**: All 8 Python scripts depend on `wiki_utils.py`.

**Fix**: Always install pyyaml: `pip install pyyaml`. If you see empty `relates_to` or `tags` in extracted data, check `python3 -c "import yaml; print('OK')"`.

**Status**: Documented. Fallback kept for edge cases where pyyaml genuinely unavailable.

---

## 19. BM25 pickle not portable across Python versions

**Problem**: `corpus.pkl` and `index.pkl` use Python pickle format, which is version-specific. Upgrading Python (e.g. 3.9 → 3.12) breaks deserialization with `ModuleNotFoundError` or `UnpicklingError`.

**Fix**: Delete `index/BM25/` and rebuild: `python3 scripts/bm25_index.py build`.

**Status**: Documented. No plan to switch to JSON (BM25Okapi object is not JSON-serializable).

---

## 20. qwen_ingest dedup is name-only, no semantic matching

**Problem**: `scan_existing_pages()` matches by exact filename stem and frontmatter `aliases`. "马尔可夫" vs "安德烈·马尔可夫" are different names and create duplicates unless one is an alias of the other. The index.md already contains this exact duplicate.

**Fix**: After Qwen ingest, run `wiki:lint` to detect orphans and broken links. Manually merge duplicates by adding aliases to the canonical page.

**Status**: Open. Semantic dedup would require embedding-based similarity, which is a future enhancement.

---

## 21. hook_graph 30s debounce can leave graph stale

**Problem**: `hook_graph.sh` skips rebuild if `graph.json` was modified within 30 seconds. During rapid batch edits (e.g. ingest-loop creating 10 pages in 20s), only the first edit triggers a rebuild.

**Fix**: Run `python3 scripts/build_graph.py` manually after batch operations, or use `wiki:maintain` which calls build at the end.

**Status**: By design. Debounce trades freshness for performance (avoids 185-file re-scan per edit).

---

## 22. qa/ folder deprecated — legacy data not auto-migrated

**Problem**: `wiki:query` previously wrote to `qa/YYYY-MM-DD.md`. It now writes to `raw/qa/qa-YYYYMMDD-HHMMSS.md`. Existing files in `qa/` are orphaned — `wiki:qa-import` does not read from `qa/`.

**Fix**: Manually move files from `qa/` to `raw/qa/` if you want them imported. Format may need adjustment (old format uses daily append log, new format is one-file-per-query with frontmatter).

**Status**: Open. Migration script not yet built.

---

## 23. raw/ read-only exception for raw/qa/

**Problem**: The schema declares `raw/` as immutable (read-only). But `wiki:query` now writes QA records to `raw/qa/`. This is intentional — QA files are source material for `wiki:qa-import`.

**Fix**: N/A — by design. Only `raw/qa/` is writable by commands. The rest of `raw/` remains read-only.

**Status**: Documented.

---

## 24. Content truncation at 100K chars (qwen_ingest)

**Problem**: `qwen_ingest.py` truncates raw input at 100,000 characters. Truncation is byte-position-based (mid-sentence possible). Pages extracted from content beyond the cutoff will be missing entirely.

**Fix**: Split large raw files (>100K chars) manually before ingesting. Check stderr for truncation warnings.

**Status**: By design. DashScope API has token limits.

---

## 25. Edge directionality change in v3.3

**Problem**: Before v3.3, all graph edges were deduplicated bidirectionally (A→B same as B→A). In v3.3, directed relations (`contradicts`, `supersedes`, `extends`, `implements`, `caused`, `depends_on`) preserve direction. This may increase edge count in `graph.json` compared to pre-v3.3 builds.

**Impact**: Graph visualization may show more edges. Statistics (degree, betweenness) may change slightly.

**Fix**: N/A — this is a correctness fix. `wiki:build` will produce the updated graph.

**Status**: Fixed.

---

## 26. XSS in wiki HTML pages (fixed in v3.3)

**Problem**: Before v3.3, wikilink names were inserted into HTML without escaping. A page named `"><script>alert(1)</script>` would execute JavaScript in the static wiki HTML.

**Fix**: v3.3 uses `html.escape()` on all wikilink names and paths in `build_wiki_pages.py`.

**Status**: Fixed.

---

## 27. jieba stderr breaks JSON pipe

**Problem**: First jieba invocation prints dictionary loading progress to stderr. When piping `search_wiki.py --json` output, stderr mixes with stdout and breaks JSON parsing.

**Fix**: Always redirect stderr: `python3 scripts/search_wiki.py "query" --json 2>/dev/null`.

**Status**: Documented. jieba initialization cannot be silenced without monkey-patching.
