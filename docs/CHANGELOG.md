- **`snapshot_index.py --slim`**: rewrites `index.md` from ~626 lines to ~35 lines (stats table + comma-separated global name list). Detailed page listings moved to `maps/*.md`
- **`build_ingest_context.py --topic`**: filters `existing_pages` to only pages in specified topic(s), reducing ingest subagent context from ~600 pages to ~20-70 per topic

  - `综合自 wiki 内部引用` (12) → `综合自内部引用：[[p1]]、[[p2]] 等`
  - URL-with-prefix (3) → `[text](URL)`
  - Academic citations without URL (24) → `[Title (Author Year)](https://doi.org/...)` via lookup table

## [v3.4] - 2026-04-15

### Added
- **`wiki:relink`**: new command — auto-link unlinked wiki term mentions across all pages. Builds term dictionary from page titles + aliases (1003 terms), scans body text with longest-match-first algorithm, inserts `[[wikilinks]]` while protecting frontmatter, code blocks, headings, existing links, and `## 来源`/`## 相关` sections. Idempotent — running twice adds zero new links
- **`scripts/relink.py`**: Python implementation of auto-linking. Protected zones (frontmatter, code, headings, existing `[[]]`, source/related sections). Conflict resolution: terms sorted by length descending, consumed character ranges prevent shorter overlapping matches. Self-reference skip: pages don't link their own title/aliases. JSON output with per-page details
- **`wiki:reorganize-raw`**: new command — Claude analyzes `raw/` content, generates nested category structure in `raw/re-map.json` (folder-level mapping), then `reclassify_raw.py` executes file moves, builds `raw/raw-wiki-map.json`, updates all wiki `[[raw/...]]` source references, and verifies file integrity (pre_count == post_count)
- **`scripts/reclassify_raw.py`**: execute raw/ reclassification from `raw/re-map.json` — no hardcoded categories, reads folder-level mapping, moves files, builds raw→wiki map, updates wiki references, cleans empty dirs. Idempotent (returns `"noop"` when nothing to move)
- **`scripts/build_raw_wiki_map.py`**: scan all wiki pages' `## 来源` sections, extract `[[raw/...]]` links, output `raw/raw-wiki-map.json`
- **`raw/re-map.json`**: folder-level mapping `{"old_path": "new_path"}` — generated by Claude, consumed by `reclassify_raw.py`
- **`raw/raw-wiki-map.json`**: raw file → wiki page list mapping — auto-built during reorganization

### Changed
- **`wiki:maintain` pipeline**: changed from `reindex → check → lint → build` to `reorganize-raw → relink → reindex → check → lint → build` (6-step). Relink runs after reorganize-raw to maximize cross-page linking density; lint restored after check for auto-repair
- **`raw/articles/` structure**: reorganized from ~50 flat folders into 8 top-level categories with 32 nested leaf folders: `ai-tools/`, `ai-engineering/`, `ai-papers/`, `game-dev/`, `programming/`, `academic/`, `essays/`, `personal/`

### Documentation
- DAG.mmd: added `wiki:relink` + `wiki:reorganize-raw` command nodes, `relink.py` + `reclassify_raw.py` + `build_raw_wiki_map.py` script nodes, data nodes, all edges
- All docs updated: CLAUDE.md (root + vault), README.md, USERGUIDE.md, docs/wiki.md, docs/CHANGELOG.md
