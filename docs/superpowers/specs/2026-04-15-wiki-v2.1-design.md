**Date:** 2026-04-15
**Scope:** Topic-clustered index maps, static wiki page viewer, full statistics dashboard
**Prerequisites:** Wiki System V2 (completed)

## Overview

Three features extending the wiki system:
1. **wiki:reindex** — split growing index.md into topic-clustered maps with snapshot integrity checking
2. **Wiki Page Viewer** — static HTML generation from wiki/ markdown, linked from graph.html node clicks
3. **Statistics Dashboard** — graph-statistics.json + statistics.html with Chart.js visualizations

All HTML pages share a consistent design system and cross-navigation (Graph | Statistics | Wiki Index).

## Feature 1: wiki:reindex + maps/ system

### Purpose

As the wiki grows, index.md becomes unwieldy. Split it into topic-clustered sub-indexes under `vault/maps/`, with index.md becoming a lightweight hub.

### Components

#### `scripts/build_reindex.py`

**CLI:** `python3 scripts/build_reindex.py`

**Logic:**
1. Scan all `wiki/**/*.md` files, parse frontmatter (tags, type, relates_to)
2. Cluster pages by primary topic using tag frequency analysis:
   - Group pages that share 2+ tags into the same cluster
   - Name clusters by most frequent tag (e.g., 数值分析, 概率论, 矩阵理论, AI/Agent)
   - Pages with no clear cluster → "其他" (uncategorized)
3. Generate `vault/maps/<topic>.md` for each cluster:
   ```markdown
   ---
   type: map
   topic: 数值分析
   page_count: 15
   updated: 2026-04-15
   ---
   
   # 数值分析
   
   ## 概念
   - [[牛顿法]] — 迭代求根方法 (confidence: 0.9)
   - [[欧拉法]] — 常微分方程数值解 (confidence: 0.85)
   
   ## 实体
   - [[艾萨克·牛顿]] — 数学家、物理学家 (confidence: 0.95)
   ```
4. Rebuild `index.md` as hub:
   ```markdown
   # 知识库目录
   
   ## 主题索引
   - [[maps/数值分析]] — 15 个页面
   - [[maps/概率论]] — 12 个页面
   - [[maps/矩阵理论]] — 20 个页面
   
   ## 统计
   - 总页面数: 110
   - 主题分类: 6
   ```
5. Save `vault/maps/tmp.snapshot.json`:
   ```json
   {
     "generated": "2026-04-15T12:00:00",
     "total": 110,
     "pages": {
       "wiki/concepts/牛顿法.md": {"title": "牛顿法", "cluster": "数值分析"},
       "wiki/entities/牛顿.md": {"title": "艾萨克·牛顿", "cluster": "数值分析"}
     }
   }
   ```

**Dependencies:** pyyaml, json, pathlib, collections

#### `vault/.claude/commands/wiki/reindex.md`

**Input:** none

**Flow:**
1. Run `python3 scripts/build_reindex.py`
2. Read generated maps/ files and report cluster breakdown
3. Verify: compare snapshot with actual wiki/ files — flag any missing/extra pages
4. Update log.md

#### Integrity hook

Add to existing PostToolUse hooks: after Write/Edit on wiki/, check if the file path exists in `maps/tmp.snapshot.json`. If not (new page), flag for next reindex. This is a lightweight check, not a full reindex.

## Feature 2: Static Wiki Page Viewer

### Purpose

When clicking a node in graph.html, open the wiki page as a rendered HTML page in a new tab. All pages are pre-generated as static HTML for GitHub Pages deployment.

### Components

#### `scripts/build_wiki_pages.py`

**CLI:** `python3 scripts/build_wiki_pages.py [--output static/wiki/]`

**Logic:**
1. Scan all `wiki/**/*.md` files
2. For each file:
   a. Parse YAML frontmatter → render as metadata header table
   b. Convert markdown body to HTML (using Python `markdown` library with `fenced_code` and `tables` extensions)
   c. Convert `[[wikilink]]` → `<a href="../<relative_path>.html">wikilink</a>`
   d. Wrap in HTML template with:
      - Shared CSS matching graph.html design system
      - Topbar navigation: Graph | Statistics | Wiki Index
      - Dark/light mode toggle (same mechanism as graph.html)
      - Breadcrumb: wiki > entities/concepts > page title
      - Prev/next navigation within same directory
   e. Write to `static/wiki/<subdir>/<filename>.html`
3. Generate `static/wiki/index.html` — browsable list of all pages grouped by type

**Dependencies:** pyyaml, markdown, re, pathlib

**HTML template features:**
- Responsive layout (mobile-friendly)
- Frontmatter rendered as a styled metadata card (type badge, confidence, tags, dates)
- `[[wikilinks]]` become clickable inter-page links
- relates_to section rendered as a link list
- Consistent with graph.html color scheme

#### `graph.html` update

Add to node click handler: when sidebar shows, include a "View Page" button that opens `wiki/<node.id>.html` (replacing `.md` with `.html`) in a new tab.

#### GitHub Actions update

Add step to `.github/workflows/deploy.yml`:
```yaml
- name: Build wiki pages
  working-directory: vault
  run: python3 scripts/build_wiki_pages.py --output ../static/wiki/
```

**Dependencies:** json, pathlib, pyyaml, collections

#### `static/statistics.html`

**Self-contained HTML** with Chart.js (from CDN) and inline CSS.

**Dashboard sections:**
1. **Summary cards** — total nodes, edges, orphans, components (large numbers with labels)
2. **Type distribution** — doughnut/pie chart (entity/concept/synthesis)
3. **Confidence distribution** — horizontal bar chart with color-coded buckets
4. **Top-20 most connected nodes** — ranked table with progress bars
5. **Tag cloud** — weighted word cloud or bubble chart
6. **Growth timeline** — line chart of pages by created date
7. **Relationship types** — bar chart of edge types (wikilink, extends, implements, etc.)
8. **Component breakdown** — list of connected components with sizes

**Design (via ui-ux-pro-max):**
- Dashboard grid layout (CSS Grid, responsive)
- Consistent with graph.html color scheme and design tokens
- Dark/light mode toggle (shared mechanism)
- Topbar: Graph | Statistics | Wiki Index
- Smooth animations on chart rendering
- Glass-morphism cards matching graph.html sidebar

#### Navigation update

Both graph.html and statistics.html get a shared topbar with navigation links between all pages.
